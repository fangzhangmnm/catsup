## 1. 撤销到一半崩掉（v0.14.27）
- **性质**：任何一步撤销 / 重做都不抛错；撤完的场景 = 那一步之前的场景。
- **最坏摆法**：人在组件里，撤过「建出 / 复制出这个组件」的那一步（所在的组件消失）。
- **发散**：① 在组里撤掉建组；② 嵌套两层，撤掉外层的复制；③ 在组件里撤掉「换轴」（组件坐标变了，选区 id 还在）；④ 撤销后立刻重做，再撤（会话记录来回）；⑤ 马后炮改值（撤 n 条重来）时那一步正好建出了当前所在的组件。
- **钉住**：`probe-undo-session`（① 的组件版、外面撤里面的改动、组件里撤、一路撤到底再重做）。②–⑤ 待补。

## 2. 推拉方向反（v0.14.27）
- **性质**：在任何变换过的组件里用工具，效果 = 在外面对同一几何做同一件事（世界里看）。
- **最坏摆法**：组件转 180°（行列式 +1）、镜像（−1）。
- **发散**：① 非等比缩放的组件里推拉（距离换算）；② 转 90° 绕 X（法线换轴）；③ 组件里的组里推拉（两层变换）；④ 偏移 / 跟随 / 画圆在同样的组件里；⑤ 平行于世界坐标轴、但在组件里是斜的面。
- **钉住**：`probe-pp-rotated`（不转 / 转 180° / 镜像）。①–⑤ 待补。

## 3. 隔着几何吸到被挡的线（v0.14.28）
- **性质**：吸附结果永远是看得见的（除了明说「隔着几何也能吸」的轴原点）。
- **最坏摆法**：被挡的线切成很多小段（候选被钳到段端点），整段都在挡板后面。
- **发散**：① 被挡的线一头刚好露出轮廓（端点在轮廓上）；② 挡板是另一个组件里的面（跨槽遮挡）；③ 挡板和线共面（贴着）；④ 透视极近 + 线穿过相机平面；⑤ 挡板有洞，线从洞里露出一截。
- **钉住**：`probe-snap-occluded`（小段线藏在盒子后面，1743 次吸附 0 次被挡）；单测「屏距」三条（④）。①②③⑤ 待补。

## 4. 一步只撤了一半（v0.14.34，斜切护栏撞出来）
- **性质**：一步要么全部生效，要么完全不生效；重做队列里没有半截。
- **最坏摆法**：一步里有多条指令，后面某条被护栏拦下（选两个组件缩放，B 先成功、A 被拦）。
- **发散**：① 阵列 ×6 的第 4 份失败；② 马后炮重做中途失败；③ 建组件 + 换原点那两条里第二条失败；④ 一步里失败的是第一条（前面没东西要回滚）；⑤ 失败之后同一步里还有提交（应该一律不执行）。
- **钉住**：`probe-shear-guard`（选两个缩放：场景不变、没错误胶囊）。①–⑤ 待补。

## 5. 屏距 / 参数不精确（v0.14.35）
- **性质**：屏上反查 3D 线段的参数 = 那一点真实的参数；屏距与「无限直线用多长的一段来给」无关。
- **发散**：① 线段一头在相机背后；② 整段在背后；③ 线几乎平行于视线（投影退化成点）；④ 毫米尺度和百公里尺度同一套断言；⑤ 正交 / 透视切换。
- **钉住**：`test/camera-persp.test.ts`「屏距」三条（①②、参数反查）。③④⑤ 待补。
