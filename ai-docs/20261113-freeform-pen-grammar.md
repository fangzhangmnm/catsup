## 二、规矩

下面是统筹照原话整理的。标了〔统筹加〕的是 user 没逐字说的，user 改口以 user 为准。

**1. 笔有三个动作。**

| 动作 | 是什么 | 等于鼠标的 |
|---|---|---|
| 滑 | 笔贴着屏幕移动 | 移动（不按键） |
| 戳 | 笔点一下：落下、几乎没动、马上抬起 | 点一下 |
| 落笔拖 | 笔落在一样东西上，按着拖，抬起 | 按住拖、松开 |

滑和落笔拖在手上是同一个动作，是哪一个由手里的工具决定（第 3 条）。笔尖悬在屏幕上方也能被感应到的设备，悬着移动和滑是一个意思〔统筹加〕。手指管视角，照旧，不在这份里。

**2. 戳才是意图。** 下点、确认，一律靠戳。抬笔不当确认：抬笔那一下笔会抖。

**3. 工具分两种。**

- **下点的工具**（刀、环切）：滑 = 找位置，吸附标记跟着笔走；抬笔什么都不发生，标记留在抬笔前停过的地方；戳 = 把点下在那里。
- **拖的工具**（挪、转、缩、挤出、插入、倒角、拉出、橡皮、笔刷、框选、拖柄）：落笔 = 开始，滑 = 拖，抬笔 = 停。抬笔那一下的抖动不算，取抬笔前停过的位置（这个 10-21 就有了，叫抬笔结算）。手势是松着手进行的时候（键盘起手的挪 / 转 / 缩这一类），滑 = 跟着走，戳 = 停。

**4. 戳下去的点落在哪。**〔统筹加〕戳在标记附近（几个像素以内，和现在「同一处」的范围一样）= 就下在标记那一点，不重新找。戳在别处 = 当成先滑到那里再戳，在戳的地方现找落点。这样滑的时候对准的精度不会被戳那一下的手抖吃掉。

**5. 吸附。** 标记吸不吸看右上角的吸附钮，和「挪」是同一个。关着 = 笔正下方那一点，不往端点、中点上拽。〔统筹加〕离端点不到 2 个屏幕像素算那个端点，免得切出看不见的碎边。

**6. 鼠标和笔一样。** 同一把工具，鼠标移动 = 笔滑，鼠标点一下 = 笔戳。规矩只写一份。

## 三、每把工具

「现在」那一列照工具说明和统筹读到的代码写；小弟的清点回来之后逐行核。

| 工具 | 种类 | 现在（v0.19.90） | 照这套规矩 | 改不改 |
|---|---|---|---|---|
| 选 | 拖 | 戳 = 选它；戳空白 = 取消选择；从空白落笔拖 = 框选；戳两下、三下 = 选得更多 | 一样 | 不改 |
| 切割（刀） | 下点 | 每个点都要落笔、滑、抬笔，抬笔处就是点；抬笔的抖动照算；只能边到边直着切 | 见第四节 | **改** |
| 环切 | 下点 | 落笔那一下点到哪条边就切哪一圈 | 滑 = 预演那一圈，戳 = 切 | **改**（跟着刀一起） |
| 挪、转、缩 | 拖 | 落笔拖、抬笔停；戳 = 选东西 | 一样；抬笔的抖动不算 | 核一下抬笔结算在这几把上有没有生效 |
| 挤出、插入、倒角 | 拖 | 落笔拖、抬笔停 | 一样 | 同上 |
| 拉出（新建方块、圆柱这些） | 拖 | 戳 = 放一个默认大小的；落笔拖 = 拖多大就多大 | 一样 | 不改 |
| 橡皮（删除） | 拖 | 落笔刮过的都算，抬笔一次删；戳 = 删点到的那个 | 一样 | 不改 |
| 笔刷（抓、鼓起、抹平、压平） | 拖 | 落笔刮 | 一样 | 不改 |
| 拖柄 | 拖 | 落笔拖柄 | 一样 | 不改 |
| 右键菜单里的那些（插一圈、合、填、桥接、细分、压平……） | 指令 | 点菜单项就做，做完在小窗里改数 | 一样 | 不改 |

所以真正要改的是刀这一家。别的工具本来就是「落笔拖、抬笔停」，和规矩对得上，只需要核抬笔的抖动。

## 四、刀（鼠标和笔一样）

1. **起刀**：滑到一个点或一条边上，标记吸上去，戳一下 = 第一个点。
2. **接着滑**：一条刀线从上一个点连到笔。
3. **戳在面中间** = 拐一个弯，刀线接着从这里往下走。
4. **戳在点或边上** = 这一刀结束，这张面沿着整条折线切开。结束之后手里不留起点，下一刀重新起。
5. **反悔**：戳回上一个点、按左下的「收刀」、或 Esc = 放弃还没切完的这一刀。没到边的刀不会留下东西。
6. 做完进小窗，能改两头在边上的位置（现在就有）。

这一版先不做的〔统筹加〕，都记愿望单：

- 从面中间起刀（现在的面表示不了悬在面里的线）。
- 一段刀线穿过好几张面、自动在每条边上落点。这一版一段的两头要在同一张面上；要过边，就先戳在边上结束这一刀，再从那里起下一刀。
- 在面里切出一个闭合的圈。

第 3 条要动内核：现在内核的切割只收「边到边一条直线」，要让它收一条带拐点的折线。小弟在清点，回来统筹写施工单。

## 五、要 user 点头的四处

1. 第二节第 4 条：戳在标记附近就下在标记上。
2. 第二节第 3 条里「拖的工具」：落笔拖、抬笔停、抬笔的抖动不算；「再戳一下也是停」只用在松着手进行的手势上。统筹是这么读你那句「抬起或者再戳一下都是停」的。
3. 第四节「先不做」的三件：从面中间起刀、一段穿过好几张面、切闭合的圈。
4. 第二节第 5 条：离端点不到 2 像素算端点。

## 六、和「触屏、笔都收进一个深模块」的关系

这套规矩就是那个模块对工具说的话。工具只声明自己是「下点的」还是「拖的」，然后只听四句：

- 在找位置（现在在哪）
- 下了一个点（在哪）
- 拖：开始、拖到哪、停在哪（停的位置已经去掉抖动）
- 点了一下（在哪）

鼠标、笔、手指各自的动作怎么变成这四句，全写在模块里面，工具不问设备。现在的情况：拖的那些工具大多已经走公共的底座；刀在 11-10 退了出来、自己写了一套，所以它没吃到抬笔结算。这一次刀搬回底座，顺手把「下点的工具」这一种在底座里做出来，就是深模块的第一块。整个模块的设计等小弟的清点回来再写。
