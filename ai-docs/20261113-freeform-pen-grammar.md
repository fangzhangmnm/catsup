## 二、规矩

标了〔统筹加〕的是 user 没逐字说的。

1. **两种按法**。轻按 = 笔尖轻轻贴着屏幕，滑不滑都算。重按 = 压力在很短的时间里猛地变重。笔尖可以全程不离开屏幕。
2. **要先找位置的操作**（用鼠标做时要滑着鼠标找位置的那些，清单在第三节）：轻按 = 找位置，吸附标记跟着笔，不下点；重按 = 下点。没先找位置、直接重按，也算下点。轻轻点一下不下点。
3. **别的操作**：轻按就算点击，和现在一样。
4. **笔尖悬空也能感应的设备**：悬空移动也是找位置，和轻按是一回事；下点还是要重按。
5. **重按怎么判**（user 10-24）：短时间突然变重才算；慢慢加重不算；不用一个固定的门槛；判到的那一下笔尖要有看得见的反馈。〔统筹加〕落笔那一下就很重也算（因为盲戳重按直接算点击）。
6. **点下在哪**〔统筹加〕：取压力开始猛升之前那一刻笔所在的位置。重按那一下手会抖，抖出来的位移不算。
7. **没有开关，永远开**。鼠标照旧（移动 = 找位置，点一下 = 下点）。手指先不支持，以后靠软鼠标（第九节）。〔统筹加〕不报压力的笔没法分轻重，点一下算点击，照现在。

## 三、哪些操作禁止盲戳

user 同意的表：

| | 要先找位置的 | 别的 |
|---|---|---|
| 例子 | 刀的每个点、环切点哪条边、硬表面画线和量尺寸的点 | 选东西、点按钮和菜单、拖柄、橡皮刮、笔刷、画画的一笔 |
| 轻按 | 只是找位置，标记出现在笔下，不下点 | 就算点击，和现在一样 |
| 怎么下点 | 重按一下 | 不需要重按 |
| 没先找位置就点 | 轻的不下点、只当成找位置；重的直接算点击 | 正常算点击 |

user 随后补的四条（原话在第一节末尾）：

- **选东西 = 轻按。** 承重的选法是套索和框选（贴着拖）。
- **挪、缩、转 = 重按**，吸附开不开都是。轻按着滑只是找位置，什么都不动；重按一下开始；之后轻按着滑，东西跟着走；再重按一下落定，或者抬笔落定。〔统筹加〕挤出、插入、倒角归同一类。
- **抬笔也算落定，带一段宽限时间。** 抬笔之后先等这一段，其间笔又碰回屏幕就接着走、当没断过（有的屏会突然断触一下）；过了才落定，位置取抬笔前停过的地方。这段时间在设置里能调。〔统筹加〕初值 0.2 秒。
- **另做一把「微调」工具，笔刷的语义。** 不用先选，轻按着拖，笔下的那个点、边或面直接跟着走，抬笔就停。

硬表面建模以后照这套重做时：抓哪里要重按一下，落定要重按一下（user）。

还没定的一样：拉出一个方块时放在哪，现在轻按一下就放，先照旧。

## 四、刀（鼠标和笔一样）

1. **起刀**：轻按着滑到一个点或一条边上，标记吸上去，重按 = 第一个点。
2. **接着滑**：不用抬笔。一条刀线从上一个点连到笔。
3. **重按在面中间** = 拐一个弯，刀线接着从这里往下走。
4. **重按在点或边上** = 这一刀结束，这张面沿着整条折线切开。结束之后手里不留起点，下一刀重新起。
5. **反悔**：重按回上一个点、按左下的「收刀」、或 Esc = 放弃还没切完的这一刀。没到边的刀不会留下东西。
6. 吸附看右上角的吸附钮；关着 = 笔正下方那一点（v0.19.91 已上）。
7. 做完进小窗，能改两头在边上的位置（现在就有）。

这一版先不做，记愿望单〔统筹加〕：从面中间起刀；一段刀线穿过好几张面；在面里切一个闭合的圈。

## 五、和「触屏、笔都收进一个深模块」的关系

这套规矩就是那个模块对工具说的话。工具只声明自己是不是「要先找位置的」，然后只听：在找位置（现在对准哪）、下了一个点（在哪）、拖（开始、拖到哪、停在哪）、点了一下（在哪）。轻按重按怎么判、悬空感应、鼠标，全在模块里面，工具不问设备、不读压力。

## 八、施工单：刀在面中间拐弯（第七节第 4 步；内核对外接口，合之前 diff 发统筹）

added by Claude Fable 5.2 2026-11-13。依据 = 小弟的清点（同日）：现在 `mesh/ops/split.ts knife` 只收顶点和边上的点，一段一段找「同时含两头的面」再 `splitFace`；面是一个简单环，没有内环；角上的列按「原面的一块」取值，面里的点现成够用；`check()` 不查环自交。

**1. 内核加一个原子**：沿折线劈面。形状（名字小弟定，下面叫它 `splitFaceAlong`）：
- 收：一张面、环上两个不同的顶点（进、出）、面里的点的位置（定义坐标，可以是零个）。
- 做：造面里的点；原面的环换成「环上进到出那一段 + 倒着的面里点」，新面 = 「出到进那一段 + 正着的面里点」。两张面的来历都是原面的一块；新边 = 新长（和现在劈面那条新边一样）。
- 回：新面的编号、新点的编号（按折线的先后）。
- 零个面里的点 = 现在的 `splitFace`。两个入口收成一个，`splitFace` 变成它的特例，不留两份。
- 进、出是相邻的两个顶点而且没有面里的点 = 抛（切不出东西）。

**2. 切之前验一道，验不过整条不做、说原因**。放在 `knife` 这一层（所有调用都过它），原子本身只管拓扑：
- 先在副本上算出两个新环，不改真身。
- 两个环各自投到自己的拟合平面上（三角化用的那一个投影，不另写）：都不自交、朝向都和原面一样。这一条同时管住了「折线自己交叉」「折线走出这张面」「切出来的面三角化会翻」。
- 面里的每个点离原面的显示三角形不超过内核现成的容差；超了 = 拒绝，不悄悄挪上去。
- 工具预演刀线的颜色（切得出 / 切不出）用同一个函数，不另写一份判断。
- 拒绝的话写事实：「刀线出了这张面」「刀线自己交叉了」「这一段两头不在同一张面上」。

**3. 指令**：`meshKnife` 的路径加第三种落点 = 面里的点（定义坐标的位置）。一刀 = 一条指令 = 一步撤销，路径是「进 → 面里的点… → 出」整条，不再两点两点地发。重放复现包的脚本跟着认新形状。文件里没有这条指令，格式不动。

**4. 工具**（规矩在第四节）：
- 第一个点在点或边上。第一个落在面中间的点定下是哪张面：笔正下方的那张，而且起点得在它的环上；不是 = 不下点、说原因。
- 之后面中间的点都得在这张面上；结束的点得是这张面环上的点或边。
- 面中间的点不吸附，就是笔正下方那一点（吸附开着也一样；以后要吸格点另说）。
- 没到边的刀线只是预演，不进撤销；放弃 = 什么都没发生。
- 做完的小窗：只列两头落在边上的位置（和现在一样），面里的点这一版不列；改了一头重切不成 = 退回原值、说原因（现成的）。

**5. 这一版不做，拦住并说事实**：从面中间起刀；一段的两头不在同一张面上；在面里切一个闭合的圈。原因写进提示：现在的面只有一圈外边，没有里圈。以后要做有两条路（用桥边把外面那块切开 / 给面加里圈，后一条要动内核和文件格式），到时统筹出方案、user 定。

**6. 验收**
- 方块正面：从左边进、面里拐两下、从下边出 = 两张面，都通过内核自检；面数、点数、边数对得上；撤销一步回去。
- 画过的面上这样切：两张面上的画都在原位，一个像素不变（拿切之前、之后各渲一张比）；空出来的地方一个框都不多。
- 折线自交、走出面、回到起点那条边（切出一小块）、两头同一条边且没有拐点（拒绝）、面里的点离面太远（拒绝）各一条。
- 不平的四边形上拐弯切：切得出的两张面三角化朝向都对；切不出的被第 2 条拦住。
- 强行对称开着切一刀：做完还是对称的（现成的路，走一遍）。
- 随机对拍：随机的凸面和凹面上随机折线 2000 次，通过第 2 条的都通过内核自检而且两张面的面积加起来等于原面；没通过的真身一个数不变。
- 量一下：一张三角形的面连切 50 刀之后空出来的地方清单有多少个框（不规则的面切开后旧框的边角会不会一直进清单），报统筹，不用改。

**7. 合之前**：第 1、2 条的 diff 发统筹（原子的形状、验的那一道）。别的自己合。升补丁号，流程图和工具说明同一个提交更新。

## 九、软鼠标（user 的设计，记账，不排期）

user 2026-11-13，原话：「手指我们可以先不支持，等以后我发明了这个软鼠标，软鼠标其实很简单，就是一个小控件，你们可以帮我记下账，设计账。就一个小控件，你可以拖着在屏幕上滑，就相当于你右手按住它拖，然后它是一个圆，圆的左上角有个小尖尖，那个小尖尖你就是模拟，甚至你可以直接接一个模拟鼠标。然后你滑的时候，就是你食指托着这个圆在滑动，然后在圆的左上角会有一个鼠标小指针，然后在你滑的时候，你食指是接触屏幕的地方，你大概中指的位置，我们。有一个虚拟按键，然后这个虚拟按键它的碰撞箱要比它实际显示的要大，就有点像我们这种射击手游的虚拟摇杆，你是戳一下屏幕，对吧？然后这个时候是它附近的一块区域都会被判定为射击。然后我们是做一个单键鼠标，有可能我们的长按对应的是右键之类的，对吧？你这个大概能理解我这个虚拟鼠标的设计吧？」

统筹的读法（没逐字说的）：
- 屏幕上一个圆形的小控件，食指按住它拖着走；圆的左上角伸出一个小指针，指针尖就是鼠标的位置。指针在手指的左上方，手指挡不住它。
- 食指拖着圆移动 = 鼠标移动。中指落在圆旁边的一个虚拟按键上 = 鼠标按下；按键能点中的范围比画出来的大，戳在它附近都算。
- 单键鼠标；长按可以当右键。
- 它对程序来说就是一只鼠标，所以接在第六节那个模块后面，工具不用知道有它。
- 做了它，手指就能用第二节那套规矩里的全部工具。
