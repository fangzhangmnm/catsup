## 1. 先说结论

不是疏忽，是**早就设计了没做**：持久化契约（`20260919-persistence-data-contract.md` §5，2026-09-20 user 第二轮回答后定）已经给了 `brep.curves[{ edges, kind, params: { center, radius, normal, xaxis } }]` 这一格，codec 从 v2 起原样往返 `curves`，内核从来没写过它。现在只有**边层**（`layers.ts`：soft / curve / smooth / hidden，每边一个布尔），没有**实体**：圆是 24 条各自为政、碰巧都带 `curve` 标记的边；圆柱侧面是 24 张各自为政、碰巧用软边相连的面。所以：

- 橡皮能擦到圆柱的竖棱——拾取（`pick.ts`）不认 soft，只认遮挡；渲染不画它们（`render3.ts`「软边不画」），于是用户在擦看不见的边。
- 擦圆的一段只擦一段：边没有「我属于哪条曲线」。
- 推拉圆柱侧面的一片：机器照拉（`pushPull` 只看膜，褶边判据把两侧软边邻膜当普通邻膜）。

要补的是两样东西，性质不同：

| | 曲线（Curve） | 曲面（Surface） |
|---|---|---|
| 是什么 | 一串**有序**边 = 一个实体，可带圆 / 弧参数 | 经**软边**相连的一组面 |
| 存不存 | **存储态**（参数不可从线段反推精确；实体身份要跨会话）；契约 §5 已有格 | **派生态**（soft 边层已存，连通分量现算；`paint-flood.ts` 的 smooth 模式就是这个泛洪） |
| 谁维护 | 内核：和边层同一套四规则 + 顺序 | 不维护，用时算 |

## 2. SketchUp 怎么做（user 2026-10-24 核过的不带问号；剩两条带 ？ 的不影响设计）

- **Curve / ArcCurve 实体**（user 确认）：圆、弧、多边形、徒手线 = 一串边当一个实体。单击一段 = 选中整条；橡皮擦一段 = 整条没了（连带它围的面）；Entity Info 显示「Arc / Circle，半径、段数」，段数在曲线还没被别的操作碰过之前可改；右键「Explode Curve」拆成散边。
- **推拉圆 → 圆柱**：顶 / 底圈仍是 Curve；侧面 24 片之间的竖棱 = soft + smooth；Entity Info 对侧面说「Surface」。
- **Surface = 软边相连的面**：soft 决定「算不算一张面来选」，smooth 只决定着色。单击侧面任一片 = 选中整张曲面（？——我记得单击即整面，双击 = 面 + 边）。
- **橡皮碰不到软边**（user「嗯 大概」）：View › Hidden Geometry 关着时软边不可见也不可拾；开着时虚线显示、可擦、可选单片。
- **推拉曲面的一片**：SU **不允许**（user 2026-10-24 纠正我的记忆：「这个是 long requested function」——推拉只认单张平面，曲面和多选推拉是 SU 用户多年要的）。我们同样拒绝 + 提示先硬化；「推拉多选」「推拉曲面」进 wishlist（§7），做成了就是超过 SU 的一处。
- **挪动曲线上的顶点**：曲线身份保留但圆参数作废（Entity Info 从 Circle 变成 Curve）。
- **一条线切过曲线**：曲线被切成两条曲线（？），各自仍是实体。

## 3. 现状盘点（代码事实，2026-10-23）

- `layers.ts`：`EDGE_LAYERS = soft / curve / smooth / hidden`；四条规则（切割传子、删边出集、新段落边入集、溶解并出）；推拉策略 = 软 / 曲 / 平滑边的侧棱 soft + smooth，帽边继承原边全部层；`riserLayers` 两侧都带才软（圆弧端点的侧棱硬）。
- 圆工具：`addEdges(segs, { curve: true })`，`last` 记 center / rim / segments 只给 VCB 用，不落盘。没有弧工具。
- 拾取 / 橡皮 / 选择：`pick.ts` 不过滤 soft；`selectExpand` 三级 = 实体 / 膜 + 环边 / 连通体；橡皮拖擦 `scrubEdges` 按拾取结果来。
- 渲染：soft 不画线；smooth 插值法向。
- 油漆桶 `paint-flood.ts`：smooth 模式 = 沿 smooth 边泛洪的面集（曲面泛洪的现成实现，只是以 smooth 而不是 soft 为准）。
- 格式：`CATSUP_brep` JSON 有 `curves: unknown[]`，读写原样带回；`attributes.edge.{soft,curve,smooth}` u8 每边一字节。
- 跟随 / 偏移：跟随按 `curve` 层决定站圈软硬；偏移环当手势线画，不知道源环是不是圆。

## 4. 提案

### 4.1 曲线 = 内核存储态 `CurveRegistry`

```ts
type CurveId = number;
interface Curve {
  readonly id: CurveId;
  kind: "circle" | "arc" | "polyline";       // 参数作废 → polyline（身份留着）
  edges: EdgeId[];                            // 有序链；闭合 = 首尾相接
  params?: { center: Pt3; radius: number; normal: Pt3; xaxis: Pt3; start: number; end: number; segments: number };
}
```
- 边 → 曲线：每边至多属于一条曲线（`Map<EdgeId, CurveId>`）。
- 维护规则 = 边层四规则加「顺序」：切割 → 子边按父边方向**按序替换**（`replaceEdgeWithChain` / `onSplit` 给的就是有序子边）；删边 → 出链，链断成两截时**不**自动分成两条曲线（先留一条带缺口的，见 §6-④）；溶解 → 并出的边顶替两条；absorb / 复制 / 粘贴 → 曲线整条随行（像表加 `curves` 一项）；推拉的帽 → **新曲线**，参数平移 δ（帽边继承层这条规则的实体版）；跟随的站圈同理；偏移 → 源环若整条是一条圆曲线，输出圆（半径 ± d），否则散边。
- 顶点被挪 → 所在曲线 `params` 作废、`kind = polyline`。
- `toBrep / fromBrep` 走契约 §5 的 `brep.curves`（边下标、kind、params 定点整数）；装载校验：边存在、链连通、每边至多一条曲线——失败整份拒开（与膜同款）。

### 4.2 曲面 = 派生态，用 soft 泛洪

`surfaceOf(faceId)` = 沿 soft 边泛洪的面集（`paint-flood.ts` 的泛洪改成以 soft 为准；smooth 只管着色，与 SU 对齐）。不存、不维护；用在选择、实体信息、推拉护栏。

### 4.3 动词与工具的护栏

| 场景 | 现在 | 提案 |
|---|---|---|
| 橡皮 / 拾取碰软边 | 能碰到、能擦掉看不见的竖棱 | 软边**不可拾**（拾取层过滤 soft；「显示隐藏几何」视图打开时才可拾，视图开关进 wishlist） |
| 橡皮擦曲线的一段 | 只擦一段 | 擦整条（`eraseEdges` 在编辑器层按曲线展开；内核不变） |
| 单击曲线的一段 | 选一段 | 选整条（selectExpand stage 0 = 实体 = 整条曲线） |
| 单击曲面的一片 | 选一片 | 选整张曲面（stage 0）；要单片 = 开「显示隐藏几何」（SU 同款） |
| 推拉曲面的一片 | 照拉 | **拒绝** + 提示「这是曲面的一片，先硬化（橡皮 + Shift）」；硬化后它就是普通面 |
| 推拉顶 / 底圈的面 | 照拉，帽边继承 curve 层 | 照拉，帽是**新曲线**（圆心平移），侧棱 soft + smooth 不变 |
| 挪曲线顶点 | 层不变 | 身份留、参数作废（polyline） |
| Entity Info / 状态行 | 无 | 「圆 r=1.20 m · 24 段」「曲面 · 24 面」「弧 …」 |
| 炸开曲线 | 无 | 右键「炸开曲线」= 删实体留散边（SU Explode Curve） |
| 弧工具 | 无 | 两点 + 凸度 / 三点，按 SU 的默认 12 段；与圆同一套曲线登记 |

① 内核 CurveRegistry + 像表 / 结算机维护（切割 / 删边 / 溶解 / absorb）+ fromBrep / toBrep + fuzz 不变量（链连通有序、每边 ≤1 曲线、曲线边都存在）

## 5. 「流形」这个词

user 说的「什么样的一 chain 线段和一组面算一个流形」，落到数据上就是 §4.1 / §4.2 两条定义：**曲线 = 一条带身份的有序边链；曲面 = 一张只靠软边相连的面集**。真正的流形判定（每条内部边恰好两张面、无 T 字）在 `followme.test.ts` 的 `manifold()` 里已经有一个只给测试用的版本；如果以后要「实体信息」里说「闭合实体 / 开口曲面」，就把它搬进内核查询层。

## 8. 落地与提案的差异（v0.10.0，2026-10-24）

- 曲线断开的判据：提案写「一条线切过曲线 = 两条曲线」。v0.10.0 落地 = 用户画的线落在曲线顶点上就断（`cutAtVertex`，动词里判）——**v0.10.2 改成结算机尾声一次判**（user 2026-10-24 截图「上一个纪元没做干净…留下 1/4」「这里也会误伤，同一个病。没有自动切弧」「太 ad hoc 了，应该在别的地方判？」）：顶点上有「不属于本曲线、且另一端在本曲线平面 τ 内」的边 → 断；出平面的边不断（侧棱 / 手画竖线；与 SU 有意分歧）；**断永久、不自愈**（SU 要 Weld；自愈会把推拉过的弧粘回圈里，擦一段连柱体底圈一起没）。先盒后圆（截图）、推拉半圆后擦另一半、弧外切顶圈都由此一条规则覆盖；0.10.0 的问题是先切再登记 → 新圆切不到自己，pushPull / followMe / absorb 根本不切。
- 擦顶圈的一段：整个顶圈 + 顶面 + 24 张侧面一起没（SU 同款：面失去边就死），侧棱留作裸线。
- 跟随的站圈只留身份（polyline），不留圆参数（斜切投影不保圆）；**单段直线路径的末帽是平移 → 保圆**（v0.10.1）。
- 偏移：源面外环恰是一条闭合圆 → 偏移环登记成同心圆（半径 r − d），工具与 VCB 重做都带（v0.10.1）。
- 挪整条圆上全部顶点同一 δ → 圆心平移保参数；只挪一个 → polyline。`transformAll` 相似变换保圆。
- 格式：`CATSUP_brep` v3 → v4（curves 本版读写；v3 文件 curves 一直空表 = 无曲线），冻结样本 v4 加 `cylinder.glb`。
- 弧工具：三下（起点 / 终点 / 凸度），段数 `arc.segments` 默认 12，快捷键 A；预演在第三下之前把弧跑到克隆内核上。
- 实体信息走提示行：「圆 r=1.2 m · 24 段」「弧 …」「曲线 · N 段」「曲面 · N 面」；没有专门的信息面板。
- 「显示隐藏几何」视图开关没做（wishlist）：软边一律不可拾。
