## 0. 本体

平面约束的非流形 radial-edge B-rep：顶点（量化格点身份，Q=1e-6）、边（radial `faceLinks` 变长）、
**膜=存储态一等公民**。每平面 = 增量 2D arrangement + 膜状态机；3D = PlaneRegistry（τ 容差 sticky
平面身份+确定性正交基→2D 管线投影复用）+ radial 装订。

## 1. 五公理

- **A1 平面性**：膜=平面多边形（曲线=多边形近似）。执行机构=autofold：非平面环→极大共面段
  贪心分解、结点连最少折缝弦、每段自成膜（失败→BURST 兜底）。
- **A2 非流形**：一边挂 N 膜。
- **A3 重合即同一**：同格点同顶点；两点间至多一边；重合共面膜 dedup。［context 槽：group 纪元
  将把本条参数化为 per-隔离域——预留的唯一修正案位］
- **A4 膜涌现且被存储**：膜是事件累积的存储态，非边集纯函数。诞生只靠手势（无主胞腔**外环**
  含手势边才 BIRTH；手势边=created+retraced，切开子边经 onSplit 继承）。
- **A5 急切无历史**：每操作立即 resolve 成规范态。
- **不对称律**：合并/切割急切（有意图）；dissolve-collinear 永不自动（无意图）。

## 2. sticky geometry 协议（一切改几何动词的骨架）

**像快照（扰动前）→ 扰动（批量坐标/线段注入+意图参数）→ 自愈①planarize（边边互切/点骑边切/
重合并/重叠去重；对抗契约：任意脏坐标+引用完整即自愈；输出只依赖终态）→ 自愈②autofold →
face-finding（filament 剥离→wedge 最紧转弯→面积序嵌套挂洞）→ 设面（§3 统一结算机）**。
**时间结构：拖拽=扰动相，落地结算=commit 事件**（2026-09-03 user 拍板）——预演走
`settleLanding:false`（搬运/伸缩/frontier/riser 照做，parity 翻灭不跑），且**取扰动参数的开区间
样本**（差 2Q，视觉不可见——恰在停靠点不触发共面重合，穿越型相交不受影响）；commit 用精确
参数全量结算一次。副产品：中间态里「目标在自身参数值上湮灭」的存在性不连续清零（对齐引擎
不动点条款的最后反例）。

## 3. 统一覆盖结算机（设面的唯一机器）

各膜以**像折线**（顶点 id 环经合并映射取新坐标）按 |绕数|≥1 认领胞腔（洞环反向自消；折片各认
各平面）。裁决：**一对一承继**（保 id；换平面重拟合跟随亦保 id）、**一对多 DIVIDE**、**多对一按
代数**、**零认领按策略**；**parity 翻灭**=已有膜区域外环⊆手势∪原环→灭；**无主胞腔外环含手势
边→BIRTH**。**边随葬（唯一清理律）**：parity 杀膜的环边失去全部膜引用→随葬（删膜/squash/
autofold 兜底不触发；用户 wire 免疫）。

**动词参数表**（每个动词=一组参数，无特例代码）：

| 动词 | 像 | 代数 | 手势(出生) | 零认领 |
|---|---|---|---|---|
| draw | 身份（自身环） | OR | 笔画段 | 保留（防御） |
| move/rotate/scale | 扰动前快照 | OR | 无（守恒） | BURST |
| **pp** | 快照+蒸发被拉膜（目标膜继承原 id=身份跟随） | **XOR**（预演=OR 无翻灭） | 补构线 | BURST |
| erase | —（独立律）| loop 身份：外环对 void=BURST、桥/内环=ABSORB、同面共享=MERGE（批始快照，序无关）| — | — |

pp 宏=move+补构；**边分类=平面不变式**：可 MOVE ⟺ 平移不改任何邻膜平面（n_邻·n̂=0）——
裸=MOVE+原位补底；全邻平行=MOVE（伸缩/结构缺口）；否则=COPY（原边留守+目标副本+竖棱）；
frontier（一端被扣留）=删原画新。**v3.1 顶点分离守卫**（2026-09-03）：环顶点可随行 ⟺ 其全部
入射边 ∈ {环边}∪{∥n̂ 伸缩轨}——带外来边（邻面/散线）→扣留走 frontier，邻居形状不可侵犯
（sticky A3 不背锅，错在只看环边邻面）。［悬置：⊥邻面伸缩 vs 留守的局部同构悖论——盒墙
stretch 与铰链地板留守局部几何同构，判据不在局部方向代数，SU 实验裁决，详 grill-sheet §v3.1］
**洞环三律**（2026-09-06 回字含岛案，rev6）：①被拉膜的**洞环副本永不带手势身份**（底副本与目标副本同律，井口/
管孔贯通；外环副本才是手势）；②parity toggle 集=原环中**随行**的边（留守 COPY 边仍是共面邻膜的边界，
入集会把「外环⊆原环」的邻膜误翻灭）；③含 COPY 时目标膜靠 BIRTH 复生，其外环可全由随行边构成——
**随行外环边计入手势**。golden=托盘（地面回字/盒顶回字）。
事件=纯叙事带血缘（BIRTH/DIVIDE/MERGE/ABSORB/BURST/STRETCH/FACE_ERASED），贴图纪元消费。

## 4. 对齐引擎（壳层，非内核；数学详一页纸）

`align(W, view, s, Q)`：W=唯一现实世界（手势中=live，平时=checkpoint，**旧 snapshot 结构性禁入**）；
Q={plane, anchor?, alignSources?, lines?, hand:{has,opaque}}——hand 同源管参赛/派生/遮挡，opaque=
动词参数（pp 帽不透明=SU 连续，move/draw 透明）。0-D 二值可见；1-D 可见区间钳制（禁逐点否决）；
选优=(dim↑,rank↓,⌈d/0.5px⌉↑,tag 序)。**不动点条款**：每个目标在自己吸附值处存在且可见。
pp 双通道：光标通道（不吸轴）+高度通道（h 标量对静态高度集咬合）。

## 5. 其余不变量

undo=日志重放（状态=批序列纯函数，含 id）。坐标=右手系、+Z 上、RGB=XYZ、渲染层禁 Y-up。
golden 语料=共同 spec（膜事件表/暗礁①/灵魂手势≡手绘/E·F 系实证/fuzz/求解器 property）。
**面环自洽**（2026-09-07 VR 真机「edge N 不存在」案，fuzz `test/kernel-fuzz.test.ts` 随机操作 + 不变量）：任何操作之后，面环的边必须存在、faceLinks 的面必须存在、无重复边、无孤立顶点、同环只准一条面记录。落地：① 零认领防御保留前先修环（死边 → 沿原线段的共线子边链 `repairRings`；修不了 → BURST 曝光）；② 擦边裁决同平面 ≥2 面全部 MERGE（此前只配前两张）；③ BIRTH 不铸与既有面同环的面；④ `regionsByPlane` 同一边环只属一张平面（拟合最好者）；⑤ 认领改纯几何（区域代表点抬回 3D、≤3τ 共面门、投到像平面 winding）——不再按平面记录 (n,d) 匹配（候选平面 cover 归属会让小面落在斜了 0.6° 的「错」记录上）。残余：5/80 种子仍出重复面（不崩），总账 D 节。
**容差对齐**（2026-09-07 VR 真机「边 4-3 已存在」案）：身份 = 逐轴 Q/2 的量化格；sticky 插入的「碰到」容差 `INSERT_TOL = Q` ≥ 格半对角线——凡可能量化成同一顶点的点都当碰到（切进来）；`splitEdge` 切点落进既有顶点且已相连 → 复用既有边（重合即同一），`addEdge` 的重复边 throw 保留为最后一层断言。fuzz：`test/subdivide-nearmiss.test.ts`。
