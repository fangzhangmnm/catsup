## 0. 本体

**平面约束的非流形 radial-edge B-rep**（Weiler 谱系）：顶点（量化格点身份）、边（radial `faceLinks` 变长）、
**膜（存储态一等公民）**。每个平面 = 一台**增量 2D arrangement + 膜状态机**；3D 只是记账：
PlaneRegistry（τ 容差的平面 sticky 身份 + 确定性正交基 → 2D 管线投影复用）+ radial 装订。

## 1. 五公理（修正版）

- **A1 平面性**：膜永远是平面多边形（曲线=多边形近似，不动本条）。执行机构=**autofold**：
  非平面环 → 极大共面段贪心分解，段边界结点连**最少折缝**弦，每段自成膜（分解失败→BURST 兜底）。
- **A2 非流形连接**：一边可挂 N 膜（radial cycle 本体）。
- **A3 重合即同一（sticky）**：同格点（Q=1e-6）即同顶点；两点间至多一边；重合共面膜 dedup。
  **［context 槽：group/component 纪元把本条参数化为 per-隔离域——预留的唯一宪法修正案位］**
- **A4 膜涌现且被存储**：膜不是边集的纯函数，是**事件累积的存储态**。诞生只靠手势
  （无主区域**外环**含手势边才 BIRTH；手势边=created+retraced，被切子边不算，onSplit 继承身份）。
- **A5 急切无历史**：每次操作立即 resolve 成规范态；无 modifier/布尔树。
- **不对称律**（A3/A4 触发时机）：合并/切割急切（有用户意图），dissolve-collinear 永不自动（无意图）。

## 2. sticky geometry 协议（一切改几何动词的公共骨架）

**扰动**（批量坐标改动/几何注入 + **意图参数**）→ **自愈①planarize**（边边互切、顶点骑边切、
重合并、共线重叠/平行去重；对抗契约：任意脏坐标+引用完整即可自愈；输出只依赖终态，与顺序无关）
→ **自愈②autofold** → **face-finding**（每平面：filament 剥离 → wedge 最紧转弯 trace → 面积排序嵌套挂洞）
→ **设面**（§3 覆盖代数）。
**时间结构**：过程中只做只读查询（WYSIWYG=影子副本预演松手结算，id 计数器同拷=预览即提交）；
拓扑结算只在松手一次。move/rotate/scale/duplicate/pp 全走此协议。

## 3. 覆盖代数（设面规则 = 动词注入的参数）

- **draw / move 注 OR**：胞腔填 ⟺ 被 ≥1 张旧膜像覆盖（|绕数|≥1，不看方向与次数——「膜没有出身」）。
  move 不注手势 → 永不生膜（守恒律 by construction）；膜像=顶点 id 环快照经合并映射后的新坐标闭折线。
- **pp 注 XOR**：着陆偶数认领成对湮灭（甜甜圈/贴边打穿——**有意不跟 SU 的 if**）；构造相位 parity
  翻灭（已有膜区域外环 ⊆ 手势∪被推面原环 → 灭；空区照常 BIRTH）。
  pp=宏（move + 补构手势线）；**边分类=平面不变式（2026-09-02 垂直判据，取代共面判据）**：
  边可 MOVE ⟺ 平移不改任何邻膜的平面（n_邻·n̂=0，邻面平行于拉方向）——裸边=MOVE+原位补底；
  全邻平行=MOVE（墙一体伸缩/结构性缺口）；任一邻不平行（共面半/棱台斜面）=COPY（原边留守，
  目标副本+竖棱）；**frontier**（MOVE 边一端被 COPY 扣留）=删原画新（残线病根）；含 COPY 时
  被拉膜先蒸发再由目标环 BIRTH。收尾清「操作涉及边中 faceLinks==0」裸线。
- **erase 按 loop 身份**（不做覆盖查找）：外环对 void=BURST；同膜双现（桥）/内环=ABSORB；
  同面共享=MERGE；批量以批始快照裁决，顺序无关。
- **事件=纯叙事**（贴图纪元消费 id 血缘）：BIRTH/DIVIDE/MERGE/ABSORB/BURST/STRETCH/FACE_ERASED；
  一对一保 id，退休铸新带血缘。

## 4. 求解器（取点/取面，工具唯一供餐口）

**solve(V,s,C)**：约束=(轨迹 0/1/2 维, 秩, ε)。活跃过滤（光标到 π(轨迹) 屏距≤ε）→ 活跃 1 维两两
**真相交**合成 0 维（gap≤1e-5、段界内，不级联）→ 字典序（维升、秩降、屏距升）。
秩：端点90>原点80>中点70>交点65>边60>交线55>轴线45>面10；ε=点10/边7/线5/合成12（CSS px）。
1 维来源=**充能制**（anchor+原点+登记点；幽灵定理：正交下屏距不载深度，候选必须意图化）。
**平面查询**：面锁（裸落膜内）>含点平面>锚轴平面>轴系平面(d=0)；同秩=底面偏置（|fwd·ẑ|≥0.34）>面向度。

## 5. 其余不变量（复原验收）

- **undo=日志重放**：状态=mutation 批序列的纯函数（同序列同结果，含 id）；零内核入侵。
- **坐标**：右手系、+Z 上、+X 红、+Y 绿=北；RGB=XYZ。渲染层不得引入 Y-up。
- **golden 语料=共同 spec**：膜事件表、暗礁①（已实机确认）、灵魂手势（矩形+pp ≡ 手绘立方体逐边）、
  E1 甜甜圈/E3 井/E5 湮灭复活/E8 墙 L、fuzz 对抗不变量、求解器 property 五件。
