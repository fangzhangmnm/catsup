## 要达到的一句话

**一笔当中每帧的花费，不随画布大小涨、不随模型大小涨、不随这一笔已经画了多长涨。**（user 11-11：「画的时候 fps 尽量流畅」；又说「一些常识级别肯定有意义的优化还是需要做的，就是至少把低效的草稿算法优化掉」——明摆着低效的写法不等读数直接换，读数用来决定换完之后还慢在哪。）

## 不能破的

- 不为了快去简化预览：预览就是结果，结果逐位或逐像素不变。
- 要动内核对外的口（画画仓的内核）先停下来报统筹形状；某一段怎么都压不下来，停下来报。
- 内核正本只在画画仓改（`../20260524 WeebPaint`），自己合进画画仓、升画画末位、三维用 `scripts/pull-paint-kernel.sh` 重拉。
- 新开持久化（device / doc）要 user 同意（守卫 `test/tool-config.test.ts`）。

## 要做的（统筹三条消息合起来；做完一条勾一条）

1. [ ] **每帧的读数**（先做，别的都靠它判断）：画画工作台里能开关的小角标，显示这一帧各段各花几毫秒——收点和滤抖、打射线、走步取笔尖、找面、画薄层、内核合成、拷到显示图和做缩小图、三维画场景——加上整帧多久、最近一秒掉了几帧。开关放在画画工作台的设置里，默认关；关着的时候不多做任何事。给 user 在 iPad 上自己看，文字用人话。
2. [ ] **走步不再每帧从头走整条笔画**（内核 StrokeCore）：对已经定型的那一段记住走到哪（游标和当时的状态），下一帧从定型的边界接着走，只重走还会变的尾巴。不加对外的口（forEachTip / collect 的样子不变）；做不到就停下来报形状。门：0-6 冻的 12 条笔画每一帧的结果逐位相同；定型那条测试（前 frozenCount 颗逐位不变）照过；画画仓逐像素基线、显卡冒烟各一次；加一条测试证明「没多做事」：一笔画到一万颗笔尖时，每帧走过的段数只和尾巴有关（数走步循环转了几圈）。画画软件自己的二维笔也因此不再每帧重走整条。合进画画仓、升画画末位、三维重拉。另外量：一笔画到两千、一万、四万颗笔尖时这一段各多久（改前改后）。
3. [ ] **这一笔的三角形公式表挪进准备**：落笔那一下的花费不许跟着模型大小走（定过的规矩）。公式已经钉在三角形自己的角上，按物件定一个原点（笔尖也减它）。
4. [ ] **一帧的数据表放不下 = 分几批画**（先后顺序不变，叠加的结果一样），不再取消这一笔。「一颗笔尖下超过 8 张面共用一块」照旧取消 + 说人话。
5. [ ] **仓里现造带坏面的小网格体**（零面积的面、很细的面），进规模探针每次都跑的那一档：开始画、画一笔、存、重开、自检过。
6. [ ] **每帧合成、拷到显示图、做缩小图只做这一帧改到的那一块**（缩小图只重做受影响的那几级里的那一块；做不到就先只在抬笔时整张做一次、画的过程中不做缩小图，两种做法的差别量出来报）。**先查内核「只合成」那个口能不能只合一块；要改内核才行就停下来报形状**。
7. [ ] **落成路时少打射线**：对半分的时候两头打中的是同一张面、而且这张面是平的（或者是同一个三角形），这一段不用再分。结果不变（测试：前后路上定下来的点在表面上的位置一样，笔尖逐位或在浮点误差内相同）；量 85° 和 89° 的面上射线从多少条降到多少条。
8. [ ] **抬笔那一下（落层读回）**：量 2021 的角色上普通的一笔抬笔多久；超过 30 毫秒就把读回按块分，或者说清为什么分不了。
9. [ ] **整条路扫一遍**：凡是「每帧做一遍、而且花费随整个模型、整张画布、整条笔画涨」的地方列进记录（哪一行、随什么涨、量出来多少）；能当场换成只随这一帧涨、结果不变的直接换，换不了的写清原因。已知五处：每帧重走整条笔画、每帧整张画布合成 + 拷贝 + 缩小图、落笔现做公式表、斜面上射线太多、抬笔整块读回。
10. [ ] **规模探针加「连续画 300 帧」的读数**（2021 的角色和仓里现造的六千面各一遍）：每段的中位数和最慢的一帧写进记录；看三条「不随……涨」成不成立——画布 1024² 和 4194304 格各量一遍、六千面和两万四千面各量一遍、一笔的开头和第 300 帧各量一遍，同一段的数应该差不多。软件显卡上的绝对数只作参考。
11. [ ] 1-4b 那张内存的账补上准备占的显卡内存（1024² 8 MB、4194304 格 32 MB；只留正在画的那一个物件 = 有上限；以后做 0-3 时一起算）。
12. [ ] 记一笔：「开始画」没有画布大小的参数，现在不加（画布多大由密度决定；「让 user 选多大」是以后和「重新生成一套」一起的事）。1024 个三角形的大面抬笔在软件显卡上 2 秒：等真显卡上有数再说，真慢和第 4 条分批是同一个办法。
