## 要达到什么

user 要的是「改了模型接着画」：在画过的模型上切一刀、加一圈线、倒个角，画留在原地；新长出来的面是空白。

要做到这件事，内核得知道两样现在不知道的：

1. **每个角上可以带数。** 贴图坐标就是「每张面的每个角在画布上的位置」。现在内核里每个角只有一个顶点号（`loopVert`）。
2. **每张新面是从哪来的。** 现在各个算子新建面的时候只顺手传了一个材质号。面是「原来那张面的一块」，还是「原来那张面的一份」，还是「新长出来的」，内核不知道，所以角上的数没法跟着走。

这一张把这两样做成内核的一部分。做完之后还没有任何地方会真的往角上放数（那是 1-3 的事），所以**现有的一切行为不变**；靠测试里放进去的列来证明规矩是对的。

## 一、角上的一列数

- 内核多一个列表：若干「列」。一列 = 一个 GUID + 每个角几个数（贴图坐标是 2）+ 一个和 `loopVert` 平行的 `Float32Array`。
- 「这个角在这一列上没有值」写成 NaN。
- **规矩（进 `check()`）**：一张面在一列上，要么每个角都有值，要么每个角都没有。列的数组长度够装下所有的角。
- 列跟着内核的每一种整表操作走：`clone`、`swapWith`（撤销就是整表互换）、`toSnapshot` / `fromSnapshot`。
- 改一个角的值要进改动日志（那张面算改过），`rev` 要动。
- 列表的先后没有意思，认 GUID。
- 这是通用的东西：以后按角存的顶点色、拆开的法线也走它。这一张只做「每个分量各自线性插值」这一种。

## 二、面的来历

`addFace` 和 `setFaceRing` 各多一个**必填**的参数，说这张面（或者这个新环）是从哪来的。不许有默认值：漏交代的地方编译不过。

先有一个小东西：**面的旧样子**。改一张面之前，先把它现在的样子记下来（环、环上各点当时的位置、每一列在各角上的值、材质）。后面说「原来那张面」都是指这份记下来的样子，因为等你新建面的时候，原来那张面多半已经被改掉了。内核上一个列都没有的时候，这一步要便宜到几乎不花时间（只记材质）。

来历一共五种：

| 来历 | 意思 | 角上的数怎么来 | 用在哪（Fable 读代码看到的） |
|---|---|---|---|
| **是它的一块** | 新面躺在原来那张面的里面 | 新角正好是原来的角 → 原值。不是 → 拿这个点现在的位置，在原来那张面**显示时用的那套三角形**上找最近的点，按三角形里的位置插值 | 劈边之后改两边面的环（`split.ts:15`）、劈面的两半（`split.ts:32–33`）、细分（`subdivide.ts`）、倒角缩小的原面（`bevel.ts:224`、`295`）、内缩 |
| **是它的一份** | 新面和原来那张面的角一一对应 | 调用的地方给一张对应表（新环第 i 个角 = 原来第几个角），照抄 | 复制（`duplicate.ts:18`）、挤出时原面搬到新点上（`extrude.ts:36`）、翻面（`geometry.ts:31`，对应表倒过来）、并点 / 溶解点之后的环（`merge.ts`、`join.ts:41`，少掉的角不在表里）、强行对称镜过去的面（`mirror.ts:336`，对应表倒过来） |
| **新长出来的，照它** | 新的表面，材质照旁边那张面 | 每一列都没有值 | 挤出的侧面（`extrude.ts:40`、`62`）、倒角长出来的条和角上的补片（`bevel.ts:235`、`258`、`299`、`320`） |
| **几张面并成的** | 溶解一条边，两张面变一张 | 新环上每个角去找原来哪张面有这个点。只有一张有 → 用它的。两张都有（原来那条边的两头之外的公共点）→ 两边的值一样才算数。**这一列上只要有一个角对不上或者没有值，整张面在这一列上都没有值** | `join.ts:24` |
| **凭空来的** | 没有来历 | 每一列都没有值；或者调用的地方直接给值（装载、整张面原样搬到另一个内核时用） | 基本体、手工补面和桥接（`build.ts`、`duplicate.ts:63`、`71`）、三角汤导入、读文件（`mesh-doc.ts`）、硬表面转网格体（`scene/kinds.ts:103`）、`fromSnapshot` |

几条说明：

- **「显示时用的那套三角形」** = `format/triangulate.ts` 的 `triangulateFace`，用记下来的旧位置算。和 `triangles()` 是同一个函数。这一条是整条路线的地基：user 定的「点到哪格就是哪格」「只认最后显示出来的那套三角形」。不许另写一套插值（比如按环的平均、按边长比例）。
- 材质照现在各处传的那个，一个字不改。面的标记（隐藏）照现在的行为，不借这张工单改。
- **合并时丢了值，上层要能知道**：内核记下「这一步里有几张面在某一列上丢了值」，算子的调用方能拿到这个数。这一张只要求拿得到、有测试；对用户说的那句话（「有几张面的画没带过来」）等界面那一张再接。不许悄悄丢。
- **整张面原样搬到另一个内核**（物体合并 `ops.ts:980`、把一部分面分成新物体 `ops.ts:825`）：角上的数跟着搬。两个内核的列按 GUID 对；对方有、自己没有的列，在自己这边补上这一列，原有的面全填没有值。经过剪贴板的那两处（`ops.ts:802`、`transfer.ts:160`）这一张先当「凭空来的」，在记录里记一笔，等贴图坐标进文件那一张一起做。
- **强行对称**：镜过去的面照抄角上的数，所以两半在画布上是同一块。这正是以后「镜像两半共用同一块像素」要的默认。两半分开画是 2-7 的事，这一张不管。
- 只挪点、不改环的操作（移动、缩放、压平、软挪）不碰角上的数。

## 四、门

1. `npm test` 全过，`tsc` 干净。现有的网格体测试、截图基线一个不变（这一张做完，没有列的网格体行为和以前逐字一样）。
2. **速度不退**：没有列的网格体，量一下十万面上的环切、细分、倒角，改之前和改之后各跑几遍，数字写进记录。慢了超过一成就停下来报。
3. **新测试 A：切不动画。** 造一个网格体，放一列，每张面上的值是「这个角的位置的一个一次函数」（每张面自己的一个，平面的面）。随机做一串「只切不长」的操作（劈边、劈面、刀、环切、细分、内缩）。做完之后，每张从原来某张面切出来的面，它每个角上的值仍然等于原来那张面的那个一次函数在这个角的位置上的值（差不超过万分之一）。
4. **新测试 B：照抄。** 复制、翻面、挤出时搬走的原面、强行对称镜过去的面：角上的值和原来对应的角一样。
5. **新测试 C：新面是空白。** 挤出的侧面、倒角的条：每个角都没有值。
6. **新测试 D：并面。** 两张面在公共点上值一样 → 并完值都在。不一样 → 整张面没有值，「丢了几张」那个数是 1。一张有值、一张没有 → 整张没有值。
7. **新测试 E：规矩处处成立。** 现有的逐算子检查（`mesh-kernel.test.ts` 那一套）里，给网格体带上两列再跑一遍：一列盖住全部面，一列只盖住一半。每个算子做完 `check()` 没有新的毛病。
8. **新测试 F：撤销。** `clone` 之后做操作再 `swapWith` 换回来，列和原来一样。同一个操作在副本上再做一遍，角上的值逐位相同。
9. **守卫**：「凭空来的」只许出现在一张白名单里的文件（上表最后一行那些），白名单只许变短；`src/mesh/` 里除了那一段代码，不许有第二处给角上的数做插值。
10. 升一个末位版本。

## 五、碰到这些就停下来报

- 某处新建面的地方，五种来历都不贴切。
- 「是它的一块」里，新点离原来那张面很远（比如某个算子先挪了点再建面），插值会明显不对。
- 为了交代来历，要改某个算子的算法（不只是多传一个参数）。
- 速度退了。
- 你觉得需要第六种来历。

## 这一张不做的

贴图坐标进文件和网格体 2.0（下一张）；谁往角上放数（1-3 的铺法）；渲染读角上的数（1-3）；并面丢了值之后对用户说的话；沿边滑点时让画留在原地（以后的选项）；经过剪贴板的两处。
