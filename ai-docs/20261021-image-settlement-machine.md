## 1. 一句话

**动词不碰图，只交一张「像表」；机器按坐标认领胞腔。**

像 = 一张多边形（世界坐标的环，外环 + 洞）+ 代数（OR / XOR）+ 继承谁的身份（可无 = 新膜）。
动词把「做完以后每张膜长什么样、在哪里」写成像表；一台机器把它们落成膜。

## 2. 大白话（给人看的版本）

把模型想成桌上的剪纸：每张面是一张纸片，每个平面是一张桌子。

- **以前**：推拉时代码给每条边贴标签（这条跟着走、那条留下、这个点分裂……），按标签一条条搬边、画线、删线，最后靠标签判断「落地那块要不要抵消」。搬到一半两个点撞在一起合并了，标签就丢了，抵消没发生——这就是 09-23 的 bug 1（切半推到底两面不消），而且这类 bug 会一直有，因为标签总有丢的时候。
- **现在**：推拉时不搬东西，而是**每张纸片重新说一遍自己做完后的形状和位置**（一圈坐标）。然后一道工序：把所有纸片摆到桌上，看它们怎么重叠——有纸的地方就是面；纸的边缘就是线；两张纸拼在一起没缝的地方不画线；两张纸**完全落在同一块**（推到底贴上对面）→ 互相抵消（SketchUp 的推穿规则）；哪张纸是原来的哪张面，看它落在哪、盖住了什么，不看标签。

因为**只看形状不看标签**，合并、拆分、复用旧边都无所谓了。

## 3. 机器的十一步（`settle()`）

1. **身份像**：没被动词消耗的膜自动交一张像（现状坐标，OR，继承自身）。
2. **插边**：手势线（画笔）、裸线段、所有像的环段，走 sticky 插入（交点切开、重合即同一）。切割血缘喂回手势集 / 随葬集 / 软边集。
3. **自愈**：planarize（交叉 / 骑边）。
4. **折**：非平面的像先 autofold 成平面片（折缝也是线）；折不动的丢弃（零认领 = BURST 曝光）。
5. **胞腔**：每个平面切出最小区域。
6. **认领**：每个像按绕数认领被它覆盖的胞腔（像平面 ∥ 胞腔平面、代表点在像平面 3τ 内）。
7. **填 / 不填**：有 XOR 参与 = 认领数的奇偶；否则 ≥ 1 即填。
8. **身份**：一个 id 独占一个胞腔 → 保 id（换平面也跟随）；一个 id 多个胞腔 → DIVIDE；一个胞腔多个 id → MERGE；零胞腔 → BURST；新像独占 → BIRTH；无主胞腔的外环含手势边 → BIRTH。
9. **随葬**：第一相（永远开）——被消耗膜的旧环边若不在任何像的环段上、也没有未动膜引用 → 结算**前**就摘（否则旧边会把新膜切成两格）；第二相（动词开关，pp 开 / move 不开）——结算后无膜的边只许是用户画的线（本次的、或操作前就是裸线的，含切割后代），其余孤儿边一律删。
10. **溶解**：**因本次操作**变成二度共线的顶点（之前不是、也不是本次显式画的端点）→ 两边并一条。用户自己的分割点永不动（不对称律）。
11. **软边层**：删掉的边出集；新软段上的边入集。

## 4. 每个动词的像表

| 动词 | 消耗 | 像 | 其他 |
|---|---|---|---|
| draw（addEdges）| 无 | 无 | 手势线段；BIRTH 靠「无主胞腔外环含手势边」 |
| move / rotate / scale（moveVertices）| 被牵连的膜 | 每张的环按新坐标读出（OR，继承自身）| 先合并组预判 + 刚移，不开随葬第二相（面移扁留一条线）|
| **pp** | F + 褶边邻膜 | 帽 = F 平移 δ（**XOR**，继承 F）；每条环边：**褶边**（全部邻膜 ∥ n̂）→ 改写邻膜的像，环里的 e 段换成 a→a+δ→b+δ→b（拉 = 伸、推 = 缩，同一句话）；否则 → 侧壁像 (a, b, b+δ, a+δ)（OR，新）；有裸边 → 原位留一张源像 | 开随葬第二相；预演 settleLanding:false 时帽用 OR（不湮灭）；软边的帽边 / 侧棱也软 |
| absorb（炸开 / 粘贴 / 复制）| 无 | 快照里每张膜（OR，新）| 裸边当线段 |
| offset（0.8，编辑器 `offset.ts` 算环 → addEdges）| 无 | 无 | 就是画线：偏移环当手势线段进机器 → 环带 + 内岛两张膜 BIRTH |
| **followMe**（0.8，`sweep.ts` 斜切站 + `Kernel.followMe`）| 孤立轮廓 → F 出库；依附轮廓（任一环边有第二张膜）→ 留表 | 扫出的全部面（侧面 + 开路径两端帽）一律 **XOR**（新）；开路径 + 孤立轮廓：起始帽继承 F | ∂(B △ S) = ∂B △ ∂S：沿实体的棱倒角时顶条 / 侧条与既有膜成对湮灭；闭路径 + 依附轮廓没被扫到 → 结算后当横截面删；共线关节先并掉（不设站）；层：平滑关节站圈 soft+smooth，否则继承轮廓边；经线按 riserLayers |
| erase | —（自己的小规则：外环对 void = BURST、洞 / 桥 = ABSORB、同平面共享 = MERGE）| | 不在本机 |
| eraseFaces | 纯出库 | | |

**褶边判据（参数 ①）默认 = (a)「全部邻膜 ∥ n̂」**（= 旧 v3 判据）。09-23 列的 T1–T9 SketchUp 实验没做（user 10-21：「不再拿人类验证卡每一步」），默认沿用现状；要改只动 `CREASE_COS` 和 `pushPull()` 里那一个谓词。

## 6. 行为小变化（user 允许的「小变化」）

- 预演在精确 h 落在既有膜上 = OR 合并一张（不再差 2 量子）；推平到底的预演 = 一张底（墙消失），commit 全湮灭（不变）。
- 旧顶棱随葬后角点溶解：盒顶拉高后墙仍是四边形（此前靠顶点随行做到；现在靠溶解规则）。
- 只共享一个顶点的邻膜永不被拽（by construction，不再需要守卫）。

## 9. 局部性定理（2026-10-23，v0.9.16，总账 #26；edited by Claude Fable 5.1）

10-21 性能两轮把「只重算被碰到的那一小块」塞进了十一步里（四个筛 + 两个缓存），其中平面归属缓存在同一次结算的第 ⑩ 步溶解之后过期且永不自愈 →
第二次拉过的盒子上贴棱描线墙 BURST、墙里画矩形墙被静默换成小矩形（10-23 截图）。修法 = 把局部化写成它自己的定理（立宪页 §3「局部性定理」）：
影响域 S 由 id 和谓词构成，归属缓存删掉，新旧平面同一套边集构造（新平面也走空间网格查包围盒）；加守恒断言（未消耗、环还在的膜认领不到胞腔 = 拒绝这一步）；
加差分 oracle（`settleMode: "global"` 的第二台机 vs 出货的局部机）。顺手清掉三处被环起点掩盖的顺序敏感：像的平面改 Newell 整环；pp 褶边判据与 τ 一致；闭路径跟随起点对齐。

## 8. 吸附那一半（bug 2）

推拉的推断世界 = 按下那一刻的模型 + 源面原位不透明；预演只管渲染，永不回流进推断（`editor.ts` 头注释「例外」条，`ppInferenceWorld()`）。理由：推拉只有一个自由度 h，拖拽中新长的帽 / 侧壁高度恒等于 h（对 h 零信息），中间态唯一贡献是遮挡，而遮挡正是「吸端面 / 不吸」逐帧交替的反馈回路。**这条翻了 2026-09-03「争取中间态 / 旧 snapshot 禁入」的拍板**（user 10-21 授权往前走；build lint 的 ghost-world 条仍在——它查的是 `snapPoint(this.checkpoint` 之类的字面，推拉经 `ppInferenceWorld()` 走，别的工具仍走 `liveWorld()`）。
