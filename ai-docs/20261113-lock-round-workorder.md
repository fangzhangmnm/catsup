# 施工单：锁的一轮——硬表面接上 X / Y / Z，N = 沿法线，锁不记忆

> created 2026-11-13 by Claude Fable 5.2（Catsup统筹）· as-of 三维开发版 v0.19.100
> 状态：**规矩定了；轴键怎么读以 `20261113-axis-constraint-module-design.md` 为准（11-13 夜重谈后的定稿）。** 施工：Catsup小弟。排在 F 顺着边往下填、自由建模藏面藏边的清点之后；开工前先侦察。
> user 的原话在讨论日记 `talks/20261110-marriage-route.md` 第八十四轮（11-13 夜，user 在用键鼠重做小屋子时提的）。

## 一、定下来的

user 定的：
1. 硬表面里也接上 X / Y / Z、Shift+X / Y / Z。画矩形、画线时特别想要。
2. 取消锁定 = 同一个键再按一下（现状已经是这样）。
3. 加 N = 沿法线锁。
4. 快捷键按出来的轴锁是空心框，不记忆；每次进入工具时锁都重置，触屏也一样。
5. 锁了轴之后：整格之外还认「正压在端点或中点上」（「可以认，应该认」）；充能这些和别的东西对齐的机制也都要留（「这么说的话充能这些机制也都要，就是和别的对齐的」）。

统筹照这几条写的规矩（user 没逐字说的）：
- **锁是约束，不是另一种吸附**（user 同一晚更正：「我刚才讲错了，就是如果只认格点的话，我们就又回到了自由建模。但我们这个 CAD建模是对称（统筹读成对齐）的，就是我们还是要全量的对称……所以我们的轴锁可能只是多了一张可以吸附的面或者轴，以及只是对我们的吸附点做了一个约束，但其他的还一切照旧。」）：吸附照常全量地求（端点、中点、边上、面上、充能、延长线、整格，一样不少），求出来的点再约束到锁的轴 / 面上。**不为锁改任何一条吸附的规则。** 这就是现在 `applyLock` 的做法，所以这一条不用施工，只用核。
- **两种锁，两种寿命，两种样子**：
  - 快捷键按的锁 = 空心框，只管这一下：落定、取消、Esc 就没了。
  - 按钮点的锁（右上那几颗、触屏的虚拟轴键）= 实心，管到放下这把工具为止。
  - 每次拿起一把工具都从没锁开始。等于撤掉 11-10 白模第一批的「每把工具记住自己的锁」（W-4）。user 同一晚又确认了一遍：「你换工具再换回来之后得重新点按钮」。
- **N 的一家**：X / Y / Z / N 四根，加 Shift = 垂直于它的那个平面。N = 沿法线；Shift+N = 锁在这张面里（现在挂在 Shift+↓ 上的「面锁：光标下的面」）。
- **轴键的读法**：11-13 夜和 user 来回谈了好几版，最后定稿在 **`ai-docs/20261113-axis-constraint-module-design.md`**（一个深模块、三个口）。这张单里凡是讲「X / Y / Z / N 怎么读、单按和加 Shift 各是什么」的，都以那一页为准；下面第三节三刀里和它不一样的句子作废（先定平面的工具怎么吃锁、N 的那一刀都已经并进那一页）。**开工顺序改成：先做那一页的语法模块和对照表 → 自由建模接上 → 硬表面接上 → 锁不记忆和两种样子。** 动手前小弟先照那一页做一次只读侦察（现成的 `lk` / `applyLock` / `lockToAxis` 怎么换成任意方向），报统筹。

## 二、现状（统筹读的，11-13）

- 锁只有一套：`editor.lockKey` / `armLock` / `toggleAxisLock` / `togglePlaneLock`，按工具吃哪种锁（`lock: "axis" | "plane"`）分派。锁是事后约束：先照常求吸附，再投到锁的轴 / 面上（`applyLock`）。
- 硬表面：方向键 → X / ← Y / ↑ Z / ↓ 解，Shift+方向键 = 面锁，Shift+↓ = 光标下的面；先定平面的工具（矩形、圆、弧……）方向键直接锁平面。
- 自由建模：操作工具里和手势中 X / Y / Z（+Shift）= 锁；拿着「选」时 Y / Z = 先锁、下一下生效，X = 删除。键盘按的锁下一下落定 / Esc / 取消就解。
- 硬表面里 X 现在是橡皮的第二个键（`TOOL_KEYS` 里 `["x", "erase"]`，第一个是 E）。N 没有绑任何东西。
- 每把工具各记自己的锁（`this.locks.set(this._tool, …)`）。

## 三、三刀

### 第 1 刀：硬表面接上 X / Y / Z（+Shift）
- 字母键接到现成的那一个入口上，不另写一套：X / Y / Z，加 Shift = 面锁。**方向键不再管锁**（user 11-13 夜：「锁xyz就xyz，不用方向键」）；方向键空出来之后先不绑别的。
- X 从橡皮让出来，橡皮只剩 E（挪键是 user 这条要求带来的，已告诉 user）。
- 拿着不吃锁的工具（选）时：照自由建模那一层的做法——Y / Z = 先锁、下一下生效；X = 删除。两个工作台同一套，不留两种说法。
- 先定平面的工具（矩形、圆、弧）：照第一节「轴键的读法」那五条——单按记边的方向（记两个），Shift + 轴 = 那个面。现在这类工具只吃面锁（方向键直接锁平面），要改成能记两个方向；方向键在这些工具里的老意思不留（user：锁 xyz 就 xyz，不用方向键）。
- 锁照第一节那一条：吸附一切照旧，只多一道约束。先只读地核一遍报统筹：现在锁着的时候，结果有没有可能不在锁的轴 / 面上；整格吸附、充能的对齐约束到轴上之后对不对。有毛病的列出来再定怎么改，求吸附的排序规则不要自己动（那一处归统筹）。
- 验收：画线时按 X = 只沿 X；再按 X = 解；按 Y 换成 Y；Shift+Z = 只在水平面里；画矩形时按 Z = 矩形躺在水平面；锁着 X、光标压在远处一个端点上 = 线头和那个端点在 X 上齐平；锁着 X、先在一个点上停一下充能再移开 = 能和它对齐；没有对齐对象、整格开着 = 长度是整格；橡皮 E 还能用、X 不再拿橡皮。

### 第 2 刀：N = 沿法线锁
- N = 锁到法线那根轴；Shift+N = 锁在垂直于法线的面里（= 光标下这张面）。Shift+↓ 跟着方向键一起退掉，只留 Shift+N。
- 法线取谁的：
  - 自由建模的操作工具：选区的法向，和手柄「朝向 = 法向」那一档同一个算法（选中的面的法向；边 / 点 = 连着的面的平均；互相抵消时退回物件轴），不另算。
  - 硬表面的取点工具（画线等）：起点所在的那张面；起点不在面上 = 光标下的那张面；都没有 = 不锁、提示一句为什么。
- 验收：斜屋顶上起一条线按 N = 垂直于屋顶出去；自由建模选一张斜面按 G 再按 N = 沿它的法线走；Shift+N = 在面里滑；没有面可取时不锁、有提示。

### 第 3 刀：锁不记忆，两种样子
- 每次拿起工具（包括临时工具被借用、借完回去）都从没锁开始。`locks` 那张按工具记的表拿掉。
- 快捷键按的锁：这一下做完（落定 / 取消 / Esc）就解。硬表面的方向键和字母键也照这条。连着画的工具（画线一段接一段）：每一段算一下，锁在一段落定时解。
- 按钮点的锁：管到放下这把工具。
- 样子：按钮点的 = 实心；快捷键按的 = 空心框。和临时工具的空心框是同一个样式，复用，不另画。右上那几颗和触屏的虚拟轴键都照这条显示。
- 原来围着「每把工具记锁」做的几处跟着收：没做手势时 Esc 只解锁不退出（照旧）；「选」上交接中的锁看得见（先锁的那种 = 空心框）；换文件清锁（本来就没了）。
- 验收：移动工具里点按钮锁 Z → 连着挪三下都锁着 → 换到旋转再换回来 = 没锁；按 G 再按 X 挪一下 → 落定后没锁、按钮是暗的；按着 X 的时候按钮是空心框、点按钮锁的是实心；触屏（笔）同样走一遍按钮那一半。

## 四、和别的东西的关系
- 「临时工具」那一刀先做：空心框的样式、「底下那把 + 临时那把」的管法都从那里来。
- 快捷键全量迁 Blender（还没做）：这一轮只动锁相关的键和橡皮的 X，别的键不碰。
- 这一轮不动文件格式、撤销、存盘。

## 四½、统筹对侦察的裁定（11-13 深夜，Claude Fable 5.2）

小弟的只读侦察（换法六条、会红的探针清单）统筹都同意。五个问题的答复：

1. 拿着移动这类工具、不在手势里按 X = 弹小菜单（删除、溶解），两个工作台都是；自由建模原来的「X = 立刻删除」同一刀换成小菜单。依据：user 定的「动作里外」那条线（[键位现行表](20261113-keymap-decisions.md) 第一节）。某个工作台没有现成的「溶解」就先不放那一项。第三节第 1 刀里「拿着选时 Y / Z = 先锁、X = 删除」那一句作废。
2. N / T 的锁线和提示：方向和坐标架某根轴平行 = 照旧用那根轴的颜色、名字、吸附种类；不平行 = 新的一种，先用品红，吸附种类加一个不带轴名的；字用 `axisDescribe` 给的那一句。颜色放在一个常量里，做出来给 user 判。
3. 沿不平行于轴的线、网格开着：硬表面 = 沿这条线的长度取整（走「长度一律取整」那个现成入口），自由建模不落；法向不和轴平行的面里不落整格，带了面里那个方向的沿那个方向长度取整。（统筹照「硬表面的结果是说得出来的数」读的，user 没逐字说。）
4. 方向键锁这一轮退掉，两边都退（硬表面的方向键、Shift+方向键、Shift+↓，自由建模的方向键先锁）；相关探针改用按钮锁的 API 或手势里的字母键。
5. `setAxisLock` / `setPlaneLock` / `lockKey` 留着当按钮锁那条路；每把工具记锁的那张表到最后一步「锁不记忆」再拿。

只有一处先发统筹：第一步的对照表（按键顺序 → 结果的测试表）。

### 第二步：自由建模接上（v0.19.111，分支 axis-freeform）
做了什么：
- 手势层 X / Y / Z / N / T（加 Shift）→ `axis.press` → `editor/axis-keys.ts`（解析方向、寿命 = 一个动作）→ 语法模块。工具只问 `ctx.axisConstraint()`（轴键那份 ?? 按钮锁那份），照自己那一族读 `controller/axis-apply.ts`（设计稿 2.3 那张表：移动 / 挤出 = moveLock、旋转 = rotateLock、缩放 = scaleLock）。自由建模的移动 / 旋转 / 缩放 / 沿法线 / 变换（`mesh-transform.ts`）和挤出（`mesh-pull.ts`）接上。
- 锁线改成按约束画（`lock-guide.ts constraintLines`）：平行于坐标架某根轴 = 那根轴的颜色；锁住的方向不平行 = 新颜色常量 `aux.ts axisDir`（品红 0xd6249f，颜色只有 user 能判、可能改）；面里撑开的另一根不平行 = 中性。按钮锁读成约束 = `lockConstraint`，老的 `lockLines` 拿掉（老格子的输出照旧，测试里钉着）。
- 拿掉：键表操作工具层（手势外 X / Y / Z 先锁）、自由建模层 Y / Z 和方向键先锁、`Editor.armLock`、`setTool` 里「选择上先按好的锁交给下一把」那段（选择不吃锁，先锁拿掉以后它上面不会再有锁）。全局层的方向键锁（A9）留到第三步两边一起退。
- 动作外按 X = 光标处弹「删除 / 溶解」（`context-menu.ts openDeleteMenuAt`；`Editor.deleteSelection(dissolve)` → 网格体 `meshDelete` 的 dissolve 旗，和橡皮 Shift 同一条）。自由建模原来的「X = 立刻删除」同一刀换掉；动作外 Y / Z / N 不响应、Shift+Z 落到全局 = 缩放到全部（统筹第 1 条）。
- 网格整格（统筹第 3 条）：自由建模沿不平行于轴的线不落格——现在自由建模的移动本来就不按锁落格，这一步没加任何取整。第三步硬表面要照「沿线长度取整（走『长度一律取整』那个现成入口）」做；那一条是**统筹照「硬表面的结果是说得出来的数」读的，user 没逐字说**。

计划之内我自己定的几处（统筹看一眼，不对就改）：
1. **手势里打数时的 N / T**：单位字母里有 n、t（in、ft、nm）。改成单位还没开始打（缓冲里还没有字母）时 N / T 归轴（「G 2 N」= 打了 2 再锁法线），打了单位的头一个字之后照旧当单位（1in、1ft 都打得出）。代价：手势里打不出 nm（以 n 开头的单位只有它；没有以 t 开头的单位）。`units.ts quantityKey`，数值小窗不受影响。
2. **溶解只在网格体里选着边 / 点（没有面）时露**：网格体面的溶解（几张面并一张）没有现成命令（现成的 dissolve 对面 = 删面），照「没有现成的就先不放那一项」不放。硬表面这一步没碰。
3. **两份锁并存时把轴键全按掉**（X 再 X）：回到按钮锁着的那份，提示行说「轴键都取消了：回到按钮锁着的那个」；按钮没锁就说「不限制」。
4. **提示行那句话一直挂在手势读数后面**（「移动 12 cm ｜ 沿 X」）：只写一次会被下一帧的预演读数盖掉。取不到面 / 边的原因也挂着，直到再按轴键或动作结束。
5. **斜面里撑开的那两根线**：其中一根正好平行于某根轴时也用那根轴的颜色（例：Shift+N 按在绕 Y 倾斜的斜面上 = 一根绿 + 一根中性）。老的「锁那张面」只有在这种巧合下颜色会变，别的输出不变。
6. **轴键按出来的不点亮右上角按钮**（按钮只显示按钮锁那份）；空心框的样子是第四步。
7. **手势里按 Esc 还会顺手解掉按钮锁**（老行为，`main.ts escape`）：没动，第四步「锁不记忆」一起理。

要统筹知道的：
- 键位冲突登记（`keymap.ts KNOWN_CONFLICTS`）：Shift+Z 那条删了（自由建模动作外不再是锁面，两边都 = 缩放到全部，已经不冲突，守卫要求删）；X 那条改了说法（硬表面 = 橡皮 · 自由建模 = 动作外弹删除 / 溶解小菜单）。这六条是 user 10-29 拍过「保持现状」的，删的是已经不冲突的那条，没有新增。
- 自由建模拿着选择按方向键：先锁拿掉以后落到全局层的方向键锁，选择不吃锁 = 提示「这把工具没有方向锁 / 面锁」，第三步方向键退掉以后就什么都不发生了。
- `ai-docs/20261113-keymap-decisions.md`（键位现行表，统筹的页）里 X 那一行要不要跟着改，统筹定。
