# 施工单：锁的一轮——硬表面接上 X / Y / Z，N = 沿法线，锁不记忆

> created 2026-11-13 by Claude Fable 5.2（Catsup统筹）· as-of 三维开发版 v0.19.100
> 状态：**规矩定了，可以开工；排在「临时工具」和「工具栏显示快捷键」之后。** 施工：Catsup小弟。分三刀，一刀一版。
> user 的原话在讨论日记 `talks/20261110-marriage-route.md` 第八十四轮（11-13 夜，user 在用键鼠重做小屋子时提的）。

## 一、定下来的

user 定的：
1. 硬表面里也接上 X / Y / Z、Shift+X / Y / Z。画矩形、画线时特别想要。
2. 取消锁定 = 同一个键再按一下（现状已经是这样）。
3. 加 N = 沿法线锁。
4. 快捷键按出来的轴锁是空心框，不记忆；每次进入工具时锁都重置，触屏也一样。
5. 锁了轴之后：整格之外还认「正压在端点或中点上」（「可以认，应该认」）；充能这些和别的东西对齐的机制也都要留（「这么说的话充能这些机制也都要，就是和别的对齐的」）。

统筹照这几条写的规矩（user 没逐字说的）：
- **锁是约束，不是另一种吸附**（user 同一晚更正：「我刚才讲错了，就是如果只认格点的话，我们就又回到了自由建模。但我们这个 CAD建模是对称（统筹读成对齐）的，就是我们还是要全量的对称……所以我们的轴锁可能只是多了一张可以吸附的面或者轴，以及只是对我们的吸附点做了一个约束，但其他的还一切照旧。」）：吸附照常全量地求（端点、中点、边上、面上、充能、延长线、整格，一样不少），求出来的点再约束到锁的轴 / 面上。**不为锁改任何一条吸附的规则。** 这就是现在 `applyLock` 的做法，所以这一条不用施工，只用核。
- **两种锁，两种寿命，两种样子**：
  - 快捷键按的锁 = 空心框，只管这一下：落定、取消、Esc 就没了。
  - 按钮点的锁（右上那几颗、触屏的虚拟轴键）= 实心，管到放下这把工具为止。
  - 每次拿起一把工具都从没锁开始。等于撤掉 11-10 白模第一批的「每把工具记住自己的锁」（W-4）。user 同一晚又确认了一遍：「你换工具再换回来之后得重新点按钮」。
- **N 的一家**：X / Y / Z / N 四根，加 Shift = 垂直于它的那个平面。N = 沿法线；Shift+N = 锁在这张面里（现在挂在 Shift+↓ 上的「面锁：光标下的面」）。
- **轴键的读法（两个工作台、所有吃锁的工具同一套；user 11-13 夜和统筹来回几轮之后收成这五条，原话在 `talks/20261103-keymap-blender.md` 第十一到十四轮）**：
  1. 画线这类一维的工具记一个轴，画矩形、画圆这类二维的工具记两个轴（两条边）。最近按的算数，多了挤掉最早的。两根轴不垂直时第一根照原样、第二根取和它垂直的那一部分。
  2. 同一个键再按一下 = 去掉它。动作做完全部清空（快捷键的锁只管这一下）。
  3. 没按满的用默认的补：光标下有面就照这张面（贴着面、边顺着离起点最近的那条边），没有面照地面（边顺着世界的轴）。只按了一根立起来的轴（垂直于默认那个面）= 图形立起来，另一条边先用默认的，要改再按第二个。
  4. Shift + 轴 = 把平面定住（那个面）。对一维的工具 = 只许在这个面里走。对二维的工具 = 图形躺在这个面里；**之后单按的轴只管边在这个面里朝哪边（投到面里，只记最近的一个），不再动平面**；没按单按的轴时边照默认。没按 Shift 时才是第 1 条（两个单按的轴一起撑出面）。再按别的 Shift + 轴 = 换成那个面。
  5. Shift+N = 光标下这张面。
  - 放弃的：两个 Shift 夹出一条线（user 提过、觉得复杂；统筹也同意不做）。
  - user 说「非常舒服」的两个例子：Shift+N 再 X = 贴着光标下这张面画、边顺着 X；N 再 X = 立在这张面上画（一条边沿法线竖起来、另一条顺着 X）。光标本来就在面上时只按一个 X，结果和 Shift+N 再 X 一样；区别是 Shift+N 之后平面锁死在那张面上，光标挪开也不变。
  - 验收里这两个例子各要一格；还要一格：Shift+N 再 X 之后再按 Y = 边换成顺着 Y、平面不变。

## 二、现状（统筹读的，11-13）

- 锁只有一套：`editor.lockKey` / `armLock` / `toggleAxisLock` / `togglePlaneLock`，按工具吃哪种锁（`lock: "axis" | "plane"`）分派。锁是事后约束：先照常求吸附，再投到锁的轴 / 面上（`applyLock`）。
- 硬表面：方向键 → X / ← Y / ↑ Z / ↓ 解，Shift+方向键 = 面锁，Shift+↓ = 光标下的面；先定平面的工具（矩形、圆、弧……）方向键直接锁平面。
- 自由建模：操作工具里和手势中 X / Y / Z（+Shift）= 锁；拿着「选」时 Y / Z = 先锁、下一下生效，X = 删除。键盘按的锁下一下落定 / Esc / 取消就解。
- 硬表面里 X 现在是橡皮的第二个键（`TOOL_KEYS` 里 `["x", "erase"]`，第一个是 E）。N 没有绑任何东西。
- 每把工具各记自己的锁（`this.locks.set(this._tool, …)`）。

## 三、三刀

### 第 1 刀：硬表面接上 X / Y / Z（+Shift）
- 字母键接到现成的那一个入口上，不另写一套：X / Y / Z，加 Shift = 面锁。**方向键不再管锁**（user 11-13 夜：「锁xyz就xyz，不用方向键」）；方向键空出来之后先不绑别的。
- X 从橡皮让出来，橡皮只剩 E（挪键是 user 这条要求带来的，已告诉 user）。
- 拿着不吃锁的工具（选）时：照自由建模那一层的做法——Y / Z = 先锁、下一下生效；X = 删除。两个工作台同一套，不留两种说法。
- 先定平面的工具（矩形、圆、弧）：照第一节「轴键的读法」那五条——单按记边的方向（记两个），Shift + 轴 = 那个面。现在这类工具只吃面锁（方向键直接锁平面），要改成能记两个方向；方向键在这些工具里的老意思不留（user：锁 xyz 就 xyz，不用方向键）。
- 锁照第一节那一条：吸附一切照旧，只多一道约束。先只读地核一遍报统筹：现在锁着的时候，结果有没有可能不在锁的轴 / 面上；整格吸附、充能的对齐约束到轴上之后对不对。有毛病的列出来再定怎么改，求吸附的排序规则不要自己动（那一处归统筹）。
- 验收：画线时按 X = 只沿 X；再按 X = 解；按 Y 换成 Y；Shift+Z = 只在水平面里；画矩形时按 Z = 矩形躺在水平面；锁着 X、光标压在远处一个端点上 = 线头和那个端点在 X 上齐平；锁着 X、先在一个点上停一下充能再移开 = 能和它对齐；没有对齐对象、整格开着 = 长度是整格；橡皮 E 还能用、X 不再拿橡皮。

### 第 2 刀：N = 沿法线锁
- N = 锁到法线那根轴；Shift+N = 锁在垂直于法线的面里（= 光标下这张面）。Shift+↓ 跟着方向键一起退掉，只留 Shift+N。
- 法线取谁的：
  - 自由建模的操作工具：选区的法向，和手柄「朝向 = 法向」那一档同一个算法（选中的面的法向；边 / 点 = 连着的面的平均；互相抵消时退回物件轴），不另算。
  - 硬表面的取点工具（画线等）：起点所在的那张面；起点不在面上 = 光标下的那张面；都没有 = 不锁、提示一句为什么。
- 验收：斜屋顶上起一条线按 N = 垂直于屋顶出去；自由建模选一张斜面按 G 再按 N = 沿它的法线走；Shift+N = 在面里滑；没有面可取时不锁、有提示。

### 第 3 刀：锁不记忆，两种样子
- 每次拿起工具（包括临时工具被借用、借完回去）都从没锁开始。`locks` 那张按工具记的表拿掉。
- 快捷键按的锁：这一下做完（落定 / 取消 / Esc）就解。硬表面的方向键和字母键也照这条。连着画的工具（画线一段接一段）：每一段算一下，锁在一段落定时解。
- 按钮点的锁：管到放下这把工具。
- 样子：按钮点的 = 实心；快捷键按的 = 空心框。和临时工具的空心框是同一个样式，复用，不另画。右上那几颗和触屏的虚拟轴键都照这条显示。
- 原来围着「每把工具记锁」做的几处跟着收：没做手势时 Esc 只解锁不退出（照旧）；「选」上交接中的锁看得见（先锁的那种 = 空心框）；换文件清锁（本来就没了）。
- 验收：移动工具里点按钮锁 Z → 连着挪三下都锁着 → 换到旋转再换回来 = 没锁；按 G 再按 X 挪一下 → 落定后没锁、按钮是暗的；按着 X 的时候按钮是空心框、点按钮锁的是实心；触屏（笔）同样走一遍按钮那一半。

## 四、和别的东西的关系
- 「临时工具」那一刀先做：空心框的样式、「底下那把 + 临时那把」的管法都从那里来。
- 快捷键全量迁 Blender（还没做）：这一轮只动锁相关的键和橡皮的 X，别的键不碰。
- 这一轮不动文件格式、撤销、存盘。
