## 0. 怎么读

一个风格要的东西分五列，对应骨架稿 v2 的四个挂点 + 屏幕一刀：

| 列 | 是什么 | 归哪 |
|---|---|---|
| 材质槽 | 从模型借什么（颜色 / 贴图 / 粗糙金属 / 起伏图 / 零件），预设往槽里写什么默认 | 材质翻译挂点（`src/minccino/material/`） |
| 几何派生通道 | 着色器要、但不是材质的东西：硬边 / 轮廓 / 折痕、到边的距离、零件号、典型厚度、遮蔽、法线 | 几何预处理挂点 + frame graph 按需产 |
| pass | 这一帧画几遍、往哪画（frame graph 节点） | frame graph + 后处理挂点 |
| 屏幕 | 分辨率上限 / 整数倍 / 色板 / 屏幕外观 / 机框 | 屏幕一刀 |
| 管线参数 | 预设级的旋钮（线宽、辉光、色阶数、光的方向、调色板） | 预设本身（数据） |

实验室的预设几乎全是**管线参数**：线的颜色、辉光、底色都是整个风格一份。模型只给颜色、贴图、声明的粗糙度 / 金属度、起伏图和零件。所以 CatsUp 槽表里「每材质」的那些槽（边发光色、包浆色…）读法是：**预设在材质挂点上写槽的默认，某个物件的材质翻译可以覆盖**。这和骨架稿 v2「预设在材质挂点上改槽」一致，第 1 步按这个读法落。

## 3. 四个挂点够不够（结论）

**够，四个挂点 + 屏幕一刀把实验室九种 pass 结构全接得住**，没有一个预设需要第五个挂点。但有四处要在契约上说清楚（改契约归 Fable，这里只提，记进周账 F-137）：

1. **「几何预处理」要分两档**：① 离线派生（按池版本缓存）：到边的距离、硬边 / 轮廓 / 折痕标记、零件号、典型厚度、每条硬边往面里能倒多宽、细件方向——倒角、剪纸、圆角卡通、Tron 都要；② **光栅时的逐顶点变换**：PS1 顶点吸附、细件保底宽度（按像素外推）、弹跳。② 不是「预处理」，是顶点着色器里的钩子，每帧跟相机变。建议挂点名不变、内部分这两档。
2. **frame graph 要能声明「同一份几何画 N 遍」**：深度剥离 1–8 层、Tron 的被挡住的边第二遍、半透的背面深度。现在的 `PassDecl`（reads / writes / appends）表达得了，但 N 层要按层数展开声明；预设里是一个数（层数）。
3. **后台作业的第一批真需求**：遮蔽的 20 方向深度图（剪纸多重阴影、平涂遮蔽、铸铜包浆）、环境图 mip + SH9（表面七个棚）、太阳阴影图——实验室在「换模型」时烘一次；CatsUp 里改一下模型就要重烘，必须是按池版本增量的后台作业（骨架稿不变量 3 的后台预算），不然每次编辑卡一下。小学可以先「编辑停手半秒后整体重烘」，如实披露。
4. **「零件」通道没有定义**：剪纸（一件一色）、多色 FDM、实验室的 `aPart` 都按零件分色。CatsUp 里候选三个：面的材质槽（同一个材质 = 一件）、组件实例、几何连通块。实验室的模型是「一个物件一个零件」，最接近 CatsUp 的**材质槽**；第 1 步先按材质槽当零件做，契约上记一条待 Fable / user 定。

另外两条不改契约、但第 1 步要遵守：

5. **屏幕和着色器无关**：实验室的「画面」栏（分辨率 + 屏幕 + 机框）独立于着色器，Tron、平涂、老主机都能接——印证不变量 6「屏幕一刀」。小学的屏幕表示只用「GPU 纹理」一种就够（整数倍放大 + 屏幕外观 shader）。
6. **编辑叠加层在风格下照画**（不变量 7）：选中 / 悬停 / 吸附画在原生分辨率、风格之后；Tron 认领选中色（Clu 橙）。低分辨率风格下叠加层不跟着像素化（视口设计笔记 §2.4 的方向）。

## 4. 第 1 步的顺序（我的打算，按基础设施递进）

| 顺序 | 风格 | 新增的基础设施（后面的复用） |
|---|---|---|
| 1 | 像素描边 | 预设数据形状 + 视图菜单入口；低分辨率目标 + 整数倍最近邻放大（= 第一块屏的骨架）；像素描边后处理（读深度）；面 shader「不打光」档 + 贴图最近邻覆盖 |
| 2 | 剪纸 · 色纸 | 平涂 shader（色阶 / 偏色 / 光方向）；遮蔽烘焙（第一个后台作业，停手后重烘 + 披露）；地面 |
| 3 | CRT Tron | 面不借色 + 边发光（多目标输出）；辉光金字塔；被挡住的边一遍；CRT 屏 + 机框（屏幕一刀第二种外观） |
| 4 | 铸铜 | 环境棚（程序海天）+ SH9；太阳阴影图；PBR 着色 + 包浆进凹处；倒角通道 |

每一个都是「默认白模不变」：风格是视图菜单里的选项，不选就是现在的样子——截图基线 11 张照旧 0 像素差；每个风格落地时加自己的基线场景（`--update` 只加新场景，日志写一行）。

## 5. 落地日志

### 像素描边（v0.17.10，2026-10-29 Claude Opus 5.5）
- **预设 = 数据** `src/minccino/preset/index.ts`：`Preset` = 材质挂点（明暗 camera / none、贴图过滤 asset / nearest、模型线稿画不画）+ 光与环境（背景色）+ 后处理（像素描边参数）+ 屏幕（像素化倍数，CSS 像素）+ 几何（空）+ 出处 / 说明 / 小字。`PRESETS` = 白模、像素描边；`presetPasses(p, xray)` 给 frame graph 的 pass 声明（白模 = 原来那一条；风格 = scene → pixelOutline → upscale，网格 / 叠加层 / X 光照旧追加）。守卫 ④ 扫 `preset/`。单测 `test/minccino-preset.test.ts`。
- **后端**：`backend/three/screen-pixel.ts` = 小图（颜色 + 深度贴图）→ 像素描边（实验室 `ShaderLab.pixelOutline` 的 GLSL 移植；正交相机那支是新加的：z 在屏幕上仿射，透视那支逐字照实验室）→ 整数倍最近邻放大回画布并写回深度。`render3.ts`：叠加层专用的 three 层（第 5 层；1 / 2 是 XR 左右眼）——网格、三轴、叠加层线点标记文字、X 光线住那一层，风格那条路里按原分辨率最后画、被写回的深度挡；白模那条路相机两层都看 = 同一批对象同一个顺序（基线 0 差为证）。小图用 view offset 让「k × 小图」恰好从画布左下角铺起，叠加层和像素逐格对齐。面 shader 加「不打光」开关（uniform 分支，白模下表达式不变）；贴图过滤跟预设走（只改采样，不改资产）。血槽位把几遍的 draw call 加起来、显存加上小图。
- **入口**：视图 ☰「显示」页「风格」下拉（白模 / 像素描边），按设备记（`ui.style`），选了提示行披露画面会怎样。**风格是视图**：不进文件、不标脏、不进撤销。
- **退回白模的两处（如实说）**：XR 会话里（小图 / 放大还没接两只眼）、缩略图（缩略图 = 模型本身）。探针 `test/probes/probe-style.mjs`（规划器按预设排 pass、缩略图逐字节 = 白模时截的、XR 只排白模、切回白模 = 原来那条）。
- **基线**：新加 `style-pixel-sel`（选中顶面 + 锁 X 轴线 + 悬停：选中面跟着像素化、锁轴线 / 网格按原分辨率）、`style-pixel-house`、`style-pixel-textured`（贴图最近邻）。我看过三张图：像素格、一格深色外轮廓、网格被模型挡都对；贴图盒右上角有一格灰 = 盒子背面在掠射角漏出的一格（风格不画模型线稿，实验室也一样）。
- **和实验室不一样的（待 user 调视觉）**：① 没上色的面用 CatsUp 白模灰（实验室平涂的「自己的颜色」是暖白 #f2efe8；CatsUp 的颜色烤在顶点色里，换底色要重建池网格，等材质模块接上再说）；② 实验室有地面（#f6d39c）+ 脚印影子，CatsUp 用自己的地面网格代替；③ 没上色的模型在这个风格下是一整块剪影（不打光 + 内部只在深度错开处描线）——实验室同样如此，这个风格本来是给有颜色的模型的。
- **没验**：真机零（iPad 设备像素比 2 时一格 = 6 个设备像素 = 3 CSS 像素，按算法应如此）；性能没量（小图是 1/9 的像素，加两遍全屏，按理比白模便宜）。

### 剪纸 · 色纸（v0.17.11，2026-10-29 Claude Opus 5.5）
- **预设形状扩了三样**：材质挂点 `shade: "flat"` + `flat`（纸色、阴影偏色、明暗强度、渐变、色阶、交界软硬、光的方位 / 高度）+ `colorize`（model / part）；光与环境挂点 `ground`（z = 0 的纸色地面）+ `ao`（强度、模型上 / 地面上的长度、影子边的软）。`presetPasses` 给剪纸排 aoBake → ground → scene（追加）→ 网格 / 叠加层。
- **后端**：`backend/three/ao-bake.ts` = 实验室遮蔽服务移植（斐波那契 20 方向正交深度图，拼成 5 × 4 图集，按场景包围球换算，`aoAt` 数学逐字照实验室）；`backend/three/paper-shader.ts` = 实验室 flat.js 剪纸用到的那几段（光跟着相机、色阶 + 交界软硬 + 渐变、阴影乘偏色、刻面感 1 = 屏幕导数求面法线）+ 地面一遍全屏（像素射线打到 z = 0，地上的多重阴影 = 同一份遮蔽、半径放长）。地面住 three 第 6 层（烘焙相机只看第 0 层，地面不挡自己）。
- **遮蔽什么时候烘（后台作业的小学版）**：第一次立刻烘；之后内容变了（提供者的内容键）先记下，**停手 0.25 秒才重烘**，后端自己要一帧（`onRedrawWanted` → editor.draw）。拖着改的时候影子停在上一份——写进预设说明，选了提示行就说。烘的毫秒记在 `perf.last.aoBake`；图集显存（512² × 20，颜色 1 字节 + 深度 2 字节 ≈ 15 MB）算进血槽位。空场景不烘不遮。
- **一件一色**：材质色 = 色纸；没上色的面 = 纸色 #f2efe8；贴图面 = 纸色（一件一色印不出贴图）。**过渡做法**：颜色还烤在顶点色里，纸的 shader 把白模灰（PALETTE.face，8 位量化后差不到 1/127）认出来换成纸色——换风格不用重建池网格、截缩略图也不用；材质模块接上槽表（baseColor 默认）后退役。代价：材质色恰好等于白模灰的那张面也会被当成纸。
- **探针** `probe-style` 加四条（剪纸的 pass 顺序、第一次就烘、改了马上画不重烘、停手后自己重烘）；单测加剪纸的规划和参数检查。**基线**加 `style-papercut-boxes`（两个盒子：零件之间、贴地处的多重阴影）、`style-papercut-painted`（材质色 = 色纸）。我看过：地上一层层硬边影子、大盒朝小盒那面被小盒从几个方向投出碎片状的影子（实验室 aoSoft 0 的「硬边碎片感」）、纸色地面都对；painted 样本侧面那道细线 = 样本自己两段盒子中间夹的一张红面在掠射角被多重采样漏出一点（白模里黑线盖住了），不是风格的毛病。
- **和实验室不一样的（待 user 调视觉）**：① 地面在 z = 0（CatsUp 的地面；实验室在模型最低点）；② 实验室地面上那团「脚印影子」（0.1）没接；③ 遮蔽的「场景半径 = 1」按整个场景的包围球算——场景很大时，同样的参数影子相对变长；④ 选中 / 悬停的面也用纸的 shader 画（选中色被纸的明暗压一点）。
- **没验**：真机零；烘焙在大场景上多贵没量（20 遍画全场景，停手才烘）。

### CRT Tron（v0.17.12，2026-10-29 Claude Opus 5.5）
- **预设形状又扩三样**：材质挂点 `shade: "tron"` + `tron`（正 / 背面色、明暗、轮廓光、线色、线芯、线宽、轮廓倍数、被挡边、认领的选中色）；后处理挂点 `bloom`（强度 / 半径 / 上限 / 暗角）；屏幕一刀 `rows`（分辨率上限：最多几行，整数倍铺满、不留黑边）+ `look`（none / crt-tv）；地面加 `grid`（Tron 地格）。`presetPasses` 通用化：地面 → 模型 →（辉光那遍 → 辉光 → 合成 | 描边）→ 放大。
- **后端**：`tron-shader.ts`（面 = 不借色的正 / 背面深色 + 视空间一盏光的明暗 + 轮廓光，选中面认领成 Clu 橙；线 = 给 CatsUp 现成的线几何换青色线材质，粗线照 SU 轮廓线那套按实例判剪影 ×1.3；被挡住的边 = X 光那两个节点换「深度反测 + 半透明」搬到模型那一层）；`bloom.ts`（四级降采样 + 横竖高斯 + 合成：0.30 / 0.30 / 0.25 / 0.25 × 1.6、tanh 上限、暗角，实验室原式）；`screen-pixel.ts` 拆成「描边」「放大」两步，放大加 CRT 电视外观（实验室 SCREEN_FS 的色度横糊、电子束横向连续、荧光粉晕、越亮越粗的扫描线、荫罩、四角暗、深灰底）；地面那遍加 Tron 地格（小格 1/4、大格 1 = 场景半径，按距离淡出，辉光那遍只出地格的光）。
- **踩到的坑**：LineSegments2 画之前拿画布的 CSS 视口当分辨率，不管当前画进的是小图——小图里的粗线只剩四分之一宽、斜线断成点（截图基线 `style-tron-house-thick` 抓到的）；线宽乘「画布 CSS 高 ÷ 小图高」修了。白模 / 像素 / 剪纸那几条路的粗线都在原生分辨率，不受影响。
- **基线**加 `style-tron-sel`（两个盒子、选中顶面 = 橙色、像素线）、`style-tron-house-thick`（粗线 + 轮廓加粗 + 房子样本；房子左墙是暗红 = 那面的背面朝外，Tron 的背面色把面的朝向露出来了，实验室同理）。我看过两张：青线连续、辉光、被挡的边淡淡透出、地格、CRT 扫描线 / 荫罩都对。探针 `probe-style` 加两条（Tron 的 pass 顺序、显存估算有数）；单测加 Tron 的规划。
- **和实验室不一样的（如实说，待 user 看）**：① **屏幕不弯**——CRT 电视的弧面会让按原分辨率画的叠加层和拾取对不上，等屏幕一刀接上鼠标逆变换再弯；② **没有街机机框**（实验室是页面上叠的一张图）；③ **扫描线那道光不跑**（实验室 pulse 随时间扫过模型；CatsUp 按需画、不常驻循环）；④ **被挡住的边是实线**（实验室 8 像素一节的虚线）；⑤ **线芯发白取整根**（实验室按离线中心的距离渐白；1 像素线差别很小）；⑥ 分辨率按「最多 240 行、整数倍铺满」（实验室是固定 320×240 留黑边）；⑦ 选中认领色 Clu 橙 #ff9a2e 是我挑的；⑧ 编辑器自己的地面网格是正片叠底，深色背景上看不见（Tron 自己的地格替它）；⑨ 上下文之外的淡出在 Tron 里看不出来（Tron 不读顶点色）。
- **没验**：真机零；性能没量（小图 + 辉光图两遍场景 + 12 遍模糊 + 合成 + CRT，全在 240 行上，按理不贵）。
