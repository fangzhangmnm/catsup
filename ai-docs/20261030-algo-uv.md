## 已拍的边界（摘自讨论日记）
- 一套 UV、打包只平移不旋转、像素不变；UV 存像素坐标；UV 点吸到**像素角**（单色面挤到调色板格时用中心）；非 2 的幂，导出给老机器时补空白。
- 没有 UV 页签，只有右键：自动生成 / 整理（只平移，无损）/ 重采样（明着做）；旧岛钉死；专家兜底微调几个点；界面不说 UV。
- 有机展开的目标 = Blender「最小拉伸」+ 按密度分面积（保角不对）；用户只管像素密度（px/m），脸单独一个物件。
- 分岛：硬边 = 线稿，照 WeebPaint 线稿填色推区域（补缺口 + 填区域）；Ptex = 每面一岛的退化情况。
- 出处：`talks/20261030-bodypaint-kernel-uv.md`、`talks/20261030-pixel-uv-straighten.md`。

## 展开（把一块摊平）
- Blender「最小拉伸」那一类（拉伸和压缩都罚；好像是对称狄利克雷能量那一派）——目标。
- **防边界重叠的变体**（展平后整体不压到自己，2015 前后）——user 点名。
- 尽量刚性展开（2008，角度和面积一起顾）。
- 边界优先摊平（2017，能指定岛角 90° → 矩形、能放锥点）。
- 整数格映射（2013 前后，参数线落在整数格 = 像素对齐）。
- Blender「跟随活动四边形」和拉直 / 矩形化插件。
- **按面积比例拉直**（user「这个我真的想做」）：Opus 起步想法——带子拉成矩形网格，log 列宽 + log 行高 ≈ log 面积的最小二乘（行效应 + 列效应的闭式解），再按总像素预算最大余数取整；锥形误差超阈值就横切成几段（Q3 待拍）。

## 分岛 / 找缝
- **硬边 = 线稿 + 补缺口**（拍了）：WeebPaint 魔棒的「线稿闭合」（论文法）和「形态学容隙」（笨但可预期）在 3D 上的对应；线 = 硬边 + 开口边界 + 材质分界；填区域 = CatsUp「到锐角为止」那套。
- 沿高角亏顶点连最短路径切开（Seamster 一类，2002）——展不平时补切用。
- 按近似可展分块（D-charts，2005）。
- 缝长和变形一起优化（Autocuts / OptCuts，2017–2018）。
- 图割 / 最大流（user 提过）。
- 非流形拆分：配对**不是**确定的（只有当双面看时唯一）；推荐挑法 = 同材质 / 同区域 > 平滑配、硬边分 > 最平的延续 > 随便。
- 低模捷径（认可）：认四边形带 → 沿最不显眼的纵边切 → 拉成矩形；帽顶 / 极点 / 三角扇成小岛；乱的退化成 Ptex。
- 纸模展开（Pepakura 类，零变形）+ 导出折纸图谱（愿望单）。
- 彩蛋：圆域映射（带洞的兔子 → 圆盘 + 圆洞），界面标「不推荐使用」。
- 展平后重叠怎么办（Q2 待拍）：再切一刀（推荐默认）/ 多容忍拉伸 / 镜像两半故意重叠共用像素（镜像物件的选项）。

## 打包 / 填边 / mipmap（user：「也许得跟着uv」）
- 只平移不旋转的打包；画布不够就加大；「整理」= 只平移的重排（无损）。
- **按缝延展的防渗填边**：岛外一圈填「缝对面那一侧的颜色」，不是简单往外扩（防渗色 + 带透明时的外扩边 = 家规级必须，不是选项，user 10-30 属性制度那轮）。
- **每个岛自己画 mipmap**：在自己的范围里缩、再沿缝填边，不让邻居岛渗进来。

## 体检
