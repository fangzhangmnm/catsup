# 键位：到 11-13 夜为止定了什么、还开着什么（现行表）

> created 2026-11-13 by Claude Fable 5.2（Catsup统筹）· as-of 三维开发版 v0.19.109（11-13 深夜 user 又回了一轮 = talks 第十六轮，已并进来）
> **这一页是什么**：11-13 夜 user 用键鼠重做小屋子时逐键批的结果，收成一张现行表。原话和来回的经过在 `talks/20261103-keymap-blender.md` 第三到十五轮；两处冲突时以这一页为准。键位的施工单 = `20261113-keymap-workorder.md`；动键表照施工单的刀来。
> 标记：〔定〕= user 明说的；〔倾向〕= user 说了倾向、没明说定；〔统筹〕= 统筹提的或顺着推的，user 没反对；〔已发〕= 已经在开发版里。

## 一、总原则〔定〕

- 硬表面的键一律往 Blender 靠。两个建模工作台除非有明显理由，快捷键都要、都一样（两种建模来回切是 user 的核心做法）。
- 建模和画画是两张分开的表，只共用「到处都一样」那一层。建模对齐 Blender；画画对齐 user 自己的画画软件，再加 Blender 的 F。
- **「动作里外」一条线**：正在做动作（键盘起手之后、取点工具点了第一下之后、鼠标按着拖的时候）= X / Y / Z / N / T 是轴、数字是打数；没在做动作 = X 弹小菜单、1 / 2 / 3 是拾取、回车进数值小窗。拿掉三样夹在中间的：动作之前「先锁」；拿着操作工具没动手时 X / Y / Z 算轴；做完之后数字归数值小窗。
- 多按都是换：一个键对应工具栏一格，多按换这一格里的变体。
- 快捷键拿起的工具是临时的（空心框，做完回原来那把）；快捷键按的锁也是空心、只管这一下。触屏不需要快捷键，快捷键这些只管空心的，不管实心的。
- 选区的编辑和蒙版的编辑要有不靠键盘的路；新功能先放进现成的右键菜单和马后炮，系统的整理等功能做全之后 user 说设计。
- 轴键怎么读 = `20261113-axis-constraint-module-design.md`。

画截面的工具（F 矩形、C 圆，两边同一套；自由建模里是新做的）〔定〕：
- 落在哪个面：光标下有面贴着面，没有面落地面；轴键改（见轴键的设计稿）。
- 在面里朝哪边：贴在面上顺着离起点最近的那条边，落地面顺着世界的轴；任意角度用旋转矩形。
- 从中心还是从角：多按 F 换；自由建模默认中心矩形，硬表面默认角到角，各记上一次。
- 画完新面自动选中。自由建模里新面是独立的一张、不切底下的面（「自由建模就是很任性的穿模的，甚至鼓励穿插」）；硬表面照旧切进去。
- 拉出（Shift+A）和它们都留；F / C 做出来之后，拉出里平的截面慢慢去掉。

别的已经定的：硬表面里不要 F 补面（该补的时候画一条线或一个矩形）；选面不自动选线、选线不自动选点；对种类敏感的操作按最高维的来，选区里有东西没参与要说一句；替换档单击点中已选着的 = 选区不变〔已发 v0.19.100〕。

## 四、画画工作台

定了的〔定〕（11-13 深夜 user 逐条回的，原话在 talks 第十六轮）：
- 工具栏上有「选」那把箭头工具，能一直拿着改选区。选的是面；选了面 = 笔、橡皮、油漆桶只落在选中的面上，什么都没选 = 哪里都能画。专门的遮罩以后再说（user：「选区当遮罩其实有时候不是很舒服」）。
- 键照画画软件的手感：B 画笔；E 橡皮（按住 = 临时橡皮）；I 吸管；G 油漆桶（多按换变体）；C 颜色面板；R 参考；[ ] 微调大小；Ctrl+D、Ctrl+Shift+I 当取消选择和反选的别名。
- F 拖动调笔刷大小：小的时候按比例走、大的时候线性；两边用同一套换算，三维先做、画画软件照抄（家族周账 F-279）。Shift+F 拖动调浓度。
- **L = 套索**（user：「套索比较重要，所以 L 还是优先是套索吧」；改掉了第十轮的「L 是选连着的一块」）。只改画画工作台，两个建模工作台里 L 照旧（统筹的读法）。
- 选连着的一块：切到「选」里再选。user 的原话是「就用删机」，统筹读成「双击」，没确认。统筹的提议：画画的「选」里双击和三击都是连着的一整块（硬表面的「选」现在是单击这一个 / 双击面连同它的边 / 三击连着的一整块；画画里只能选面，「面连同边」那一档是空的，跳过）。
- H 仍是隐藏；不做平移（user：「平移没怎么用」）。
- 油漆桶在硬表面是 B、在画画是 G：认了。
- 滚轮只管视口和小窗里的画，不调笔刷。Delete 和 X 不许删几何。

统筹顺着定的：套索自己占工具栏一格、L 拿起它，里面的变体（圈一块填色、圈选区、图章）多按换；原来打算放在油漆桶格里的「圈一块填色」挪过来。套索做出来之前 L 在画画里不绑东西。

## 五、还开着的

1. 画画里「选连着的一块」是不是双击（上面那条读法和提议）。
2. 藏面带出来的两件（已告诉 user，不急）：导出时藏着的东西出不出（现在工程文件原样带、glb 藏面不出而藏着的物件照出带标记、OBJ 都不出，表单没说；统筹建议统一成照样导出）；选着一条边按 H 是只藏这条线（现状，和硬表面同款）还是像 Blender 连挨着的面一起藏。
3. （已定：「验证」工作台里画线也是 K，写进键位施工单第 3 刀；统筹定的。）
4. 触屏上的锁按钮怎么对应轴键那一套（以后再定）。

这一轮定掉的：矩形 = F；硬表面 1 / 2 / 3 要；Alt+A 留着；卷尺 T 留着；只选点、边、面时界面上一直挂显眼的小标记 = 要；自由建模里移动 / 旋转 / 缩放做完回车改数 = 要（排在锁那一轮之后）；移动这些工具里点空白不取消选择。

**视图那一组不做**（user：切换视图「用的非常少，可以先不用担心它」；硬表面这套交互是给斜着看设计的，正视图里没法用，「我们的轴锁实际上把视图这个给基本搞掉了」）。现有三个（缩放到全部、缩放到选区、X 光）不动；Shift+Z 动作之外照旧是缩放到全部。
