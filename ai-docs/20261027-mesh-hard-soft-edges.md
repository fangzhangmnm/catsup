# 网格体的硬边 / 软边：明暗方式 + 手标，造面怎么继承，硬表面和软角色怎么做

> created 20261027 by Claude Opus 5.5 · as-of v0.15.26 / 2026-10-27 深夜 · 纪元账本 FM129 · **设计稿，还没做**
> user 2026-10-27 原话（照录）：「网络体应该也有硬边软边，然后想一下不同的造面方法应该怎么继承，想一下我想做硬表面和做软角色，怎么办」

## 1. 现状（代码里查过的）

- 网格体的每条边已经有两个标记（`mesh/mesh-kernel.ts`）：**软**（不画线、点不中）和**平滑**（两侧明暗连续）。存进文件（`CATSUP_mesh` 的 edgeFlags），SU 体转网格体会带过来（`scene/kinds.ts`），导入 glb 时按角度一次性烤成标记（`mesh/ops/shade.ts`，Fable）。
- 缺的三样：
  1. **自由建模里没法标**：硬表面那套「软化 / 硬化选区」和橡皮 Ctrl 只对 SU 体。
  2. **造面的操作不管标记**：挤出 / 插入 / 新建出来的边一律什么都不标（= 硬）。例子：一根转过来的平滑圆柱，把顶面挤出去一截，新长出来那段侧面是一棱一棱的。
  3. **自由建模里软边看不见、点不中**（`pick.ts` 软边不可拾、`render3.ts` 软边不画）：转过来的圆柱，侧面那些竖边选不到，也就没法环切 / 挪它们。

## 2. 推荐：每个网格体一个「明暗方式」+ 手标覆盖

不给每种造面操作各写一套继承规则，而是让**几何自己决定大部分边**，人只在想改的地方手标。

| 明暗方式（每个网格体一个，马后炮 / 物体右键里改） | 一条没手标的边 | 适合 |
|---|---|---|
| **按角度**（推荐默认，30°，Blender 默认也是 30°） | 两侧面夹角小于 30° = 平滑，否则硬 | 硬表面：道具、建筑、机械；也是新建基本体的样子（16 段圆柱侧面 22.5° 自动平滑、盒子 90° 自动硬） |
| **全平滑** | 平滑 | 软角色、布料、有机体 |
| **全硬** | 硬 | 低多边形风格 |

**手标** = 右键边菜单「标成硬边 / 标成平滑 / 清除标记」（网格体指令，一步撤销），手标永远压过明暗方式。文件里多存一位「手标硬」（`CATSUP_mesh` minor +1，老文件照开）。

为什么这样而不是逐个操作定继承：按角度时，新长出来的边绝大多数不需要规则——挤出一个 16 段圆柱的顶面，侧面竖边夹角 22.5°，自动平滑；帽子那圈 90°，自动硬。要定规则的只剩手标那几条。

## 3. 手标怎么继承（只管手标；没手标的边交给明暗方式）

| 操作 | 新边 | 手标怎么来 |
|---|---|---|
| 切割 / 环切切开一条边 | 切出来的两段 | 都继承原边（现在就是这样，`split.ts`） |
| 挤出面 | 帽子那一圈 | 继承原边界那圈的手标（帽子是原面的复制） |
| 挤出面 | 侧面竖边 | 不标 |
| 挤出面 | 原来的边界（现在夹在老面和侧面之间） | 原手标留着 |
| 挤出边 / 点 | 新边 | 不标 |
| 插入 | 新的一圈和连接边 | 不标（在面内、夹角 0 → 按角度时平滑，明暗不断） |
| 溶解 / 合并（两条边并成一条） | 并出来的边 | 见 §6 第 3 问（现在网格体是「有一条就有」，SU 体是「两边都有才有」） |
| 新建基本体 | 全部 | 不标 |
| SU 体转网格体 | 全部 | SU 的平滑边 → 手标平滑；SU 的硬边里夹角小于 30° 的 → 手标硬（不然转过来以后明暗变了） |
| 导入 glb | 全部 | 不再烤标记，明暗方式 = 按角度（和现在烤出来的结果一样，以后改角度不用重新导入） |

## 4. 两种工作流

**硬表面**（道具、建筑、机械）：明暗方式「按角度」，大部分时候不用管。想让一条锐角看起来圆 = 标平滑；想让一条缓弯有棱 = 标硬。棱角接高光要靠倒角（bevel，wishlist，和插入的「点 / 边的倒角」是同一件事）。

**软角色**：明暗方式「全平滑」。用挤出 / 环切 / 插入搭低模（四边形为主），关节处多加几圈环切；要折痕的地方（眼皮、衣服边、指甲）标硬。真正圆润要靠**细分曲面**（Catmull-Clark）：推荐做成一条明确的指令「细分一次」，结果烤进网格（一步撤销），**不做常驻的修改器**（user 10-27「历史不存在，只有被打歪的原子」）。以后再加「折痕权重」（边半硬）。

## 5. 自由建模里线怎么画

推荐：**编辑这个网格体的时候，所有边都画、都能点中**（平滑边画淡一点）；退出到外面一层 = 只画硬边和轮廓（同 SU）。不然 §1 第 3 条：转过来的圆柱侧面的边选不到。

## 6. 要 user 拍的（都有默认）

1. **明暗方式三档 + 手标覆盖**这个模型行不行？默认「按角度 30°」？
2. **自由建模编辑时，平滑边也画出来（淡）、也能点中**？（默认：是）
3. **两条边并成一条时手标怎么算**：「两边都有才有」（和 SU 体一致，默认）还是「有一条就有」（网格体现在这样）？
4. **细分曲面**：做成一条「细分一次」指令（烤进网格），排在硬软边之后？（默认：是，排后面）
5. SU 里「软」（不画线）和「平滑」（明暗连续）是两件事。**网格体要不要只留一个「平滑」，线跟着明暗走**（硬边画线、平滑边不画）？（默认：只留一个；转回 SU 体时两个一起设）
