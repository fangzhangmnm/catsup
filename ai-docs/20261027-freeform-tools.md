## 0. 一句话

自由建模工作台管**网格体**（双击进去自动切过来）。工具和硬表面**同一个 id、同一个快捷键、同一套「点几下」语法**（user「不要一个工具在不同模式下面语义和用法差太多」），差别只有三处：**不推断**（拖多少走多少，FM24「永远不吸是日常」）、**拉总是长新几何**（= SU 推拉的 Ctrl 档）、**做完的新几何留在选区里**（FM14，接着挪 / 缩）。

## 1½. 显示（v0.15.19，纪元账本 FM113）

- 自由建模里活动物体的**全部顶点画成小黑点**；选区覆盖的点（选中的点 + 选中的边 / 面的角）画成蓝点——不画「半截边」。
- **不悬浮高亮**（user「自由建模模式不要悬浮高亮」）：工具都不写 hover；刀只在落点画一个吸附小标记。
- 选中的面：在它自己那个物体节点下、用和面本身同一组三角 / 同一个材质画在后面（深度逐位相同、后画的赢 = 换颜色，不 z-fighting；v0.15.22）。切割的刀线永远画、在最上层，切不出来 = 灰。画板光标 = 普通箭头（user「不要用十字鼠标」）。
- 左柱 = 工作台自己定死的一列（`main.ts MODE_RAIL`）：选择 · 挤出 · 移动 · 旋转 · 缩放 · 切割 · 删除 · 插入（删除 / 插入做出来才露）。**界面上一律两字词，和硬表面对齐**（user 10-27「用两字词语吧和硬表面对齐」）；这份表里的单字（挪 / 转 / 缩 / 刀 / 删 / 插）只是讨论时的简称。

## 2. 全部工具共用的规矩

- **一个手势 = 一条 op = 一步撤销**；op 按内核 id 寻址（网格体是数组制度，id 稳定、克隆保号），重放逐字一样。
- **目标与做完的选区**（user 10-27，FM117）：一开始有选区 = 作用于选区，做完留选区（挤出：新几何成选区）；一开始没选区 = SU 手感，作用于按下处那一个，做完还是没选区、接着挑下一个。悬停不高亮（FM113）。
- **轴心** = 目标点的平均（FM7「各工具自己管轴心」，不做 Blender 的全局轴心设置）。
- **拖动量**都在「过轴心、垂直于视线的平面」上量（不是硬表面画图用的「最朝向镜头的轴平面」——等轴视角下那是地面，锁 Z 就拖不动了）。
- **锁** = 方向键（→ X、← Y、↑ Z、↓ 解锁；Shift+方向键锁面），和硬表面同一套；手势落定自动解锁（SU 同款）。
- **预演**：拖的时候在网格体的一份拷贝上跑同一条 op（类型数组，几毫秒），真身不动；松手才提交。
- **工作台守门**：网格体里按硬表面才有的工具键（画线、圆…）不会跳进硬表面建模，提示一句；SU 体的菜单动词（建组、镜像、软化…）在网格体里不露。
