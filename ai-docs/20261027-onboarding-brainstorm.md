# 新手怎么知道 CatsUp 能做「不是 SketchUp 的模型」：脑暴

> created 20261027 by Claude Opus 5.5 · as-of v0.15.19 / 2026-10-27 深夜 · 纪元账本 FM114（user「然后到时候帮我propose一下新手引导，现在如何切换模式我觉得很多人都会被卡住，我觉得顶栏模式切换还是加一个转为自由建模的选项比较好？不过也不一定，关键是一个不熟悉我们的新手怎么知道我们可以做非su的模型？帮我脑暴一下」）
> **都是脑洞，不是要求**；每条写「做什么 → 得什么 → 会错过什么」。末尾是 AI 的排序建议。

## 0. 现在卡在哪

进自由建模要四步、而且每一步都看不出下一步：画一个东西 → 建组件 → 浮条「转成网格体」→ 双击进去，左上才变成「自由建模」。左上下拉在 SU 体上只列「硬表面建模 / 表面」，新手根本看不到「自由建模」这个词。导入的 glb 倒是直接是网格体，但没人告诉他双击进去就能捏。

## 1. 点子

1. **左上下拉永远列「自由建模」**（user 的想法）：在 SU 体上选它 → 一张小面：「自由建模管网格体。把选中的组件转成网格体 / 新建一个网格体立方体 / 取消」。
   得：词一直摆在眼前，点一下就知道怎么去。错过：下拉不再只是「切工作台」，多了一个会改模型的入口（要说清楚会转换、丢什么）。
2. **新建文件时选起手**：「空白（SketchUp 式）/ 一个网格体立方体（Blender 式）」。
   得：两种人第一秒就各自上手，Blender 用户看到默认立方体就懂。错过：多一步；以后要第三种（绘制 / 物理）还得加。
3. **右键菜单「新建」**（user 10-27「创建物体可以放右键」）：空白处右键 = 新建网格体立方体 / 平面 / 圆柱；选中组件的右键 = 转成网格体 / 转回 SU 体。
   得：会右键的人（大多数桌面用户）自己摸得到。错过：iPad 上长按才出来，发现率低。
4. **图库里放两个样例**：一个 SU 小房子、一个网格体小红帽白模，打开就能各自进去看。
   得：「原来还能做这种」一眼可见，也是最好的教程。错过：要做、要维护样例文件；图库归 gallery 包（样例怎么放要和库对齐）。
5. **碰壁时提示**：硬表面里做 SU 做不到的事（把一张面拖得不平、想单独挪一个点又不想折面）时，提示行加半句「想自由捏？试试自由建模（网格体）」。
   得：在最需要的那一刻出现。错过：提示行已经很挤；做得不好就是唠叨。
6. **第一次打开的三张卡片**：硬表面 / 自由建模 / 表面，每张一个十秒动图，点卡片 = 进对应的起手。
   得：一次讲清。错过：大多数人会直接关掉；家族 zen「别让用户被踢下去」——卡片不能挡路。
7. **导入 glb 后的一句话**：「导入的是网格体：双击进去就是自由建模；要用 SketchUp 那套工具，先『转回 SU 体』」。
   得：导入的人马上知道两条路。错过：只覆盖导入的人。
8. **改词**：「转成网格体」对新手陌生，改成「改用自由建模（转成网格体）」；左上下拉里分组写「SU 体：硬表面建模 · 表面 ／ 网格体：自由建模」，不能用的灰着并写一句为什么。
   得：不加功能、只改字，就能把「两种物体、两种做法」讲出来。错过：字变长；iPad 竖屏上下拉要够宽。
9. **宣发**：B 站 / YouTube 一支「SketchUp + Blender 二合一」的短片（宣发文案归 user）。

## 2. AI 的排序建议

先做 **8（改词 + 下拉分组）+ 1（下拉里一直有「自由建模」）+ 3（右键新建 / 转换）**：都在现有界面里、不挡路、桌面和 iPad 都够得着，一晚上能做完。再做 **2（新建时选起手）** 和 **4（样例）**。5 / 6 先不做（唠叨 / 挡路的风险）。

## 3. 要 user 拍的

1. 先做 8 + 1 + 3 这三样，可以吗？（默认：做）
2. 1 里那张小面的第二个选项「新建一个网格体立方体」放在当前所在的地方（根上 = 新建一个组件），可以吗？（默认：是）
3. 2 和 4 要不要排进本轮冲刺？（默认：不排，记 wishlist）
