## 关键设计决策（为什么这么做）

1. **face 是存储态非派生量**（公理 4 修正版）→ findRegions 输出不直接替换 face 集，而是按 mutation 类型 reconcile。face↔region 匹配用**几何 anchor**：面的 representativePoint（扫描线取内点）落在哪个新 region 就是后继。region 互不重叠 → 无歧义。
2. **手势边语义**是 BIRTH 的裁决依据：`created`（沿画线新生）+ `retraced`（与既有边重合）是手势边；**既有边被切开的子边不是**（T 触碰空环不生膜）。手势边被同批后续段切开时经 onSplit 回调继承身份。BIRTH 只看无主 region 的**外环**是否含手势边（在空环里画小方生的是小方，不是外圈环带）。
3. **erase 无条件按 loop 身份裁决，不做覆盖查找**：外环对 void 被擦 = 无条件 BURST。若做覆盖查找，回字内填外空擦内边会把面错误长满外方（「intention 被结构化成了 loop membership」）。内环/桥缝 = 存活整理（ABSORB）；两面共享 = MERGE（union-find 支持批量链式并）。
4. **批量语义**：裁决快照以批开始时的环结构为准，再统一删除（删除顺序无关）。并组被 burst 污染 → 整组死——与逐条串行擦的任一顺序结果一致（测试钉了）。
5. **move 守恒零成本**：moveVertices 不传手势边集 → 结构上不存在 birth 路径。sticky 三件套：落点撞顶点=合并、落他边内部=切开再并、拖出交叉=rip & reinsert。
6. **id 纪律**：DIVIDE/MERGE/ABSORB 退休旧 id 铸新 id（事件携带血缘）；延续/STRETCH 保 id。
7. **局部性接缝已留**：`findRegions(g, region?)` 的 region 参数 M1 忽略（整平面重跑）；增量局部 face-finding（spec 点名的工程命门）以后在接缝内换入，接口不变。

## 暗礁①已钉推导值（待真机 SU 裁决）

三层回字（填-空-填）：**擦中环边 = ABSORB**（外膜长满、内方岛经重嵌套变成它的洞）；**擦内环边 = BURST**（内方邻接空环带=void，破防；外环带不受牵连）。两个方向都有 golden 测试。若真机证伪：只改 `face-lifecycle.ts` 裁决规则 + `test/golden.test.ts` 对应断言。
