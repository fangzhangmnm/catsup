## 一、一句话，一张图

**这一轮做成一件事：把这个角色的脸在模型上画出来。** 眼睛是斩杀线：高分辨率，位置精确到可以信任，画完能在视图里反复调。

整个工程是三层：

```
┌──────────────────────────────┐      ┌──────────────────────────────────┐
│ 画画软件自己的界面              │      │ 三维软件自己的界面（画画工作台）      │
└──────────────┬───────────────┘      └───────────────┬──────────────────┘
               │                                      │
               │                      ┌───────────────┴──────────────────┐
               │                      │ 空间层（新写，在三维仓）              │
               │                      │ 这一轮的数学全在这                   │
               │                      └───────────────┬──────────────────┘
┌──────────────┴──────────────────────────────────────┴──────────────────┐
│ 画画内核（两边逐字节同一份；正本在画画仓，三维机械拷贝，只在画画仓改）          │
└─────────────────────────────────────────────────────────────────────────┘
```

| 层 | 管什么 |
|---|---|
| **画画内核** | 手感（滤抖、按间距走步、压感）；把一张薄层合进图层（橡皮、锁透明、混合、选区和蒙版挡着）；图层；撤销的记录怎么产生；小块存储和显卡缓存；在一小块平的图上跑的程序（涂抹那十来步） |
| **空间层** | 屏幕上一点落在模型的哪里（射线，精确到贴图像素）；把笔尖在空间里的形状画成贴图格子里的一张薄层；把一小块平面和贴图互相取放（涂抹用的切平面、套索和贴花用的虚拟屏幕）；补边；怎么铺贴图；面的来历 |
| **界面** | 各写各的 |

内核和空间层之间只交接三样东西：

1. **笔尖的列表**（内核 → 空间层）：手感算完之后的一串笔尖。
2. **贴图格子里的一张薄层**（空间层 → 内核）：这一笔、这一次贴花、这一次填色落在贴图上的样子。
3. **一小块平的图**（来回）：涂抹、模糊要处理的那一小块。

内核里没有相机、网格、三角形；空间层里没有具体工具的名字。

## 二、跳出来看，查出来要改的三处

设计稿是两天里一块一块补出来的。通读一遍，施工部分有三处已经对不上了：

1. **内核不用认「坐标表」了，画画软件要动的地方因此变少。**
   - 设计稿第 2、3 版让内核去认一张坐标表（烤笔画时照表取、浮层变换前后各垫一张表）。
   - 定了「笔在空间里」「落点反算、不查近似的表」「统一按空间做」之后，照表取样这件事整个落在了空间层自己的着色器里。内核只需要多认一种薄层：「宿主已经画好的」。
   - 我核了内核的代码：它现在认三种薄层（笔尖的、填色的、整块替换的），加第四种是照着第一种抄几行、去掉「自己画笔尖」那一步。
   - 所以设计稿里「取样的两处改成照坐标表取」「浮层变换前后垫表」两张工单取消。遍历贴图像素、反查来源这个原则没变，只是做这件事的着色器住在三维仓。
2. **漏了几张工单。**
   - **画画的界面和输入**：进出画画状态、笔和橡皮的按钮、大小浓度硬度、取色、笔和手指的分工（笔画画、手指转视角、防手掌误触）。没有这些，第一笔画不出来。
   - **预算归宿主**：设计里说了「给多少内存和显存由宿主说了算」，没有对应的工单。
   - **存盘和崩溃恢复**：一份画比几何大得多。存盘的大小、崩溃快照带不带画、没在画的画在显卡上只留一张合成图，这些是数据安全的事，要单列。
   - **变换手柄的数学**：画画软件里浮层的手柄（拖角、拖边、三种模式）是纯数学，可以共用；但它和「怎么抬起、怎么放下像素」写在同一个文件里，后者三维这边不能用。要把纯数学单独抽出来。
3. **顺序：共用显卡画面的探路提到最前面。**
   - 它是你定的硬要求，也是最大的未知数。它只需要内核的原样拷贝就能试，不依赖别的工单。先知道它通不通，再投后面的。

## 三、五段路线和每一段的工单

大小是粗分的：小 = 一处改动、有现成的测试罩着；中 = 一个新模块或十来处改动；大 = 要动很多地方或者有没验证的数学。

### 第 0 段：整理内核（在画画仓做，画画软件的行为一个像素都不变）

**入口什么时候露出来**（11-10 夜定）：贴图坐标进文件（1-2½）和画的字节进文件（1-8）落地之前，带着画的文件存不下来。所以在那之前，造得出画的指令只有测试、探针、重放够得着，不进普通界面；写盘碰到存不了的东西就抛，不悄悄丢。1-7 的入口要等 1-2½ 和 1-8 合了才打开；1-3d 最好也赶在那之前，赶不上的话，那几样动作碰到走画的面先明着说「还搬不了」。这个先后是 Fable 的默认，user 可以改。

毕业条件：iPad 上在你自己建的模型上画，手感和画画软件一样；斜面上线不拉长；转视角接着画；改几刀模型画还在；撤销；关了再开还在。

### 第 3 段：铺得好

UV 实验室；硬边当线稿分块；带子拉直（可选项）；最小拉伸；密度；整理（只平移）；重采样（明着做）；自己做缩小图。毕业条件：从零建的整个角色，不知道 UV 是什么也有能看的贴图；加一只手臂，旧的画一个像素不变。

### 第 4 段：接住现成的

贴图独立成条；导入图片；导入带贴图的模型不丢贴图和坐标；材质窗口；导出时两层压成一张。毕业条件：小红帽带着贴图打开，补两笔，导出，Blender 里看是一样的。

### 第 5 段：往后

每件一小版：涂抹和模糊（切平面跟着每个笔尖走）、形状笔、锁透明和混合模式的界面、调色、笔架、贴一张图上去、扒取窗口、扫漆和渍洗、VR 里画。

    - **看和切**：图层树最上面是这个材质的几个槽，每个一个组、各有图标，组里面是那张画的图层。不另做切换槽的东西：选中哪个组里的图层，笔就画哪个槽。每个槽记着自己上次用的笔和上次写的东西。写的东西跟着槽的种类：颜色槽写颜色，「一个数」的槽写 0 到 1，标签槽写一个标签（只能硬边）。组上有「只看这个槽」的开关（数显示成深浅，标签显示成各自的颜色）。
    - **一笔写几个槽**（这一条 user 11-11 认可了：「每个组的行上有一个『吃不吃这一笔』的开关。亮着的槽都吃这一笔，当前图层所在的那个槽总是亮的 nice ui feedback! gret!」）：每个槽栏的行上有「吃不吃这一笔」的开关，亮着的都吃，当前图层所在的槽总是亮的；一笔写到哪里是看得见、user 自己点的，不藏在笔里。材质笔 = 一个预设，带着每个槽各写什么，选它就点亮那几个槽并填好值。吸管对应地吸一整套。一笔写几个槽是一步撤销。
    - **存法：每个槽一张独立的画，不做「一个图层里装好几个槽」**（那要内核的图层变成多通道的）。一笔同时落到几张画上，就是已经有的「一笔画到几张贴图、算一步」。几个槽同一套坐标时，笔尖的覆盖只算一次、各自上色。代价：各槽的图层各管各的；以后想要「关一层、几个槽一起关」，在界面上加联动的图层（把几个槽里的几层绑成一行），不动内核。这一句只是记一笔，不设计。
    - **界线**：笔的形状、手感、笔架是内核的东西，在共用的 `paint-panels` 里；「每个槽写什么」「写哪几个槽」是三维这边材质的事，内核不知道有槽，存在三维这边、叠在笔架上面。
