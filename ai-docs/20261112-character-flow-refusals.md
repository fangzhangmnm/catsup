# 做人物那一趟：每一步之后哪些动作会被拒（只查不改）

> created 20261112 by Claude Opus 5.5 · as-of v0.19.68 / 2026-11-12
> 起因：统筹 11-12（user 说的「群不闭合」）：按做人物的顺序——建白模 → 开镜像 → 标接缝、展开 → 开始画 → 上底色 → 细画 → 回头改模型（切刀、挤出、删面、并点）→ 再画 → 画不对称的地方 → 建组件、复制 → 导出——每一步之后，哪些动作会被拒、拒的时候说了什么、有没有别的路。用来定地基还缺哪几块。

## 零、要紧的几条（按挡路的程度排）

1. **导出模型不带画，也不说。** 「导出模型…」出来的 glb 一张图都没有，材质「画」上不挂贴图；状态行照常说「已下载」。原因：导出直接用场景拼文档（`session.exportModelGlb` → `documentFromScene`），画的字节要在存盘的编码那一步（`paintSave.freeze`）才编出来，导出没走那一步。工程文件（.catsup）里画是在的。做人物那一趟的最后一步就断在这里。
2. **带着画的面：建组件、复制粘贴、做成唯一、炸开、转回硬表面，全拒，没有别的路。** 说的是「这些面上有画：带着画的面现在还不能并进别的物件、分出去、做成唯一、复制粘贴、炸开或者转成硬表面（这个功能还没做）」。整个物件复制粘贴可以（两份共用同一个定义、同一张画）；一旦开始画，就不能再把一部分面分出去做成组件，也不能复制一只画好的鞋再改。
3. **进出组件、撤销 / 重做一下选区，都算「改过」**（不该算的算了，和存盘忠实度清点第五节方向相反）。进入组件、退出组件、撤销或重做一步纯选区，文档改动号各加一；全选、取消选择、换工作台不加。后果：只是进去看一眼再出来，文件就脏了——会自动保存，离开时会被问「保存到文件再离开？」。原因：这几处调的 `editor.rev()` 同时加场景改动号（画面缓存要作废，对）和文档改动号（不该加）。
4. **开着镜像画画，另一半不跟着画**（画画的代码里没有镜像）。对称的地方要两边各画一遍；不对称的地方倒是直接能画。第 3 刀已批的「镜像只展开一半、两半共用」补的就是这个口子。
5. **开着镜像改拓扑**（挤出、删面、并点……）：从工具 / 菜单来的会先问「关掉镜像，照做 / 取消」（`mesh/mirror-ops.ts`，`probe-mesh-mirror` 第 ④ 段用真工具验过）。别的路只有关掉镜像，关了之后两半不再同步。

## 一、怎么查的

- 真软件（无头浏览器，v0.19.68 构建）里一步一步做下去，每一步真做、留着；每一步之后把同一串动作（二十二样）都试一遍：做成了没有（文档改动号）、提示行说了什么、问了什么（问话面的标题和选项，自动点「不做 / 取消」退出）、有没有报错；做成了就撤回到这一步的原样。全程页面零报错。
- 白模：盒子 → 做成组件 → 转成网格体 → 进去 → 正中环切一刀（物件原点在底面中心，本地 x 从 −1 到 1，镜像面在正中）。画用真的笔（指针事件，pen），模型操作直接提交指令。
- **脚本的口子，读表时要知道**：
  - 模型操作是直接提交指令，绕过了工具 / 菜单那一层的镜像护栏，所以表里「开着镜像改拓扑」那几格按真界面写（会问），不按脚本看到的（没问）写。
  - 同一条线、同一个颜色再画一遍，像素没变，不算一步，也不说话。这是对的，不是拒绝（第一轮里「跨中线画一笔」在第 5、6 步「什么都没做」就是这个，换一条没画过的线就成了）。
  - 第一轮脚本的找面条件写错了，冒出过两句英文内部错误（「操作失败（提交）：extrudeFaces: no alive faces」「op target vanished: separate: no faces」）——是拿空的面号去调指令，界面上走不到；但走到了就是内部英文直接给人看，记一笔。

## 二、表：每一步之后

「—」= 这一步之后和上一步一样。只列被拒、被问、或者不对劲的；没列的动作都照常做成了（环切、挤出、删面、并点、切刀、插入、细分、挪点、标接缝、开关镜像、整个物件复制粘贴……）。

| 做完这一步 | 被拒 / 被问的动作 | 说了什么 | 别的路 |
|---|---|---|---|
| 1 建白模 | 画一笔 | 「这个物件还没开始画：点上面的『开始画…』」 | 有：开始画 |
| | 回最外层炸开（网格体物件） | 问「炸：要转种类」【不做 / 转成硬表面体再炸】；点不做 =「炸开：没做（你选了不转）」 | 有：转成硬表面体再炸 |
| | 转回硬表面、做成唯一 | 照常（做成唯一只摆一份时说「本来就只摆了一份」） | — |
| 2 开镜像（镜像编辑） | 选几张面复制粘贴 | 问「镜像编辑开着」【不做 / 关掉镜像，照做】 | 有：关掉镜像 |
| | 选几张面建组件 | **没问**，直接做了（和复制粘贴不一致） | — |
| | 改拓扑（真工具 / 菜单） | 问「关掉镜像，照做 / 取消」（见上面第 5 条） | 有：关掉镜像，之后两半不同步 |
| | 画一笔 | 还没开始画（同第 1 步） | 有 |
| 3 自动标接缝 | 再点一次自动标接缝 | 「每一片都已经能摊平…不用补：6 片都已经能摊平」（第一次说「补了 16 条接缝…分成 6 片」） | 不用 |
| 4 开始画（整个物件） | 再点开始画（不选面） | 「这个物件已经有画了，直接用笔画（要给别的面另开一张：先选中那几张面）」 | 有：选面另开一张 |
| | **选几张面建组件** | 「这些面上有画：……（这个功能还没做）」 | **没有** |
| | **选几张面复制粘贴** | 「拷贝：这些面上有画：……（这个功能还没做）」 | **没有** |
| | **转回硬表面 / 做成唯一 / 炸开** | 同一句「这个功能还没做」（炸开先问转种类） | **没有**；整个物件复制粘贴可以 |
| 5 上底色、6 细画 | — | — | — |
| 7 回头改模型（环切、挤出、删面、并点） | 都做成了（开着镜像时真界面会先问，见第 2 步） | 带画的面上改拓扑不拒；画怎么跟着走归施工单十八 | — |
| 8 再画、9 画不对称的地方 | 不拒；开着镜像只画笔碰到的那一侧 | 不说 | 对称的地方要画两遍（见第 4 条） |
| 10 回最外层复制一份 | 复制粘贴整个物件 = 做成（两份共用一张画）；对其中一份做成唯一 = 拒（同第 4 步那句） | | 没有：想改一份的画只能改两份 |
| 11 导出 | 导出工程文件：照常 | | |
| | **导出模型（glb）** | 说「已下载」，**里面没有画** | **没有**（见第 1 条） |

## 三、顺带量到的

- 「算不算改过」逐个量（文档改动号的变化）：全选 0、取消选择 0、选中物件 0、换工作台 0、**进入组件 +1、退出组件 +1、撤销一步纯选区 +1、重做一步纯选区 +1**。
- 画笔不对着镜像：`src/paint/`、`app/paint-workbench.ts` 里没有一处管镜像。

## 四、没查的

- 真工具拖出来的每一种操作（这次只拿真笔画画；模型操作是直接提交指令）。
- 画过的面改拓扑之后画落在哪、有没有糊——归施工单十八。
- 文件夹 / 网盘图库家里的自动保存实际写了几次（只量了改动号）。

## 五、统筹裁定之后补了什么（v0.19.70，2026-11-12）

- 第 1 条（导出模型不带画）：先说实话——模型上有画时，导出面的说明行先写「这个模型上有画，这一版导出的文件里不带画」，导出完的状态行也带上（`session.exportPaintNote`，判据 = 有材质的颜色槽是画 / 平铺的画）。真带上画排在施工单十八之后。`probe-export` ⑦ 钉住。
- 第 3 条（进出组件、撤销 / 重做纯选区算改过）：改了。`rev()` 拆成 `docChanged` / `viewChanged`，规矩和已知多算见存盘忠实度清点页第九节；`probe-doc-revision` 两向钉住。
- 第 5 条的不一致（开着镜像「选面建组件」不问）：补成和「选面复制粘贴」同一道门（`mirrorGateEntry`）；`probe-mirror-ask` 钉住（选面建组件 / 选面复制粘贴 / 删除 / 右键网格体指令都问，取消什么都不动；建组件照做 = 关镜像 + 建组件一步）。

**镜像编辑开着、改拓扑的入口：谁问、谁还没问**（问话住在每个入口自己身上，所以会漏；第 3 刀碰镜像时收成一处按指令判断——统筹 11-12 记的结构问题）：

| 入口 | 问不问 | 在哪 |
|---|---|---|
| 工具（挤出、切刀、插入、拉出……）落下那一下 | 问 | `editor.ts toolCommit → mirrorBlocks` |
| 删除（Delete / 菜单）、剪切（先拷再删） | 问 | `deleteSelection → mirrorGateEntry` |
| 粘贴 | 问 | `pasteClipboard → mirrorGateEntry` |
| 右键网格体指令（环切、连线、插入、倒角、并到中心、复制、补洞、翻面……） | 问 | `runAction` 按 `MIRROR_TOPO_ACTIONS` |
| 选面建组件 | **v0.19.70 起问** | `makeComponent → mirrorGateEntry` |
| 把一个物件炸开进网格体（`explodeSelection` / 物件动作 `explode`） | **不问** | 物件动作不在 `MIRROR_TOPO_ACTIONS` 里 |
| 合并进（物件动词 `mergeInto`：贴 → 炸 → 删）到开着镜像的网格体 | **不问** | 同上 |
| 右键「新建 ›」（`addPrimitive` 直接提交 `meshAddPrimitive`） | **不问**；同一件事用左栏「拉出」工具会问 | `editor.ts addPrimitive` |
| 导入素材 / 素材架取东西落在最外层，最外层是开着镜像的网格体时 | **不问**（少见） | `paste-plan.ts` 导入落在根 |
