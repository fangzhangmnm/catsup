## 二、画布小窗第一版

**是什么**：一个浮着的小窗，显示一张 atlas（一块画布）和排在上面的面。不挡三维、不抢键盘、能拖能改大小、能关。只看，不改任何东西。

**入口**：画画工作台里一颗钮（放哪由你按版图文档定，先改版图文档）；别的工作台里也能开（看数据不分工作台）。开着没有记进文件（这一版只在这一次打开期间记着；以后要跟文件走再加桌面状态的键，那时找统筹）。它是一种会盖住场景的面：进输入闸的名册一行。

**显示什么**：

1. 哪张 atlas：当前物件有几张就能切哪几张（一行下拉）；在三维里点了一张面，自动切到那张面所在的那张。
2. 图：三维里看到的那份合成结果。放大用最近邻，放大到一定程度画出格线。
3. 面的轮廓：每张面在画布上的多边形画成细线；片和片的外沿粗一点。
4. 两边一起亮：三维里选中的面在小窗里高亮；小窗里悬停一张面，三维里那张面高亮、小窗底下一行写它是谁（哪张面、在哪一片、一格多大）；小窗里点一张面 = 在三维里选中它。
5. 调试视图（一个开关）：每格归谁——按归属的那块多边形上色，没人要的格子画成棋盘格。
6. 底下一行数：宽 × 高、一格多大、多少片、面占到的格数占画布多少、几层、文件里占多少（分层那份和合成图分开）、打开占多少显存（用施工单十五的那套记账）。

**怎么取图**：一笔当中不为小窗多做读回（抬笔之后再刷新）；别的时候画板变了才刷新。要是有便宜的办法让它一笔当中也跟着动，可以做，前提是那一帧的花费不涨。

**分两半写，中间一条窄的缝**（为了以后搬进共享库时是原样搬）：

- 一半只认识「一张图 + 平移缩放 + 上面叠一层折线」，不认识三维。
- 另一半是三维这边递进去的东西：画布上的折线、「这个点落在哪张面上」的回调、选中和悬停的集合。

画画内核不认识三维，这条界线不动。

**测试 / 探针**：打开小窗，折线的条数 = 这张 atlas 上的面数；三维里选面，小窗里高亮的是同一批；小窗里点一张面，三维里选中的是它；底下那行数和铺法、存盘算出来的一致；开着小窗画一笔，每帧的读数不涨。

## 三、连成片收紧

统筹定的（小弟报的三条路里）：

- **不做「两种都铺一遍取密的」**。那样同一个模型在不同大小的画布上片的分法不一样，以后换大小时结构会变，小窗里看到的也对不上；大画布上还回到满是缝。
- **做「片太空就不往里收面」**：往片里收一张面之前算一下，收了之后（片里面的面积 ÷ 片的包围盒面积）低于一个门槛就不收，留给后面的种子。门槛是一个常数（一处），先量 0.5 / 0.6 / 0.7 再定。片的分法只看几何，不看画布大小。
- **片的朝向取包围盒最小的**：候选 = 片外沿上每条边的方向，取包围盒面积最小的那个；一样小取种子最长的那条边（所以只有一张面的片仍然和旧铺法逐位相同）。
- 按形状排（片和片互相嵌着放）这一版不做，留给以后的「重新铺紧」。

要量的（回统筹一张表）：四个样子在 128 / 256 / 1024 / 2048 四档，门槛 0.5 / 0.6 / 0.7 各自的片数、填充率、一格多大、最大拉伸；和旧铺法、施工单十五的铺法并排。目标：小画布不退步，2048 见方上追回大部分差距。

**标杆：user 自己给小红帽展的那一份**（user 11-11：「31还是毕竟难看，你可以和我的对标一下，以后慢慢赶」；统筹量的，检疫仓 `littlered.glb` 自带的贴图坐标，256 见方）：

| 量 | user 的手工展开 |
|---|---|
| 被某张面盖住的格子 ÷ 画布 | 61.9% |
| 被两张以上的面同时盖住的格子 ÷ 画布（对称的两半叠着放） | 41.3% |
| 所有面在画布上的面积加起来 ÷ 画布 | 103.9%（一张画布当 1.68 张用） |
| 每张面多少格 | 平均 234，中位数 151 |
| 不同部位的密度（每单位模型面积多少格） | 第 10 百分位 3637、中位数 15327、第 90 百分位 37333（差 10 倍） |
| 拉伸（长短轴之比） | 中位数 1.66、第 90 百分位 2.88 |

以后每次量铺法，小红帽这一行都和它并排报：盖住的比例、每张面多少格。小红帽另外按「开着强行对称」再铺一遍报一次（那才是和手工展开公平的比法）。差距有三块：排得紧（这张单追一部分）、重复利用（对称和合用）、按重要程度给密度（靠一个物件好几张 atlas 和以后的小窗里放大缩小一片）。拉伸不是该省的地方：手工展开的拉伸比我们的门槛大。

不变的：夹角门槛 45°、不重叠、留的格数、`startPaint` 的参数。已经画过的画不重铺（它们的坐标在文件里）。
