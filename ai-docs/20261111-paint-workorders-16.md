## 二、画布小窗第一版

**是什么**：一个浮着的小窗，显示一张 atlas（一块画布）和排在上面的面。不挡三维、不抢键盘、能拖能改大小、能关。只看，不改任何东西。

**入口**：画画工作台里一颗钮（放哪由你按版图文档定，先改版图文档）；别的工作台里也能开（看数据不分工作台）。开着没有记进文件（这一版只在这一次打开期间记着；以后要跟文件走再加桌面状态的键，那时找统筹）。它是一种会盖住场景的面：进输入闸的名册一行。

**显示什么**：

1. 哪张 atlas：当前物件有几张就能切哪几张（一行下拉）；在三维里点了一张面，自动切到那张面所在的那张。
2. 图：三维里看到的那份合成结果。放大用最近邻，放大到一定程度画出格线。
3. 面的轮廓：每张面在画布上的多边形画成细线；片和片的外沿粗一点。
4. 两边一起亮：三维里选中的面在小窗里高亮；小窗里悬停一张面，三维里那张面高亮、小窗底下一行写它是谁（哪张面、在哪一片、一格多大）；小窗里点一张面 = 在三维里选中它。
5. 调试视图（一个开关）：每格归谁——按归属的那块多边形上色，没人要的格子画成棋盘格。
6. 底下一行数：宽 × 高、一格多大、多少片、面占到的格数占画布多少、几层、文件里占多少（分层那份和合成图分开）、打开占多少显存（用施工单十五的那套记账）。

**怎么取图**：一笔当中不为小窗多做读回（抬笔之后再刷新）；别的时候画板变了才刷新。要是有便宜的办法让它一笔当中也跟着动，可以做，前提是那一帧的花费不涨。

**分两半写，中间一条窄的缝**（为了以后搬进共享库时是原样搬）：

- 一半只认识「一张图 + 平移缩放 + 上面叠一层折线」，不认识三维。
- 另一半是三维这边递进去的东西：画布上的折线、「这个点落在哪张面上」的回调、选中和悬停的集合。

画画内核不认识三维，这条界线不动。

**测试 / 探针**：打开小窗，折线的条数 = 这张 atlas 上的面数；三维里选面，小窗里高亮的是同一批；小窗里点一张面，三维里选中的是它；底下那行数和铺法、存盘算出来的一致；开着小窗画一笔，每帧的读数不涨。

## 三、连成片收紧

统筹定的（小弟报的三条路里）：

- **不做「两种都铺一遍取密的」**。那样同一个模型在不同大小的画布上片的分法不一样，以后换大小时结构会变，小窗里看到的也对不上；大画布上还回到满是缝。
- **做「片太空就不往里收面」**：往片里收一张面之前算一下，收了之后（片里面的面积 ÷ 片的包围盒面积）低于一个门槛就不收，留给后面的种子。门槛是一个常数（一处），先量 0.5 / 0.6 / 0.7 再定。片的分法只看几何，不看画布大小。
- **片的朝向取包围盒最小的**：候选 = 片外沿上每条边的方向，取包围盒面积最小的那个；一样小取种子最长的那条边（所以只有一张面的片仍然和旧铺法逐位相同）。
- 按形状排（片和片互相嵌着放）这一版不做，留给以后的「重新铺紧」。

要量的（回统筹一张表）：四个样子在 128 / 256 / 1024 / 2048 四档，门槛 0.5 / 0.6 / 0.7 各自的片数、填充率、一格多大、最大拉伸；和旧铺法、施工单十五的铺法并排。目标：小画布不退步，2048 见方上追回大部分差距。

**标杆：user 自己给小红帽展的那一份**（user 11-11：「31还是毕竟难看，你可以和我的对标一下，以后慢慢赶」；统筹量的，检疫仓 `littlered.glb` 自带的贴图坐标，256 见方）：

|---|---|
| 被某张面盖住的格子 ÷ 画布 | 61.9% |
| 被两张以上的面同时盖住的格子 ÷ 画布（对称的两半叠着放） | 41.3% |
| 所有面在画布上的面积加起来 ÷ 画布 | 103.9%（一张画布当 1.68 张用） |
| 每张面多少格 | 平均 234，中位数 151 |
| 不同部位的密度（每单位模型面积多少格） | 第 10 百分位 3637、中位数 15327、第 90 百分位 37333（差 10 倍） |
| 拉伸（长短轴之比） | 中位数 1.66、第 90 百分位 2.88 |

不变的：夹角门槛 45°、不重叠、留的格数、`startPaint` 的参数。已经画过的画不重铺（它们的坐标在文件里）。

## 四、开始画的面板加一组：按一格多大（11-11 傍晚加）

user：「所以这么说的话，创建画布的时候也应该有像素密度和贴图大小两个指定方式？」（前面一串：「packing用的是像素坐标，不是百分比坐标」「加东西了之后只是1024*1024变成了1300*1300，但是每一个岛的像素还是一样的」「uv完全静默，用户不知道，不需要焦虑uv空间管理」。）

- 面板上现在的五行是「按总大小」。再加一组「按一格多大」：
  - 「和上一张画一样（一格 X）」——这份文件里最近那张画的密度；没有画就没有这一行。
  - 几个常用的档（一格 1 cm / 5 mm / 2 mm / 1 mm 这一类，按文件的显示单位换；具体哪几档你看着定，走 `units.ts`）。
  - 自己填（那个单位输入框）。
  - 每一行写算出来的画布有多大、打开占多少。太大（超过 4096）的灰掉写原因。
- 底层：`layoutPlan` 本来就认 `density`；`startPaint` 加一个可选的密度参数（和画布边长二选一；都不给 = 老行为）。按密度铺时画布的宽不要死守 1024：取接近正方形、够用的最小宽高（宽高不必是 2 的幂；步长照现在的规矩）。
- **记下定住的是什么（11-11 傍晚加；user：「不过如果是指定贴图大小的话，后面自动涨也不好」）**：那一套坐标的行加一个可选键 `fit`：`"size"`（按总大小开的）或 `"density"`（按一格多大开的）；缺 = `"size"`（以前的画都是按大小开的）。这是文件格式：`CATSUP_mesh` 的 minor 加一、冻样本、老读者检查；`src/format/` 的改动合之前发统筹看一眼。
  - `"density"`：加面放不下时画布照现在的规矩长大。
  - `"size"`：**画布不许自己变大**。加面（建模长出来的、或者面板里「加进已有的画」）在现有的宽高里找地方；找不到 = 那些面先没有位置（照底色显示，上方正中的按钮照现在的规矩露出来），面板里「加进已有的画」那一行灰掉写「这张画定的是 W × H，放不下了」。变粗重铺、放大画布这两条出路等换大小那张单。
  - 以后排法成为独立的条目时，这个键跟着搬过去（`ai-docs/20261111-paint-moves-design.md` 第三½节）。
- 测试：按密度铺出来的每张面，画布上的边长 ÷ 空间里的边长符合那个密度（连成片里斜的面按第五节的界）；两个物件用同一个密度开始画，一格一样大。

### 2026-11-11 第三节 连成片收紧（Catsup小弟；分支 `canvas-viewer`，自己合）

**做了什么**（`src/paint/layout.ts`）
- **片太空就不收**：往片里收一张面之前，按种子的方向算「收了之后片压平的面积 ÷ 片的包围盒面积」，低于 `PATCH_MIN_FILL` 就不收（留给后面的种子；这一片里别的面收进来以后再碰到会再试）。常数一处，**定 0.5**（量过 0.5 / 0.55 / 0.6 / 0.65 / 0.7，下面的表）。
- **片的朝向取包围盒最小的**（`tightFrame`）：候选 = 片外沿上每条边（只属于片里一张面的边）的方向，包围盒按片的凸包算；比种子的方向严格小才换，一样小留种子的——结果只会比原来紧。只换两张面以上的片：**只有一张面的片不换**（单子说「一样小取种子最长的边，所以一张面的片仍然逐位相同」，但不是长方形的单个四边形，包围盒最小的方向不一定是最长的边；为了守住「和一张面一块逐位相同」，单张面的片直接不转）。新的 t = 法向 × e，和原来同一个手性，不镜像（测试查了每张面的绕向）。
- **离种子近的先试**（顺手改的，单子没写）：加了「片太空就不收」以后，试的先后会改结果；原来先进先出、邻面按编号，结果就和面的编号有关了（施工单十五的测试「倒着建同一个形状、片一样」当场红）。改成从种子往外，面心离种子面心近的先试（一样近看面心的位置，坐标量到 0.1 微米再比）；种子一样大也看面心位置。这样和编号无关，片也更圆。
- 不变的：夹角 45°、不重叠、留的格数、`startPaint` 的参数；已经画过的画不重铺。
- 测试（`paint-layout-patches.test.ts` 加三条，共 13 条过）：两张面以上的片铺好后满 ≥ 门槛、门槛 0 时片更少；斜的平行四边形带转成顺着带子摆、不镜像、零拉伸、比按种子摆的满；起伏网格每一片转了只会更满。

### 2026-11-11 第二节 画布小窗第一版（Catsup小弟；分支 `canvas-viewer`）

**两半、中间一条窄的缝**
- 「看」那一半 = `src/app/ui/image-view.ts`：只认识一张图（一格 = 一个像素）、两种粗细的线段、按编号取的多边形（选中涂蓝 / 悬停涂橙）、一个「这一点落在哪个编号上」的回调；滚轮在光标处缩放、拖着平移、两指捏合、点一下（没拖）= click、鼠标停着 = hover；放大最近邻，一格 ≥ 8 个屏幕像素画格线；只在变了的时候画。守卫：它不 import 场景 / 编辑器 / 画画 / 渲染 / 内核（`atlas-outline.test.ts` 最后一条）。
- 三维那一半 = `src/app/canvas-window.ts`（递线、递「落在哪张面」、递选中 / 悬停，外加图从哪来、底下两行）+ 纯计算 `src/paint/atlas-outline.ts`（一张 atlas 上每张面的多边形；一条边两边的面在画布上连着 = 片里的细线，不连着 / 只有一边 = 外沿粗线；片的编号按画布上从上到下、从左到右；盖住 / 共用按格子中心数，和标杆表同一个数法；一点落在哪几张面 = 格子哈希）。

**入口**（版图文档 2026-11-11 追记先写）：右上顶排 **画布** · 参考窗 · 渲染；这个文件里有画就露、不分工作台；图标用库里现成的 `checkerboard-background`（没有新图标需求）。浮窗（`createFloatWin` 多了右下角拖角改大小）；位置按设备记（和别的浮窗同一个 WIN_POS），开没开、大小不记。进输入闸名册的是 `refwin`（有焦点时键盘归它；不是模态，不挡三维）。

### 2026-11-11 第四节 开始画的面板加「按一格多大」+ fit（Catsup小弟）

**面板**（`canvas-size-picker.ts`）：五行「按总大小」下面加一组「按一格多大」——「和上一张画一样（一格约 X）」（文件里最近那张画、按它那个物件在世界里的大小算；没有画就没有这一行）、四个常用档（米制 1 cm / 5 mm / 2 mm / 1 mm，英制 1/2 / 1/4 / 1/8 / 1/16 英寸，跟文件的显示单位）、「一格多大，自己填…」（应用内输入框，什么单位都接 = `units.ts parseQuantity`；填错 / 太大不关、说原因）。每行一行一行填「画布 W × H　打开占 …」，放不下（超过 4096）灰掉写原因。「一格多大」是世界里的长度，换成这个物件自己的密度 = 物件的缩放 ÷ 一格。
**底层**：`startPaint` 指令的参数多 `density`（给了 = 按一格多大，`canvas` 不看）；op 多 `fit`。`fit = density` 的铺法（`layoutFaces` 的 `squarish`）：宽从 128、256、512、768 … 往上试，留的格数跟着这个宽（`gapForCanvas`），排完的高（取到步长）不超过宽就是它。老入口（只给 density、不给 fit）照旧（宽 1024 起），逐位不变。
**fit（格式改动，合之前给统筹看）**：那一套贴图坐标上可选键 `fit`：只写 `"density"`；缺 = 按总大小。`CATSUP_mesh` 2.0 → 2.1，**只有带 fit 的网格体盖 2.1**，别的照旧盖 2.0 / 1.2（`MESH_STAMP_UV_NO_FIT`，和以前逐字节一样）；读到不认识的值 = 当按总大小；进条目内容（跨文件粘贴比内容时算）。冻了新样本目录 `v…-2.1.0-…`（多一个 `uvDensityFit.glb`）。
- **按总大小的画不长大**：补面（`layoutAppend` 的 `grow: false`）只在现有宽高里找地方，找不到的先没有位置（照底色），提示行「有 N 张面在画布上放不下，先照底色显示（这张画定的是 W × H，不自己变大）」；面板里「加进已有的画」那一行灰掉写「这张画定的是 W × H，放不下了」。**以前开的画都没有 fit = 都按总大小 = 从这一版起不自己长大了**（单子的规矩：缺 = size）。
