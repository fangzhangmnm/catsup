# 施工单：键位大改——照现行表把键表改过去

> created 2026-11-13 by Claude Fable 5.2（Catsup统筹）· as-of 三维开发版 v0.19.109
> **规矩只有一处**：[键位现行表](20261113-keymap-decisions.md)（user 逐键批的；原话在 `talks/20261103-keymap-blender.md` 第三到十六轮）。这一页只管怎么切刀、哪几处要先发统筹。两处对不上时以现行表为准，并告诉统筹。
> 施工：Catsup小弟。排在锁的一轮、存进图库之后。

## 一、开工前

只读清点一次，发统筹：拿现行表第二、三、四节逐行对现在的键表，每行写「现在是什么 → 要变成什么 → 归下面哪一刀 → 会红的测试和探针」。现行表里没有、键表里有的键也列出来，去留统筹定，不自己删。

**先收测试里写死的按键**（统筹 11-13）：225 个探针里 26 个直接按字母键拿工具或起手（93 处）。键一换它们就悄悄红——`probe-input-gate` 按 L 拿画线，L 从 v0.19.104 改了意思，红到 v0.19.111 才被碰巧发现。七刀要换很多键，所以第 1 刀之前先做：
- 不是专门测键位的探针，拿工具 / 起手改成按名字（走编辑器的接口，或者一个从键表现查「这把工具现在是哪个键」的小帮手），不写字母。
- 专门测键位的探针留着按字母，在登记表里标出来。
- 键表（`keymap.ts`）一改，凡是标着「按键」的探针都跑一遍，写进探针的触发表。

## 二、通用的规矩

- 键表只有一张。每一刀的测试是一张「工作台 × 有没有在做动作 × 键 → 做什么」的对照表；改规矩 = 改表。
- 提示行、工具栏按钮右上角的小字、右键菜单里写的快捷键都从键表出，不另写一份。
- 拿掉一个键之前，那个功能要有不靠键盘的路（工具栏或右键）；没有的先补上再拿键。
- 「动作里外」那条线照现行表第一节。轴键归锁那一轮，这里不碰。
- 每刀单独一版、自己合，每推一次升一个补丁号。要先发统筹的只有第三节里标出来的三处。

- **键盘弹出来的菜单一个样**（统筹 11-13，起因 = 动作外按 X 的「删除 / 溶解」小菜单弹在光标右下、光标不在任何一项上，删一次要多挪一下）：弹出来时第一项正好在光标下面，点一下就是它；回车 = 第一项；Esc / 点外面 = 收起。做成 `openPopupMenu` 的一个选项，不写死在某一个菜单里；以后凡是按键弹出来的菜单（这一轮里的、以后的「添加」之类）都用它。手感 user 没判过，做出来给 user 判。

## 三、七刀

1. **到处都一样的那一层**（只挪键，不加功能）：Delete = 删除、Backspace = 溶解；Ctrl+X 剪切；Ctrl+A / Ctrl+I；Alt+A 取消选择；W = 选择，多按换点选 / 框选 / 套索；Tab 在这个物体的几个工作台之间循环（步行里的 Tab 不变）；空格空出来；Ctrl+G = 建组件、Ctrl+Shift+G = 炸开，组不给键；Shift+D 两边都要；老键 M / Q / P 拿掉。
2. **点空白和拾取**（「选」和「拾取」分成两个入口并在这一刀，清点已交）：
   - 取消选择只在「选」里（点空白，抬起那一下算）。移动、旋转、缩放这些工具里点空白是正常操作，不取消选择，鼠标和笔都是。
   - 硬表面里 1 / 2 / 3 = 只选点 / 边 / 面（没在做动作时），和自由建模一样。
   - 拾取范围不是「都能选」时，界面上一直挂一个显眼的小标记；点不中时当场说原因。
   - 框选的减选补一条屏幕上的路。
3. **硬表面的键**：G / R / S 按了就开始（键盘起手，新做）；E = 推拉（已提前到锁的第三步 v0.19.112，连同橡皮不占键；这一刀只核一遍，并定「验证」「表面」两个工作台里的 E——现在还是橡皮）、I = 偏移；F = 矩形，多按换三种；C = 圆；T 动作之外 = 卷尺（留着）；弧、跟随、橡皮没有键，点工具栏；B 油漆桶不动。「验证」工作台里画线也是 K（L 改掉之后那里没有键拿得到画线；统筹定的）。
4. **自由建模的键**：J 连线；Ctrl+R 环切；O 软选择开关，半径 = 做动作时滚轮、Shift+O 拖动调半径、Alt+O 拖动调软硬、[ ] 微调；Alt+S 沿法线（Alt+W 拿掉）；Ctrl+B 倒角一个入口，看选的是边还是点。
5. **画截面的工具进自由建模**（F 没选东西 = 矩形、C = 圆；新做的工具）：规矩照现行表第三节「画截面的工具」那五条。**先发统筹**：新面怎么进属性表（贴图坐标、材质槽号各给什么）、撤销记哪一档。
6. **画画工作台**：工具栏加「选」那把箭头工具；选了面 = 笔、橡皮、油漆桶只落在选中的面上，没选 = 哪里都能画；键照现行表第四节；L 留给套索，套索做出来之前不绑；H 仍是隐藏。**先发统筹**：「只在选中的面上画」接在哪一层——统筹的要求是画画内核不知道选区，接在算落点的那一层，和「藏着的面不收落点」同一处；二维小窗里直接画的时候怎么办，先报现状和代价，统筹定。
7. **回车改数**：没在做动作时回车 = 光标进数值小窗，改刚才那一步；自由建模里移动、旋转、缩放做完也要有「刚才那一步」可改。**先发统筹**：这一步怎么记、和撤销怎么配。

新建类的键（Shift+A 加基本体、Ctrl+Shift+A 新建子物体）跟物体种类那一轮走，不在这里。
