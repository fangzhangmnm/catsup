# 取点求解器 · 一页纸定义

> as-of v0.1.2 / 2026-09-01（创建日）· created by Claude Fable 5
> 与 `src/playground/solver.ts` 逐条对应；改实现必回写本页（属 snap-model SSoT 体系）。

## 输入

- **视图** V = (π, ρ)：正交投影 π: ℝ³→ℝ²（CSS px）与拾取射线族 ρ(s)⊂ℝ³（屏幕点 s 的逆像）。
- **光标** s ∈ ℝ²。
- **约束集** C（有限）：每个 c = (L, r, ε)——轨迹 L ⊆ ℝ³（0 维点｜1 维线段/直线｜2 维平面）、
  秩 r ∈ ℕ（语义强度）、捕捉半径 ε（CSS px；2 维取 ∞）。

现行秩表：端点 90 > 原点 80 > 中点 70 > **交点 65** > 边 60 > **交线 55** > 轴线 45 > 平面 10。
现行 ε：点 10、边 7、线 5；合成确认 ε* = 12。（哨兵测试锁定，改值=有意识决策）

## 候选生成

1. **活跃**：c 活跃 ⟺ dist₂(s, π(L)) ≤ ε(c)。
2. **代表点**：0 维 x=L；1 维 x = argmin_{p∈L} dist₃(p, ρ(s))（线段夹段内）；2 维 x = ρ(s)∩L。
3. **合成（降维涌现）**：活跃 1 维对 (c₁,c₂) 真相交（最近距 ≤ δ=1e-5 且交点在段界内）→
   涌现候选 x=交点（有段者取段上点，保 sticky 落边）、dim=0、r=max(r₁,r₂)、used={c₁,c₂}；
   须 dist₂(s,π(x)) ≤ ε*。**不级联**。

## 选择

字典序最小：**(dim ↑, r ↓, dist₂ ↑)**。输出 = (x, used)。
一切叙事（kind/tooltip/提示线）是 used 的纯函数——不存在第二套真相。

## 不变量（test/solver.test.ts 钉死）

- I1 邻域：解满足 dist₂(s, π(x)) ≤ ε*。
- I2 确定性：solve 为 (V,s,C) 的纯函数。
- I3 解释完整：used ≠ ∅ 且 used ⊆ C。
- I4 有限来源前置（幽灵 align 定理）：1 维轨迹来源必须有限且用户指定（充能制）——
  正交投影下 dist₂(s,π(线)) 无法定向深度（任何不顺视线的线在某深度必穿过 ρ(s)），
  调参无解，唯一解法 = 候选集意图化。

## 情境构建（buildConstraints——工具唯一取点入口，单一供餐律）

C = 顶点(端点) ∪ 原点 ∪ 边中点 ∪ 边(1维段) ∪ {anchor, 原点, 充能点}×方向集(1维线)
  ∪ **交点**(线×线载线段外相交) ∪ **交线**(面×面∩裁剪段) ∪ {画面平面}；
方向集 = 世界 {X,Y,Z} ∪ 画面基 {u,v}（仅非轴对齐平面）。
外层状态（不进求解器）：充能 = hover≥300ms / 手势中≥120ms / 落笔端点，LRU 3；
磁滞 = 无解时上帧解在 1.5×ε 内保持。

## 附：平面查询（同一机器的第二查询）

resolvePlane 字典序：面锁（裸落膜内）> 含点平面（解析点落进过 p₁ 的轴向平面）> 过锚点轴向平面 >
轴系平面（d=0）。同秩裁决 = 底面偏置（|fwd·ẑ|≥0.34 时底面优先）> max|n·fwd|。
