## 全部语义就这几行

```
align(W, view, s, Q) → Snap3
  W  = 现实世界，唯一（壳的 liveWorld()：手势中=live 中间态，平时=checkpoint；旧 snapshot 结构性禁入）
  Q  = { plane, anchor?, alignSources?, lines?, hand?: {has(vid), opaque} }
  目标集 = 由 W∖hand 生成：0-D 点/中点/派生交点 ∪ 1-D 边/交线 ∪（lines≠false）轴/共轴线 ∪ 兜底平面
  可见(p) = W 中无膜严格居于 p 与眼之间（hand 透明时触手膜豁免；贴面不算挡）
  参赛   = 0-D 二值可见；1-D 按可见区间钳制；2-D 兜底永远豁免
  选优   = 字典序 (dim↑, rank↓, ⌈d/0.5px⌉↑, tag 字典序)
```

- **hand 同源三用**：手中顶点→点/边不参赛、不产派生目标（载线交点/面交线）、触手膜按 opaque
  决定是否遮挡。`opaque` 是动词参数：pp=不透明（光标在帽上背后无目标=SU 连续）；
  move/draw=透明（落点必须可见）。
- **不动点条款**：每个目标在**自己的吸附值处**存在且可见（贴面不算挡给出边界闭包；会在自身
  参数值上湮灭/被排除的东西必须都在 hand 里）——满足则 W 可依赖手势参数，违反则逐帧振荡
  （案例：底角湮灭案、帽平面误杀静态点案=探针 P5）。拖拽=扰动相（XOR 落地推迟到 commit，
  `settleLanding:false`）把「在自身高度上湮灭」这类反例从源头清零。

## solve(V, s, C) 核

- **输入**：视图 V=(π,ρ)（正交投影+拾取射线族）；光标 s∈ℝ²；约束集 C，c=(L,r,ε)——
  轨迹 L（0 维点｜1 维线段/直线｜2 维平面）、秩 r、捕捉半径 ε（2 维取 ∞）。
- **秩表**：端点 90 > 原点 80 > 中点 70 > 交点 65 > 边 60 > 交线 55 > 轴线 45 > 平面 10。
  **ε**：点 10、边 7、线 5；合成确认 ε*=12（CSS px；哨兵测试锁定，改值=有意识决策）。
- **候选**：活跃 ⟺ dist₂(s,π(L))≤ε；代表点=0 维自身｜1 维 argmin 到 ρ(s)（段内夹取）｜2 维 ρ(s)∩L。
  **合成（降维涌现）**：活跃 1 维对真相交（gap≤1e-5、段界内）→ 0 维候选，r=max，须 ≤ε*，不级联。
- **选择**：字典序 (dim↑, r↓, ⌈d/0.5px⌉↑, tag 字典序)。dist 量化 0.5px 桶+tag 定序=重叠轨迹稳定
  裁决（两条共线轨迹精确同距，浮点噪声不换桶；axis>align>edge-align>edge，再按轴名/源点）。
  输出=(x, used)；一切叙事（kind/提示线）是 used 的纯函数——不存在第二套真相。
- **不变量**（test/solver.test.ts 钉死）：I1 邻域 dist₂≤ε*；I2 纯函数确定性；I3 used≠∅⊆C；
  I4 幽灵 align 定理——正交投影下屏距不载深度，1 维轨迹来源必须有限且意图化（充能制）。

## 遮挡

- **0-D=二值判**：固定点可见性不随光标变，安全。
- **1-D=可见区间钳制**（`occludedSpansOnLine`：影柱∩直线——s(t) 线性、q2(t) 仿射→边界=多边形
  边交点+子区间中点采样）：候选 t 落入被挡段→钳到最近可见边界（光标不变量），屏距平滑出 ε
  自然掉出。**禁止逐点否决 1-D 候选**——候选点随光标沿轨迹滑，剪影边界二值判=反复横跳（抖动案根因）。

## 情境构建（buildConstraints——工具唯一取点入口，单一供餐律）

C = 顶点(端点) ∪ 原点 ∪ 边中点 ∪ 边(1 维段) ∪ {anchor,原点,充能点}×方向集(1 维线，lines 开关)
  ∪ 交点(线×线载线段外) ∪ 交线(面×面∩裁剪段，可描不改图) ∪ {画面平面}；全部先过 hand 滤。
方向集 = 世界 {X,Y,Z} ∪ 画面基 {u,v}（仅非轴对齐平面）。
壳侧状态（不进求解器）：充能=hover≥300ms/手势中≥120ms/落笔端点，LRU 3；磁滞=无解时上帧解
在 1.5×ε 内保持；基线手=checkpoint 之外的新生 vid（wip 线端/planarize 切点——追光标者不参赛）。

## pp 双通道（壳层，SU 对齐）

- **光标通道**：align(W=中间态, lines:false, hand={帽环∪(新生∧贴帽平面), opaque})——静态老 vid
  永不按 h 排除（不动点条款）；底环不动就不是手（底四边可吸 On Edge）。
- **高度通道**：h 标量对静态高度集咬合（落笔取全场景顶点沿 n̂ 投影+0；ε=7px 折算世界单位）。
  标量杀不死→无回路；「光标不动也咬底面」= h 吸到 -30，不是光标吸到底边。
- 取面高度=现实世界拾取+手中膜跳过+∥推向面拒收；推穿不硬钳（比 SU 强，E5 一族保留）。

## 附：平面查询（同一机器的第二查询）

resolvePlane 字典序：面锁（裸落膜内）> 含点平面 > 过锚点轴向平面 > 轴系平面（d=0）。
同秩裁决 = 底面偏置（|fwd·ẑ|≥0.34 底面优先）> max|n·fwd|。（2026-09-02 收敛；矩形三规则由此派生。）
