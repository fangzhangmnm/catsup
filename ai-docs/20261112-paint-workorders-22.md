## 一、为什么，做完是什么样

user 11-12 凌晨（语音；「余维编辑器」= 贴图坐标编辑器，「横屏竖直」= 横平竖直）：

- 「Blender 你最常见的那个……那个叫最小 Stretch 的贴图展开方式，还有就是标一些贴图展开的线，对吧？我们到时候启发式的算线，就是说用户可以标贴图展开的线，如果用户不标，我们可以也可以启发式的标。」
- 「非横平竖直的就 Blender 的那种，和我们自己研发一个横平竖直的方法……即使我们不做这个贴图坐标编辑器，我们把这两个做了之后，我们就已经能开始投产做些模型。」

做完：一个曲面多的物件（不是方盒子），标上接缝或者让软件自己标，点「开始画」，它被摊成几大片、拉伸小，而不是现在那样碎成很多小片。

三样里这一张做两样：接缝；一种照 Blender 的展开。**横平竖直不在这一张**：11-11 说好要和 user 专门讨论，统筹不先定。

## 二、查到的（统筹 11-12 查了 Blender 的手册）

Blender 的展开有三种：按角度（ABF，默认）、保角（LSCM）、最小拉伸（SLIM，4.3 起加的；一遍一遍迭代，每一遍把变形再压小一点；有「不许翻面」的开关，还有「重要性权重」可以让某些面在图上占得大一些）。user 说的「最小 Stretch」是第三种。

出处：Blender 手册「UV Operators」（https://docs.blender.org/manual/en/latest/modeling/meshes/editing/uv.html）、4.3 的更新说明（https://developer.blender.org/docs/release_notes/4.3/modeling/）。

## 三、定下来的（改之前先问统筹）

1. **接缝是边上的一个标记，看得见、能改。** 文件格式里已经有这一位（`CATSUP_mesh` 的 edgeFlags 接缝位），这一张不改格式。
2. **软件自己找的接缝也写成这个标记，不藏在算法里。** 「自动标接缝」是一个明着的动作：标出来的和手标的一样显示、一样能改、撤销里算一步，提示行说标了几条。user 定过：数据要机械、看得见、用户自己指定，猜的事归明着的工具（11-04「不静默，不潜规则」）。
   - 展开时发现某一片摊不平（是封闭的，或者有把手）而需要多切一刀：同样写成看得见的接缝并说出来，或者停下来说「这一片要再标一条接缝」。哪一种你先提、我定，不许悄悄切。
3. **展开是一个纯函数**：吃面、点的位置、接缝，交出每一片每个角在平面上的位置（还没乘密度）。密度、量化到 1/1024 格、排进画布，走现有的那一套，不另写。
4. **要的是最小拉伸那一类。** 怎么走到（先保角再迭代，还是别的路）你调研之后报我，报的时候带上：每条路要自己写多少求解的代码、万面级要算多久。依赖一律进仓，不许运行时去拿。
5. **四条不变量**（都要有检查）：没有翻过来的三角形；一片里不自己叠自己；每一片在拓扑上是一张盘；片和片不叠（排法保证）。
6. **拉伸要有数。** 每一片报两个数：面积变了多少倍（最大、平均）、角度歪了多少。先在小窗的「…」里能看到数；画成热图以后再说。
7. **只展开还没画的面。** 画过的面重新展开要把画搬过去，那是搬画那张单的事。这一张里碰到画过的面 = 不动、说原因。
8. **不悄悄改现在的行为。** 「开始画」里多一个选项「怎么展开」：按朝向连成片（现在的，照旧是默认）／ 照接缝展开。选了照接缝而物件上一条接缝都没有 = 先自动标（第 2 条），再展开，两步都说出来。
9. 慢的先说：估计要超过一秒的，先说要多久、给取消。

### 第 0 刀之后定的（统筹 11-12 夜，看了小弟的侦察报告；edited by Claude Fable 5.2）

**A. 接缝和棱、平滑、软是同一组边标记，拓扑操作对它们一起走。**
- 规矩：棱带到哪，接缝就带到哪。现在各个操作各自点名带哪几位（挤出只带三位、把接缝丢了），改成全仓一个「跟着走的边标记」常量，各操作都用它，不再各自列位。
- 结果：一条边被劈成两半，两半都带；倒角照现在对棱的做法；挤出照现在对棱的做法，新长出来的侧边不带。
- **两条边并成一条（溶解二度点）不是「搬家」，每一位自己说怎么合**（同日更正：原来这里写的是「有一条带就带」，和硬软边设计稿 §6 第 3 问定的对不上，小弟指出来的）：棱、平滑、软 = 两条都有才留（旧裁定不动）；接缝、隐藏 = 有一条就留（接缝断一截那一片就切不开，而且不丢 user 标的）。这张按位的表和上面那个常量住在一起，拓扑操作只许引用它们。
- 「隐藏」这一位这一张不改行为（倒角带、挤出不带，照旧），但要在同一处写明各操作现在怎么对它；这个不一致记进手感账，等有人动隐藏边、或 user 提了再定。
- 合到一点时边是重建的，边标记全丢（棱也丢）：现状，这一张不动，写进同一张表。
- 守卫：拓扑操作里不许单独点名某一位；新加一个拓扑操作，没声明边标记怎么走 = 红。
- 标和清接缝可以是另一条指令（「清掉手标」不碰接缝，照旧），但设位、清位、撤销记录用同一段代码，不抄一份。

**B. 接缝的样子：红色的线（照 Blender）。**
- 在自由建模里和现有的手标一起显示；在画画工作台里一直显示；画布小窗里，是接缝的片边用同一种红。白模、演示这类只看的模式不显示。
- 要和选中、悬停、坐标轴的红分得开。这是手感上的事，记进手感账，user 看了不合意再改。

**C. 摊不平的片：选 Y，在「照接缝展开」这个动作里补接缝再展开。**
- 理由：真模型里一片不是一张盘是常事（小弟统计的三个模型都是），停下来让人再点一次是形式上的确认；第三节第 8 条本来就是「没有接缝先自动标、两步都说出来」。
- 条件：只加，不动、不删 user 自己标的；补的接缝是普通的看得见的标记；提示行说补了几条，点一下能把补的那几条亮出来；补接缝和展开在撤销里是一步。
- **展开不改模型的形状和拓扑。** 非流形的点按扇面拆开只发生在展开自己的工作副本里；写回模型的只有每个角的贴图坐标和接缝标记。

**D. 展开走最小拉伸（SLIM），自己写，放 worker。批。**
- 纯函数、无头、同样的输入同样的结果（不用随机数，结果不随时间和线程变）。
- Tutte 起步的权必须是正的（均匀权或平均值权，不用余切权），不然「一个都不翻」不成立。
- 退化的三角形（面积为零、三点共线、重复的点）不进能量，位置跟着邻居走，报个数；真模型里有，不许因为它算出无穷大或卡死。
- 多边形面怎么拆成三角形，和显示用的拆法一致。
- 有轮数上限和停下的判据；能取消；超过一秒先估时间（第三节第 9 条）。
- 检查除了四条不变量，再加：能摊平的面（圆柱侧面、圆锥、折纸）展开后拉伸应该接近没有；每一轮的能量不许上升。

**E. 拉伸的数。** 面积比：最大、最小、按面积加权的平均（挤小了和拉大了都要看得见）。角度：每个三角形两个方向伸缩的比，最大和按面积加权的平均，另附三个角平均差几度。

## 施工记录

### 第 0 刀：侦察和调研（2026-11-12，Claude Opus 5.5；只报，没写功能代码）

**一、接缝现在是什么样**
- 网格内核里有这一位：`F_SEAM = 4`（`src/mesh/mesh-kernel.ts`）；文件格式会原样存（网格体载荷只列带标记的边）。**全仓没有人读、没有人写它**：界面上标不了、不显示、没有指令。
- 现有的「手标 ›」= 标成棱 / 标成平滑 / 清掉手标，指令 `meshEdgeMarks`，`mark` 只认 sharp / smooth / none，「清掉手标」只清棱和平滑那几位、不碰接缝。接缝和棱 / 平滑是两件独立的事，打算另开一条指令（标 / 清接缝），不塞进 `meshEdgeMarks`。
- 拓扑操作对这一位不一致：挤出只带棱 / 平滑 / 软三位（接缝丢）；倒角除了裸线都带；细分把带标记的边劈开、标记跟着两半。第 1 刀要定一张表：接缝跟着走到哪（提议：劈开的两半、倒角沿着的那条带过去；挤出新长出来的侧边不带——照 Blender）。
- 显示：平滑边在自由建模里有淡线；接缝要一种新的样子（Blender 是红线）。

**二、最小拉伸怎么走到（第三节第 4 条）**
| 路 | 是什么 | 自己写多少 | 1 万面要多久 | 不变量 |
|---|---|---|---|---|
| A 保角（LSCM） | 一次稀疏最小二乘 | 约 250 行 | 约 0.1 秒 | 会翻面、弯的片面积变形大；不是最小拉伸 |
| B 按角度（ABF++，Blender 默认） | 先非线性优化角度、再用 LSCM 还原 | 约 600 行 | 0.2–0.5 秒 | 不保证不翻 |
| **C 最小拉伸（SLIM，Blender 4.3 起）** | **Tutte 嵌入起步（边界按弧长放在圆上；对一张盘保证一个三角形都不翻）→ 一轮一轮：每个三角形 2×2 分解 + 解一次加权的稀疏方程（u、v 两次，共轭梯度、上一轮的解热启动）+ 线搜索（每个三角形算出不翻面的最大步长，取最小）** | 约 600–800 行（含检查） | 见下面实测：0.5–1.1 秒 | 每一轮都不翻（第 1 条靠构造保证） |
| D 进仓一个库 | xatlas（MIT，有 wasm）参数化是 LSCM、长处是自己切片和排——和「接缝看得见」那条相冲；libigl 的 SLIM 是 C++ + Eigen，没有现成 wasm，自己编要一整套工具链和 1–2 MB 的 wasm | — | — | — |

实测（这台机器、node 单线程、一次性基准不进仓：半球面网格，Jacobi 预条件共轭梯度）：Tutte 起步（u + v）1 万三角形约 45 ms、2 万约 100 ms、10 万约 0.8 秒；SLIM 每一轮（u + v）约 53 ms / 150 ms / 1.3 秒。一片 10–20 轮 → 1 万面 0.5–1.1 秒、10 万面 13–27 秒：要按第 9 条先估、给取消，放进 worker。iPad 没量。

**提议走 C、自己写**：没有依赖、同样的输入同样的结果、不翻面靠构造。第 2 条不变量（一片里不自己叠自己）：SLIM 管住了局部、管不住边界绕回来叠上（细长卷曲的片偶尔会）——做法是每一轮查一次边界有没有相交（扫描线，边界点数的 n log n），**交出最后一个没叠的那一轮**（Tutte 起步那一轮一定没叠，所以总有一个能交）。这样第 1、2 条都靠构造保证，不用为它多切。
拉伸的数（第 6 条）：面积 = 每个三角形（平面面积 ÷ 三维面积）再除以整片的比，报最大和按面积加权的平均；角度 = 每个三角形两个奇异值之比（1 = 不歪），报最大和平均，另附三个角平均差了几度（人看得懂）。

**三、摊不平怎么办（第三节第 2 条，提议）**
摊不平的几种：封闭的壳（没有开口）、有几个开口圈的（筒）、有把手的、非流形的边 / 点。
- 提议 **Y：在「照接缝展开」这一个明着的动作里，先补接缝再展开，两步都说出来、一步撤销**：补的接缝写成看得见的标记（和手标的一样能改）——非流形的边一定切；有把手的用「树-余树」找穿过每个把手的最短一刀；几个开口圈之间连最短路；封闭的壳从两个最远的点之间沿折痕切开。提示行说「为了摊平补了 N 条接缝（在哪几片上）」。
- 另一种 X：不补，停下来高亮那一片、说「这一片要再标一条接缝」。
- 第 2 条不变量用上面「交最后一个没叠的那一轮」解决，不为它切。

**四、自动标接缝打算按什么找，在哪些模型上试**
user 的三个模型（检疫仓 `catsup-user-models`，按三角形统计，一次性脚本不进仓）：
| 模型 | 三角形 | 块 | 封闭 / 带开口 | 非流形边 | 二面角 > 30° / > 60° 的边 |
|---|---|---|---|---|---|
| 小红帽 | 291 | 16 | 0 / 16（有欧拉数 −1、0 的：几个开口圈或把手） | 0 | 210 / 93（共 363） |
| wip2020 | 4556 | 34 | 7 / 27（带开口的有 −2、−1、0） | 2 | 1487 / 546（共 6396） |

### 第 1 刀后半：自动标接缝（v0.19.64，2026-11-12，Claude Opus 5.5）

**做了什么**
- 纯函数 `src/mesh/auto-seams.ts autoSeams(网格体, 范围, { angleDeg })`：只读内核、不用随机数（所有选择按编号打平）、**只加不减**（user 的接缝原样留着、当已经切开的地方用，补的里不会有它）。找法照第 0 刀侦察第四节 ①–④（⑤「展开后拉伸太大再切」要等第 2 刀的展开）：
  ① 三张以上的面共用的边一定切；② 两张面法向夹角 ≥ 角度（默认 60°）的边当折痕切；③ 沿没切的边连成片，切开后欧拉数 = 1 的片（一张盘）不动；
  ④ 别的片：对偶生成树按「先留平的边」（Kruskal：二面角小的先连、再按边长长的、再按编号）→ 不在树里的边都切开一定是一张盘 → 把一头悬空的新切口一条条粘回去，粘到不动 → 剩下的就是要补的（开口之间的连线、把手的两圈）；封闭、没把手的壳会粘到一条不剩，就从一个点找最远的点、再找最远的点，两点之间沿边走最短路切一刀。
  「是不是一张盘」= `chartTopology` 按切开后的欧拉数判：点按「绕着它、隔着没切的边连得上的面」分份（非流形的点自然分开），χ = 点 − 边 + 面，连通、有边界的片 χ = 1 ⇔ 一张盘。
- 指令 `mesh.autoSeams`（马后炮里改角度）→ 一条 op `meshEdgeMarks` seam（只列新补的）= 一步撤销；**做完把补上的那几条选中**（统筹 C 的「点一下能把补的那几条亮出来」我做成了直接亮出来：补完就是选中的，不用再点；不对的话改成提示行里一个钮）。提示行：「补了 N 条接缝（折过 60° 的切开；补的已经选中）；折痕 a、三张以上的面共用的边 b、为了摊平（开口之间、把手）c、封闭的壳切一刀 d；分成 K 片」。
- 入口：物件菜单（工作台下拉左边「物件」钮）「接缝 › 自动标接缝…」= 整个网格体（物件级的动词住这里，和「默认平滑 ›」一样；没选区时右键空处出的是「新建 / 回上一层」那一层，不放这里）；自由建模右键「接缝 › 自动标接缝…」= 有选区时（选了面 = 只管那几张，范围的外沿当片的边界、不补）。镜像分类 = 只改标记、直接做。
