# 施工单（二十二）：展开贴图第一版——接缝，加一种照 Blender 的展开

## 一、为什么，做完是什么样

user 11-12 凌晨（语音；「余维编辑器」= 贴图坐标编辑器，「横屏竖直」= 横平竖直）：

- 「Blender 你最常见的那个……那个叫最小 Stretch 的贴图展开方式，还有就是标一些贴图展开的线，对吧？我们到时候启发式的算线，就是说用户可以标贴图展开的线，如果用户不标，我们可以也可以启发式的标。」
- 「非横平竖直的就 Blender 的那种，和我们自己研发一个横平竖直的方法……即使我们不做这个贴图坐标编辑器，我们把这两个做了之后，我们就已经能开始投产做些模型。」

做完：一个曲面多的物件（不是方盒子），标上接缝或者让软件自己标，点「开始画」，它被摊成几大片、拉伸小，而不是现在那样碎成很多小片。

三样里这一张做两样：接缝；一种照 Blender 的展开。**横平竖直不在这一张**：11-11 说好要和 user 专门讨论，统筹不先定。

## 二、查到的（统筹 11-12 查了 Blender 的手册）

Blender 的展开有三种：按角度（ABF，默认）、保角（LSCM）、最小拉伸（SLIM，4.3 起加的；一遍一遍迭代，每一遍把变形再压小一点；有「不许翻面」的开关，还有「重要性权重」可以让某些面在图上占得大一些）。user 说的「最小 Stretch」是第三种。

出处：Blender 手册「UV Operators」（https://docs.blender.org/manual/en/latest/modeling/meshes/editing/uv.html）、4.3 的更新说明（https://developer.blender.org/docs/release_notes/4.3/modeling/）。

## 三、定下来的（改之前先问统筹）

1. **接缝是边上的一个标记，看得见、能改。** 文件格式里已经有这一位（`CATSUP_mesh` 的 edgeFlags 接缝位），这一张不改格式。
2. **软件自己找的接缝也写成这个标记，不藏在算法里。** 「自动标接缝」是一个明着的动作：标出来的和手标的一样显示、一样能改、撤销里算一步，提示行说标了几条。user 定过：数据要机械、看得见、用户自己指定，猜的事归明着的工具（11-04「不静默，不潜规则」）。
   - 展开时发现某一片摊不平（是封闭的，或者有把手）而需要多切一刀：同样写成看得见的接缝并说出来，或者停下来说「这一片要再标一条接缝」。哪一种你先提、我定，不许悄悄切。
3. **展开是一个纯函数**：吃面、点的位置、接缝，交出每一片每个角在平面上的位置（还没乘密度）。密度、量化到 1/1024 格、排进画布，走现有的那一套，不另写。
4. **要的是最小拉伸那一类。** 怎么走到（先保角再迭代，还是别的路）你调研之后报我，报的时候带上：每条路要自己写多少求解的代码、万面级要算多久。依赖一律进仓，不许运行时去拿。
5. **四条不变量**（都要有检查）：没有翻过来的三角形；一片里不自己叠自己；每一片在拓扑上是一张盘；片和片不叠（排法保证）。
6. **拉伸要有数。** 每一片报两个数：面积变了多少倍（最大、平均）、角度歪了多少。先在小窗的「…」里能看到数；画成热图以后再说。
7. **只展开还没画的面。** 画过的面重新展开要把画搬过去，那是搬画那张单的事。这一张里碰到画过的面 = 不动、说原因。
8. **不悄悄改现在的行为。** 「开始画」里多一个选项「怎么展开」：按朝向连成片（现在的，照旧是默认）／ 照接缝展开。选了照接缝而物件上一条接缝都没有 = 先自动标（第 2 条），再展开，两步都说出来。
9. 慢的先说：估计要超过一秒的，先说要多久、给取消。

## 四、分四刀

**第 0 刀：侦察和调研，报统筹**（不写功能代码）
- 现在界面上能不能标接缝、标了显示成什么样、哪条指令在管。
- 第三节第 4 条的调研；第 2 条里「摊不平怎么办」的提议。
- 自动标接缝打算按什么找（棱的夹角、曲率、让每片够平……），在哪些模型上试。检疫仓里 user 的三个模型拿来试，路径用参数给，仓里的测试不写死。

**第 1 刀：接缝**（自己合）
- 手标（界面上没有就补上）、清掉、显示。
- 「自动标接缝」：明着的动作，一步撤销。

**第 2 刀：展开的纯函数**（自己合；不变量和拉伸的数怎么算，合之前报我一句）
- node 里的检查：方盒子、圆柱、球、环、一张带洞的面，加上 user 的模型；四条不变量；拉伸的数在你报的范围里。

**第 3 刀：接进「开始画」，小窗里看得见**（自己合，一个版本）
- 第三节第 8 条的选项。
- 小窗里：接缝对应的片边、每片的拉伸数。
