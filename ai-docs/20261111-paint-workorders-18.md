# 施工单（十八）：排法成为独立条目，画跟着面走

> created 2026-11-11 by Claude Fable 5.2 · as-of 三维 v0.19.45（开发版）
> 施工：Catsup小弟。方向稿 = `ai-docs/20261111-paint-moves-design.md`（第三½、四、五½、五¾、六、六½ 节）；这一页只写定下来的格式、不变量、分几刀、哪几处要发统筹。
> 词：**排法** = 一套贴图坐标（代码里一直叫 `uvSet`，文件和代码都沿用这个词）；对 user 说的「一张 atlas」= 一套排法连同挂在它上面的图。

## 一、做完是什么样

- 带着画的面并进别的物件、炸开、分出去、建组件、做成唯一、在同一个物件里复制，都直接成功，画一格不动。结果是几个物件的面在同一套排法上各占各的位置（或者副本和原件占同一块，画一处两处都变）。
- 把画过的材质给别的物件的面：那些面在这套排法上找地方（照这套排法「定住的是什么」的规矩）。
- 「这张画属于哪个物件」这句话从文件和代码里消失。
- 这一张**不做**的见第八节（跨文件粘贴带画的东西还是拒，等下一张单的「搬画」）。

## 二、三条不变量（审查只对着这三条看）

1. **同一个版本**：一套排法的那一行、挂在它上面的图、所有物件的面在它上面的位置，永远是同一个版本。同一份文件里靠「一步撤销里一起翻」保证；剪贴板和素材架是唯一能把旧版本带回来的路，所以那条路要查（第六节第 4 刀），查不过就拒。
2. **新面的位置上没有旧画**：一张面新得到的位置，那几格在每个图层里都是空的。（现在不成立：`layoutAppend` 只把「这个网格体里现在有值的面」算占着，删掉画过的面之后，新面会落在旧画上。第 0 刀先写一条红的检查。）
3. **改几何不悄悄毁画**：没被碰到的面，像素逐位不变；丢了位置的面要数得出来、说得出来（方向稿第五¾节的表）。

## 三、文件格式（统筹定；改一个键先问）

### 3.1 新的一节 `CATSUP_uvsets` 1.0（可选的顶层扩展；表空 = 不写）

`{ version: 1, list: [ 行… ] }`，一行：

| 键 | 值 | 规矩 |
|---|---|---|
| `guid` | GUID | 表里两行同一个号 = 这几行都不认（不挑第一个、不现铸：列是按这个号找它的） |
| `name` | 字符串 | |
| `width` `height` | 正整数，单位格，每边 ≤ 16384 | 16384 = 内存里 32 位浮点还能把 1/1024 格表示精确的上限；现在铺法的上限是 4096 |
| `pxPerM` | 正的有限数 | |
| `fit` | 字符串，必写 | `"density"`（定密度：画布跟着长）/ `"size"`（定大小：不自己长）。不认识的值原样带回，行为 = 什么都不自动动（不给新面找地方、不长大）。以后的「手工」到有人能造它的时候再加 |
| `freed` | 整数列表，四个一组 `[x0, y0, x1, y1]`（格，左上含、右下不含）；缺 = 空 | **空出来的地方**：原来有面、现在没面了，里面可能留着旧画。补面绕开它；以后的重排把它收回、清空。形状不对 = 当不认识的键带回，并且这套排法不自动给新面找地方 |
| 别的键 | | 连同它们指着的字节原样带回（照贴图表那一行的 `carryJson` / `landCarried`） |

- 表里的先后没有意思。坏的一行 = 这一行不认、记进 `notes`，模型照开（和现在读贴图坐标的收口同一条规矩）。
- 大版本比本版新 = 拒开（不学桌面态那几个「带回、先不显示」的例外：建模的每一步都要碰它）。
- 记给以后的两条：① 行里带着不认识的键 = 静默重排不碰这一套；② 任何会让已有位置失效的动作（重排、换大小、手工改坐标）必须给这一行加一个版次，版次键到第一个这样的动作出现时加（缺 = 0），剪贴板靠它认旧载荷。

### 3.2 `CATSUP_mesh` 3.0：`uvSets` 键没了，换成 `columns`

`columns: [ { guid, kind, arity, data: { bufferView, count }, …别的键 } ]`

- `kind: "uv"`（贴图坐标）：`arity` 必须是 2；`guid` 就是排法表里那一行的号；`data` = 每个角两个 32 位有符号整数（小端，和 `loopVert` 同序），**单位 1/1024 格**；这个角没有值 = 两个数都是 −2147483648。
- 别的 `kind`（这一版一种都不造）：`guid` 是这一列自己的号；`data` = 每个角 `arity` 个 32 位浮点，NaN = 没有值。这一版把它当普通的一列带着走完每一步建模（继承规则本来就是所有列共用的）、`kind` 和别的键原样写回。
- 收口照 2.x：一张面在一列上半有半无、有值落在画布外 → 这张面在这一列上整面没有，记 `notes`；`uv` 列的号在排法表里找不到、同一个网格体里两列同一个号 → 这一列不认，记 `notes`。
- 拍子：不带列的网格体照旧盖 1.2（逐字节不变，没画过的文件旧版本照常开）；带列的盖 3.0；2.0 / 2.1 不再写。
- 两条规矩写进文件头注释：① 以后跟着角走的数据一律做成新的一列，不许塞进列的行里当别的键（旧版本改了网格它就过时了）；② 换编码、或者哪个种类受不了线性继承 = 大版本。

### 3.3 `CATSUP_textures` 1.3（原来写的是 1.2；1.2 让给了施工单二十一的「平铺的画」，统筹 11-12 改）

画的那一行 `layout = { uvSet: GUID }`。认的形状 = **正好这一个键**；多出别的键、或者不是 GUID = 这一版不当它是画（照旧原样带回、按底色显示、不能画）。以后加「排法的几分之一」靠这一条保住旧版本不乱画。

### 3.4 身份层

- 新种类 `uvSet`：`carry: true, structural: false, overwrite: false`，自己不指别人。贴图行指它挂的排法；定义指它的 `uv` 列用到的排法；`rewrite` 跟着改这两处。
- `overwrite: false`（粘贴时永远用目标文件里的那一份）是因为这一张只放行「原件还在」的粘贴；更新和断开等搬画那张单重新定。

### 3.5 方向稿第六½节的三条验收项

1. 列写明种类和每角几个数、种类开放：3.2 就是。
2. 图能声明彩色还是灰度：这一版不加键。核一下贴图行不认识的键确实原样带回（已有），在文件头注释里写一句「第一张灰度图出现时加一个可选键」。
3. 一个材质的不同槽可以指挂在不同排法上的图、一张面可以同时在两套排法上：数据上不拦，各写一条测试（手造的文件能开、能存、建模一步之后两列都还在）。

## 四、坐标的精度

- 内存里照旧是 32 位浮点、单位格。**凡是产出贴图坐标的地方，最后一步量化到 1/1024 格**：铺法的输出、`corner-columns.ts` 里唯一的那份插值（只对 `uv` 这一种列；所以 `ColumnDef` 要带 `kind`）。照抄的不用管（本来就是）。
- 内核自检加一条：`uv` 列里每个有值的数乘 1024 是整数。这样存成整数再读回来逐位相同。
- 1024 这个数和归属表取样点用的 `SAMPLE_Q` 是同一个数：收成一个常量，两边都从它来。
- **不取整格**：只量化到 1/1024，哪个点都不往整格上凑（方向稿第五½节第四版：有画的点一个都不挪）。

## 五、迁移和旧版本

- 读 2.x 的网格体：每个（物件，那一套）一对 = 排法表一行（名字、宽高、密度抄过来；`fit` 缺 = `"size"`）；坐标量化到 1/1024（挪动不到 1/2048 格；像素不动）。两个物件里出现同一个号（照旧规矩不该有）= 第二个起现铸新号，指着它的贴图行跟着改。贴图行 1.1 的 `layout.definition` 丢掉。
- 迁移要读字节、又跨两节，不走 `STEPS` 表，照 0.14 三角汤那条的做法写在读的路上，代码住 `migrate/`。
- 冻结样本：改格式之前，先确认语料里有一份现在的版本写的带画的文件（定密度一张、定大小一张、开着对称的、有没位置的面的、带合成图的）；没有就先冻。
- **拿 v0.19.45 的真代码当读者**（照门 6 的做法）：新版本写的带画的文件 = 明着拒开；不带画的文件 = 照常开，存回去再用新版开，排法表和贴图行都还在。
- 新版本读旧样本：画逐位相同；存了再开逐字节稳定。

## 六、分几刀

**第 0 刀（现在的格式下，自己合）**
- 冻旧样本（第五节）。
- 「一颗笔尖下同一块最多 8 张面」：复制 = 合用之后，一排复制出来的东西很容易超过 8。这个上限只是着色器循环的上界；WebGL2 的循环上界应该可以不是常数，你核一下，去掉上界或者把常数抬高带 `break` 都行。验收：64 张面共用一块、一颗笔尖全罩住，显卡版和标准答案对拍一致，量一下那一帧。
- 写一条现在是红的检查钉住不变量 2：画一张面 → 删掉 → 长一张新面落到同一块 → 新面上有旧画。
- 把方向稿第九节那七处读一遍，有和这一页对不上的先告诉我。

**第 1 刀：格式和表搬家，行为一点不变（合之前 diff 发统筹）**
- 第三、四、五节全部。场景里排法的表从网格体身上搬到场景这一层（`MeshBody.uvSets` 没了）；撤销的快照带上这张表。
- `Scene.facePaint` 改成：面的材质指着一张画 → 画挂的排法在表里 → 走画；有没有位置 = 这张面在那一列上有没有值。不再看「画属于哪个物件」。
- `paintMoveBlocked` 这一刀照旧全拒。全套测试、全部探针照过。

**第 2 刀：一切按排法看所有物件（`freed` 那一部分的 diff 发统筹，别的自己合）**
- 每格归谁的表、补面时「哪里被占着」、画板跟着改大小、小窗：都按排法收**所有定义**里在这一列上有值的面（没有摆放的定义也算）。空间位置那一半照旧只算正在画的那一份摆放；别的物件的面占着格子，但这一笔碰不到。
- `freed`：一张面在一套排法上失去位置（删面、整个定义没了、并面对不上丢了、转硬表面）→ 它的包围盒记进那一行的 `freed`；补面把 `freed` 也当占着。跟着撤销走（它在行里）。清单太长时怎么并你定，只许并大、不许漏。不变量 2 那条检查变绿。
- 小窗里把空出来的地方标出来（只标现在没有面占着的那一部分；别的物件的面画成淡的）。
- 一套排法上挂两张图：数据上不拦，画板跟着改大小对每一张都做（一条测试）。

**第 3 刀：放开，加两道防线（登记表的分类和探针的判据先发统筹看一眼，代码自己合）**
- 方向稿第四节的表里这几行放开：并进别的物件、炸开、分出一部分、建组件、做成唯一、同一个物件里复制面。面带着列过去，排法表和图不动。
- 合用发生的那一下，提示行说一句人话（「这几张面和原来的共用同一块画：画一处，两处都变」）。不提还没有的按钮。
- 转成硬表面：先问「画会丢，转不转」，转了 = 位置丢掉、进 `freed`。
- 防线一、二见第七节。

**第 4 刀：剪贴板只放行一种（查的那几行 diff 发统筹）**
- 放行的条件：目标文件里有这套排法，而且每张进来的面，在目标文件里都找得到一张在这套排法上位置一模一样的面（原件还在）。放行 = 合用；排法和图用目标文件里的，不弹窗。
- 别的情况照旧拒，原因说人话（原件已经不在了 / 这份文件里没有这张画：带着画粘贴过去还没做）。剪切之后粘贴、跨文件、素材架都在「别的情况」里。

每一刀做完推开发版。测试照家族的 `ai-docs/20261112-test-tiers-and-release.md`（11-12 立）：这一张从头到尾都在改文件格式和撤销，属于红线那几类，所以每一刀合之前把那一刀点名的探针跑完；推完开发版后台跑红线那一小组；场景和格式是公共层，每一刀推完后台整跑一次（没有人等，新版本出来旧的一轮先杀）；最后一刀收尾跑一次性能档。

## 七、两道防线

1. **登记表**：每条会改网格的指令登记它对画做什么，漏登记 = 测试红（照 `mesh/mirror-ops.ts` 那张表和它的守卫）。类：位置不变 / 按公式继承 / 长出没位置的新面 / 面没了 / 并面（可能丢位置）/ 整面搬到别的物件。一条指令可以占几类。
2. **随机乱改的探针**（照 `probe-undo-fuzz`）：在画过的、有合用的、两个物件共用一套排法的模型上随机做几百步，每一步之后核：
   - 没被碰到的面，每个图层的像素逐位相同；
   - 每张有位置的面都在画布里；
   - 除了位置一模一样的（对称、复制），没有两张面在画布上叠着；
   - 新得到位置的面，那几格每个图层都是空的；
   - 丢了位置的面数得出来，而且只出现在登记成「可能丢」的指令里；
   - 撤销回去：网格、排法表、每个图层的像素逐位相同。
