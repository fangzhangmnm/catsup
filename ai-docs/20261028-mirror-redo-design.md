## 0. 现在坏在哪（输入 → 输出）

镜像面 = 网格体自己坐标的 X（或 Y / Z）= 0 那张面；「中缝上的点」= 离这张面 1 mm 以内的点（`MIRROR_TOL`）。两半都是真几何（不是修改器）。

| 你做的 | 现在的结果 | 该是 |
|---|---|---|
| **强行对称**开着，把中缝上的一个点往外拖 | 这个点离开镜像面 → 下一拍「对称化」把它当成这一边的点：沿镜像面切开、镜过去 → **一个点变两个**（+ 多出来一圈切痕） | 点钉在镜像面上，只在面内滑（你：「不应该变成两个点，而是被吸附在中线上」） |
| **镜像编辑**开着，把 +x 的点拖过镜像面到 −x | 它穿过去、对面那个孪生点反向穿过来，两个点**擦身而过换边** | 到镜像面就停（你：「不要拖到对面去」） |
| 镜像编辑，把 +x 的点拖到中缝上 | 它和孪生点落在同一个位置，**两个重合的点**（double point） | 并成一个点（你：「collapse到中线，不要有double point」） |
| 并点之后 | —（今天并不了） | 退化的面清掉；躺在镜像面上、变成夹层的面清掉（你：「degenerate和中线上的面也许应该清」） |

根因：挪点那条 op（`meshMove`）在镜像下只做了「补对面的点」和「中缝点钉回」（镜像编辑），**没有「不许穿 / 到了就并」这两条**；强行对称那条路根本没碰 `meshMove`，全交给事后的对称化，对称化只会「切开 + 镜」，不会「钉」。

## 1. 四条规则（你的原话 → 精确说法）

记 c(p) = 点 p 沿镜像轴的坐标；按**挪之前**的位置分边 s ∈ {−, 0, +}（|c| ≤ 1 mm 算 0 = 中缝）。两种模式都遵守。

- **R1 钉**：s = 0 的点，目标点的 c 强制为 0（只在面内滑）。
- **R3 不穿**：s ≠ 0 的点，目标点跑到对面（sign c ≠ s）→ c 夹成 0（停在镜像面上）。
- **R2 并**：s ≠ 0 的点，目标点落在中缝（|c| ≤ 1 mm，含被 R3 夹过来的）→ c 置 0，**和它的孪生点并成一个点**（孪生点 = 挪之前在容差里找得到的对面那个；它自己的目标作废）。找不到孪生（模型本来就不对称的那块）= 只夹不并。
- **R4 清**：并点并出来的退化面（少于 3 个不同顶点）删掉；**整张躺在镜像面上、而且已经变成夹层的面**（每条边都夹在 ≥ 3 张面之间）删掉。

镜像编辑里孪生点照旧跟着镜过去（`to_w = mirror(to_v)`）；两个孪生点都在选区里、往不同方向拖 = 照旧「动得多的那边说了算」。

## 2. 哪些操作怎么保对称

| 操作 | 镜像编辑 | 强行对称 |
|---|---|---|
| 挪点（移动 / 旋转 / 缩放 / 沿法线 / 对齐吸附 → 都是 `meshMove`） | R1–R4 + 孪生点跟着 | R1–R3 先管住这一边，再对称化（本来就对称 = 对称化什么都不做，另一半的点 id 不乱换） |
| 改拓扑（挤出 / 插入 / 倒角 / 切割 / 环切 / 删 / 合并 / 细分） | 照旧护栏：「关掉镜像，照做 / 取消」 | 照旧：做完沿镜像面切开 → 删另一半 → 镜回来（动了哪边哪边为准） |
| 对称对齐（右键指令，只对选区） | 照旧 | 照旧 |
| 细分 | （护栏） | 对称的输入出对称的结果，不重建另一半（Opus 10-28 已做） |

**没动的**：挤出一张贴着中缝的面，新长出来的点沿面法向走——法向要是歪出镜像面，新点就离开中缝，强行对称会切开再镜（这是「长出去」不是「拖出去」，Blender 也这样）。要「挤出也钉中缝」另开一条，不在这稿里。

## 3. 预演和提交走同一条路

拖动中每一帧都在影子内核上做同一套 R1–R4（钉 / 夹 / 并 / 清），所以**拖到中缝眼睛看到的就是并好的样子**；松手前拖回去，影子从真身重算，点又分开（没有承诺）。松手 = 一步：`meshMove`（已钉 / 夹过的目标）+ 每一对并点一条 `meshMerge`（写进 op 日志，重放一致）。

## 4. 撤销

同一步里（挪 + 并 + 强行对称那条对称化）= **撤销一下全回**。马后炮重做（改数值）用同一批点。

## 5. 我替你读的几处（不对就说一句）

1. R4 的「也许应该清」读成「**只清会变成夹层的**」：半个盒子贴着镜像面有一张盖子面，强行对称以后盖子夹在两半中间 = 清；一张本来就躺在镜像面上的孤零零的平面（没有两侧）= 不清。
2. 并点只发生在**松手**那一刻（提交）；拖动中是预演，拖回去自动分开。
3. 两个孪生点一起选中、一起往中缝推 → 并成一个。
4. 镜像面的「中缝容差」还是 1 mm（`MIRROR_TOL`），不加设置。
5. 并点落在**已有的中缝点**上 = 那个点也一起并进来（不留重合点，退化的面清掉）。并点落在**中缝的一条边的中间**（点吸到边中点那种）= 这版不劈那条边，面会在那里捏一下（自检不报错，看得见）；要干净得先在那条边上切一刀再拖。记成已知边角，不挡这一版。
6. 一个贴着中缝的角并进中缝以后，它到两个中缝邻居的边变成两半共用的**折边**（一条边四张面，像把纸角捏扁）——这是几何上该有的样子（Blender 镜像修改器 + merge 同款），不算错。
