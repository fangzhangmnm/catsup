# 施工单：加一个毫米单位制（工业设计 / 3D 打印）

> created 2026-11-13（user 当地日期；本机钟 11-12）by Claude Fable 5.2 · as-of 三维 v0.19.69（开发版）
> 统筹写、小弟施工。碰文件格式的那一处（第三节）合之前发统筹。

## 一、为什么

user 在用硬表面做 3D 打印的小零件，打 1 出来是 1 米。原话：

- 「为什么我输入一的时候它会识别为一米而不是一厘米？还是说我们要加一个这种工业设计的单位制？」
- 「然后毫米可以，我建议是毫米，毫米更舒服。加一个新的单位制吧，我觉得比米制要好，就加一个工业设计的毫米单位制。」

现状（统筹读的代码）：单位制只有公制、英制、D&D 三种（`src/editor/grid-settings.ts`）。公制下显示和输入的单位写死是米（`units.ts setUnitSystem`），不带单位的数按米算，没有地方能改。10-30 已经把显示单位、网格制式、格距收成「单位制」一个旋钮，所以加一种单位制是顺着这个结构走。

## 二、定了的

下面除了「加毫米单位制、以毫米为底」是 user 定的，别的是统筹定的细则，user 用了不合意再改。

1. **单位制列表多一行**：名字「毫米」，说明「工业设计、3D 打印；不带单位的数按毫米」。排在「公制」后面。原来三种一个字不改。
2. **不带单位的数按毫米**（数值小窗、吸附长度的框、别的能填长度的框，都是同一个读法）。带单位照旧都接（`1cm`、`0.5m`、`2in`）。
3. **读数一律写毫米**，不随大小换成 cm / m（工业设计的习惯：1.5 米写 1500 mm）。小数位数你定一个合适的（建议最多两位、末尾的零去掉），报我。
4. **吸附的几档**：0.1、0.2、0.5、1、2、5、10、20、50、100 毫米。换到这个单位制时默认落在 1 毫米。
5. **网格自动换层**：和公制同一张进位表（十倍一层）。上面每一档都整除比它粗的下一层，`grid.test` 那条规矩照样成立。
6. **新文件的默认单位制不改**，还是公制。单位制是每个文件自己的设置。
7. **数据照旧存米**。导出、存盘里的坐标一个数都不变，换的只是显示和输入。
8. 贴图那边「一格多大」的写法（`app/canvas-size-picker.ts` 里按单位制分的那三处）在毫米制下怎么写，你提一个、报我。

## 三、文件格式（合之前发统筹）

单位制存在文件的设置里（`settings.unitSystem`，读写的门口 = `src/format/migrate/settings.ts`）。

1. **新的值**：`"metric-mm"`。
2. **给旧版本照写的旧键**：`displayUnit` 写 `"mm"`（3.4 之前的版本认这个值，会显示毫米），不写 `gridPreset`。
3. **版本号按内容盖**（照 v0.19.61 平铺的画那次的写法）：只有单位制是新值的文件，`CATSUP_document` 的中间那一位才加一；别的文件一个字节不变。
4. **旧版本会怎样**（要实测，拿这张单合之前的最后一个开发版的真代码当旧读者）：打得开；提示一次「这份文件是更新版写的」；按公制显示；模型数据不变。它存回去会把单位制写成公制——这个设置会被盖掉，模型不受影响。这一条 user 已经知道。吸附长度如果不在公制那几档里，旧版本怎么处理，实测了报我。
5. 冻一份新样本；读写来回一遍不变。
6. 过了读的门口，运行时不许出现「如果是旧文件」的分支。

## 四、结构：单位制收成一张表

现在按单位制分支的地方有三十来处，散在七个文件里（`grid-settings.ts` 11、`units.ts` 8、`format/migrate/settings.ts` 5、`app/canvas-size-picker.ts` 3，另有 `format/document.ts`、`view-state.ts`、`editor.ts`）。公制、英制之后加过 D&D，这次是又一次；再照样加一遍，下一个单位制还要改七个文件。

- **这次就收成一张表**：一行一个单位制，写全它的一切——名字和说明、显示怎么写（按大小自动换 / 固定一个单位 / 英尺英寸）、不带单位的数按什么、网格进位表、吸附的几档和默认档、给旧版本照写的旧键。
- 对外的函数（`gridLadder`、`snapLevels`、`DEFAULT_SNAP`、`setUnitSystem`……）签名不动，里面改成查表。`isUnitSystem` 从表里来。
- 加毫米 = 表里加一行 + 门口那一处。做完之后数一下还剩几处按单位制分支、各是为什么，报我。
- 守卫：一条测试钉住「表里每一行都齐」（吸附每一档整除比它粗的下一层、默认档在档位里、旧键写得出来）。

## 五、验收

1. 换成毫米制：打 `1` 回车 = 1 毫米；`1.5` = 1.5 毫米；`1cm` = 10 毫米。读数、吸附标签、网格标记写的都是 mm。
2. 吸附 10 毫米时推拉，高度是 10 毫米的整数倍（依赖「做小零件」那一批先修好）。
3. 存盘、关掉、再打开：单位制和吸附长度都还在。
4. 换回公制再换回来，模型一个数不变。
5. 原来三种单位制的行为和读数一个字不变（现有测试全过，不改它们的期望值）。
6. 第三节第 4 条的旧版本实测。
