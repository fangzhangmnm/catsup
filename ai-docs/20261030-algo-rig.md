## 自动蒙皮权重
- 热扩散（Blender「自动权重」，2007 Pinocchio）——脏网格上会失败（「Bone Heat Weighting: failed to find solution」）。
- 有界双调和权重（2011）。
- 测地体素绑定（2013，Maya 在用）。
- 按修补的权重迁移（2023）。
- 学习派（2024–2025）：RigNet、UniRig、Make-It-Animatable、MagicArticulate、RigAnything——要模型权重（走家族模型库）+ 先核许可证；对破机器偏重。Opus 倾向几何派先做。
- **区域 → 骨骼子集**：面 / 点上一列区域标签 + 对照表（区域 → 一组骨头的 GUID，按家规编号 = 对照表的代号），自动重算时每区只在自己那组骨头里分。

## 摆骨
- Mixamo 式：人点几个点（下巴、手腕、手肘、膝盖、裆）→ 套模板 → 自动摆正骨头的朝向和自转（「棒骨歪」的根）→ 人微调。Mixamo 自己的骨架档位（手指 3 / 2 / 1 节 / 不要）没核。
- 任意模型自动找关节 = 科研；人形 + 模板 = 好做的拟合。

## 自定义骨骼 + 语义（user 10-30 夜「狗和未知生物，自定义骨骼我们也要可以接……四足，马，蜘蛛机器人」，拍了）
- 语义 = 每条骨头链的角色（腿 / 胳膊 / 脊椎 / 脖子 + 头 / 尾巴 / 翅膀 / 触手）；全身 IK、看向、解剖把手、程序化行走只认角色。
- 模板：人形（VRM）、四足（趾行：狗猫；蹄行：马，腿多一节）、多足（蜘蛛机器人，分组交替）、鸟、蛇 / 触手（曲线 rig）。未知生物 = 人给链点角色。
- 前辈：Spore（2008，按角色写动画、套到任意捏出来的身体，凭记忆）。
