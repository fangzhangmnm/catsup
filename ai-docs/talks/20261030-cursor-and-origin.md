## 10-30 · 对齐原点 / 对齐坐标架；坐标架 = 3D 游标
- **user 原话**（按收到顺序照抄）：
  - 「brep 加一个对齐原点到坐标架功能还有对齐坐标架到选择功能，对于面，边，要对齐法线或者切向」
  - 「坐标架其实就是blender里面的3d cursor这个记住。」
  - 「这么说的话mesh也要有这些功能。现在这个版本如何设置原点？」
  - 「哦已经有设为组件原点按钮了，sorry之前没找到」
  - 「那么只要记坐标架=blender 3d cursor这个设计直觉，以后遇到了慢慢grill」
- **对上 Blender**：「原点对齐到坐标架」= Origin to 3D Cursor；「坐标架对齐到选择」= Cursor to Selected（再加：选面 = 对齐法线、选边 = 对齐切向）。
- **现状（Opus 10-30 核过代码）**：
  - 坐标架工具（`tools/axes.ts`）只搬画图用的坐标架，从不碰几何、也不碰原点——这本来就是 3D 游标的性质。存在硬表面体的 `drawFrame`（每一层一份，跟着文件走）；**网格体没有**（网格体那层的坐标架恒 = 世界，自由建模左柱也没有坐标架工具）。
  - 设原点现有三处：① 建组件时右下角马后炮选原点（包围盒角 / 包围盒中心 / 底面中心 / 顶点平均，默认底面中心）；② 硬表面：只选一个组件 → 右键「改组件原点…」→ 坐标架那套点三下改的是这个组件的原点（几何不动），落定后马后炮还能换成预设；③ 网格体：进去选点 / 面 → 右键「设置原点到选择中心」。「改组件原点…」只认硬表面组件。
- **以后 grill 时要定的（Opus 列的，没拍）**：坐标架是每一层一份（现在）还是像 Blender 一个文件一个；网格体也有坐标架就要往文件里加一个可选键（格式小改）；「原点对齐到坐标架」只对位置还是连方向一起；选边时切向当 X、法向怎么取。
- **更正现状（Opus 10-30 晚）**：坐标架工具条上本来就有两颗——「移到选择中心」（= Cursor to Selected 的**位置**那半；不对齐法线 / 切向）和「设为组件原点」（= Origin to 3D Cursor）。user 找不到是因为后者在最外层不露。
- **状态**：记账，以后遇到再 grill（坐标架对齐法线 / 切向、网格体补齐坐标架不做）；**根上的「设为组件原点」做了**，见下一节。

## 10-30 · 根也能「设为组件原点」
- **user 原话**：「根组件为什么没有设置原点到坐标架，难怪我一开始找不到，加上这个功能可以吗」「我说了root和其他的尽量一视同仁」「模型在视口上的位置不动，视角平移，对齐组件的行为」「如果太难就算了，没事」「但是undo redo不还原视角」
- **落地 v0.18.19（Opus）**：最外层用坐标架工具也露「设为组件原点」。根没有外层实例能补偿，所以 = 内容整个乘坐标架的逆（坐标架那一点落到世界原点、坐标架跟着回到世界帧），**视角同一下平移（+ 绕竖轴转），屏幕上的模型不动**——和组件里「世界不动、原点挪过来」同一个手感。撤销 / 重做只动模型、不动视角（user 那句）。视角只跟位置 + 绕竖轴的转（相机永远 Z 朝上，坐标架歪着放的那部分跟不了）。网格体做根时自由建模右键「设置原点到选择中心」也走同一条（以前在根上会报错）。
- **状态**：拍了 = 落地。
