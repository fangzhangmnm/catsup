- **对上 Blender**：「原点对齐到坐标架」= Origin to 3D Cursor；「坐标架对齐到选择」= Cursor to Selected（再加：选面 = 对齐法线、选边 = 对齐切向）。
- **现状（Opus 10-30 核过代码）**：
  - 坐标架工具（`tools/axes.ts`）只搬画图用的坐标架，从不碰几何、也不碰原点——这本来就是 3D 游标的性质。存在硬表面体的 `drawFrame`（每一层一份，跟着文件走）；**网格体没有**（网格体那层的坐标架恒 = 世界，自由建模左柱也没有坐标架工具）。
  - 设原点现有三处：① 建组件时右下角马后炮选原点（包围盒角 / 包围盒中心 / 底面中心 / 顶点平均，默认底面中心）；② 硬表面：只选一个组件 → 右键「改组件原点…」→ 坐标架那套点三下改的是这个组件的原点（几何不动），落定后马后炮还能换成预设；③ 网格体：进去选点 / 面 → 右键「设置原点到选择中心」。「改组件原点…」只认硬表面组件。
- **以后 grill 时要定的（Opus 列的，没拍）**：坐标架是每一层一份（现在）还是像 Blender 一个文件一个；网格体也有坐标架就要往文件里加一个可选键（格式小改）；「原点对齐到坐标架」只对位置还是连方向一起；选边时切向当 X、法向怎么取。
