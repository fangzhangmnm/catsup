# 讨论：动画曲线（时间轴的关键）

> created 20261030 by Claude Opus 5.5 · as-of v0.18.19
> 状态：**开着**。user：曲线要「发明」，会反复想。已拍的边界：只编辑每个 clip 自己的时间轴、没有全局时间轴；编排（过场）是另一种身体（`20261030-world-things.md`）。

## 10-30 晚 · 开题
- **user 原话**：「时间轴关键是要把animation curve发明出来，我可能要内耗很多次」
- **Opus 记的地基（不是方案）**：
  - 已有的几家：Blender / Maya 的贝塞尔曲线（每个关键帧两个把手）、TCB 曲线（张力 / 连续 / 偏移三个旋钮）、阶梯（定格动画、日式「一拍二」）。
  - **导出的硬边界**：glTF 的动画只认三种插值——线性、阶梯、三次（每个关键帧带进出切线）。任何分段三次的曲线都能一点不差地写成第三种；我们发明的曲线只要落在分段三次里，导出就无损，不然只能逐帧采样烘出去。
  - **转动是另一个岔路**：人好编的是欧拉角（三条曲线），glTF 存的是四元数。欧拉曲线导出要采样，四元数又几乎没法手编。这个岔路发明曲线时要一起想。

## 10-30 晚 · 第二轮：先 key pose 再二阶微扰；插值方案不一样
- **user 原话**：「但是关键是一般的动画流程是先key pose，然后二阶微扰吧。这么说洋葱片，打点算曲线我们也都需要我们是可以好好创新，不用照着blender，可以多看看图形学论文」「所以不同的插值方案是不一样的」
- **Opus**：
  - 这就是传统动画的「姿势到姿势」：先关键姿势 → 再加过渡姿势 → 再调间距（缓入缓出、跟随、重叠）。user 说的「二阶微扰」= 后两步。洋葱片（前后几帧半透明叠着看）、运动轨迹（手 / 头在空间里画出的弧线，打点看间距）都是这一步的工具。
  - 图形学里可以看的方向（Opus 记得的，没核；做的时候 Opus 调研）：时空约束（1988，把动画当优化问题解）、动作线摆姿势（2013，画一根线定整个人的姿势）、时空草图（2015，画一笔轨迹出一段动作）。
  - **插值方案进文件**：每段（或每个关键帧）用哪种插值 = 一个闭集选项，写进文件（编号 = 对照表的代号，按家规）。按 10-30 定的「兼容管数据、不管衍生算法」：插值是现算的，算法以后改进了，老动画的中间帧会跟着变，不并存两套；想保住某段的样子 = 烘成逐帧关键帧。Opus 提一句（没拍）：插值和自动法向不太一样，它决定的是 user 看过、认可过的动作；不过照规矩，烘一下就能保住。
  - 导出：glTF 只认三种插值，别的方案导出时烘（逐帧，或拟合成三次）。
