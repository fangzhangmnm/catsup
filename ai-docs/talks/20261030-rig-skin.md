# 讨论：绑骨与蒙皮（自动为主、刷顶点兜底、人体模板）

> created 20261030 by Claude Opus 5.5 · as-of v0.18.19
> 状态：**拍了的方向**：默认自动（Mixamo 式）+ 刷顶点兜底 + 区域指定骨骼子集；摆骨 = 生成后人稍微调、不全量自动；人体有自己的绑定预案、不元编程；关节极限 + 手动越狱；骨架精度可配。**没拍**：算法选哪个、数据长什么样（归 Fable 定格式）。
> 相关：化身 = 骨架 + 蒙皮 + 一串 clip（`20261030-world-things.md`）；IK（`20261030-ik.md`）。

## 10-30 晚 · 开题（user 当周剩下的时间 = 设计讨论，「帮我记账」）
- **user 原话**：
  - 「绑骨和贴图都默认用自动的，帮我搞2026年最好的算法，做成mixamo那种，但是小红帽这种嫉妒抠门古早做法还是需要刷顶点。反正到时候把klee和小红帽借给你试算法你就知道那些裙子头发因为会相交，所以要专门指定哪个区域对应哪个骨骼的subset」
  - 「然后骨骼的话我是希望humanoid我们自己做一个rigging的预案，而不是每次都得元编程，比如blender里面IK还要额外一个copy rotation就特别恶心」
  - 「摆骨骼是mixamo的方案啊，不过mixamo的棒骨都是歪的，我是觉得骨架生成之后艺术家稍微调整一小下就行了，不需要全量自动」
  - 「然后人体模板要支持关节极限，反正你知道这些生理知识，但是路飞这种情况也允许手动越狱。然后不同的精度的骨骼，几层，手指要不要，也都可以独立配置」
  - 「脏网络反而还行吧，我是觉得图形学科研opus足够」
- **Opus 的看法**：
  - **数据的真相 = 每个顶点的权重**（glTF 标准：每个顶点最多 4 根骨头一组，可以多组）。「自动算权重」和「刷顶点」是两个动词，都写同一份权重，做完就烘进状态（「历史不存在，只有被打歪的原子」）。自动不是一个常驻的修改器。
  - **区域 → 骨骼子集**正好治热扩散那类算法的老毛病：裙子贴着腿、头发贴着脖子，算出来权重互相串。做法 = 面（或点）上一列「属于哪个区域」的标签 + 一张对照表（区域 → 一组骨头的 GUID），按家规「编号只能是对照表的代号」。自动重算时每个区域只在自己那组骨头里分权重。
  - **要定的（没拍）**：蒙皮之后再改网格（挤出、细分、加一圈），新长出来的点权重怎么来——从邻居插值？区域标签跟着面的血缘走，和材质一样？
  - **算法候选**（Opus 记得的，没核；真到做的时候 Opus 先调研 2026 年的现状）：
    - 几何派：热扩散（Blender 的「自动权重」就是这个）、有界双调和权重（2011）、测地体素绑定（2013，Maya 在用）、按修补的权重迁移（2023）。
    - 学习派（2024–2025）：RigNet、UniRig、Make-It-Animatable、MagicArticulate、RigAnything 等。要下模型权重（走家族模型库 + 先核许可证），对破机器也重。
    - Opus 倾向：先做几何派 + 区域子集；学习派以后当可选的包。
  - **摆骨（Mixamo 式）**：人在模型上点几个点（下巴、手腕、手肘、膝盖、裆）→ 套模板骨架 → 人微调。「棒骨歪」大多是骨头的朝向和自转（roll）没对齐肢体，模板要自己把朝向摆正（沿肢体方向、按手肘 / 膝盖弯的平面定 roll），所以「稍微调一下」才够。Mixamo 自己就有骨架档位：手指 3 节 / 2 节 / 1 节 / 不要（Opus 记得，没核）。
  - **人体预案，不元编程**：前辈是 Unity 的 Humanoid（骨头按角色登记 + 每块「肌肉」有上下限）和 **VRM 的人形骨骼表**。VRM 是 glTF 的扩展，有一张标准骨骼表：必需的十几根 + 胸 / 脖子 / 肩 / 脚趾 / 手指这些可选（Opus 记得，没核）。我们的模板对齐 VRM 的表，导出给 VRM / VRChat 那边就只是对照，不用翻译。Blender 那种「IK 再加一个 copy rotation」是把绑定写成一堆约束程序；我们的模板是数据（骨头的角色 + 极限），解算器来解释它（同「数据驱动、不写逻辑」）。
  - **关节极限 + 越狱**：生理极限按关节给默认（扭转 + 摆动的范围），某根骨头标「不限」= 路飞。和「默认平滑 + 边上手标」是同一个形状。**关键**：极限只管编辑工具（IK、拖拽），不管数据——关键帧里的转动读出来永远不被夹，越狱就是自由的。
  - **精度可配**：脊椎几节、脖子、手指（不要 / 1 / 2 / 3 节）、脚趾、扭转骨，每个角色独立选。VRM 的可选骨头正好就是这个。
  - **分工**：图形学科研（自动权重、脏网格、摆骨）Opus 做；数据格式（权重、区域对照表、骨骼模板）Fable 定一次。
