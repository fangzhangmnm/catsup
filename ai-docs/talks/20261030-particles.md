- **Opus（凭记忆，没拍）**：
  - **手游攻击特效靠什么撑**：
    - 帧序列图：一张图上画好几格（火花、烟、爆炸），粒子一格格换着播。
    - 刀光 / 拖尾：一条跟着武器尖走的带子，贴图沿着带子流。
    - 面片：朝着镜头的小方块（或固定朝向的片），一次喷一堆。
    - 一点点着色器：叠加发光、按噪声溶解消失、颜色随寿命变、贴图滚动。
    - 生命周期里随时间变的：大小、颜色、透明度、转速。
  - **「能自己画」接上贴图内核**：帧序列图的每一格直接在 CatsUp 里画（WeebPaint 的笔搬过来那套）；画在一张卡片上，旁边就能看它在角色身上播出来。不出 app、不开 Photoshop。
  - **三样东西其实是同一个「格子图」**：表情卡片（脸那块换格）、精灵图导出（渲成一格格）、粒子帧序列（一格格播）。可以是同一个概念、同一套「画格子 / 换格子」的工具，只是用途不同。
  - **所见即所得的要点**：
    - 跟角色动画在同一条时间轴上：攻击第 12 帧喷一道刀光。
    - 发射点挂在骨头 / 挂点上（武器尖、手、脚底）——又是骨骼语义。
    - **可重复**：同一个随机种子，拖时间轴到哪一帧，看到的粒子永远一样（不然没法逐帧调，也没法烘焙）。
    - 低分辨率：粒子按像素密度画、按像素对齐，和像素风一致。
  - **导出**：glTF 没有粒子标准。出口：① 烘成一串带动画的面片（贴图换格 / 透明度这些用 glTF 的动画去驱动，具体扩展没核）；② 精灵图导出时粒子自然一起渲进去——像素游戏白拿；③ 给 Unity / VRChat 那边，只能烘成动画网格或帧序列，粒子系统本身搬不过去（各家格式不通）。
  - **前辈**：Unity 的粒子系统、Unreal 的 Niagara；**Effekseer**（日本那边常用的免费开源特效编辑器，独立出一个工具，导给各家引擎，凭记忆）；MMD 圈靠 MME 着色器做特效。
  - 着色器那一点点可以从 Shader 实验室拿（叠加发光、溶解、颜色渐变）。
