- **Opus（凭记忆，没核；没拍）**：
  - **三种做表情的路，VRM 都已经有标准位置**（VRM 1.0 的表情可以绑三样东西）：
    1. **morph（形状键 / 混合形状）**：一套顶点挪动，0–1 的权重混。= MMD 的顶点 morph、glTF 原生的 morph target。适合平滑的脸、口型。
    2. **换贴图上的一格（UV 偏移）**：眼睛 / 嘴画成几格，表情 = 把脸那块的 UV 挪到另一格。**= user 说的低分辨率表情卡片**。VRM 表情里有「贴图偏移」这一种绑定，MMD 也有 UV morph——所以表情卡片导出给 VRM / MMD 都有地方放，不是野路子。
    3. **改材质颜色**：脸红、阴影。
    - 还有用骨头的：下巴骨、眼球骨（看向）。
  - **表情卡片和我们的 UV 正好对上**：UV 存像素坐标、打包只平移 → 一张卡片 = 脸那块岛整格平移，像素一个不变。要定的：卡片格子要同大小、对齐（打包时一组卡片当一块走），放进 UV 实验室一起试。低模 + 像素风很适合：几格眼睛、几格嘴，混搭出几十种表情。
  - **VRM 的标准表情表**：高兴 / 生气 / 难过 / 放松 / 惊讶、五个口型（a i u e o）、眨眼（左 / 右 / 双）、往上下左右看、中性，再加自定义。对齐它 = 导出给 VTuber / VRChat 那边就是对照，不用翻译（同骨骼对齐 VRM 人形表那条）。
  - **脸部动捕已经很成熟**：浏览器里就有现成的小模型，摄像头一帧帧看脸，直接吐出几十个表情权重（52 个，和苹果脸部追踪的命名一样）；VTuber 软件（VSeeFace、VTube Studio、Warudo 一类）都是这一路。接法 = 把这几十个权重映射到我们的表情表（morph 的权重；卡片按阈值换格——眨眼过了一半就换「闭眼」那格）。只在本机算，同动捕那条。
  - **口型**：从声音推口型要碰音频 → 只在本机（家规第 8 条，硬的）。脑洞：MoonSinger 唱的歌本来就知道每个字的音素和时刻，口型可以直接从乐谱出，不用听声音。
  - **专门的工作流里有什么**（Opus 读法）：
    - 做表情：morph 在网格上直接挪点（自由建模那套工具 + 软选择），存成「这个表情」；卡片在贴图上画几格。
    - 调表情：几根滑条混；存成预设（「坏笑」= 高兴 0.6 + 眨左眼 1）。
    - 上时间轴：表情是一条条轨道（权重曲线）；卡片天然是阶梯插值（一拍二那种）。
    - 动捕进来：脸的权重直接落成表情轨道，再反烘焙抽稀（曲线那份第五轮）。
