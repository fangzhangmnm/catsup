## 10-30 夜 · 开题
- **user 原话**：「一键非GenAI的procedural行走我们也做，可以参考 https://www.youtube.com/watch?v=LNidsMesxSE 这个也是我小时候的wishlist，lowfi估计够用」

- **拍了**：一键程序化行走要做；不靠生成式 AI；低保真够用。
- **Opus（没拍）**：
  - **做法（那一路的经典配方，凭记忆）**：
    1. **步子跟着走过的距离转，不跟时间**（像一个滚动的轮子）：走得快步子就快，脚永远不滑。
    2. **每只脚两种状态**：着地 = 一颗钉子钉在地上；迈步 = 沿一条弧线飞到下一个落脚点。落脚点按前进方向和速度预测，地面高低用射线找。
    3. 全身 IK 把腿解到脚上（又是那一个全身 IK + 钉子）。
    4. 身体按步子的相位上下起伏、左右晃；加速往前倾、减速往后仰、转弯往里倒。
    5. 胳膊和腿反着甩（FK，弧线）；头稳住、看前方（看向）。
    6. 头发 / 尾巴 / 裙摆交给二次动作。
  - **只认骨骼语义，所以不只是人**：步态 = 每条腿的相位差一张表——两足交替；四足走 / 小跑 / 跑各一张；马多几种步法；蜘蛛机器人分两组交替（三条一组那种）。未知生物只要点了「这几条是腿」就能走。
  - **一键的输入**：画一条路径（地上拖一笔）或者用步行模式那套方向键 / 手柄直接带着走；速度可调。
  - **产出 = 一段普通动画**：程序化的结果烘成关键帧，再用反烘焙抽稀成人能改的少数关键帧——一键出个八十分，人再按「先 key pose 再二阶微扰」修（狗咬坦克：程序化不是死路）。不导出「运行时的程序」（glTF 没地方放），导出的就是那段动画。
  - 放进骨骼动画实验室先做低保真版：先两足 + 平地，再四足、蜘蛛、坡和台阶。

- **Opus**：
  - **以前的 grill 在哪**：ai-docs 里没找到程序化动画的 grill 记录，多半只在聊天记录里。开这个纪元之前，先用家族的原话抽取工具把 user 以前说过的捞出来（两个通道都扫），别凭这份重新发明。
  - **Spore 的论文**（凭记忆没核）：SIGGRAPH 2008「把动作实时套到千奇百怪的玩家自创身体上」（Hecker 等人）；Chris Hecker 在 GDC 还讲过一场「怎么给一个你从没见过的角色做动画」。核心 = 动画师按角色（腿、手、脊椎、嘴……）写动作，运行时套到任何身体。
  - **为什么怪物不吃恐怖谷**：人对人的动作最挑剔，差一点就怪；怪物、机器人、小动物没有「真的长什么样」可比，低保真的程序化动作看着就是「它就是这么走的」。低模 + 像素风再降一档要求。
  - **为什么 3D 量产可能比 2D 便宜**（读法，没拍）：
    - 2D：每个怪物 × 每个动作 × 每个方向 × 每一帧都要画，成本跟着数量一直线性涨；换个颜色以外的变化就得重画。
    - 3D 这条线：零件拼（素材架里的头 / 腿 / 翅膀 / 尾巴，接口带骨骼角色）→ 动作按角色共用（走 / 待机 / 攻击 / 挨打 / 倒下写一次，所有怪物都能用）→ 换色（老 RPG 史莱姆那种调色板换色，材质纪元的事）→ 任意角度渲染。多一个怪物的成本主要只剩「拼一下 + 微调」。
    - 照实说：单个的主角级角色（要演戏、表情细）3D 不见得便宜；16×16 的小像素怪，2D 本来也很便宜。3D 赢在**数量 × 动作 × 方向**乘起来以后。
  - **Opus 提一个连带的（没拍，脑洞）**：3D 渲成 2D 像素图——像素风画风已经有了，加一个「按 8 个方向 × 每个动作渲成一张张像素帧」导出，就是给 2D 游戏用的精灵图（老游戏《大金刚国度》、《暗黑破坏神》那种 3D 预渲染成 2D 的做法）。这样「3D 比 2D 便宜」连 2D 游戏都吃得到。要不要进愿望单等 user。
