# 对几何敏感的喷枪（墙上涂鸦、模型涂装）

> created 2026-11-11 by Claude Fable 5.2 · as-of v0.19.25（开发版）
> 状态（11-11 傍晚更新）：三维的笔按战锤那张表做、加像素笔，不照搬画画软件的笔架（user 定，见第二轮）；跨好几个物件的墙、硬表面的墙仍然是 wishlist。这里记的是讨论。

## 第一轮（11-11 下午）

**user 原话**

- 「wishlist: 软件affordance逼出一个人类直观：墙上涂鸦的splat，喷枪，柏林墙。这个可能是未来的killer app本轮筑基的时候不做，但是是一个高价值unexpected点子」
- 在 v0.19.25 上往柱子上写了字之后：「非常intuitive的开始想在墙上写字了」「真的完全没想到会有这个behavior」
- 「墙上涂鸦关键是要有喷枪的手感和物理模拟，2d的时候喷枪就是一个软笔刷，但是3d的时候能做3d几何敏感的喷枪吗，这个我觉得会是killer，你可以回顾一下一个高质量的顶配warhammer模型是怎么涂装的」

**Fable 的回答（不是 user 说的）**

能做。我们是在空间里画的，画布上每一格知道自己在模型上的位置和朝向，喷枪要的就是这个。

真喷枪和二维软笔的差别是五条规律：

- 朝向：正对喷口的面吃得多，斜的少，背过去的没有。
- 距离：远 = 斑大、淡、软；近 = 斑小、浓。
- 遮挡：喷口看不见的地方没有漆，前面的东西在后面的墙上留影子。
- 积累：按住不动越喷越厚，看停了多久，不看走了多远。
- 流挂：太厚了往下流。

顶配的战锤模型怎么涂，每一步在利用什么几何：

| 手法 | 实际在干什么 | 用到的几何 |
|---|---|---|
| 黑底漆加天顶喷 | 从上方喷灰和白，朝上的亮，凹处留黑 | 朝向、遮挡 |
| 渍洗 | 稀的深色自己流进凹缝 | 凹 |
| 干扫、勾边、海绵掉漆 | 颜料只挂在凸起的棱上 | 凸 |
| 光源色 | 从灯的方向喷一层光色 | 朝向、遮挡、距离 |
| 流痕、落灰、泥点 | 往下拖，落在朝上的面，从下往上溅 | 重力、朝上、离地高度 |
| 遮盖带、漏喷板 | 挡住喷雾 | 遮挡 |
| 罩染、叠色 | 透明薄层一层层盖 | 不用几何（图层） |

所以是一族「对几何敏感的笔」：每格的几何量（朝向、凹凸、遮蔽、离地高度、从某一点看不看得见）当笔的调制。喷枪是第一支，渍洗和干扫是兄弟。专业软件里有按烤出来的凹凸图、遮蔽图自动生成旧化的做法，那是程序生成的；这里要的是手上的、有手感的那一种。VR 里已经有喷罐涂鸦的应用，说明这个手感有人要。

落到现在的结构上：

- 每格吃多少 = 流量 × 朝向 × 距离 × 看不看得见。前两项现成。
- 看不看得见 = 从喷口渲一张深度图。渲染器烤遮蔽时已经在做同一类事。
- 流挂 = 一小段自己沿表面往下走的笔画（笔尖沿表面走的那一套现成）。
- 漏喷板不用单独做：场景里挡在喷口和墙之间的物件就是遮盖。
- VR 里手柄 = 喷罐。iPad 上相机离墙多远 = 喷多远，笔的压力 = 扳机。

难的地方：

- 画布小的时候软渐变是一格一格的。
- 一面墙常常是好几个物件、多半是硬表面体；user 同日定了现在只画当前物件。第一版只能是「当前物件吃漆，别的只挡不沾」。
- 流挂、渍洗不做真流体，只做几条规律。

筑基时留心别写死的（Fable 的旁注，合在一起）：

1. 笔尖只能是贴在表面上的一个球。
2. 一笔只能落到一张画上。
3. 只有网格体能画。
4. 笔只能按走过的距离出漆（喷枪按时间出）。
5. 渲染器只能从相机渲深度（要能从任意一点渲）。

**状态**：第一轮时是 wishlist、没有排期；第二轮改了，见下。

## 第二轮（11-11 傍晚）：三维的笔按这张表做

**user 原话**

- 把上面那张战锤涂装的表整张贴回来，然后：「记账，以及看一下我们现在能实现多少了。我建议是先按照这个做笔，以及像素笔，而不是抄weebpaint的」
- 「当然weebpaint的画anime眼睛的承重的笔也要，我到时候会说需要什么」

**Fable 的评估（不是 user 说的）**

今天一样都还没露出来。按「要什么几何」分三档：

| 档 | 要什么 | 能做哪些 | 现在有的 | 还缺的 |
|---|---|---|---|---|
| 一 | 每一格自己知道的：位置、朝向 | 落灰、天顶喷不带遮挡的那一半、离地越近越脏 | 画一笔时本来就在算 | 出漆时多乘一个数 |
| 二 | 进门时多算一张几何图：离凸棱多远、离凹缝多远（以后还有遮蔽） | 干扫、勾边、掉漆、渍洗 | 面和面怎么连；每条棱是凸是凹一算就有 | 准备时多算一张表；笔照着它出漆 |
| 三 | 从一个点看出去 | 真喷枪、光源色、漏喷板、带遮挡的天顶喷、流挂 | 笔尖沿表面走；渲染器烤遮蔽时渲过深度 | 渲染器从任意一点渲深度图的口；笔按时间出漆；流挂 = 沿表面往下走的小笔画 |

罩染、叠色靠图层（等图层面板）。像素笔单独一条，有了画布小窗之后在二维里做最自然。

一支笔的定义 = 三样的组合：笔尖的形状 × 怎么出漆（按距离 / 按时间）× 吃哪种几何（不吃、朝上、凸、凹、看得见、离地）。以后笔跟着文件走时，笔的条目按这三样存。

**先后（Fable 排）**：前面七件打底子的不变 → 像素笔 + 小窗里能画 → 第一档和第二档一起（落灰、干扫、渍洗 =「战锤第一套」）→ 第三档真喷枪。画动漫眼睛承重的那几支等 user 点名。

**状态**：方向 user 定了（按这张表做笔 + 像素笔，不照搬画画软件）。三档的分法和先后是 Fable 的。

## 第三轮（11-11 傍晚）：手办师会用什么笔

**user 原话**：「或者你自己想一下手办师会用什么笔」

**Fable 的回答（不是 user 说的）**

| 手办师手里的 | 实际在干什么 | 落到我们这里 |
|---|---|---|
| 喷笔 | 底色、肤色渐变，薄薄地叠 | 软、按时间出漆、吃朝向和遮挡（第三档） |
| 面相笔 | 眼线、眉毛、勾线，一笔定型 | 细硬边、压感粗细、带防抖 |
| 平头笔平涂 | 一块区域涂匀底色 | 按面、按片的油漆桶（已有） |
| 渗线液 | 点在凹槽上，自己沿着槽流过去 | 点一条凹棱，整条棱自动上色 |
| 干扫 | 颜料挂在凸起上 | 吃凸（第二档） |
| 粉彩、色粉 | 腮红，很淡很软，一点点叠 | 极软、低流量 |
| 遮盖带、遮盖液 | 分色，挡住不想沾的地方 | 选中的面就是遮盖 |
| 水贴 | 眼睛、图案直接贴上去 | 把一张图贴到表面上 |
| 牙签点高光 | 眼睛里的亮点 | 点一下一个圆点 |
| 光油、消光 | 眼睛亮、皮肤哑 | 画的是光泽那一槽，不是颜色 |
| 溶剂擦 | 擦掉上层不伤下层 | 橡皮只擦这一层（图层） |
| 湿笔晕开 | 把边缘晕软 | 涂抹、晕染 |

低模上特别便宜的三样（棱和面是明摆着的）：渗线 = 沿现成的棱画过去；遮盖 = 选面；平涂 = 按面、按片填。画动漫眼睛承重的是面相笔、水贴、点高光，加喷笔做虹膜的渐变。

一支笔的组合在第二轮的三样（笔尖形状 × 怎么出漆 × 吃哪种几何）之外再加两样：沿棱走；只画选中的面。

**状态**：Fable 的整理，user 没逐条表态；要哪几支等 user 点名。

## 第四轮（11-11 傍晚）：user 点名的那几支

**user 原话**：「那几支 草稿笔，勾线笔，然后随便一个可以上色的，可以喷的，可以混色的」（接着「当然weebpaint的画anime眼睛的承重的笔也要，我到时候会说需要什么」）

**Fable 的判断（不是 user 说的）**：草稿笔、勾线笔、上色笔基本是现有那条路上的预设（压感、收尖、防抖由画画内核算好了每颗笔尖再交给三维）；能喷的第一版先是一支软笔，真喷枪是第三档；能混色的要读画布上已有的颜色，三维这条路上还没有，是新活。在画布小窗里画的话这五支都是内核原生的。

**状态**：第一批笔 = 这五支 + 像素笔（user 定）；之后是对几何敏感的那一族。内置的笔留在 app 里，不拷进文件。
