# 讨论：网格体的单面 / 双面（小红帽这种低模的薄面皮）

> created 20261030 by Claude Opus 5.5 · as-of v0.18.19
> 状态：**拍了（第六轮）**：材质带「体 / 面」语义，默认 = 体 = 单面，材质纪元一起做。

## 10-30 · 开题
- **user 原话**：「小红帽这种lowpoly，是mesh不是brep，双面策略是什么。就是薄面皮两边应该都能看到的问题。但是又有一部分闭合流形可以culling。给不同的方案和利弊」
- **现状（Opus 核过代码）**：网格体整块按单面画（`pool-mesh.ts singleSided` → render3 换只画正面的材质），薄面皮（裙摆、披风、头发片）从背后看是透明的；硬表面体是双面的（正反两面能刷不同材质）；导出时所有材质都写 `doubleSided: true`；导入外来 glb 不读材质（也就不读它的 doubleSided）。
- **别家怎么做**：Blender / Unity / Godot / three 都是**按材质**一个开关（Blender 材质上的「背面剔除」勾、glTF 导出器照它写 doubleSided）；SketchUp 永远双面 + 正反两种颜色。
- **Opus 列的方案**：
  - A 按物件一个开关（整个网格体单面 / 双面）：最简单；但一个角色里身体是闭合的、裙子是薄片，只能一刀切。
  - B 按材质（glTF 原生 `doubleSided`，业界标准）：和文件 / 引擎一一对应、导出零翻译；坏处 = 「单面还是双面」其实是几何的性质（这片是不是薄片）不是外观的性质——同一块布既做闭合的袖子又做敞口的裙摆就得复制一份材质。
  - C 按拓扑自动算（不存）：属于闭合壳的面剔背面，带开口边 / 非流形的那一块画双面；好处 = 零操作、符合直觉、符合「能算的不存」；坏处 = 每次改拓扑要重分（只算改到的那一块）、敞口的帽子整顶都会变双面（多数时候正是想要的）、有意只要单面的薄片（只从一边看的布景板）要另说、导出要翻译（见下）。
  - D 面属性手标（表面工作台给面刷「双面」）：完全可控；坏处 = 全靠手刷。
  - E = C 默认 + D 覆盖：自动算 + 面上手标「双面 / 单面」压过自动（和「默认平滑 + 边上手标」同一个形状；手标列 = 编号 + 对照表，按家规）。
  - F 真给厚度 / 复制翻面：游戏美术的做法（把薄片复制一份翻过来当真几何），是建模手段不是渲染策略；可以当导出的一种翻译。
- **Opus 推荐 E**，理由：和平滑那套同形、和「算出来的 / 画出来的分开」一致、日常零操作。
- **E 带出来的事**：① 导出怎么翻：glTF 的 doubleSided 只能挂在材质上 → 要么按（材质 × 单双面）拆成两份材质（第三方看到材质变多），要么双面那部分复制一份翻面三角形（引擎友好、材质不变、只多薄片那点面数），要么全写双面（现在的做法，最省事、引擎多画背面）；看所见即所得 / 引擎友好两种保存模式各选哪种——这是导出契约，按分工归 Fable。② 双面的背面打光要翻法线（自家几个着色器要核）。③ 拾取跟渲染一致：画了双面的薄片从背后也要点得中。④ 导入外来 glb：材质 doubleSided = false 的那部分要不要转成手标「单面」。
- **状态**：问了（推荐 E）→ 见下一轮，user 改走 B。

## 10-30 · 第二轮：跟着材质
- **user 原话**：「要不就用材质？确实你思考一下其实熟悉跟着材质而不是几何」「比如如果我切一刀的话，皮肤 vs 裙子」「懂了吧」
- **Opus**：认同。单面 / 双面是「这是什么」（皮肤是实心的、裙子是一层布），不是「现在长什么形状」；按拓扑自动算会在切一刀、建到一半留着开口时把皮肤翻成双面、补上又翻回去——改着改着闪。材质 = 稳定的语义；也正好是 glTF / Blender / 引擎的做法，导出零翻译（Opus 第一轮推荐 E 是把「几何像不像薄片」当成了语义，错在这）。
- **照这个方向还要定的（Opus 列，没拍）**：① 新材质 / 没刷材质的面默认双面还是单面；② 什么时候做（开关的家 = 材质纪元的材质编辑器；现在没编辑器，要么先只改默认、要么等纪元）；③ 硬表面体照旧永远两面（每面正反各一个材质，SketchUp 语义），这个开关只对网格体的面起作用；④ 双面的背面打光翻法线、背面点得中；⑤ 导入外来 glb 时把材质的 doubleSided 带进来（现在导入器不读材质，到时一起）；⑥ 材质上的开关就是 glTF 标准字段 doubleSided，文件里本来就写（现在一律写 true），user 说过材质新字段不叫 Fable。
- **状态**：方向拍了 = 跟着材质；①② 问了。

## 10-30 · 第三轮：材质的「体 / 面」语义
- **user 原话**：「我是说 皮肤 石头 这些自然语义是一个体积。一个非manifold的石头是奇怪的。所以有洞必然是美工在省面」「然后旗帜布料 是面。之前我们做过的肥皂泡 树叶。这种更暧昧。」
- **Opus**：材质该带的不是「单面 / 双面」这个画法开关，而是**它是什么物质形态**：
  - **体**（皮肤、石头、木头……自然界大多数）：实心；有洞 = 美工省面，背面本来就不该被看到 → 剔背面。
  - **面**（旗帜、布、纸……）：薄的一层，两面都看得见 → 画两面，背面打光翻法线。
  - 肥皂泡、树叶「暧昧」是因为按拓扑看分不清（泡泡是闭合的、叶子常是一张卡片），按物质形态看就不暧昧：两个都是**面**（薄壁），只是再叠了透明（泡泡）/ 镂空（叶子）。泡泡 = 面 + 透明 → 两面都画、先画背面再画正面；叶子以后还可以加「背光透过来」。
  - **glTF 已经有这一刀**：透明扩展 `KHR_materials_transmission` 不配 `KHR_materials_volume` = 薄壁（泡泡、叶子），配了 = 有体积的实心透明（玻璃砖）。所以一个「体 / 面」语义字段，翻译成文件里两件标准的事：体 → `doubleSided: false`（透明时再挂 volume）；面 → `doubleSided: true`（透明时不挂 volume）。和 Tron 骨架稿「材质 = 语义 + 工艺 + 翻译」那条不变量同一个形状：语义存进文件，各画风 / 导出器自己翻。
- **还要定的（Opus 列，没拍）**：① 新材质和没刷材质的面默认「体」还是「面」（Opus 推荐「体」：自然界大多数是体、和 glTF 默认单面一致、和网格体现在的画法一致；代价 = 白模阶段做的旗子 / 裙摆从背后看不见，要刷一个「面」材质）；② 什么时候做（开关的家 = 材质纪元的材质编辑器）。
- **状态**：方向拍了 = 材质带「体 / 面」语义；①② 问了。

## 10-30 · 第四轮：默认单面还是双面（行业共识）
- **user 原话**：「一小步：默认应该是双面还是单面？我感觉默认是单面？行业共识是什么样的？」
- **Opus（按训练知识，没联网核）**：分两派——**跑 / 画的一方**默认单面：glTF 规范（`doubleSided` 缺省 false）、Unity（Render Face 默认 Front）、Unreal（Two Sided 默认不勾）、Godot（cull_mode 默认 Back）、three.js（`side` 默认 FrontSide）；**建模工具视口**默认两面都看：Blender（材质「背面剔除」默认不勾，所以 Blender 导出的 glTF 默认被写成双面——习惯的副作用）、SketchUp（永远两面）。后一派是怕建到一半 / 法线翻了东西消失。
- **结论（推荐）**：默认 = 体 = 单面，合 user 的直觉、合 glTF / 引擎默认、和网格体现在的画法一样（换过去零变化）。「建到一半看不见背面」另做一个**只是看的辅助**（自由建模里背面画淡红，像 Blender「面朝向」显示），不改数据。
- **状态**：默认单面 = user 直觉 + 推荐，待一句确认；「一小步」包含什么见回复（材质多「体 / 面」+ 老文件迁移 + 按材质画 + 导出 + 一个开关），问了做不做。

## 10-30 · 第五轮：树叶的正反语义；硬表面体怎么判（老游戏一张面当墙）
- **user 原话**：「树叶是说它本来就是透光的，正反面有语义区别。那篇论文你忘了啊」「然后brep上面需要小心，双面和树叶这种有正反的语义的是两边一起覆盖，单面的话反而可以假设你的片是有厚度的」「还是说brep也是单面是单面？有点晕，就是老游戏一个面当墙，你怎么判」
- **那篇论文**：Opus 在对话记录（本会话 + 最近 60 个会话）、CatsUp / Shader 实验室文档里都没找到。猜是 Wang 等 SIGGRAPH 2005《Real-Time Rendering of Plant Leaves》（叶面 / 叶背分开建模 + 透射）——**是猜的，等 user 认**。
- **树叶**：不只是「两面都画」，是**面**这一类里带正反语义的：叶面、叶背是材质自己的两套样子 + 光从背后透过来。所以「面」材质要能区分正反（不是一张面两边画一模一样）。
- **Opus 的判法（硬表面体，按 user 第二句理）**：几何是硬表面还是网格体不决定单双面，**材质**决定；硬表面体每张面有两侧，每一侧问「刷在这一侧的是体还是面」——
  - 刷了**面**材质（布、旗、树叶）：这张面就是那层薄片 → 两侧一起刷（刷一侧 = 两侧都是它），两侧都画；正反由材质自己区分（叶面 / 叶背、透光）。
  - 刷了**体**材质（砖、石、皮肤）：这一侧是某个实心东西的表面。另一侧也刷了体 → 当成有厚度的薄板（外砖内白墙），两侧各画各的；另一侧**没刷** → 那边是实心里面。
  - **老游戏一张面当墙** = 朝屋里那侧刷了砖（体）、背面没刷 → 判成单面墙（背面是墙里面），不用另外的开关。编辑器里照旧把背面画出来（用背面色，提醒「你在看里面」，SketchUp 的老规矩），导出 / 演示时剔掉。
  - 两侧都没刷（白模）= 默认材质 = 体 → 编辑器画两面（正面色 / 背面色），导出只留正面。
- **状态**：判法问了（没拍）；论文问了。
