## 11-13 夜 · 第四轮：全量的键位表（含 1 2 3、X Y Z、视图）；系统的管理办法

recorded by Claude Fable 5.2（Catsup统筹）。

- **user 原话**：「你在对话里帮我打个表。我说的是全量的快捷键，包括一二三 xyz 之类的，这些才是最头疼的，还有视图的这些。然后我们可以设计一个系统的快捷键的管理方案，比如说像 Blender 它会在不同语境下面有不同的快捷键绑定，对吧？」

**全量的现状**（统筹照 `src/controller/keymap.ts` 读的，as-of v0.19.100；Blender 那一列凭记忆，改键时要核）

到处都一样的（`GLOBAL` 层里不算工具键的那些）：Ctrl+S 保存、Ctrl+O 打开；Ctrl+Z 撤销、Ctrl+Shift+Z / Ctrl+Y 重做；Ctrl+X / C / V 剪切 / 拷贝 / 粘贴；Delete / Backspace 删除；Esc 取消或退一层；Ctrl+A 全选、Ctrl+I 反选、Alt+A 全不选；H 隐藏选中、Alt+H 全部显示；Alt+Z X 光；Shift+Z 缩放到全部；`.` 缩放到选区；Shift+Tab 格点吸附；`\` 藏起所有窗；Ctrl+G 建组、Ctrl+Shift+G 炸开；Ctrl+J 合并进光标下那个；方向键锁 X / Y / Z、↓ 解锁；Shift+方向键锁平面、Shift+↓ 光标下的面。

硬表面的工具键（SketchUp 式，现在也住在 `GLOBAL` 层的 `TOOL_KEYS`）：空格 / Tab 选择；L 画线、K 画线；R 矩形（轮换中心矩形、旋转矩形）；C 圆；A 弧；M 移动；Q 旋转；S 缩放；P 推拉；F 偏移；W 跟随；B 油漆桶；E / X 橡皮（轮换另两种）；T 卷尺（轮换量角器、坐标架）；G 建组件。

自由建模（`FREEFORM` 层盖在上面）：G / R / S / E / I 键盘起手；Alt+S / Alt+W 沿法线；Ctrl+B、Ctrl+Shift+B 倒角；Ctrl+R 环切；K 刀；J 连线；Shift+A 拉出；Shift+D 复制并接着挪；A 全选；X 删除；O 软选择、[ ] 软半径；Y / Z、Shift+Y / Shift+Z 先锁（手势外）；M / Q / P / F 从全局漏下来 = 拿起移动 / 旋转 / 挤出 / 插入。拿着操作工具（`TOOL_OPS`）或手势中（`GESTURE`）：X / Y / Z 锁轴、Shift = 锁面；移动中 G = 沿边滑；手势中数字 = 打数（`TYPING`）。拾取（`PICK`）：1 / 2 / 3 只选点 / 边 / 面，Shift+1 / 2 / 3 开关一种；压在「刚做完一步的数值小窗」上面，小窗里有字了才让给打数。

别的语境：步行（WASD 走、空格跳；Tab 原地编辑 / 接着走；Esc 离开；空格 / E / S / Q / A / T 归走路）；硬表面镜像把手出来时回车 = 应用；画画工作台没有自己的键（也不在工具键跳转表里）。

**最头疼的几处**（统筹列的）
- X：硬表面 = 橡皮；自由建模平时 = 删除；拿着操作工具或手势中 = 锁 X。
- 1 / 2 / 3：手势外 = 拾取；手势中 = 打数；刚做完一步时两者撞（第八十五轮）。
- Shift+Z：全局 = 缩放到全部；自由建模手势外 = 先锁面 XY。
- G / R / S / E / A：两个工作台意思不同；步行时 S / E / A 归走路。
- 视图只有三个键（Shift+Z、`.`、Alt+Z）；切前 / 侧 / 顶视图、切正交和透视没有键。Blender 用小键盘，user 的机器没有小键盘。

**管理办法（统筹的提议，等 user）**
- 骨架现成、不换：层从底到顶叠（`layersOf`），按键从顶往下第一个认的生效（`resolveKey`）；帮助页和工具提示从表生成；`test/keymap.test.ts` 守冲突。
- 要改三处：① `GLOBAL` 只放真正到处一样的键，硬表面的工具键搬进硬表面自己的一层（现在硬表面垫底、自由建模盖在上面，所以自由建模里按 L 会漏下去找画线）；② 语境固定成几级并写明谁盖谁：到处 → 工作台（硬表面 / 自由建模 / 画画）→ 拿着某类工具 → 手势进行中 → 打数 → 特殊状态（步行、镜像）；③ 同一个键跨语境保持同一个家（X / Y / Z / N 做动作时永远是轴；数字要么拾取要么打数，交界处写死谁赢）。
- 批的顺序（统筹建议）：第一组 X / Y / Z / N 和数字键；第二组视图键；第三组硬表面的工具键（第三轮摆的第一批并进这一组）。

**统筹答的和提的（等 user 回的标了）**
- Blender 没有「回到选择工具」的单键（W 是几种选择工具轮换）；油漆桶在 Blender 里没有单键。
- [ ] 不是记错：是 10-28 照画画软件调笔刷粗细定的；Blender 的软选择半径是做动作时滚轮。统筹提：[ ] + 做动作时滚轮；画画工作台里 F 拖动调笔刷大小（Blender 画画 / 雕刻的做法）；自由建模里 F 是造面，软半径用 [ ] 和滚轮。
- M / Q / P 是 SketchUp 时代的老键，从全局层漏到自由建模里的；改完两边都没有。
- **等 user 回**：矩形给 B（Blender 的 B = 拖框框选，我们用不上；备选 = 放进 Shift+A 菜单），油漆桶因此不给键；Tab = 在管得了当前物体的工作台之间循环（步行里的 Tab 不变）；新建子物体 = Ctrl+Shift+A。
- **X Y Z / 1 2 3 的打架，统筹的提议（等 user 回）**：一条线分到底——正在做动作（键盘起手之后、取点工具点了第一下之后、鼠标按着拖的时候）= X / Y / Z / N 是轴、数字是打数；没在做动作 = X 是删除、1 / 2 / 3 是拾取。拿掉三个夹在中间的东西：手势外的「先锁」（Y / Z、Shift+Y / Shift+Z、方向键先锁）；拿着操作工具没动手时 X 也算轴（`TOOL_OPS` 层）；做完一步之后数字归数值小窗。它们都是工具一直拿着那个年代的补丁，临时工具之后可以拿掉。后果：X 不打架（= user 10-29 的 T39）；橡皮留在工具栏不给键，删除 = 选中按 X 或 Delete；快捷键的锁只存在于动作里，没法残留；改刚才那一步 = 点一下小窗再打；Shift+Z 动作里 = 锁水平面、动作外 = 视图的键；画矩形要定平面 = 点了第一下再按轴。会残留的只剩按钮点的锁（看得见、放下工具就没）和拾取范围——后者加两道：点到被挡掉的东西当场说话；Esc 按到底恢复成都能选。
- **选面会不会自动选线**（统筹读代码：选区分开记，命令里 `s.faces.length ? … : s.edges.length ? …`）：现在不会，统筹认为对。理由：「倒角一个入口看选的是什么」靠的是选区记得点的是边还是点；自动往下带就分不清（Blender 因此给倒角两个键）；更不能自动往上凑（选了两个端点不算选了边）。移动时面带着自己的边和点一起动，那是算出来的，不进选区。对种类敏感的操作按最高维的来（user 提的），加一条：选区里有没参与的要说一句，不许悄悄忽略。
- **两边都要的**：G / R / S / E / I；X / Y / Z / N 锁；L；H 一套；F；J；Shift+A；Shift+D；Ctrl+G 一套；Tab。有理由不要的：环切（硬表面的面不是一圈一圈的四边形）、软选择（硬表面要精确的数）。以后要的：硬表面的倒角、沿法线。对齐模式的切换键没摆。
