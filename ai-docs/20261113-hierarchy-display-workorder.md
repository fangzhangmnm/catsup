# 施工单：层级的显示——只有现在能直接改的才显示线框

> created 2026-11-13 by Claude Fable 5.2（Catsup统筹）· as-of 三维开发版 v0.19.109
> 物体的管理那一轮的第一刀。规矩是 user 11-13 夜定的，原话在讨论日记 `talks/20261110-marriage-route.md` 第八十四轮补、第九十轮、第九十一轮和它的补。
> 施工：Catsup小弟。排在锁那一轮之后（统筹排的：这是 user 重做小屋子时说的最大的阻力，规矩已经定了，不等键位那七刀）。

## 一、user 定的（原话）

- 「我这里面最大的 friction 不出所料就是物体的层级管理」
- 不做严格分层：「我倾向于的是说我们。强化一下 UX，就是让你知道你在哪一层。」
- 「外层和你的孩子，他们或者任何不能直接编辑的东西，就是他们就不会显示线框，除非是你画风要求显示线框，不然的话他们就是按照画风或者游戏引擎里未被选择的样子显示不就行了。」
- 画风本身带线时，能直接改的那一层靠顶点的小圆点区分：「就用顶点」「不是说我讨厌粗线，只是可能要留给别的」。

## 二、规矩

1. 编辑用的线和点（线框、顶点的小圆点这一类）只画在「现在能直接改的那一层自己的几何」上。
2. 别的一律照画风原样画，像游戏引擎里没被选中的物体：外层的东西、这一层的子物体、别的物体。画风自己要求画的线照画。
3. 画风本身带线时：能改的那一层 = 有顶点的小圆点。不用粗线（粗线留给别的用处）。
4. 子物体和外层静止时长得一样，区别在去碰的时候才出现（子物体能整个选中、能进去；外层照现状）。〔统筹加〕
5. 每个工作台同一条规矩。〔统筹加〕
6. 只改画不画，不改吸不吸：外层和子物体的点、边照旧能吸。有冲突的地方报统筹，不自己定。〔统筹加〕

## 三、开工前：只读清点，报统筹

样本：一个物体里既有自己的几何又有子物体，子物体里还有子物体；硬表面和自由建模各做一个。

- 现在每个工作台里，「外层的 / 这一层自己的 / 这一层的子物体」各画了什么（面、边线、点、淡不淡、有没有线框），各截一张图。
- 粗线现在用来标什么（user 记得是标选中）。
- 「画风要求显示线框」现在对应哪些开关或画风。
- 现在点外层的东西会怎样、移到子物体上有没有整个亮、「只看这个」做什么。
- 照第二节改，会碰哪几处画线的代码。

## 四、验收

- 进到一个物体里：只有它自己的几何有线框和点；兄弟、外层、它的子物体照画风画，没有编辑用的线和点。
- 进子物体，线框跟着换过去；退出来，换回来。
- 画风带线时：能改的那一层有顶点的小圆点，别的没有。
- 选中的标记照旧；吸附照旧（外层的端点还吸得到）。
- 改前改后的截图发统筹，统筹拿给 user 看。这是只有 user 能判的东西，这一刀只改这一样。

## 五、不在这一刀的

层级怎么进出、怎么挪、层级窗口、面包屑：这一刀发了之后等 user 用过再说还卡在哪。物体种类强类型（新建子物体、空物体、创建父物体、物体窗口四页）= [施工稿](20261113-object-kind-strong-typing.md)，排在后面。
