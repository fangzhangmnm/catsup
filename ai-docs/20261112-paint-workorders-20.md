## 一、为什么提前

user 11-12 凌晨：「现在我们这几大轮优化都还没有新的功能嘛？就是说，从我上次说我可以开始在柏林墙上面涂鸦之后，到现在一直都还是在做地基和优化，对吧？」

是。能画的第一版是 v0.19.25；v0.19.26–29 加了笔的设置跟文件走、开始画的面板、画布小窗；v0.19.30 到 v0.19.53 这二十四个版本全是修毛病、流畅、安全、测试、显存，画画的本事一样没多。原来的先后把第一批笔排在「画跟着面走」「搬画」「材质面板」后面，照那样还要好几天才有新东西可画。这四支不依赖那几张单，所以提到前面。渍洗、干扫（要一张几何图）和「小窗里能画」照旧排在后面。

## 二、做完是什么样

画画工作台里，「笔」不再只有一支：能挑普通笔、草稿笔、勾线笔、按格的笔；橡皮能挑普通的和按格的；多一把「按面填色」。每支笔记着自己的大小和浓度，跟着文件走。

## 三、定下来的（改之前先问统筹）

1. **内置的笔是一张表，每行是笔的模型里那条记录**（模型第二节）。现在的 `paint/brush-kinds.ts` 长成它；`erase`、`accum` 从记录的 `tool`、`compositeMode` 算，不另存。`id` 定了不改：`pen`、`eraser`（现有）、`sketch`、`ink`、`cell`、`cell-eraser`、`fill`。
2. **桌面态 `CATSUP_desk` 1.6**（模型第五节，逐键照那里）：`paint.brushes { <id>: { size?, opacity?, hardness? } }`、`paint.active { <tool 的取值>: <id> }`；1.5 的 `tools` 保留读、停止写。这是文件格式，diff 发统筹。
3. **草稿笔、勾线笔只是数**：记录里手感那一组的值，草稿笔照画画软件的「铅笔」抄，勾线笔照它的「勾线」抄（从画画仓内置笔的数据里读出来，抄进表里，注释写出处和抄的是哪一版）。画出来像不像由 user 判断，不自己调。
4. **按格的笔**（模型第三节第 2 条）：大小的单位是画布的格；笔尖照旧是空间里的球（半径 = 格数 ÷ 2 ÷ 这套排法的密度），硬边、不抗锯齿；**永远包含落点所在的那一格**，大小是 1 格时只涂那一格。悬停时会被涂的格子亮出来，亮的就是会被涂的（同一个算法，不另写一份）。不在贴图坐标里画方块。
5. **按面填色**（模型第三节第 1 条）：按住在模型上拖，划过哪张面填哪张面；点一下填一张。填的是这张面在画布上归它的那些格（照每格归谁的表），写进当前图层，颜色和浓度用旋钮的。一次按下到抬起 = 撤销里的一步。和别的面合用同一块的（对称、复制），一起变。手感照表面工作台的油漆桶「刮涂」。
6. **选笔的界面**：带文字的列表或下拉，不是一排只有图标的钮（家里的规矩：四项以上用带文字的）。放在哪、长什么样你照画画工作台现有的样子定；新图标照图标库的规矩走，这批新增了哪些图标需求在报告里明着列出来。
7. **一支笔在这里能不能用**照模型第四节做成一个函数和一张「宿主认得什么」的单子，放在不引用三维自己东西的那个文件里。这一张里所有笔在模型上都能用；画布小窗还不能画，先不接。

**第 2 刀：按格的笔、按格的橡皮**（自己合）

## 五、测试（照家族的 `ai-docs/20261112-test-tiers-and-release.md`）

- 每一刀：快档、这一刀点名的探针，推开发版；推完后台跑红线那一小组。第 1 刀碰文件格式（桌面态），第 3 刀碰撤销，合之前把那一块点名的跑完。
- 探针按「走的是哪条路」覆盖（模型第七节第 2 条）：这一张新增的路 = 按格（`pixelMode` + `size.unit = cell`）、填（`tool = fill`）。草稿笔、勾线笔和普通笔是同一条路，不另加一组。
- 按格的笔要有一条：在一张被拉伸的、不是长方形的面上，点到哪一格就是哪一格（悬停亮的那一格 = 落笔后变色的那一格，逐格对）。
- 做完这一张，把这三刀里加的细探针收成一两条综合的；碰了画画那条路，收尾跑一次性能档。
