## 二、做完是什么样

画画工作台里，「笔」不再只有一支：能挑普通笔、草稿笔、勾线笔、按格的笔；橡皮能挑普通的和按格的；多一把「按面填色」。每支笔记着自己的大小和浓度，跟着文件走。

## 三、定下来的（改之前先问统筹）

1. **内置的笔是一张表，每行是笔的模型里那条记录**（模型第二节）。现在的 `paint/brush-kinds.ts` 长成它；`erase`、`accum` 从记录的 `tool`、`compositeMode` 算，不另存。`id` 定了不改：`pen`、`eraser`（现有）、`sketch`、`ink`、`cell`、`cell-eraser`、`fill`。
2. **桌面态 `CATSUP_desk` 1.6**（模型第五节，逐键照那里）：`paint.brushes { <id>: { size?, opacity?, hardness? } }`、`paint.active { <tool 的取值>: <id> }`；1.5 的 `tools` 保留读、停止写。这是文件格式，diff 发统筹。
3. **草稿笔、勾线笔只是数**：记录里手感那一组的值，草稿笔照画画软件的「铅笔」抄，勾线笔照它的「勾线」抄（从画画仓内置笔的数据里读出来，抄进表里，注释写出处和抄的是哪一版）。画出来像不像由 user 判断，不自己调。
4. **按格的笔**（模型第三节第 2 条）：大小的单位是画布的格；笔尖照旧是空间里的球（半径 = 格数 ÷ 2 ÷ 这套排法的密度），硬边、不抗锯齿；**永远包含落点所在的那一格**，大小是 1 格时只涂那一格。悬停时会被涂的格子亮出来，亮的就是会被涂的（同一个算法，不另写一份）。不在贴图坐标里画方块。
5. **按面填色**（模型第三节第 1 条）：按住在模型上拖，划过哪张面填哪张面；点一下填一张。填的是这张面在画布上归它的那些格（照每格归谁的表），写进当前图层，颜色和浓度用旋钮的。一次按下到抬起 = 撤销里的一步。和别的面合用同一块的（对称、复制），一起变。手感照表面工作台的油漆桶「刮涂」。
6. **选笔的界面**：带文字的列表或下拉，不是一排只有图标的钮（家里的规矩：四项以上用带文字的）。放在哪、长什么样你照画画工作台现有的样子定；新图标照图标库的规矩走，这批新增了哪些图标需求在报告里明着列出来。
7. **一支笔在这里能不能用**照模型第四节做成一个函数和一张「宿主认得什么」的单子，放在不引用三维自己东西的那个文件里。这一张里所有笔在模型上都能用；画布小窗还不能画，先不接。

## 四、分三刀，一刀一个版本

user 定过：只有他能判断的改动（手感、画面）每轮只改一样、留上一版好对比。所以一刀只加一样能画的东西。

**第 1 刀拆成两半**（11-12 小弟核过之后统筹改的。核到的：三维的一笔用的是内核的 `StrokeCore`，但喂进去的是调试钩子的 `hookBrush`——压感系数全是 0、收尖和跟手关着、间距写死 0.1；压感写死 1，`PaintPointer` 里没有压感；时间用的是处理时刻。也就是说现在在模型上画，笔不吃压感。）

**1a 接管道，不改手感**（自己合，单独一版）
- 笔的记录换成内核的 `ResolvedBrush`，取代 `hookBrush`；`PaintPointer` 带上压感和事件时间。一笔里只用一种钟，拿不到像样的事件时间就整笔退回处理时刻（照抬笔结算那次的规矩）。
- 内置的笔那张表在这里建，先只有普通笔和橡皮两行，写成和现在一模一样的数（压感系数 0、不收尖、不跟手、间距 0.1）。
- 门：同样的几笔，画出来和上一版逐字节相同（钉死时间的合成指针事件，照画画仓那次像素对比的做法）。
- 普通笔要不要吃压感是手感，归 user，不在这里顺手改。

**1b 笔的表长出两行 + 桌面态 1.6 + 选笔的界面 + 草稿笔、勾线笔**（桌面态的 diff 发统筹，别的自己合）
- 老文件（1.5 的 `tools`）打开，笔和橡皮的大小、浓度、硬度照旧。

**第 2 刀：按格的笔、按格的橡皮**（自己合）

**第 3 刀：按面填色**（撤销那几行发统筹）

## 五、测试（照家族的 `ai-docs/20261112-test-tiers-and-release.md`）

- 每一刀：快档、这一刀点名的探针，推开发版；推完后台跑红线那一小组。第 1 刀碰文件格式（桌面态），第 3 刀碰撤销，合之前把那一块点名的跑完。
- 探针按「走的是哪条路」覆盖（模型第七节第 2 条）：这一张新增的路 = 按格（`pixelMode` + `size.unit = cell`）、填（`tool = fill`）。草稿笔、勾线笔如果抄来的叠法和普通笔不一样（画画软件的铅笔和勾线多半是「取最浓的」，普通笔是「越叠越浓」），那就是一条新的路，要加一组；一样才不用加（11-12 统筹改：原来写的「同一条路」没看叠法）。
- 按格的笔要有一条：在一张被拉伸的、不是长方形的面上，点到哪一格就是哪一格（悬停亮的那一格 = 落笔后变色的那一格，逐格对）。
- 做完这一张，把这三刀里加的细探针收成一两条综合的；碰了画画那条路，收尾跑一次性能档。

## 施工记录

### 1a：接管道，不改手感（2026-11-12，Catsup小弟；自己合）
- **笔的表**：`paint/brush-kinds.ts` 长成表，每行是笔的模型第二节的那条记录（键照画画软件笔架条目、内核 `resolveBrush` 认的那些；类型本地写，没从内核多拿名字，白名单不动）。这一版只有 `pen`、`eraser` 两行。起笔 `resolvedBrushOf(种类, 旋钮)` → `ResolvedBrush`，取代 `hookBrush`。`erase` / `accum` 从记录的 `tool` / `compositeMode` 算（wash = max、buildup = over），种类表 `BRUSH_KINDS` 从记录算出来，原来的口不变。
- **数一模一样**：测试逐项比——两行在三组旋钮下解出来的笔 = 以前的 `hookBrush` + 浓度，除了 `compositeMode`：现在按叠法写成 buildup（以前继承默认的 wash）。三维这条路只拿它算 accum（两支都是 over，和以前一样）；内核那份只有二维笔引擎读，三维不经过（测试也查了三维这边没有别处读它）。
- **管道**：`ToolPointer.pressure`（`at` 早就有）→ 编辑器拖动时把指针递给工具（`track` 多一个可选参数）→ `PaintPointer.pressure / at` → 画画控制器。一笔的时钟和压感的规矩抽成无头的 `controller/stroke-clock.ts`：落笔的事件时间像样就整笔按事件时间，不然整笔按处理时刻；按事件时间的一笔里偶尔一个样本不像样，按落笔时两种钟的差折算（相对落笔 = 处理时刻 − 落笔的处理时刻），不往回走；压感只信笔的（报 0 = 用上一个），鼠标 / 手指一律 1。「事件时间像不像样」从抬笔结算里抽成 `eventTimeUsable`，两边共用一个判据。
- **门**：同样三笔（钉死事件时间的合成笔事件，压感在 0.2–0.9 之间变，走真的指针 → 编辑器 → 画画工具 → 画画控制器），新包和 v0.19.54 画出来的每层像素、整张合成逐字节相同（两次都一样）。门看得出差别：临时把普通笔的 `sizeCoeff` 改成 0.6，同样几笔墨从 1011 变成 746 像素——压感真的传到了一笔里。门的脚本是临时的，没进仓（和画画仓那次像素对比一样）。
- 普通笔要不要吃压感没动（手感，归 user）。调试钩子 `paint.stroke` 照旧用 `hookBrush`。
- 测试：`stroke-clock`（新，六条）、`brush-kinds` 加三条（逐项一样、叠法从记录算且三维没别处读 compositeMode、工作台不再调 / 导入 hookBrush）。editor.ts 的行数棘轮没破（4069）。

### 1b：笔的表长出两行 + 桌面态 1.6 + 选笔的界面 + 平滑收成一个内核函数（2026-11-12，Catsup小弟；桌面态统筹审过，别的自己合）
- **画画仓 v0.14.86**（统筹定「平滑只有一个内核函数」）：`common/smooth-defaults.ts resolveSmooth(跟手, 防抖, scale) → {tau, deadzone, tailBow}`，公式不变；后端起笔改调它（钉住时间的 20 笔、10 种取值 × 上色 / 擦，改前改后逐字节一样）；前端 `input.ts _resolveSmooth` 吃用户改过的那份，没动。单测进内核名单，守卫：内核里只有它读 `tauMaxMs` / `stabMaxPx`。全套 1834、内核 626、显卡冒烟过，推了开发版。三维的白名单加了 `resolveSmooth` 一行（只拿函数，不拿出厂表）。
- **桌面态 1.6**（统筹审过、要求改的一处改了）：`paint.brushes { <笔的 id>: 旋钮 }`、`paint.active { <tool 的取值>: <笔的 id> }`；1.5 的 `tools` 保留读停止写，它在 = 最后是老版本存的，以它为准，**只盖它带着的数**，这支笔在 `brushes` 里不认识的键留着（统筹要的那条测试钉了）。新样本冻了；旧读者检查（golden 20 + 随机 200）过。
- **笔的表**：搬进 `paint/brush-records.ts`（只引用画画内核，守卫查 import；以后搬进内核）。草稿笔 = 画画软件 `default-brush-pencil`「铅笔」、勾线笔 = `default-brush-ink`「勾线」，数原样抄（size → `size.base`、sizeBaseMax → `size.max`、spacingValue → `spacing`……；那两支没写 taperFloor = resolveBrush 的缺省 0.4，写明），测试把抄的数再对一次。普通笔 / 橡皮补了 `size {base, max}`（12 / 24、上限 400 = 以前滑条写死的数），`shape.hardness` 改成 0.8（= 一直以来的旋钮初值；旋钮总会盖过它，画出来不变）。
- **能不能用**（第三节第 7 条，顺着这一刀做了）：`brushUnusableWhy(笔, 宿主)` + `SURFACE_HOST`（模型上：brush / eraser、两种叠法、圆笔尖、不认格）；这一张里的笔在模型上全能用；画布小窗没接。
- **选笔**：工具条「笔」下拉（带文字，选项从笔的表生成）。每支笔的旋钮 = `app/paint-brushes.ts`：换笔时手上的旋钮存回上一支、套上新的那支（没记过的用记录里的初值），大小夹到这支的上限；左栏大小滑条的上限跟着笔（草稿笔 80、勾线笔 60）。没有新图标需求。
- **平滑**：起笔时 `strokeSmoothOf` → 内核 `resolveSmooth(跟手, 防抖, 1)` → 一笔的平滑器；普通笔 / 橡皮两个都是 0 = 不递 = 和以前一样。
- **路**：草稿笔、勾线笔都是 brush + 取最浓（wash）= 一条新路（和普通笔的越叠越浓不同）。守卫改成按路：表里每一条路在 `probe-live-region` 的 `BRUSH_MATRIX` 里都要有一组、一条路只一组；加了「取最浓」一组（草稿笔代表，五种极端）。
- **门**：普通笔 / 橡皮和 v0.19.55 逐字节相同（钉死事件时间和压感的三笔普通笔 + 一笔橡皮，经画画控制器，两边各两次同一个哈希）；同样几笔换草稿笔 / 勾线笔就不一样（墨 21864 → 13299 / 12390 像素），各自两次一样。门的脚本是临时的，没进仓。
- 调试钩子 `paint.stroke` 带 `kind` 时改走笔的表 + 平滑（普通笔 / 橡皮解出来 = 以前的 `hookBrush`，测试钉着）。
- 测试：`paint-brushes`（新，六条：换笔各记各的、上限、跟文件走、本版没有的原样带回、套的时候不报）；`brush-kinds` 加八条（抄的数、解出来的笔、平滑、路、拿的哪支、能不能用、记录文件只引用内核、下拉 = 表），按路的守卫改了；`desk` 改成 1.6 的形状（1.5 读、1.6 写、两者同在、只盖带着的数、坏值带回）；两处写死的拍子 1.5 → 1.6。
