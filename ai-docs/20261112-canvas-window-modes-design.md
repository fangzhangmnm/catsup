## 二、三种摆法

固定的三种，不是随便拖到哪停哪。

| 摆法 | 样子 | 谁默认用它 |
|---|---|---|
| 浮着 | 现在的样子：一个能挪、能改大小的窗 | 大屏（iPad 横屏、电脑） |
| 停在下面 | 画布占屏幕下半、通栏；上半是三维，照常能转能画。两块之间那条边可以拖 | iPad mini 竖屏和更小的屏幕 |
| 全屏 | 画布占满，三维先不显示 | 谁都不默认，手动进 |

```
停在下面（iPad mini 竖屏）              全屏
┌───────────────────────┐            ┌───────────────────────┐
│ ☰ ☁ 工作台▾     ◎ ☰视图 │            │ ☰ ☁ 工作台▾   缩放 1:1 │
│┃笔 ┃                  │            │┃笔 ┃                  │
│┃橡皮┃    三维          │            │┃橡皮┃                  │
│┃吸管┃   （上面看）      │            │┃吸管┃                  │
│┃填色┃─────────────────│ ← 可以拖    │┃填色┃     画布          │
│┃ ⌄ ┃                  │            │┃ ⌄ ┃                  │
│┃撤销┃    画布          │            │┃撤销┃                  │
│┃重做┃   （下面画）  参数 │            │┃重做┃              参数 │
│ 提示行                 │            │ 提示行                 │
└───────────────────────┘            └───────────────────────┘
```

怎么换：小窗的壳上一颗钮，点一下轮着换（浮着 → 停在下面 → 全屏）。打开时用哪一种由设备定。

## 三、谁盖着谁：一条规矩

**停在下面和全屏的时候，小窗不算窗，算「画面」，和三维视口是同一层。浮着的时候它才是窗。**

从下到上：画面（三维、停着或全屏的画布）→ 栏（左边的工具柱、左上那一排、右上那一组、右下的参数小窗、提示行）→ 浮窗 → 菜单 → 从底下上来的面 → 通知。

照这条规矩：

- 左边的工具柱永远盖在画布上面，而且是整个屏幕那么高，画布停在下面时它不缩短。画布把左边让出工具柱那么宽，不让柱子压住画。
- 右下的参数小窗照旧在右下角，画布停在下面时它浮在画布的右下角上面。
- 「一键藏起所有窗」藏的是窗和栏，两块画面都留着。

## 四、工具：一只手，两块画面

- **手上拿的工具只有一个，在左边的工具柱里。** 笔落在模型上，走空间里的那条路；落在画布上，走二维的那条路。同一支笔、同一个大小和浓度。
- 一把工具在这块画面上用不了（比如渍洗在画布上），就在这块画面上是灰的、说原因。这一条笔的模型里已经定了（`20261111-brush-model.md` 第四节）。
- **小窗不带自己的工具栏，全屏的时候也不换一套。** 这样没有两只手、两套工具单子要对齐。
- 工具的选项（大小、浓度）照旧在右下的参数小窗，两块画面共用。
- 右上是「看」：画布停在下面时，右上管的是三维；画布自己的缩放、摆正用手势，再加小窗壳上「…」里的几项。全屏时右上换成画布的（缩放到合适、一比一、显示像素格），三维的方向球收起。
- 手势两块画面一样：笔画，手指看（挪、缩）；手指在哪块画面上就动哪块。

## 五、全量的工具以后怎么进来（方向，现在不做）

- 工具（套索、魔棒、填色、移动和变换……）进左边的工具柱。柱子本来就有「放不下的收进 ⌄」的规矩。
- 面板（图层、取色、笔架）不新开窗，各找现有的地方：选笔的那个列表长成笔架；图层和取色放哪，搬到它们的时候再定。
- 全屏的时候它就是一个完整的二维画画软件的样子：左边工具、右下选项、画布满屏。这就是「买三维送二维」。

## 六、分步

1. 浮着的时候能画（和「小窗里能画第一步」是同一张单）。
2. 停在下面：iPad mini 竖屏默认用它；第三节那条规矩；工具柱盖在上面。
3. 全屏；右上换成画布的。
4. 以后：全屏时角上放一个小的三维预览（主次对调，就是界面版图里记着的「第二视口」）；参考窗也用这三种摆法（要动共享的界面零件库，升它中间那一位要 user 批）。
