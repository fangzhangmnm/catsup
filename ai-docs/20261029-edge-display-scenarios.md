## 1. 三样线，各归一条规矩

画面上的「线」其实是三样东西，以前混在一起由不同的地方各管各的，所以会不一致：

| 线 | 是什么 | 归谁管 | 规矩（一句话） |
|---|---|---|---|
| **结构线** | 正在编辑的那一个的拓扑：硬边实线；网格体另有软边淡线 + 全部顶点小点 | 编辑器（「正在编辑的」= 唯一的活动槽：根上 = 根里的散几何；进了组件 / 网格体 = 那一个） | **任何画风都画**（编辑要看得见自己在改什么）；演示锁里不画（不编辑） |
| **线稿线** | 不在编辑的物件的硬边 | 画风（预设 `material.edges`） | 只有两档：**线稿**（画）/ **不画线**（不画）。以前的第三档「只画编辑中的」= 不画线 + 结构线，退役 |
| **状态线 / 点** | 选中 / 悬停 / 刮擦 / 检查的边和点、X 光的隐线 | 标记（面 / 边换材质槽）+ 辅助几何 | 只出现在能编辑的地方（= 结构线所在），颜色走画风的标记色（一处定，见 §3） |

软边、折线、隐藏的边永远不是线稿线（硬表面里软边只在橡皮刮过 / 检查标到时以状态线出现）。

- 场景 6：演示锁现在不区分，结构线（根上的散几何）照画 → **v0.17.58 做了**（user 10-30「12修」；Claude Opus 5.5）：锁着时流提供者不标「正在编辑的那一层」（`stream-provider.ts setWorld(…, editing)`），线跟画风走；自由建模的顶点小点 / 软边淡线也不画。选中高亮、X 光照旧（那是你自己点的 / 开的）。探针 `probe-present-lock` noEditingLayer / editingLayerBack。
- 「只画编辑中的」那一档（`edges: "active"`）没有画风在用，和「不画线 + 结构线」一模一样 → 删。

## 3. 颜色收成几个角色（提案，待 user 点头）

> **v0.17.44 定了「强调」那一格（账本 T150，user 10-29「纸 线稿是蓝 写实和铜和像素是红」）**：线稿 / 剪纸 = 蓝（选中 #2b6cb0、将删红、检查橙）；写实 / 铸铜 / 像素描边 = 红（选中 #d8323a、将删让成橙、检查紫）；Tron = 自己的（Clu 橙）；1-bit = 墨，不闪（T151）。视图 ☰「选中色」可以换，撞色时将删 / 检查一起让开。下表「像素描边」那列就是这份红；「四个颜色」的收拢本身还没做。


每个画风只声明四个颜色，其余全由它们推出来（现在散在全局色板 / 标记色 / 画风翻译表三处）：

| 角色 | 用在 | 线稿（现） | 像素描边（v0.17.37 第一版） | 1-bit 线稿 |
|---|---|---|---|---|
| **墨** | 线稿线、结构线、描边、字、顶点小点 | #2a2a2a | 黑描边 #1b1b1b | 墨 #111111 |
| **纸** | 背景、字的底板 | #f2f0ea | #fde6bd | 纸 #f4f1e8 |
| **强调** | 选中（边 / 点 = 强调色，面 = 强调色调淡）、悬停（再淡一档） | 蓝 #2b6cb0 | 红 #d8323a | 墨（面 = 50% 网点） |
| **警示** | 刮擦将删、检查 | 红 #cc3333 / 橙 #d97706 | 橙 #f08a00 / 紫 #8b5cf6 | 墨 |

gizmo 的轴色（红绿蓝 = XYZ）和吸附的 SU 色是「通用语言」，不跟画风走（1-bit 这种两色的屏会把它们一起抖掉，那是屏的事）。
