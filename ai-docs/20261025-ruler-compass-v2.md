## 1. 为什么会晕：两种「尺规」

- **欧几里得尺规**是数学游戏：只能「过两点画直线」「以一点为心、过另一点画圆」，新的点只来自交点，**不许量**，平行垂直都得自己作。
- **CatsUp 要的是制图板**：丁字尺、三角板、比例尺、量角器、圆规。能量，平行和垂直是白给的。卷尺「从边拖开 = 按垂距出平行线」就是平行尺，属于制图板，不属于欧几里得——所以「卷尺不是尺规」这个感觉是对的。
- **从欧几里得只借一条规矩**：工具只产出「线」和「圆」；点只来自交点（求解器现找）。量多少、平行垂直、轴向，都是工具和推断白给的方便。

## 3. 工具

- **卷尺 T（只出线）**：起手在边 / 参考线上 → 平行线（打距离）；起手在点上 → 过两点的线（第二点吃平行 / 垂直 / 轴向推断，所以垂线白给）。不再新造参考点。
  - 平行模式打 **/5** = 起点线和终点之间等距 4 条平行线（N 等分白给）；**x5** = 按这个间距往外再出 5 条。与移动 / 旋转的阵列同一套语法（数值小窗已支持 x / /）。
- **量角器**：过圆心、按角度出线。打 **/3** = 三等分（角的 n 平分线白给）；**x6** = 每隔这个角度一条。
- **圆规（新，user 提的）**：圆心 → 半径点（或打半径）；平面规则同圆工具的首点。/n、xn = 同心圆。
  - **圆在哪个平面**（user 2026-10-25「3d，其实我蛮好奇会不会需要球规的。还是圆规的吸附可以决定圆画在哪个平面上面。这个怎么定」）：照圆工具 / 量角器——圆心落在面上 = 那张面；空处 = 当前画图平面（栅格开 = 栅格面 XY / YZ / XZ，否则地面）；要强制就用 Shift + 方向键平面锁。**球规先不做**（定长绳子 / 梯子够得到哪这种需求在关卡和建筑里少，参考球很挡视线；碰到具体场合再加）。
  - **球规（user 2026-10-25 晚拍了要）**：「对了，做圆规的时候顺便我真的想要球规。因为发现关卡设计这个会很有用」——随圆规一起做（参考几何多一种：球 = 到圆心距离 r 的点集；吸附 = 落在球面上）。edited by Claude Opus 5.5
