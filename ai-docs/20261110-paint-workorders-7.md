## 要达到什么

user 定的三条，这一张把它们变成能测的东西：

- **点到哪格就是哪格**：笔尖指着模型上哪一点，画的就是那一点底下的那一格贴图。
- **只认最后显示出来的那套三角形**：显示、落点、每格在空间里的位置、导出，四处用同一套三角形。
- **铺法再难看，画出来也要规整**：第一段的铺法是最笨的（每张面在画布上各占一块），但格子要和面的边对齐，从正面看不是镜像的。

做完之后有三样纯计算的东西，后面的显示（1-3b）和空间里的笔（1-4）都建在它们上面：

1. 给一批面铺贴图坐标。
2. 一张表：画布上每一格属于哪个三角形；每个三角形一条公式，把格子的位置换成空间里的位置。
3. 落点：屏幕上一点 → 打到模型的哪个三角形 → 哪一格。

## 一、先把三角形并成一处

现在网格体的一张面有两条路出三角形，两条路投影用的平面不是同一个：

- 屏幕上画的（`editor/pool-mesh.ts` 的 `buildFaceRec`）：`triangulateRings`，平面来自 `MeshView`。
- 内核、导出、网格体的吸附（`MeshKernel.triangles()`、`format/bake.ts`、`tools/mesh-snap.ts`）：`triangulateFace`，平面来自 `planeOfRing`。

算法相同，所以多数面上结果一样。但四个点共圆的面（正方形、长方形，白模里最多的就是它）两条对角线一样好，选哪条取决于投影的细节，两条路可能选得不一样。平的面上看不出来；不平的面、或者贴图坐标被拖过的面上，显示出来的和算出来的就对不上了。

要求：

- **网格体的一张面切成哪几个三角形，只从一个地方来**：`triangulateFace`（内核按 `rev` 缓存的那份）。屏幕上画网格体的面时用它，不再自己另切一遍。硬表面的面不动。
- 做法由你定（比如 `KernelView` 上加一个可选的「这张面的三角形」，`MeshView` 给，`buildFaceRec` 有就用）。
- **守卫**：一条测试，拿一批网格体（带正方形面、不平的四边形、凹多边形），逐面比较「屏幕上画的三角形」和 `MeshKernel.triangles()` 的三角形，顶点三元组的集合相同。再加一条扫源码的守卫，网格体的显示那条路上不许再直接调 `triangulateRings`。
- 现有的截图基线要照过。不平的四边形上对角线可能换了一条，基线变了的话，逐张说明是哪张面、为什么，不许直接重拍。

## 二、最笨的铺法

**输入**：一个网格体内核；要铺的一批面；一列贴图坐标（1-2 的那种列，每个角两个数）；密度（每米多少格）；块和块之间留多少格（整数，默认 4）。

**输出**：这批面的每个角在这一列上的值（单位是格，画布左上角是原点，横轴朝右、纵轴朝下）；画布的宽和高。

**每张面怎么摆**（一张面一块）：

1. 取这张面的朝向 n（环的绕向定的那个，`faceNormal`）和最长的那条边的方向 e（一样长取环上靠前的）。t = n × e。
2. 每个角的位置 p 换成平面上的两个数：横 = p·e，纵 = p·t，都乘密度。
3. 画布的纵轴朝下，所以纵向要倒过来：这样从正面看这张面，它在画布上的样子不是镜像的，最长的边是横着的。
4. 整块平移，让它的包围盒的左上角落在**整数格点**上。

这样一张长方形的面，如果边长乘密度是整数，它的四个角正好落在格点上，格子的行列和面的边平行。

**块怎么排**：按块的高从大到小排（一样高看宽，再一样看面的编号），一行一行从左往右放，放不下换行。块之间、块和画布边之间都留够间隔。同样的输入永远得到同样的结果。

**画布多大**：

- 没给密度：画布定成 1024 见方，二分找出能放下的最大密度（精确到每米一格）。
- 给了密度：宽取 1024（有一块比它宽就取够宽的最小的 256 的倍数），高取放得下的最小的 256 的倍数。
- 超过上限（参数给，默认 4096）→ 不铺，返回原因（哪张面、要多大）。不许悄悄把密度降了。

**以后给新面补一块**（这一张要留好口、做出来、有测试）：已经有一批面铺好了，再给几张新面各铺一块，放在画布上空着的地方；放不下就把画布往下加高（256 的倍数）。已经铺好的角一个数都不变。因为坐标的单位是格、不是零到一的比例，画布加高不会动到已有的东西。

**要成立的性质**（进测试）：

- 平的面：画布上任意两个角的距离 = 空间里的距离 × 密度（误差不超过千分之一格）。
- 每张面的多边形都在自己的块里，块和块不重叠，间隔够。
- 从正面看不镜像：画布上按环的顺序走，转的方向和从正面看这张面时一致（纵轴朝下算在内）。
- 确定性：同一个网格体铺两遍，逐位相同。
- 退化的面（面积是零）占一格，不报错。

**强行对称的网格体**：只铺留着的那一半；镜过去的那些面的角上的数是照抄的（1-2 定的），所以两半在画布上是同一块。这一张里提供「只铺这批面」的入口就够了，哪批面由调用的人给。

## 三、格子属于哪个三角形的表，和位置公式

**输入**：画布的宽高；这个网格体走这一列贴图坐标的所有面的三角形（第一节那一套），每个角带着贴图坐标和空间位置。

**输出**：

- **画布三角形**的列表：把贴图坐标完全相同的三角形（三个角的坐标逐位相同，不管顺序）并成一个。镜像的两半共用同一块画，它们的三角形在画布上是同一个。
- **归属表**：画布上每一格一个数，是画布三角形的编号，或者「没人要」。
- **空间三角形**的列表：每个带着它对应的画布三角形的编号，和一条**位置公式**（一次函数：格子中心的位置 → 空间里的位置；用这个三角形三个角的贴图坐标和空间位置解出来）。

**一格归谁**：

- 格子的中心是 (列 + 0.5, 行 + 0.5)。
- 算它到每个画布三角形的距离（在里面 = 0）。归最近的那个；一样近归编号小的。
- 距离超过「块之间间隔的一半」的格子没人要。

这一条规则同时管了三件事：中心在三角形里面的归它；正好压在两个三角形公共边上的有唯一的归属；块边上只被盖住一部分的格子也有人要（不然贴图边上会露底）。

**位置公式用在归属之外的格子上**：归属给了块边上那些中心在三角形外面一点的格子，它们的空间位置就是公式往外延出去的值（在那个三角形所在的平面上，略微出界）。这是有意的。

**两个画布三角形部分重叠、但不完全相同**：第一段的铺法不会产生这种情况。表照「最近、编号小」的规则给出唯一的归属，另外报出有多少格是被两个以上的画布三角形盖住的（以后手动拖贴图坐标的工具用它来提示）。

**要成立的性质**（进测试）：

- 中心严格在某个画布三角形里面的格子，归属就是它。
- 用空间三角形的公式算归属格子中心的空间位置，再用这个三角形三个角做重心插值反算回贴图坐标，回到格子中心（误差不超过千分之一格）。
- 相邻两个三角形在公共边上，两条公式给出的空间位置相同（平的面上处处相同）。
- 镜像的两半：两个空间三角形指着同一个画布三角形，各有各的公式，两条公式算出来的位置互为镜像。
- 改了点的位置、没改贴图坐标：归属表不变，只有公式变。

**速度**：建表的时间只随「所有块的面积」涨。一千张面、1024 见方的画布，量一下建一遍多久，写进记录。超过 50 毫秒就说，Fable 定要不要做成只重建改过的面。

## 四、落点

**输入**：一条射线（定义坐标）；网格体；那一列贴图坐标；归属表。

**输出**：没打中 = 空。打中 = 哪张面、哪个空间三角形、重心坐标、空间位置、贴图坐标（格为单位，重心插值）、哪一格（贴图坐标往下取整）。

- 打的是第一节那一套三角形。藏起来的面不算。
- 打中的面不走这一列贴图坐标（它的角上没有值）→ 照实返回「打中了，但这张面不在这张画上」，不当成没打中。
- **找最近的三角形不许逐个试**：一笔里每一帧要打很多条射线。用一个按空间分格或者分层的索引（三维仓里已经有的就用现成的；没有就写一个最简单的均匀格子）。一万个和四万个三角形的模型上各打一千条射线（看花的时间是不是不跟着三角形数涨；造模型加上量，总共不超过半分钟），量一下时间写进记录。

**要成立的性质**（进测试）：

- 随便取一格（中心在某个三角形里面的），用公式算出它中心的空间位置，从外面朝这一点打一条射线：返回的那一格就是它。
- 打在两个三角形的公共边附近，返回的格子和「显示时最近邻取样会取到的那一格」相同（都是贴图坐标往下取整）。

## 六、碰到这些就停下来报

- 把三角形并成一处之后，有截图基线变了。
- 1-2 做出来的列的形状和这里假设的不一样（每个角两个数、没有值 = NaN、按 GUID 认）。
- 归属的规则在某种情况下给不出唯一的答案。
- 三维仓里没有现成的空间索引，而且你觉得均匀格子不够用。
