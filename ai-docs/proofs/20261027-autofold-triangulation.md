# 证明留档：自动折面 rev2（非平面环 → 平面片 + 折缝）

> created 20261027 by Claude Fable 5.1 · as-of v0.15.2 / 2026-10-27 · 家族周账 F-105 / Fable 账单 K3 · 代码 `src/kernel/autofold.ts` · 钉住它的测试 `test/autofold.test.ts`

> 留档格式（Fable 账单 §0）：命题 → 定义和前提 → 证明 → 反例 / 边界 → 哪条测试钉住。

## 1. 命题

**输入**：一个空间多边形 R = (外环 O, 洞 H₁…Hₘ)，顶点是 3D 点；容差 tol（内核的同一平面容差）。
**输出**：若干片 Pᵢ（每片是一个 3D 顶点环）和折缝 Cⱼ（3D 线段），满足：

- (P1) **平面**：每片的全部顶点在 tol 内落在一个平面上。
- (P2) **不出多边形、不重叠、不漏**：取 O 的最佳拟合平面 π，把一切投影到 π；则各片的投影是互不重叠的简单多边形，它们的并集恰好是 O 的投影减去各 Hᵢ 的投影（面积相等）。
- (P3) **折缝 = 片与片之间的边**：每条折缝是某两片共有的边、且不是 R 的原边；原边都不是折缝。
- (P4) **确定性**：同一输入（同样的点、同样的顺序）给同样的输出；环的起点换一个，片的集合（按几何）不变。
- (P5) **凸环上折缝最少**（user 09-01「十边形对折应该只出一条折缝」）：R 是无洞凸多边形且恰能分成两个平面段时，输出 2 片 1 缝；拉单顶角时输出 2 片 1 缝。
- (P6) **诚实退路**：算法找不到满足 (P1)–(P3) 的分解时返回 null（调用方 BURST），不返回错的。

**前提**：O 和各 Hᵢ 作为 3D 环**至少在一个候选平面上的投影是「可用」的**（§2 定义）。候选平面 = O 的最佳拟合平面（Newell 法）、XY、YZ、ZX。不满足前提 → (P6)。

## 2. 定义

- **投影可用**：O 的投影是简单多边形（无重复点、面积非零、不相邻的边不相交、相邻的边只在公共端点相碰）；每个 Hᵢ 的投影简单、整个落在 O 的投影内部、和 O 及其他洞的投影不相交、不套在别的洞里。
- **圆盘块**：三角剖分里一组三角形的并，拓扑上是一个圆盘（边界是一条简单闭链，没有洞、没有捏点）。
- **原边**：O 和各 Hᵢ 的边（按顶点 id 的无序对）。

## 3. 算法

两条路都算，取片少的（同样多取缝少的，再平手取快路）：

**快路**（只在无洞时）：v1 的「极大共面段 + 结点弦」——沿环贪心取最长的共面前缀作为一段，段的端点是结点；相邻结点间连弦，每段自成一片，结点多边形自成一片。**新加验证**：在 π 的投影里 O 简单、每条弦是 O 的内部对角线（中点在 O 内、不与任何不相邻的边相交）、每片的投影简单且与 O 同向、各片投影面积之和 = O 的投影面积。任一不过 → 弃用。

**兜底**（总是算）：对每个候选平面依次：
1. 投影；检查可用；不可用换下一个平面。
2. **桥洞**（Eberly）：外环按逆时针、洞按顺时针；洞按最右点的 x 降序逐个并入：取洞的最右点 M，从 M 向 +x 射线找最近的边，得可见顶点 P（射线打到端点就用它；否则取边的较右端点，若三角 (M, I, P) 内有反射顶点则取与射线夹角最小的那个）；把洞一圈插进外环：… P, M, 洞, M, P, …。得到一个弱简单多边形（桥接处的顶点重复）。
3. **耳切**：逆时针多边形；每次在「还是耳」的顶点里选**离 π 最远的**（同距离取下标小的）切下三角形。耳 = 凸顶点且三角内（含边上）没有别的顶点（桥接重复点除外）。没有耳时先剔共线三点，再没有 = 多边形不简单 → 换平面。
4. **合并**：三角形按下标顺序做种子，向相邻三角形贪心生长；只有满足 ①并入后全部顶点在 tol 内同一平面（平面 = 种子三角形的平面）②并入后仍是圆盘块 时才并。圆盘判据：与当前块共享 1 条边 → 三角形的第三个顶点不在块里；共享 2 条边 → 公共顶点在块边界上恰有这两条边；共享 0 或 3 条 → 不并。
5. 每块的边界走成一个环（从最小 id 起）= 一片；片边界上不是原边的边（去重）= 折缝。

## 4. 证明

**(P2) 兜底路线。** 投影可用 ⇒ O 的投影是简单多边形、洞在内部互不相交。Eberly 桥接：每一步把一个洞用一条两次走过的桥接边连进外环，得到的多边形是弱简单的（边界只在桥接边上自接触），且它围住的区域 = 当前区域减去该洞（桥接边面积为零）。按最右点 x 降序处理保证射线只会打到外环或已并入的洞，不会打到还没并入的洞内部——Eberly 原文的引理。耳切定理（Meisters）：任何顶点数 ≥ 4 的简单多边形至少有两只耳；弱简单多边形同样成立（桥接重复点不构成新的交叉）。每切一只耳，三角形在多边形内且与剩余多边形内部不交；归纳到三个顶点，得到一个三角剖分：三角形互不重叠、并集 = 多边形区域 = O 减洞。合并只做三角形的并，不改变覆盖的集合；每块是若干三角形的不交并，所以各块的投影仍互不重叠、并集不变、面积之和 = O 减洞的面积。块是圆盘 ⇒ 块的边界是一条简单闭链，走出来的环是简单多边形。∎

**(P1) 兜底路线。** 三角形三点总共面（精确）。合并时每个新顶点都检查到种子平面的距离 ≤ tol，所以块的全部顶点在 tol 内同一平面。（注意：平面取种子三角形的精确平面而不是重新拟合，避免「每并一个三角形平面漂一点、最后首尾相差超过 tol」的滑移。）∎

**圆盘判据的正确性。** 设 B 是圆盘块，T 是与 B 共享边的三角形。
- 共享恰 1 条边 e，T 的第三个顶点 v ∉ B：B ∪ T 是把一个三角形沿一条边界边贴上去，边界链在 e 处被 T 的另两条边替换，仍是简单闭链 ⇒ 圆盘。若 v ∈ B，v 必在 B 的边界上（三角剖分里 T 的顶点不会落在 B 内部），贴上去后边界在 v 处自接触 ⇒ 捏点或夹出洞 ⇒ 拒绝。
- 共享恰 2 条边 e₁、e₂（必交于 T 的一个顶点 u）：若 u 在 B 的边界上恰有 e₁、e₂ 两条边，贴上去后 u 成为内点、边界用 T 的第三条边替换 e₁e₂ ⇒ 圆盘。若 u 的边界度 > 2，B 在 u 处已经自接触（不是我们生成的情形，但判据仍拒绝）。
- 共享 3 条边：T 填的是 B 的一个三角形洞 ⇒ B 不是圆盘，矛盾；判据拒绝。
归纳：种子三角形是圆盘，每一步并入都保持圆盘。∎

**(P3)**。折缝按定义取自块边界且剔除原边、按无序对去重。块边界上的非原边一定是三角剖分的内部边，内部边恰被两个三角形共享，两个三角形在不同块里（同一块的内部边不在边界上）⇒ 它是两片共有的边。∎

**(P2) 快路。** 验证条件直接就是 (P2) 的投影表述的充分条件：每条弦是内部对角线 ⇒ 片的边都在 O 内（片的边 = O 的边或弦）；片简单且同向 ⇒ 片的投影是 O 内的简单多边形；面积之和 = O 的面积且片都在 O 内 ⇒ 片互不重叠（若两片重叠，面积之和严格大于并集面积 ≤ |O|）且并集 = O（若漏了一块，和严格小于 |O|）。(P1) 由段的构造（每段共面 ≤ tol；结点多边形共面 ≤ tol，否则返回 null）保证。∎

**(P5)**。十边形对折：快路得 2 段、1 弦（直径），验证通过（弦是内部对角线、两半简单同向、面积守恒）→ 2 片 1 缝；兜底至多也是 2 片（见下），平手取快路。拉单顶角 v：兜底里 v 离 π 最远，第一只耳就是 (prev, v, next)（凸顶点、三角内无其他顶点，因为 v 的两个邻点之外的顶点都在 O 的另一侧），剩下的 n−1 边形全在原平面，耳切出的三角形全共面且每个新三角形与已合并块共享 1 条边、第三顶点为新顶点（耳切的剩余多边形是简单的，每只耳贴在当前块外侧）⇒ 合并成 1 片；共 2 片 1 缝；快路给 3 片 ⇒ 取兜底。∎

**(P4)**。所有选择都按确定的全序：候选平面顺序固定；洞按 (最右点 x 降序, 下标)；耳按 (离 π 的距离降序, 下标)；合并种子按三角形下标升序、候选按下标升序；块边界从最小 id 起走。Newell 法平面对环起点无关（求和），所以起点换一个时 π、投影、洞序都不变；耳序里的「下标」是 id 序（随起点变），但 (P2) 的集合性质不依赖具体剖分——测试只断言片的几何集合在起点旋转下不变（在样例上成立；一般情形下只保证 (P1)–(P3)，不保证剖分逐点相同，这是**有意不承诺**的）。∎

**(P6)**。每个候选平面都「不可用」或耳切失败 ⇒ 返回 null。快路验证失败不会返回错的（直接弃用）。∎

## 5. 边界与反例

- **蝴蝶结**（四点自交的环 (0,0),(2,2,.3),(2,0),(0,2,.3)）：四个投影都自交 → null → BURST。这是正确的：它不是一个面。测试「真拧成麻花」。
- **环里有重复的非相邻点**（捏点多边形）：投影不简单 → null。settle 的 `dedupeRing` 只去相邻重复点；捏点环以前也是 BURST，行为不变。
- **投影在拟合平面上退化、在坐标平面上简单**（一个几乎竖直的折片）：候选平面顺序兜住。
- **拟合平面投影简单但严重倾斜的三角形**：投影面积很小但非零；耳切照样正确（面积只用来判方向）。
- **多个洞互相靠得很近**：桥接的射线可能先打到已并入的洞的边——这正是 Eberly 要求按最右点降序的原因。
- **不保证最少片**：合并是贪心的；(P5) 只对两种典型情形承诺。更少的片 = 以后的优化，不影响正确性。
- **带洞时两条路只算兜底**：快路的 v1 算法不管洞。
