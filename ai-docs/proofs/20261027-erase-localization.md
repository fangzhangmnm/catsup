> 现象（Opus 10-26 实测，全合并坦克 3.2 万面 / 1.35 万平面）：擦 50 / 200 / 800 条软边 97 / 95 / 138 s，和擦几条几乎无关——99% 在 `reconcileErase` 把**全部平面**重新切胞腔。

## 1. 擦边机做什么（定义）

设状态 S = (图 G, 膜库 F, 平面登记 Π)。擦边集 X：
1. **裁决**（删边前）：对每条 e ∈ X，看挂在 e 上的膜（按平面分组）：同平面 ≥2 膜共享 e → 这些膜 MERGE；只有 1 膜且 e 在它环上出现两次（桥）或在洞环上 → 该膜 heal（ABSORB）；只有 1 膜且 e 在外环上 → BURST。裸边 → 无事。
2. **删边**：G ← G \ X。
3. **整理**：并组（按并查集合成）和 heal 膜要找**后继胞腔**：在膜所在平面 P 的胞腔分解 Cells(P) 里，取包含膜的代表点、且没被别的活膜占着、没被本轮别的后继拿走的那个胞腔；找到 → 出库旧膜、铸新膜；找不到 → 死。纯 BURST 直接出库。
4. faceLinks（边 → 膜的索引）更新。

Cells(P) = 平面 P 上全部边（两端点都在 τ 内）构成的平面图的面（findRegions）。

## 2. 命题

**（局部化）** 设 A = {并组成员和 heal 膜所在的平面}（「被碰到的平面」）。只对 P ∈ A 计算 Cells(P)（输入 = 删边后 G 中落在 P 上的全部边），其余平面不算，得到的整理结果（事件、膜库、faceLinks）和「对全部平面计算 Cells」逐字相同。

**（裁决的候选）** 裁决只需看 `faceLinks(e)` 列出的膜，不需扫全部膜。

## 3. 证明

**裁决的候选。** faceLinks 是边 → 膜的权威索引：膜 f 的环含 e ⇔ f ∈ faceLinks(e)（装载时全量重建，之后每次结算 / 擦边增量维护，relinkFaces 的不变量）。裁决只用「哪些膜的环含 e」这一事实，所以从 faceLinks 取候选再数出现次数（`occurrences`）得到的裁决与扫全部膜相同。顺序：faceLinks 按 id 升序，扫全表时按膜库插入序——并组成员的顺序可能不同，但并组是集合（并查集），后继查找「按成员顺序找第一个有后继的」在同一组里对任一成员找到的是同一个胞腔（见下一段），事件里 `from` 的成员列表按 id 序，两台机一致（差分测试逐字比）。∎

**局部化。** 整理步只在 `findRegionAt(f.planeId, ·)` 处读胞腔，f 遍历并组成员和 heal 膜，所以**只读 P ∈ A 的 Cells(P)**。因此只要对每个 P ∈ A，局部算出的 Cells(P) 等于全局算出的 Cells(P)，整理结果就逐字相同。

全局路径：`groupCoplanar` 先从全部顶点发现 / 登记平面，再把每条边按「两端点在 τ 内」分到每个登记平面（cover：一条边可进多组），每个平面各自 findRegions；最后跨平面去重：同一个边环若在两张近平行平面上都成了胞腔，只留拟合误差小的那张。
局部路径：只对 P ∈ A，把删边后 G 的全部边按同一条「两端点在 τ 内」规则挑出来（一次扫边，O(E × |A|)），交给同一个 findRegions；跨平面去重只在 A 内做。

两者在 P ∈ A 上的输入边集相同（同一条规则、同一张 G），findRegions 是确定性的纯函数 ⇒ Cells(P) 相同。差别只有两处：
- (i) 全局路径会**发现新平面**（discoverPlanes）并 prune 没边组的平面；局部路径不发现、只可能删掉 A 里没边组又没膜的平面。擦边不加顶点，删边不会产生需要新平面的几何；A 里的平面本来就有膜（它们是膜的平面）所以不会被删。登记表的差别不影响 A 上的胞腔。
- (ii) 跨平面去重：若某个边环在 P ∈ A 和 P′ ∉ A 上都成了胞腔、且 P′ 拟合更好，全局把它判给 P′、从 P 的列表里拿掉，局部留在 P。这要求两张 τ 内近平行的平面共享同一个边环——和结算机局部化（立宪页 §3）依赖的同一条前提：**膜的平面是它自己的平面**（同环不同平面 = τ 带里的脏嵌入，差分测试的 nasty 档已知不是不动点）。在这个前提下 (ii) 不发生。

faceLinks：全局用 `rebuildFaceLinks`（清空重建、按 id 排），局部用 `relinkFaces(changed, oldRings)`（只动出库膜的旧环边和新膜的环边，碰到的边按 id 排）。没碰的边：全局重建后内容 = 原来挂的膜集合（这些膜没动）按 id 排 = 局部不动的那份（不变量：faceLinks 始终按 id 排）。碰到的边：两边都是「现在挂着的膜按 id 排」。相同。∎

## 4. 代价

- 裁决：O(Σ|faceLinks(e)| × 环长) 代替 O(|X| × 全部膜 × 环长)。坦克 800 条：4.6 s → 毫秒级。
- 整理：O(E × |A|)（一次扫边）+ Σ_{P∈A} findRegions(P) 代替 Σ_{全部平面} findRegions(P)。擦一条软边：|A| = 1，只切那一张平面。
- 可以再省的（没做）：按平面索引边（空间网格或每平面边集），把 O(E × |A|) 的扫边变成 O(被碰平面上的边数)；以及只对被碰平面上「含被擦边的连通分量」做 findRegions。坦克数字（§5）说明现在这一刀已经够。

## 6. 边界

- 一条边挂 ≥3 膜（非流形、radial）：裁决按平面分组各自判，候选来自 faceLinks（每个平面各挂一次）——和以前一样。
- 擦到曲线的一段 = 整条曲线一起（调用方在裁决前把曲线成员并进 X），不变。
- 并组被 BURST 污染 → 整组死，不找后继，A 可以为空 → 一张平面都不算。
- 空闭环（闭环无膜）落在被碰平面上：它的边在 Cells(P) 的输入里，并后的膜会把它当洞——全局也是这样（差分测试的场景里有一个）。
