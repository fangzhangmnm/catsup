## 1. T1：10-26 补丁（③b 手势出生、⑤ 双胞平面、去掉 1 m 余量）审了什么、结论

**审的命题**（立宪页 §3）：在被碰平面 P 上只用边集 S 切胞腔，去掉与未受影响膜同环的，等于用 P 上全部边切胞腔去掉未受影响膜的胞腔。骨架：会被填的胞腔只有两种来源——被像认领、手势出生。

**结论：骨架成立，③a / ③b / ⑤ 的构造对；但有一条「经验条款」说明 D（这次变化的边）在 τ 带里被低估了，补丁是把洞盖住、不是把洞找到。** 逐条：

1. **③a（像的包围盒 ± 2τ）成立。** 像的环段在 ② 插边时已经进了平面图，所以 P 上每个胞腔要么整个在像的环里、要么整个在外（胞腔不跨环）。被像认领 = 代表点在环里 = 整个胞腔在环里 = 胞腔的全部边界边在环的包围盒里。2τ：在 P 上的边两端点离 P ≤ τ，盒子在法向上可能零厚度。∎
2. **③b（手势出生胞腔的外环走一圈）成立。** 出生条件 ⑧ = 无主胞腔、外环含手势边。从每条手势边两侧沿当时的平面图走胞腔边界（`around(v)` 用的是 g 里这张平面上的全部边，不是 S，所以走的是真胞腔），逆时针闭合 = 有界胞腔的外环，它的边全进 S；它的洞是环包围盒里的孤岛，盒 ± 2τ 盖住。顺时针 / 零面积那侧是无界区或别人的洞，不会出生。前提：手势边在走之前已经插进 g（② 在 ③/影响域之前，代码顺序如此）。∎
3. **⑤（双胞平面）成立但偏保守**（Opus 自己说的「< 2.6° 偏保守」）：认领是跨平面的（平行 2.6° 内、代表点离像 ≤ 3τ），所以像可能在 Q 上认领到胞腔，Q 上像的盒 ± 3τ 里的边和与盒相交的膜要进 S，入选的膜的身份像又会认领 → 迭代到不动点。保守 = 多补边、不出错，可接受。
4. **经验条款**（`settle.ts` 影响域里「这张平面上脏边的包围盒 ± 2τ（经验条款，没证明）」，nasty 种子 271·104729+17 第 7 步：盒里两张旧面没入选、全局却改了它们）。读法：**全局改了一张「未受影响」的膜 = 那张膜其实受了影响、但 D 没记到它**。D 的定义是「新插入 / 切出 / 动过坐标的边」；能漏的地方只有 ③ planarize（τ 带自愈：把近重点并掉、把骑边的点压到边上、切开交叉）——它改的边如果没有全部回流到 `dirtyLive`，那张膜的环边变了而它不在 F*。补丁用「脏边的包围盒」把附近的膜一并捞进来，在那个种子上够用，但不是定理。
   - **要做的（没做，排在 mesh 内核之后）**：让 planarize 把它碰到的每条边（切出的、并点改写的）都登记进 D（它已经有切割血缘「喂回手势集 / 随葬集」的管道，补一条喂回 dirtyLive 即可），然后用差分 oracle 的 nasty 档跑 271 那个种子验证可以去掉经验条款。去不掉 = D 还有别的漏，继续找；去掉了 = 定理完整。
   - 经验条款留着不伤正确性（只多算），所以不急。
5. **clean 档 4 个种子「新面编号 / 列出顺序局部与全局不同、几何逐点相同」**：编号来自铸新膜的顺序 = 遍历胞腔的顺序，局部的 S 比全局小，findRegions 的追踪起点不同 → 顺序不同。几何相同即定理成立；id 序差异不是定理的事，是「事件逐字相同」这条**测试口径**比定理严。两条路：把 clean 档的比较改成几何 + 按几何配对后的 id 一致（放松口径），或者让 findRegions 的输出按环的几何键排序再铸（两边同序，代价一次排序）。推荐后者（确定性更强，联机重放也受益），小改，排在 mesh 内核之后。

## 2. K4：公理是不是归纳、自愈能不能「一次装进去再修」

**答：公理是不变量，靠归纳维持；「转回去那一下生效一次」的读法是对的，而且是唯一可能的读法——因为结算机在两种模式下都不自愈未碰到的地方。**

1. **不变量**（brep 状态合法 = 五条同时成立）：(I1) 每张平面上的边构成平面图（不交叉、点不骑在边内部）；(I2) 每张膜 = 它平面上的一个胞腔，膜与膜不重叠；(I3) 重合即同一（量化格上没有两个点同坐标）；(I4) 每张膜的环在 τ 内共面；(I5) faceLinks / 平面登记与膜一致。
2. **归纳**：基 = 空内核（显然成立）或一次合法装载；步 = 每个动词的结算机在影响域内重建 (I1)（② 插边 sticky、③ planarize）、(I2)（⑤–⑧ 认领裁决）、(I3)（量化 + 粘连）、(I4)（④ autofold，rev2 起不再因折不开而丢面）、(I5)（relinkFaces / 平面登记）。**影响域之外一个字节都不碰**——这正是局部化定理：局部结算 = 全局结算，而全局结算也只重铸受影响膜的胞腔、未受影响膜原样保留（定理的右边就是「去掉未受影响膜的胞腔」）。所以**没有任何一步会去检查或修复远处的违规**；如果基不合法，违规会一直躺着，直到某次操作碰到它——那时结算机在那块影响域里按合法的规则重算，可能把它「修」成合法的、也可能撞守恒断言（宁炸不糊）。
   - 「一步不满足后面雪崩」：不会雪崩，会**潜伏**。远处的违规不传播（影响域是局部的），碰到时局部处理。这比雪崩好，但也意味着**合法性必须在装载那一下建立**，不能指望「用着用着就好了」。
3. **装载 = 建立不变量的一次性检查 + 修**（`from-triangles.ts`，10-26）：量化合点 (I3) → 去退化 / 重复 → 按平面分组 (I4) → `Kernel.fromBrep` 整批装（只查结构 (I5)）→ 用内核的精确谓词挑出违反 (I1)/(I2) 的三角（点骑在别的边内部、同平面边相交、同平面互相盖住）→ 只把这些交给结算机 `absorb`（整批 → 32 一块 → 逐个，逐个也被拒的丢掉并计数）。**这就是「一次装进去再修」**，而且是对的：装进去的那份只要通过了 (I1)–(I5) 的谓词，归纳的基就成立；没通过的那一小撮走结算机 = 按合法规则重算它们的影响域。
   - **谓词完备吗**：(I1) 两条谓词（骑边、同平面交叉）盖住；(I2) 「同平面互相盖住」盖住重叠，但**没查「同平面两张膜共用一条边且在同一侧」以外的边界共享不一致**（例如两张三角共享一条边但一张的环把那条边走了两次 = 桥）——这类由 `fromBrep` 的结构检查（环闭合、边存在）部分覆盖；(I3)/(I4)/(I5) 由构造保证。**没核的**：谓词是对三角跑的；mesh → brep 转换 n 边形时要先按 K3 的办法（投影三角化 + 合并）变成平面块，再走同一套谓词。建议转换时**直接复用 `kernelFromTriangles` 的管线**（先三角化、装、修），而不是另写一条 n 边形装载路——少一套要证明的东西。
   - 熊 392 三角修 30 拒 0、坦克 32018 三角修 809 拒 0（28.6 s，平方的那半在修的批次里）。
4. **测试缺口**（user 问的「差分测试永远从空内核起步」）：对。要补一条「从装载态起步」的差分：装载一个三角汤（熊 / 球）成 brep，之后同一串随机操作 local vs global 对拍。这条测试本身不证明装载态合法，只证明「从装载态开始局部化仍成立」——合法性靠谓词 + 守恒断言。排在 mesh 内核之后，和 §1 第 4 条一起做。

## 3. 一句话给 user

- 公理 = 不变量，归纳维持；远处的违规不雪崩、会潜伏到被碰到；所以「一次装进去再修」是对的，而且必须在装载那一下把不变量建立好——现在的谓词 + absorb 做的就是这件事，mesh → brep 转换照抄这条管线。
- 10-26 的局部化补丁构造正确；留着一条「经验条款」说明 planarize 改的边没全部回流到脏边集——不伤正确性（只多算），根治是让 planarize 回流 D，排在 mesh 内核之后。
