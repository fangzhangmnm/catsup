## 2. AI 的看法（think critically；都不是要求）

### 2.1 框选和套索合在一个选择工具里，怎么切（FM2）

- 自动认（拖出来的线回到起点附近 = 套索，否则 = 框）会误认：画一个很扁的套索、或者框拖到一半拐回来。
- 推荐：选择工具一个子选项「框 / 套索」，记住上次用的；按住一个键临时换另一种。笔默认套索（笔画圈最自然），鼠标默认框。
- 框保留 SU 的两种语义（左往右 = 全在框里才选、右往左 = 碰到就选）；套索里点按「在不在圈里」，边和面按同一规矩。

### 2.2 X 光下的框选（FM3）

- 现在 CatsUp 的框选不管 X 光开不开都穿透（SU 同款：框住盒子打组要连背面一起）。Blender 是 X 光关 = 只选看得见的，开 = 穿透。
- 自由建模里「侧视图框上半身」两种都要：只要前面那层（修脸）和整片穿透（选整条手臂）。推荐：**X 光开关同时管单击和框选**，自由建模默认关、硬表面保持现状（穿透）——这是两个工作台的默认值不同，不是语义不同。要 user 拍。

### 2.3 选完自动弹环形菜单（FM4）

- 好处：菜单在手边（iPad 上手不用跑到屏幕边）、按方向记肌肉记忆（Blender 的饼菜单就是这个好处）。
- 坏处：① 每次选完都弹，挡住刚选的东西，而很多时候选完是要换工具或者直接拖把手；② 和「点两下」手势打架（选完马上要点下一下）。
- 推荐先做成「不自动弹、在选区上长按 / 鼠标右键在原地弹」（现有上下文菜单本来就按指针分流：鼠标右键 / 笔和手指长按），环形只是这个菜单的另一种画法；自动弹做成开关去实验。

### 2.4 绑骨变换（FM6）

- **轴心默认 = 选区边界那一圈的中心**：套索圈住一条手臂，选中和没选中的交界正好是肩膀那一圈，它的中心就是关节。点一下可以改，改过的记住（FM7 各工具自己记）。
- **衰减按表面走，不按直线距离**：直线距离会把挨着手臂的腰侧也带走；按网格连着走的距离只影响肩膀附近。WeebPaint #25 列的「解拉普拉斯」就是这一类（权重沿表面平滑过渡）；低多边形角色几百个点，算一次很便宜。
- **转的时候按权重缩放角度，不要把位置按权重插值**：把「转了的位置」和「没转的位置」按权重线性混合，转大角度时关节会塌成一团（骨骼动画里的「糖纸扭」问题）；每个点「绕轴心转 权重 × 角度」就不会塌。缩放同理（倍数取权重次方）。
- 半径 = FM20 那个全局软半径。

### 2.5 SU 的选择和自由建模对齐（FM9）

- 三击 = 整块，两边本来就一样。
- 双击：SU 现在双击面 = 面带它的边（SU 用来连边一起挪一张面的老手势），对齐后双击面 = 面环。**这一处会改 SU 的老习惯**，要 user 确认是不是这个意思（另一种读法：只是把灌面模式对齐，双击照旧）。

### 2.6 刀：误切、名字、收尾（FM10–FM12）

- **双击误切**：刀在还没开始切的时候双击一条边 = 「起点和终点是同一个点」的线，这本来没有别的意思，所以识别上不会和别的操作撞；已经在切的时候双击 = 收尾（见下）。误切靠：第一下按下就预览整圈、马后炮能改位置和刀数、一步撤销；再加你要的模式按钮（不想用双击的时候点它）。
- **名字**：「刀」和 Blender 对齐、搜得到；「线」守你的「同一个工具别在两个模式差太多」——SU 模式的线画过面本来就会把面切开，自由建模的刀 = 同一个线工具，只是不自动长面、只吸拓扑点。如果叫两个名字，就是同一个工具两个名。AI 偏「线」，提示里写「（Blender 的刀 K）」、命令搜索搜「刀」也能找到。user 拍。
- **Blender 怎么收尾**（据我所知，没在本机 Blender 里核）：点一下加一个切点，自动切过路上碰到的边；回车 / 空格 = 确认，Esc / 右键 = 取消；E = 另起一条线、不退出；回到起点闭成环、点到已有的点或边上**都不会自动结束**。SketchUp 的线是另一种：闭合成面那一下就断开、重新开始。
- 推荐：**成环 = 收尾**（SU 的习惯，一圈切完就是一件完整的事）；**落到线上 / 点上不收尾**——沿着一串已有的点切（重新布线时很常见）会被打断，而且路过的边本来就自动切开；另外回车 / 小窗「完成」/ 在最后一点双击 = 收尾。代价：最常见的「点 A 连到点 B」要多一下收尾（双击 B）。

### 2.7 Blender 里「加几何」的操作有哪些（FM13 科普）

按「拓扑怎么变」分，常用的就这几族：

| 族 | Blender 里的操作 | 拓扑在干什么 | 我们这边 |
|---|---|---|---|
| 长一圈、原来的留着当帽 | 挤出 E（沿法线 / 自由 / 每张面各自 / 挤到游标）、内插 I（留在面里往里缩，带深度就等于挤出）、加厚 Solidify、旋转扫 Spin / 螺旋 Screw | 复制边界、连起来 | 拉 / 插；扫 = SU 跟随 |
| 把一个东西换成一条带 / 一圈、原来的没了 | 倒角 Ctrl+B（边）/ Ctrl+Shift+B（点）、边环偏移 Offset Edge Slide（一条环变两条）、戳 Poke（面中心加一点连成扇）、撕开 Rip | 拆开再连 | 插在点 / 边上 |
| 在面上加边 | 刀 K、连线 J、环切 Ctrl+R、细分 Subdivide、平面切 Bisect、投影刀 Knife Project | 只切不长 | 刀（含环切） |
| 补面 / 连两块 | 填 F、网格填 Grid Fill、桥接边环 Bridge | 长出新面 | 填 |
| 减 | 删除 X、溶解 Ctrl+X / 有限溶解、合并 M、塌缩 | — | 删 / 橡皮 / 合 |
| 只挪不改拓扑 | G / R / S、滑边 / 滑点、收缩 / 膨胀 Alt+S、推 / 拉向中心、变球 To Sphere、平滑、扭曲 / 弯曲 | — | 挪 / 绑骨 / 缩 / 雕 |

- 所以 insert / pull / bevel 就是前两族的核心，再往外是低频的（戳、加厚、桥接、网格填、撕开），放右键 + 命令搜索。
- **合租建议按「拓扑怎么变」合，不按目标合**：挤出和内插在面上是**同一个操作**（都长一圈、原面留着当帽），只是那一圈往哪走——正是你 D-9 说的「e和i完全是等价的，就是对齐模式不同」。所以「拉」= 一个工具，对齐默认沿法线、一个键 / 把手换成「留在面里」= 插。倒角是另一族（原来的边 / 点没了），单独一个工具，和拉合租一个工具格（小三角换）。手稿里「插」的另外两种意思分出去：空处建 n 边形 = 形状格里的多边形（和 SU 模式同一个工具）；点 / 边上 = 倒角。
- 这样每个工具只做一种拓扑操作，「一个工具几种意思」只剩对齐方式一种，提示行写明当前对齐就看得出来。

### 2.8 锁轴贴近视线时挪得变慢（FM18）

- Blender 的做法：让点「跟着鼠标的投影」走，轴快和视线平行时，轴在屏幕上很短，鼠标动一点点 = 沿轴走很远，平行时除以 0。
- 你要的：动多少 = 鼠标位移 · 屏幕上那根轴（不归一化）。轴在屏幕上越短，走得越慢，平行时 = 0，不跳不炸，守「石膏没有刻度、输入是光滑映射」。侧视图 Shift+Z 时 X 照常、Y（朝屏幕里）自动变慢，正好是想要的。
- 一个例外要想清：**拉（只有一个方向）正对着拉**的时候，按这个规则就拉不动了（轴在屏幕上缩成一个点）。拉的那根轴快和视线平行时，改用鼠标上下移动当拉的量（SU 推拉的做法）。

### 2.9 永远自动粘连（FM19）

CatsUp 的「粘」有四件：① 落在同一格（1 µm）的两个点就是同一个点；② 点落在边上会把边切开；③ 同一平面里交叉的边在交点切开；④ 同一平面里的面按封闭的环自动分 / 并（肥皂膜）。

- **温柔的地方**：永远不会有重复点——Blender 的「按距离合并」（你 D-9 列的低频必卡之一）从此不用了；镜像中缝、填洞、合点永远焊上；不会有看不见的裂缝。
- **坑**：① 和 ② 在自由拖点时几乎碰不到（不吸附的手拖不进 1 µm）；**③ 和 ④ 会咬人**：起型阶段全是轴对齐的盒子和圆柱，挤出来的腿侧面和身体侧面一旦挪到同一平面又叠在一起，就会被自动切开 / 并面，拓扑悄悄变了（多出 T 形接点、边环断掉），要到下次选环的时候才发现。刀绕一圈长出夹层面（设计稿 §3 坑 ①）就是 ④ 的一个例子。
- **推荐**：① 留着（这是真温柔）；②③④ 在自由建模里要不要关，是内核公理的事，并进 Fable 的内核权衡（家族周账 F-104）；不管关不关，「这一步顺带并了 2 个点、切开了 1 条边」都要说出来（默认 + 披露），不静默改拓扑。
