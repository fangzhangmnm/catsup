# 跨模型挑着拷：把一个模型当素材库——规划稿（等 user 拍）

> created 20261029 · as-of v0.16.57 / 2026-10-29 · created by Claude Fable 5.1 · 周账 F-127（user 10-29「wishlist，如何把东西从一个项目拷贝到另外一个项目，但是不是全量导入，到时候让fable计划一下，也是比较优先的。其实就有点像一个项目被当作素材库用的感觉」）
> 现状：剪贴板 Ctrl+X / C / V 只在同一个模型里（v0.16.50：载荷里组件 / 材质按编号，换了模型对不上就如实拒绝）。设计稿 `20261028-object-layer-and-clipboard-design.md` §3 已留口：「载荷能序列化成 .catsup 片段」。

## 0. 一句话

**不另造「素材库」这个东西**：素材库 = 任何一个 .catsup 模型；拿东西 = 在那个模型里拷贝，到这个模型里粘贴。要做的只有两件：① 载荷从「按编号引用」改成「带着值走」（组件定义的几何 + 材质的颜色 / 贴图字节一起装进去）；② 贴进来时按**内容**对上已有的定义 / 材质（一样的不重复长出一份），对不上就新建。浏览 = 开另一个模型（图库本来就能开）；以后「摆放」工作台 / 物品栏做了，再把「从别的模型拿」挂成一个入口，底下还是这两件。

## 1. 载荷带值走（改 `editor/transfer.ts`）

现在 `TransferPayload` 里实例 = `{ def: DefId（编号）, xform }`、面的材质 = 槽号 → 文档材质编号。改成：

- `defs: Record<DefId, { name, body: brep 快照 | mesh 片段, materialSlots, 子实例 [...], guides, drawFrame }>`——被引用的每个定义**深拷贝**进载荷（§3 本来就有「每个被引用定义的深快照（兜底）」，现在它不是兜底、是正文）。
- `materials: Record<MatId, { name, color, texture?: { mimeType, bytes, sizeM } }>`——贴图字节随载荷走（贴图一张几百 KB，剪贴板住内存，没问题；序列化成文件时也带）。
- 剪贴板不再记 `docEpoch` 拒绝跨模型；改记「这份载荷自带一切」。

## 2. 贴进来按什么对上（三选一，推荐甲）

| 方案 | 规则 | 好 | 坏 |
|---|---|---|---|
| **甲 内容指纹**（推荐） | 定义 / 材质各算一个内容指纹（定义 = 几何规范序 + 槽表 + 子树；材质 = 名 + 色 + 贴图字节 sha256）；目标模型里有指纹一样的 → 复用、不新建；没有 → 新建 | 拷两次同一个组件 = 同一个定义（SketchUp 的「同名组件就是同一个」我们用指纹做，不靠名字）；拷过来再改过的 = 指纹不同 = 新的一份，不互相踩 | 指纹要算（规范序已有：`brep-codec.ts canonicalize`、mesh 可按同样做法）；大定义算一次几十 ms，可接受 |
| 乙 按名字 | 同名 = 同一个 | 最简单 | 两个模型里恰好同名但不同的组件 = 贴错（静默）——不行 |
| 丙 永远新建 | 每贴一次长一份新定义 | 零判断 | 拷十次椅子 = 十个定义「椅子」「椅子 2」…；物品栏里全是重复 |

甲落地：`scene/fingerprint.ts`（纯函数，定义 / 材质各一个）；贴的时候 `paste` op 多一步「对指纹 → 映射编号」；重名但指纹不同的新定义名字后面加「(2)」并提示行说一句（不静默）。

## 3. 浏览：怎么从素材库里挑

- **第一步（这一批）**：就是「打开那个模型 → 选 → Ctrl+C → 回到这个模型 → Ctrl+V」。图库已经能开模型；剪贴板跨页面存活靠 §1（载荷住内存，同一个页面换模型不丢）。**不做**第二个窗口、不做侧栏预览。
- 第二步（「摆放」工作台 / 物品栏做了之后）：物品栏多一页「别的模型」——列图库里的模型，点开一个 = 列它的组件定义（名字 + 缩略图），点一个 = 当作剪贴板载荷挂到光标上放。底下仍是 §1 / §2。缩略图：定义级的还没有（只有文件级封面），到时按 `peek.ts` 的路子烤。
- 不做：「链接」到别的模型（改那边这边跟着变）。素材 = by value（家族规矩同音源库：用到什么拷进文件）。

## 4. 和别的事的关系

- 「摆放」工作台（user 10-28 夜拍 entity = 物件、验证并进摆放）：它是入口的归宿，不是前提。
- 材质槽：贴进来的材质和目标模型的材质表按指纹合并；材质面板只多出真的新材质。
- 文件格式：载荷序列化成 .catsup 片段（§3 留口）= 导出「只这几个物件」已有（`writeGltfModel only`），反过来「从 .catsup 文件挑着导入」= 同一个载荷模块读文件 → 走 §2。这就把「素材库 = 任何 .catsup」坐实了，连打开都不用。

## 5. 要你拍的（一次问完）

1. 对上的规则用甲（内容指纹）吗？——选甲：拷两次 = 同一份，改过的 = 新的一份；选丙：每次都长新的、物品栏会重复。
2. 第一步只做「开那个模型拷、回来贴」（不做浏览界面），浏览等物品栏——可以吗？
3. 贴图字节随载荷走（剪贴板里会有几百 KB 到几 MB）——接受吗？不接受的替代 = 只带引用、贴时提示「贴图没带过来」。
