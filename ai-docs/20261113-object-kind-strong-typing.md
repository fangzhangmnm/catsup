## 二、规矩

1. 种类在新建时定。之后只有「切换种类」这一个动作能改它。删光几何，种类不变。别的任何操作都不许顺手改种类。
2. 种类现在三种：硬表面、自由建模、空物体。空物体 = 自己没有几何，只装子物体。
3. 在一个有东西的物体里要另一种类的东西 = 在它里面新建一个那种类的子物体，不碰原来的。
4. **切换种类**：物体窗口第一页的动作。列出能切到哪几种，每一种说清会丢什么（现成的丢失清单在 `scene/kinds.ts` 的 `castsTo`）。切到空物体只在这个物体里面没有东西时可用。〔统筹加〕「没有东西」= 自己没有几何；挂着子物体不算。
5. **创建父物体**（Unity 的 Create Empty Parent）：新建一个空物体，当前这个物体整个放到它下面，位置不动。和切换种类是两个按钮。空物体也能用。在根上用 = 给根包一层：那份定稿（讨论文件「给根包一层：设计定稿」第 1 到 6 条）照用，新的根 = 空物体。
6. 空物体里不显示要几何的工具（画线、拉出这类）。空物体有自己的工作流：摆放、排布（user 11-13：「工具不显示，空物体有自己的工作流，就是排布之类的placement……我希望是把blender和sketchup里面的好处都拿到」）。这一套怎么设计正在和 user 谈，谈完另写一节。统筹先前提的「不能用、说原因、给出口」作废。

## 三、物体窗口四页

| 页 | 放什么 |
|---|---|
| 物体 | 现有的字段（名字这些）；切换种类；创建父物体；〔统筹加〕新建子物体 |
| 种类的那一页（页名 = 种类的名字） | 这个种类自己报的选项和动作。自由建模 = 对称和镜像面、细分、默认平滑、展开贴图（user 11-13：「uv展开也放到网格体这个tab（就是对称 细分 平滑里面」；它和镜像一样是一个选项、分自动和手动两档，见本节表下）、修复面板；硬表面 = 它现在有的那些；空物体 = 没有这一页 |
| 元素 | 现有的 |
| 材质和贴图 | 这个物体挂着的材质、画、贴图坐标的表。〔统筹加〕第一版只看，外加一个「把画拿掉」的出口（user：「如果有drop贴图我也能逃生」）；和任务清单里的「材质面板第一版」是同一件事 |

**展开贴图是一个选项，不是一个动作**（user 11-13，语音：「展开贴图，它不是一个动词，而是相当于和镜像一样是一个制动的选项，就你可以勾选制动，然后就是它会自动帮你每次有大的变动的时候展开。如果你勾选手动的话，就是如果你有增加的话，就是用比较笨的方法往后加，然后你可以在手动点一下来优化。」「制动」= 自动）。手动 = 现在的做法（新面往画布下面接着放）加一个「优化」的按钮；自动 = 有大的变动时自己重新展开。两档都要靠搬画（重新展开时画跟着搬到新位置），所以排在搬画之后。〔统筹标着没定〕自动档里「大的变动」指什么。

以后带标记的物体（游戏关卡里的标记这类）多出来的页，也照第四节的办法由挂在物体上的东西自己报。

## 四、每个种类自己报选项（窄接口，提案；合之前这个接口过统筹）

现状：物体窗口里的动作来自一张放置表（`editor.commandMenu("objectWindow")`），字段（镜像模式那几行）是界面里手写的、按种类分支。种类的登记表（`scene/kinds.ts KindDef`）现在只报可用的模式、能转到哪、对齐几何、包围盒。

提案：`KindDef` 多一个口，报「物体窗口里我那一页有哪几行」。

```ts
/** 物体窗口里这个种类的那一页：一行一个，界面照着画。 */
panel?(ctx: KindPanelCtx): readonly KindPanelRow[];

type KindPanelRow =
  | { kind: "field"; key: string; def: ParamFieldDef; value: ParamValue; off?: string; set(v: ParamValue): Op | null }   // off = 灰掉的原因
  | { kind: "command"; id: string }      // 注册表里的指令
  | { kind: "note"; text: string };
```

- 字段只有现成的三种形状（枚举、数值、开关 = `param-panel.ts ParamFieldDef`），控件用现成的那一个模块，不另写。
- 界面那一层（`app/object-window.ts`）不许出现种类的名字，加一条守卫。加一个种类 = 加一条登记。
- 先搬家、后加东西：第一步只把现在手写的那几行搬进自由建模和硬表面的登记里，看得见的一样都不变。

## 五、空物体这个种类

- 身体里没有几何；可以挂子物体；坐标架照旧。可用的模式 = 没有（只能在物体这一层摆）。
- 能转到：硬表面、自由建模，不丢东西。
- 别的种类转到它：只在自己没有几何时可用；要丢的是挂在那个种类上的设置（镜像、默认平滑、材质槽、贴图坐标的表），逐条列给人看。
- 现在被塞成「空的网格体」的地方（网格体里把几个组件包成新组件）改成空物体。
- **文件格式会动**：定义上的种类多一个值。小弟先清点（第七节第 0 步），统筹出方案给 user 定。

## 六、新建子物体

- 在当前所在的这一层新建一个空的子物体，种类当场选（硬表面、自由建模、空物体）。不碰这一层已有的任何东西。
- 建完直接进去编辑（user 11-13：「可以」）。
- 放在哪、入口放哪几处：等 user。统筹的提议：放在点的位置；入口 = 物体窗口第一页和右键空白处。

## 七、施工顺序（每步单独一版）

0. 清点，只读，报统筹：种类这个键在文件里写在哪、缺省是什么；现在的版本读到不认识的种类会怎样；物体窗口现有的每一行各从哪来；「空的网格体」现在在哪些地方被造出来。
1. 种类自己报选项：现有的行搬家，行为不变。
2. 物体窗口改成四页。
3. 空物体这个种类；切换种类收成一个系统的动作。格式那一步过统筹和 user。
4. 新建子物体。
5. 创建父物体。根的那一半先做定稿第 2 条（把根的特殊收到读写的门口），那两处 diff 过统筹。
6. 顺带修的两处（读代码看到的）：
   - 拒绝的话说准。现在整个物体画过、而要搬的这几张面没画时，说的还是「这些面上有画」。
   - 把面分成新物件时，画布对照表被原样抄给了新物件，没画的新物件因此也转不了种类。没有面用到的那几项不该带走。

另有一条归画那边、不在这张单里：新长出来的面先不带画，笔或油漆桶碰到时按连成一片给（user 同意）。

## 八、空物体的工作台（摆放）和两族移动、旋转、缩放

user 2026-11-13 夜，原话：

- 「工具不显示，空物体有自己的工作流，就是排布之类的placement。我们可以设计，因为我希望是把blender和sketchup里面的好处都拿到」
- 「之前的设计是所有种类选中子物体时都有，但就有一个问题，就是说网络体建模的移动和我们这里和 BRAP 建模的移动它们不一样，所以说现在就变成了一个二选一的寿命题……但反正就是 T R S 放一起的那个gizmoos模式，这个肯定是要有的」（「网络体」= 网格体，「BRAP」= 硬表面，语音）
- 「以「变换」（移动、旋转、缩放合在一起的控制柄）当主工具 同意」
- 「Blender 里面的 TRS，他们是定义轴，然后用轴来做，然后 SketchUp 是自动的。对齐，我的想法是要不就用小三角，让你可以选」「手感会越来越往 Blender 飘，所以我们以 Blender 统一，慢慢的牺牲 SketchUp」
- 「可以先小三角合租作为一个转型期的过渡方案，然后我们慢慢地把它们给理清楚对齐。……名字也不用太绞尽脑汁想，就对齐式移动和freeform移动这种比较笨的方式就可以了。」

早先定过的（10-26，狗和坦克那一轮的账本 DT58）：「变换还是接不住move rotate scale的，算作一个单独的吧」「所以transform就是知道倍数和角度，然后rotate scale就是基于对齐的」。

统筹查到的现状（读的是 `editor/tools/move.ts`、`rotate.ts`、`scale.ts`、`mesh-transform.ts` 的说明）：两边共用的只有工具的名字、「按下开始、拖着松手或再点一下落定」、锁轴的键、和「变换」那一把；手势本身三把都不一样——

| | 硬表面（对齐式） | 自由建模（自由式） |
|---|---|---|
| 移动 | 先点抓哪里，再对到目标；自动推断轴向和吸附，一直开着 | 相对拖动，拖多少走多少；默认不吸，锁轴靠方向键或把手，开了吸附才吸 |
| 旋转 | 点三下：圆心、参考方向、角度；圆心落在面上就绕面的法向 | 绕视线方向，锁了轴就绕那根轴；中心 = 选中点的平均 |
| 缩放 | 拖包围盒上的柄：角 = 等比，面心 = 单轴 | 按离中心的屏幕距离算倍数；锁轴 = 单轴 |

**两族真正的分界线**（user 2026-11-13 夜，语音，原话）：「自由建模是艺术家，所以说你希望不吸附，因为一吸附的话，吸附点附近的那些浮点数的区域你就选不中，就我相当于我们拖动的时候是一个连续的体验，然后你的吸附更多的是走锁和对齐到点」「硬表面的吸附就是横平竖直对齐，是 CID 的这种吸附，就是相当于在这种情况下面浮点数是很少的，就相当于硬表面的时候，我们大多数的输入都是有理数，无理数和整数，包括我后来不是把整数格点给默认永远开吗？……我们即使用一个特别歪的地方，我们进行整数级别的吸附，我们最后得到的还是一个特别难看的根号，它还是一个无顶数，不是一个超越数。然后自由建模的时候，我们大部分的输入是超越数。」（「走锁」= 轴锁，「CID」= CAD，「无顶数」= 无理数）

统筹的读法：自由式 = 连续，任何位置都到得了，吸附只在明着开的时候才有，而且轴锁和对齐到点是两样分开的东西（现状已经分开：轴锁 = 方向键或把手，对齐到点 = 吸附钮或 Shift）。对齐式 = 结果永远是说得出来的数（整数、有理数、带根号的数）。以后把两族理清、对齐，拿这一条当标准，不拿「像哪个软件」当标准。

定下来的：

1. 空物体的工作台只有摆放用的工具：选、变换（主工具，常驻）、移动 / 旋转 / 缩放、新建子物体。要几何的工具不显示。
2. 移动、旋转、缩放三格各带一个小三角，里面两把：对齐式的、自由式的。这是过渡办法，以后慢慢理清、对齐（user）。界面上的字先写「对齐式移动」「自由式移动」这种，旋转、缩放同理〔字是统筹写的〕。
3. 〔统筹提、user 没反对〕每个种类里都能选这两族，默认不一样：硬表面默认对齐式，自由建模和空物体默认自由式。不给空物体另造第三套。
4. 笔的规矩照笔的设计稿：两族都是重按起、重按或抬笔落定；对齐式的抓哪里要重按一下、落定再重按一下。
5. 快捷键全量迁 Blender（user 11-03 拍过、11-13 又说以 Blender 统一）和这一轮一起排；那份讨论 = `ai-docs/talks/20261103-keymap-blender.md`。硬表面要先有键盘起手（按 G、按 X、打数、回车）那一层。

## 九、右栏：锁和对齐由工具自己报

user 2026-11-13 夜，原话：

定下来的：

1. 右栏从上到下三段：显示选项那一排（X 光挪进来）；看东西用的一组（视图方块、平移、缩放）；下面一整段只归当前工具，放它的锁和对齐方式。
2. 锁和对齐方式由工具自己报，界面照着画；工具没报的不出现。和第四节「每个种类自己报选项」是同一个办法，报的东西用同一种行。现状：工具已经会声明自己吃哪种锁（`ToolHandler.lock`），界面有没有完全照这个声明显示，小弟核。

4. **「微调」（tweak）是独立的一把，不进雕刻，也不叫挪**（user 11-13 夜：「挪是单独的一个点，所以还是应该叫tweak而不是nudge，就叫微调，是一个一个点调，然后这样的话不应该进sculpt。它是一个很特殊的语境，就是我们在做这种极端的 no poly 的时候，我们希望能快速的一个一个顶点的进行调整。它确实不是雕刻，就虽然雕刻可以用来平替它，但它是一个完全不同的语境。」）。统筹先前提的「放进雕刻那一类」「和抓合成一把」都作废。
5. 〔统筹的看法，user 问的，还没回〕微调独立一格、常驻，挨着「选」，不和「移动」合租：按法不同（微调轻按着拖，移动重按起落）；「移动」的小三角只放对齐式和自由式。
6. **雕塑是一个按钮**（user：「几种不同的 sculpt，它们应该是同一个按钮，就是你按这个雕塑之后是再出现一个条，你可以调整雕塑的工具，但它所有的雕塑的都是同一个工具」）：左边只有「雕塑」一格，按下后出一条，在条上选抓、鼓起、抹平、压平。常不常驻 user 没说，先照现在的（用过才出现）。

读代码看到的（备查）：「抓」= 按下那一刻笔下半径里的点按衰减跟着走，不管点属于哪条边哪张面；「移动」已经有软选择的开关，半径和衰减与「抓」共用。
