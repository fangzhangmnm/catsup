## 纪元顺序（user 10-27 定，FM58）

现在 = **自由建模** → **接 Shader 实验室**（最有杠杆，但要先做一批架构决策）/ **绘制**（先 Grease Pencil 式草稿笔，再和 WeebPaint 结婚）→ **物理（生命之粉）**、**验证（猫娘）**在后。

## 跨纪元的原则（都拍了）

- 数据契约保持通用；几个基本的、图灵完备的工具兜底；其余都是语义工具（FM59）。
- 历史不存在，只有被打歪了的原子：动词做完就烘进状态，不留事件串 / 修改器栈；能改参数的只有刚做完那一步的马后炮（FM60、FM40）。
- 高频操作永远做成内置指令（镜像这类），几何节点以后也许捏着鼻子做（FM41）。
- 10-26 起不再抗拒撒点 / AAA PBR / 几何着色器（user 10-27）；各赛道的面数预算照旧。
- 同一个工具在两个工作台里语义和用法别差太多（设计稿 §2 的标准）。

## 1. 现在：自由建模（0.15）

**已经拍的方向**
- 套索常驻，「合」做成选区之后的按钮；框选 / 套索都归选择工具（FM1、FM2）。
- X 光一个开关管单击和框选：关 = 只选看得见的，开 = 连背面；补每张面的中心小点；放到右上角锁旁边，锁要看上下文（FM3、FM44、FM48、FM51）。
- 双击 = 环，三击 = 整块；加「同材质」等灌面方式（FM9）。
- 刀：双击一条边 = 环切（Ctrl+R），另有模式按钮；切完马上能滑；要吸点和边；不带 XOR；按住键临时变橡皮（橡皮去边 = Blender 的溶解）（FM10、FM11）。
- 拉面沿法线；点 / 边走屏幕空间、按轴键换方向（FM14、FM15）。
- 绑骨变换（= 转）：带轴心、软影响；各工具自己记轴心和方向，不要 Blender 的全局设置（FM6、FM7）。
- 软编辑半径全局一份，像 WeebPaint 的笔刷大小滑条（FM20）。
- 雕 = 笔刷式沿法线挪 + 软半径（FM21）。
- 自动镜像：硬表面和自由建模都有，以正在编辑的那边为准；镜像面淡画、中缝的点高亮；镜像只管焊，复制多份走组件摆实例（FM23、FM36、FM39）。
- 吸附：必须有永远不吸，偶尔吸 = 按住 Shift（FM24）。
- 硬表面不要软 TRS（FM25）。
- 不分点 / 边 / 面模式，另给可选的筛子；笔优先，手指靠软鼠标（FM29）。
- 「.」= 缩放到选区，已做（FM28，v0.15.1）。

**本纪元要做的整理**
- 不常用命令和右键命令的收纳规则（FM35）；SU 模式右下角参数小窗太吵（FM5）。
- 理一张「每个操作做完后选区是什么」的表（FM14）。
- 选区扩一圈 / 缩一圈（FM27）。

**还开着、等 user 拍**（账本 §3 清单）：刀还是线、拉点 / 边默认垂线还是屏幕、拉和插按拓扑合并、刀什么时候算切完、SU 双击面要不要改、扩缩选区的键、框选 / 套索怎么切、绑骨变换三个默认、缝等不等 UV。

**等 Fable**：用 brep 加开关还是另做网格内核、「同一个灵魂」（转网格时带着 brep 元数据）、两个坑（刀绕一圈长夹层面；拖乱了凹的 / 带洞的面会破或乱）、brep 自愈（一次装进去再修、公理是不是归纳）、证明留档（周账 F-104、F-105、F-106）。

**本纪元里的小愿望**
- 3D 游标，可设、可「移到游标」，也许取代充能（DT21）。
- 自由建模里软边用细一级的线（DT89）；硬边标记（DT65）。
- 拉多张面 = 有选区时的拉（FM25 / B18）；把边 / 点竖直拉起来当墙，SU 模式也要（FM16）。
- SU 倒角，放低频区（FM8）。

## 2. 接 Shader 实验室 / 渲染（Tron）

- 渲染模式不照 Blender 四种：**覆盖模式**（各种风格化预设：读贴图、顶点色、白模、线框）+ **全量渲染**（卡就关一些，主要靠聪明的离线加速）（FM49）。
- 每个风格自己声明支不支持 X 光：接得住的（如 Tron）有开 / 关两种画法，接不住的（玉石这类雕刻用）就不支持（FM46、FM54）。
- 量 X 光多画多少像素、Quest 接不接得住（FM55）。
- 普通线框风格还没做（FM46）。
- Tron 纪元风格化覆写大合集，第一条「水晶」（纪念 2014 图形学作业）（DT98）。
- 网格用叠加混合画在面上（B38）；只有轮廓和悬线才是粗线（B45）。
- 实验室留给 CatsUp 拍的：和工作台描边打不打架、性能取舍、要不要颜色映射、天空离线烘（实验室 handoff §3）。
- 着色器编辑器第一步 = 聊天框 + 类 Shadertoy + 一个 LLM 的 API key；到时要先开外接服务白名单（FM42）。
- 剖面：本质还没想好（渲染用的标记实体？后处理器？），UX 也许放进图层（FM52）。
- 图层放右上角锁和 X 光旁边，点开是原神角色列表那样带小眼睛的列表（FM53）——纪元未定，可能提前随 UI 做。

## 3. 绘制

- 2D 草稿绘图：画立绘 / 立面，借 WeebPaint 的铅笔或只借手感做 Grease Pencil（FM30）；轴和格点的本质是用来 2D 画画的，「画画平面」和「格点」可能是两个职责（FM31）；freehand 重新设计（B31）。
- **画语义不画 PBR 槽**：颜色、苔藓、腐朽……材质读语义；换材质语义留着（蜡娃娃 → 塑料 → 剪纸）；单通道语义我们拼 RGBA；导出时才翻成 PBR 或烤成漫反射（B48）。
- 不做专门的 UV 编辑器：右键「创建画布」；要更多像素 = 再开一张画布；判定标准 = 不用管贴图名字、不用起名、不用指派（B48）。
- UV 像素级对齐 → 加东西、重排都不丢；拉伸太厉害的先说清再问要不要重采样，用 WeebPaint 最好的重采样（B48）。
- 「乐谱」= 现在原子身上的语义，不是历史（B48，user 10-27 纠正）。
- 缝（UV 切线）标记（DT66）。
- 和 WeebPaint 结婚：画贴图不切 app；套索 + 变换是刚需；每层自己的 UV 的 bodypaint 方案留着备用；matte painting（设计稿 `20261024-design-weebpaint-marriage-bodypaint.md`）。
- 图片导入深模块（参考卡片和贴图共用）（B42）。
- WeebPaint 的纹理笔刷纪元可以由 CatsUp 的真实需求带着做（B46 里 user 原话；碰到 WeebPaint 时再提）。

## 4. 物理（生命之粉）

整件事 = 一条「做到静止就停」的长指令：结果是静止那一刻的几何 / 语义，一步撤销，不出时间轴（B46）。

- **user 给的 / 批了的**：选一张面变布或枕头（布料参数、自动细分，结果是网格）；打碎一堵墙；扔一堆垃圾物理堆好；灌水；倒土 / 沙 / 雪（物质点法）；积雪盖顶、落灰；撞瘪 / 凹痕 / 弹孔（烘成高模或烘进贴图）；下垂、软塌、帐篷；磕边、风化（程序化或烘进贴图）；撒草粉烘进贴图；做旧归物理不归绘制；树叶直接刷、烘死锁定（有法线覆盖等旋钮）。
- **公式物理（user「同意，记账」）**：悬链线、静水面、休止角堆积、积雪落灰、苔藓、雨痕、缝里积脏 / 边上掉漆、日晒褪色 / 烟熏、梁的下垂、印章式脚印车辙、沿表面长的藤蔓。
- 侵蚀之类，不一定改几何，以后有地形类型时也可以只改材质（B46）。
- 原则：不零敲碎打，UX 只是在抽象数学外面包一层「物理转译」；有 PBR 接法线 / 浮雕，只有漫反射也有路由。

## 5. 验证（猫娘）

- 像魔兽争霸一样往场景里拖小人，点地让她走，验碰撞体；拖好几个看拥堵（B47）。
- 占位美术 = 胶囊体 + 一块面罩；小人的身高、胖瘦、能不能跳 / 二段跳 / 跳多高可配（B47）。
- 偏路点不偏导航网格；「走到哪烤到哪」= 真物理当标准答案、路点图当缓存；拥堵要给边记宽度；寻路到时候再定（不寻路的老算法 / 撒探针）（B47）。
- 人自己进去：第一人称 + 枪（从眼睛射 / 手拿带修正）、弹着反馈、推东西和牵引光束（要刚体物理，和生命之粉同一块地基）、手游式键位（B47）。
- 验证 = 常开叠加层：射界、两个地点之间走几秒几拍、人的尺度（设计稿 `20261024-design-verification-overlay.md`）；读数后面加「相当于什么」（B43）。

## 6. 更远 / 还没排纪元

- 雕刻：要稠密网格 + 加速结构，做成网格那一套的搭档（FM38）。
- 地形类型（Shader 实验室 handoff 提过 terrain 纪元可以从实验室起头）。
- 性能路线：小学 → 初中（WASM）→ 高中（复杂场景）（DT92）；预演往「GTA 毕业考」方向慢慢优化（DT53）。
- 动画：很未来（10-24）。
- 常用几何体（楼梯、球……），先放着评估（FM34）。
- 「氪金商城」= 资产 / 图层 / 场景树的家（B27）；小地图 = 第二视口（B28）；截图分享（B30）；视角记忆 + 宏（B32）。
- 输入：没笔的 iPad = 软鼠标（B44）；Apple Pencil 悬停找点 + 笔输入统一（B25）。
- SU 那边：切转角走跟随（B20）；自交和布尔（B21）；移动的第一下也悬停找参考点（B24）；慢慢颠覆 SU 界面里不聪明的地方（DT34）；工具设置记忆的存储规范（DT52）；记住「这片光滑面是圆柱」以便重细分 / 出精确圆柱（DT94）。
- 参考人卡片（第二种物体类别，带帧动画和状态机）（A26）。
