## 0. 背景一句话

那个 2024 年的场景死在「灰模 → 有画面」那一步，不在 SU 本体：地形 / 树 / 布 / 原木都不是平面；光住在引擎里，编辑器里看不到；画贴图得切出去，切出去就回不来。

## 1. 期末考和高考

- 期末考 = 及格线：「小学一年级期末考你想多了，灰盒数学不崩就行了」。但不是「只许想灰盒」：「我不想听只要做灰盒不要想别的的规训。而且postmortem反而是因为我只被允许做灰盒才死掉的吧」。
- 高考真题（长期目标，不 active）：「给你偷看一眼高考真题。考不到150没关系」「不止，我是说一整桌」——一整桌战锤对战：印刷地垫 + 激光切割 MDF 地形 + 目标点 / 量尺 + 涂装模型。大半分值在 CatsUp 主场（SU 克隆 + 关卡编辑器 + 地垫贴图）。

## 2. 赛道 / core（定）

- 「不同的风格，不同的平台，是不可能强制类型转换的！！！转换了必丑！」「所以就是不同的core」「也许可以混搭。但是没法fallback」。赛道按工程选，原生做；别提议自动降级 / 兜底 / 转换。
- 「不胖」= 2013–2016 手游那本 draw call 账（合图、一个材质）：「所以我一开始说的psp接得住是这个……这个是我对 不胖的标准」「不是技术上一定psp，反而更类似warcraft3那个时代的模型风格，那个是我的home」「天空盒和必要的东西我可以按xr2 的标准做」「我导出的时候默认都是transparent cutoff，极少用transparent，宁愿窗户空着」「全家族都是控制在10MB一下」「我的规则是室外一般用顶点色，不然贴图太胖」。
- PBR 不进契约，除非编辑器就是最终渲染器：「其实pbr的话已经依赖光照和环境了，不全量阴影编辑器里看到的和游戏里的完全不一样。又是我最恨的给你一个灰盒没有feedback你自己想象看着办」。
- 贴图承重赛道（RPG Maker、PSP 的 GTA / 怪猎 / 战神）不提几何草；以几何草为风格的赛道可以。
