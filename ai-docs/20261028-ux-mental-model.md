## 0. 一句话

控制器 = MVC 的 C = 一个**无头骑士**：它只看得见三样东西——①从设备抽象出来的手势、②模型的只读视图 + 一组带类型的动词、③给窗口 / 画面的显示模型。它的「智能」（捕获优先级、默认布尔、轴向、吸附立场）**全是表里的一行**，不是散落的 if。设备（鼠标 / 笔 / 手指 / VR）只差一个适配器和表里「默认值」那一列。

## 1. 你在抱怨什么（10-28 下午已确认「对」）

1. Blender 的属性编辑器 / Unity 的 Inspector：「对每个当前的东西，显示它全部的上下文」——全局、物体、网格数据、修改器、材质、贴图叠在一根柱子里，不同逻辑层级混在一个窗口，字段不知道属于谁，窗口形状还随选中物变。
2. Opus 下午的「物体设置选项窗」同一个病：修复 / 转换 / 镜像 / 细分 / 默认平滑 / 组件的进入炸开锁藏改原点，塞成一张菜单——几何层动词、物体层属性、工作台层设置三种东西混在一起。右键菜单也一样，编辑几何时被物体级的东西污染。
3. 你要的：**一个窗口只盯一个指针，窗口按类型分**（文件 / 视口 / 物体 / 材质 / 贴图各一个，`类型 → 当前`）。窗口只显示自己那一类的属性；「物体 → 它的材质」是跳转（换材质窗口的当前指针），不是在物体窗口里展开。
4. 顺带要理的：Blender 和 SketchUp 两套肌肉记忆焊在一起（周账 F-117）、各工具各一套选择逻辑、把手大小 / 画在哪、镜像硬表面一套网格体一套。你自己的要求前后也可能不一致——所以这份稿不是抄话，是把话摆到一张图上，把打架的地方挑出来。

## 2. 模型（五张图）

### 2.1 窗口 = 类型 → 当前（一个窗口只看一个指针）

| 窗口（类型） | 它的「当前」指针 | 住哪（iPad 竖屏优先，版图文档 `20261024-ui-layout.md`） | 里面只放 | 现在的代码 |
|---|---|---|---|---|
| **文件** | 当前文档 | 左上 ☰ | 打开 / 保存 / 另存 / 导出 / 云 / 设置 / 帮助 | ☰ 分区菜单（已是） |
| **视口** | 当前视口 | 右上 ☰ + 导航把手 | 透视 / 线稿粗细 / 栅格 / 单位 / 参考窗 / 步行 / VR / 渲染方案（以后）/ **工作台下拉框**（user FM161「工具下拉框是视图」——它是「怎么看、怎么编这份东西」，归视口） | 视图 ☰ 分页（已是） |
| **工具** | 当前工具 | 左柱 + 底部选项条 | 这把工具自己的选项（工具配置表 `tool-config.ts`）+ 它的动作钮 | 已是 |
| **指令** | 当前指令（马前炮 = 正要做的；马后炮 = 刚做完的那一步） | 右下参数小窗 + **画面里的指令把手** | 这条指令的参数、应用 / 取消、说明行 | 参数小窗 + 平面把手（已是；把手只有镜像有） |
| **物体** | 当前物体：默认 = 你所在的这一层（最外层 / 进着的组件）；右键一个子组件 / 点选中组件的「设置」= 换成它 | 右边一颗钮（自由建模 / 硬表面都有） | **这一个物体的**：名字、种类（硬表面体 / 网格体）、几份实例、锁 / 藏 / 层；编辑属性：**镜像面 + 模式**、默认平滑；对它的一次性动词：转换种类、细分、修复…、应用缩放、改原点、炸开、进入 | **没有**（Opus WIP 停在分支，形状不对） |
| **材质** | 当前材质 | 油漆桶再点一下 / 以后右缘 | 这一个材质的：颜色、贴图尺寸、（以后）贴图指针 → 跳到贴图窗口 | 材质面板（已是，雏形） |
| **贴图** | 当前贴图 | 以后 | 这一张图的 | 没有 |
| **系统** | — | 右下血槽 / 底部通知 / 调试日志 | 状态、版本、报错 | 已是 |

规矩（这就是和 Blender 的区别）：

- **窗口只显示自己类型的当前那一个的属性和动词**。「相关的别的东西」= 一行跳转，点了换那个窗口的当前指针。永远不内联另一类型的属性。
- **窗口第一行写清当前是谁**（user「选窗要说明选择的是哪个object」）：「物体：组件「块」（网格体）」「物体：最外层（硬表面体）」。
- **指针是显式状态**，不是选区的影子：物体窗口的当前 = 上次设的那个（默认这一层），换选区不自动换；右键子组件才换。关掉窗口不动选区。
- 每个窗口有**固定的家**（左上 / 右上 / 左柱 / 右下 / 右边钮）。小屏（手机）上家变成底部抽屉（sheet），但身份不变——还是「文件 / 视口 / 物体 / …」五个抽屉，不是一个大 Inspector。
- 导航把手上的小灯（吸附锁、镜像状态）= **状态灯 + 快捷键**（user 10-28「对，或者说快捷键吧，就是也可以操作，只是快捷键」）：灯可以跨窗口、可以点（点 = 快捷键：开 / 关、切模式），但**正主在它自己的窗口**（镜像的正主 = 物体窗口；吸附的正主 = 视口窗口栅格页）。灯上做不了的（挪镜像面、选轴）去正主那里。

### 2.2 菜单 = 对着什么点，就只给那一层的动词

右键 / 笔长按 / 触屏浮条是同一张表的三个渲染器（已是）。按「点在哪」分三层：

| 点在哪 | 给什么 | 现在的代码 |
|---|---|---|
| **空处** | 新建 ›（立方体 / 圆柱 / …）、回上一层 | 右键菜单里混着（v0.15.46）；user「先做空白就剩下新建，回上一层」 |
| **几何（选区 / 点中的点线面）** | 几何层动词：删除、建组 / 建组件、焊接、炸开曲线、软化 / 硬化、选连通体、选成环 / 洞、反选、取消选择；自由建模的环切 / 连线 / 插入 / 倒角 / 合并到中心 / 对称对齐 / 手标；选中的**组**的进入 / 炸开 / 锁 / 藏（组不是物体，它的动词留在这里） | 右键菜单（已是，但混着物体级的） |
| **子组件（选中的只有组件、点中的是组件）** | **打开物体窗口、当前 = 它**（不弹菜单） | 没有 |
| 物体钮 | 物体窗口、当前 = 这一层 | 没有 |

「xx 指令放在 yy」的集中处 = **放置表**（Fable 10-27 指令注册表提案的那张；代码 `src/editor/commands/action.ts` Placement，`placementsAt(面, 工作台)` 查）。现在它只管注册表里的指令（修复九条 / 转换 / 网格体十几条）；右键菜单里写死的二十几项（删除 / 建组 / …）和快捷键、左柱还在 `main.ts` 里。**整理 = 把这三样都搬进放置表**：面 = `空处右键 / 几何右键 / 物体窗口 / 左柱 / 快捷键 / 手腕面板 / 搜索 / api`，每行 = 动作 × 面 × 工作台 × 顺序 × 键。菜单 / 窗口 / 左柱 / 键盘都是「按面查表」的渲染器。以后你「再抖动」= 改这张表的一行。

### 2.3 工具的立场表（「直乘」怎么变成「立场」而不屎山）

你说的「直乘」：老软件把 工具 × 捕获优先级 × 布尔模式 × 轴向 × 吸附 全暴露给用户配置（Blender 的 preferences / 顶栏那一排下拉），因为它不敢替用户决定。套路固化了以后我们敢：**每把工具一行立场**，引擎读行，用户不配置。不屎山的办法只有一个：**立场是数据，不是代码里的 if**——一张表、一个解释器、一条守卫（每把工具必须有一行、每一格的值必须在枚举里）。

列（哪些已经有、散在哪）：

| 列 | 意思 | 现在散在 |
|---|---|---|
| 抓什么（grab）= **捕捉优先级 + 半径** | 没选区时按下作用在谁上：点 > 边 > 面 / 只认面 / 只认点和边 / 取点 / 刮 / 不抓；半径按工具（自由建模点 14 px、边 6 px，常量；FM162 / FM163「按工具分 vs 按大小比例」收口：**按工具 × 工作台分，写在表里**，user 10-28「点线面的捕捉逻辑也乱，不同的工作流和工具下面也有不同的最优解」） | `tools/selecting.ts pressTarget`（v0.15.46 刚收）、`pick.ts` 常量、各工具 down |
| 点一下 | = 选 / = 放第一个点（SketchUp 点 → 挪 → 点）/ = 落点（刀）/ 没意思 | `ToolHandler.tap` / `armable` / `repeatTap` |
| 空处拖 | = 框 / 套索 / 什么都不做 / 相机 | `BoxDrag`（刚收）、手势路由 |
| 布尔默认 | 替换 / 加 / 切换 / 减——**按手势 × 设备**：鼠标点 = 替换、框 = 替换；触屏点 = 切换、框 = 加；套索 = 加（待拍） | `selecting.ts selModeOf` + 工具配置「选区」两档 |
| 方向默认（frame） | 这把工具沿什么动：视线平面 / 推断 / 法向 / 面内 / 视线轴 / 均匀；把手旁「世界 / 物体 / 法向」按钮改它，**每把工具自己记**（user 10-26「是工具自己记住的选项。而且每个工具单独记」） | 各工具 solve 里写死 |
| 吸附立场 | 默认推断（SketchUp）/ 默认不吸（Blender）/ 无 | 各工具；Shift 的意思从它推出来（修饰键稿 §2） |
| Shift / Ctrl / Alt | Shift = 把吸附立场反过来；Ctrl = 这把工具的另一种做法；Alt = 换目标（环 / 洞、沿法线） | 修饰键稿 + 各工具 |
| 锁的种类 | 轴 / 面 / 无（方向键、X Y Z） | `ToolHandler.lock` |
| 轴心 | 包围盒中心 / 平均 / 最后选的 / 抓的那个点 | `ctx.pivotOf` + 各工具 |
| 语法 | steps（按下 = 起点，再按 = 落定）/ direct（按住拖，松手提交） | `ToolHandler.grammar` |
| 键 / 图标 / 名字 / 在哪个工作台的左柱第几格 | | `main.ts TOOL_SPEC` / `MODE_RAIL` / `MODE_TOOL_LABEL` |
| 工具选项 | 段数、油漆桶模式… | `tool-config.ts`（已是表）|

**同一把工具在两个工作台立场不同 = 表里两行**（硬表面那行 = SketchUp，自由建模那行 = Blender），差异一眼看得见——这就是周账 F-117「两套肌肉记忆焊在一起」的解法：不是抹平，是**把焊缝画出来**，每一格你拍。工具模块（`tools/*.ts`）只剩「拿到目标以后做什么」（挤面还是挤边、插入还是倒角）——那一半是和几何核绑的。

### 2.4 把手（gizmos）：三种，各是某个窗口在画面里的那一半

| 把手 | 是谁的 | 管什么 | 现在 |
|---|---|---|---|
| **导航把手**（右上坐标球 + 手 / 放大镜） | 视口窗口 | 转视角、平移、缩放、切正视图；**状态灯**：吸附锁、镜像（§3-9） | 已是 |
| **指令把手**（镜像面的方块、变换的三轴） | 指令窗口（马前炮）——参数的画面版 | 拖它 = 改参数；和参数小窗同生同灭 | 镜像面有（大小已修成只看屏幕像素）；变换有 |
| **选区把手**（点一下弹出的箭头 / 环 / 方头 + 「世界 / 物体 / 法向」小按钮） | 工具的方向列 | 约束方向；按钮改这把工具记住的方向 | 没做（把手稿 `20261027-gizmo-design.md`） |

规矩：把手**按屏幕像素定大小**（不随缩放、不随视角）；**模型上不画装饰**（user「自由建模模型上的干扰需要少一点」）——模型上只许：选区、中缝点、吸附标记、预演影子；别的状态去导航把手的灯或窗口里。

### 2.5 设备：鼠标 / 笔 + 手指 / 纯手指小屏 / VR

控制器看见的手势（已经抽象出来的部分）：指针帧（射线 + 度量，`pointer-frame.ts`；VR 帧 = 手柄射线 + 角距，没有虚拟屏）、按下 / 跟随 / 松手 + 指针种类、修饰键 {Shift, Ctrl 类, Alt}、「要菜单」意图、点按族（几下）、**和工具分开的相机通道**。设备只做两件事：适配器把物理输入翻成这些；立场表里「默认值」那一列按设备分。

| 设备 | 工具指针 | 相机 | 菜单 | 修饰键 | 还缺什么 |
|---|---|---|---|---|---|
| 鼠标 + 键盘 | 左键 | 中 / 右拖、滚轮 | 右键 | 键盘 | — |
| 笔 + 手指（iPad） | 笔（悬停 = 吸附预告；点两下） | 手指（单指转、双指平移缩放、双指轻点撤销） | 长按 | **芯片**：选区两档、锁轴徽章、复制开关、（吸附反转没有——§3-3） | 吸附反转芯片 |
| **纯手指小屏**（手机 / 笔丢了） | 单指（「手指画」开关已有） | 双指 = 平移 + 缩放 + 转；单指平移 / 缩放走导航把手的手 / 放大镜 | 长按 | 芯片放大、常驻 | 窗口变底部抽屉、左柱折叠、点按精度（点两下 + 放大镜，探索） |
| VR | 手柄射线（`xr-pointer-frame.ts`） | 握把抓世界（没做）；摇杆 = 走路（`player/`） | 手腕面板 | 手柄按钮 | 握把相机、手腕面板吃放置表 |

手感常量（点按容差、拖的门槛、长按时长、吸附半径、把手像素）**每设备一套、各自量纲**（桌面 = 视场角的 1/800、VR = 度；已是）。集中到一张「手感表」按设备一列。

### 2.6 控制器的窄接口（无头骑士：换成 Blender / SketchUp / ZBrush / Unity 的几何核，能插上吗）

三条缝，今天都在、都有漏：

| 缝 | 控制器看见什么 | 今天的代码 | 漏在哪 |
|---|---|---|---|
| **进**（设备 → 控制器） | 指针帧 + 按下 / 跟随 / 松手 + 修饰 + 点按族 + 相机通道 | `pointer-frame.ts`、`ToolPointer`、`gestures.ts`、`tap-train.ts`、`xr-pointer-frame.ts` | 基本干净；键盘快捷键散在 `main.ts` keydown |
| **读模型** | 世界视图（各池合成到世界坐标的点线面 + 变换 + 槽，`WorldView`）、内核显示契约（`KernelView`：面环 / 平面 / 显隐）、拾取和吸附服务、选区、上下文 | `scene/world-view.ts`、`scene/kernel-view.ts`、`pick.ts` / `solver.ts` | **工具直接拿 `Kernel` / `MeshKernel` 查几何**（`ctx.kernel()` / `ctx.mesh()`）——换核就要改每把工具 |
| **写模型** | 带类型的动词 = `Op` 联合（约 40 条：brep 族 / mesh 族 / object 族）+ 注册表的指令 / 动作 | `ops.ts`、`commands/` | 这就是「核契约」：换核 = 每条 op 在那个核上有实现。预演假设核能便宜地克隆 + 倒回（brep `rewindTo`、mesh `clone`）——Blender 没有，得换成「重跑」 |
| **出**（控制器 → 画面 / 窗口） | 叠加层（框、把手、影子、吸附标记、提示）= `ViewState`；窗口模型 = `HudModel` + 参数小窗状态 | `render3.ts` 只读 `ViewState`；`app/` 只读 HudModel | 干净（three 只在 render3，DOM 只在 app） |

诚实的答案：**能插，但按工作台插**——自由建模的控制器插 Blender 的 BMesh（mesh 族 op 和 bmesh 算子基本一对一；`KernelView` 包一层 BMesh 就行）；硬表面的控制器插 SketchUp 的 API（画线 / 推拉 / 跟随）；一个控制器通吃四个核不成立，因为「拿到目标做什么」那半本来就是核的语义。ZBrush 是雕刻（笔刷 = 配置好的指令 × 一笔，注册表提案 §2.4 留了位）；Unity 不是几何核，是场景 + 组件——我们的物体层（定义 / 实例 / 变换 / 层）对得上。

folder（user「可以工程文件也单独隔离出一个folder」，我读作「控制器的代码单独一个文件夹」——读错了说一声）：样板就是 **`src/player/`**：零 kernel / three / DOM import、node 直测、窄的 `WorldQuery` 当模型接口、`InputFrame` 当输入接口。编辑控制器照它搬成 `src/controller/`（工具 / 立场表 / 放置表 / 选法 / 把手数学 / 参数会话 / 窗口模型），只许 import `src/controller/api/` 里的接口类型；守卫测试 = 文件夹里不许出现 `../kernel/`、`../mesh/`、`three`、`document`。今天 `editor.ts` 3800 行是 C 和 M 的胶水混在一起、`main.ts` 1460 行是适配器和窗口混在一起——**探索期不做大搬家**：先画线 + 守卫只管新文件，碰到哪个搬哪个。

## 3. 你的要求里打架的地方（每条带推荐，要你拍）

1. **「不要一个工具在不同模式下面语义和用法差太多」（10-27）vs 硬表面 = SketchUp、自由建模 = Blender。** 推荐：**语法一样、立场不一样**——按下 / 拖 / 松手 / 点一下 / 点两下的读法全编辑器一套（§2.3 的「语法」列只有两种值），差异只在立场表的那几列（抓什么 / 吸附 / 方向 / 布尔），表里两行并排摆着。
2. **Alt**：移动复制认 Ctrl / Alt / ⌘（SketchUp 的 Ctrl）vs Alt 点边 = 环 / 洞、Alt+S 沿法线、Alt+Z X 光、Alt+A 全不选。推荐：**Alt = 换目标 / 换变体**，复制只认 Ctrl / ⌘（Mac 上 Ctrl 空着，不撞）。
3. **Shift**：硬表面 = 临时不吸，自由建模 = 临时吸（这两条是一条规律：反转吸附立场）；选择 = 加 / 切换（全世界约定，留）；旋转 15° 档（= 吸附反转，合规律）；橡皮 Shift = 硬化（不合）；自由建模挤出 Shift = 自由拖（不合，应是吸附）。推荐：照修饰键稿 §3——**Shift 只有一个意思 = 反转本工作台的吸附立场**；橡皮的硬化 / 软化搬到 Ctrl / Ctrl+Shift（SketchUp 原样）；挤出的 Shift 改成吸附、「自由拖」给选区把手的中心。iPad 要一颗「吸附反转」芯片。
4. **X**：Blender X = 删除 vs 方向键 → = 锁 X；今天为「先按轴锁下一下」加了「X 没选区 = 锁、有选区 = 删除」——看上下文变意思，是谜语人。推荐：**X 永远 = 删除；先锁轴只用方向键**（→ ← ↑ ↓，SketchUp 原样）；手势中 X Y Z 照 Blender 锁轴。
5. **点一下是什么**：硬表面 = 放第一点（点 → 挪 → 点）；自由建模 = 选（10-27）；把手稿 = 弹手柄。三个答案。推荐：硬表面留 SketchUp 的点 → 挪 → 点；自由建模点一下 = 选（刚做完）；「点一下弹手柄」做成**选择工具的一个选项**（FM4 / FM17「选完要不要弹把手」），不占操作工具的点一下。
