## 0. 读法：笼子和仓鼠

引擎要像五美元的仓鼠——便宜、可丢、死了重写一只（T31）。贵的是笼子 = 下面那十条不变量和它们的守卫。本文写的是笼子；仓鼠怎么写由每一刀自己定，不在这里预写。按可逆性分两堆（T13）：不可逆的（数据的形状和归属）今天钉成守卫；其余先做出来再收——实验室那几十个覆写就是「先做出来」那一半，接口从它们身上反推。

## 1. 不变量（笼子；每条都是一个守卫测试）

1. **内容 / 视图分开**：文件只存原子和原子身上的意思（几何、边信息、语义材质、灯、工艺标签）；风格、烤产物、代理、派生物全是视图侧，不进文件、不进指纹、不标脏。
2. **输入是一条流，不是树**（T28）：引擎只会「拉」——按视锥**带**（数组）+ 预算向提供者要块；一块 = 一个池的几何 / 边信息 / 材质语义 / 实例变换 / 烤通道，各自可独立到达，带池的版本号（增量）；层级和实例表也是块；编辑器 = 一条恰好全在手的流；池可以是**惰性**的（描述 + 生成器，T30）。数据没到不等：画已到的 + 占位，永不卡帧（T12）。
3. **预算挂在视图上，内容无上限、护栏归引擎**（T12 / T15）：每个视图三个数——每帧毫秒、显存、draw call；**后台预算另立**（空闲 / 不在前台时给烤作业、串流预拉、着色器预热；电量档；**电量感知默认开、跟设备的省电模式走、设置里可关，降档时披露不静默**，T35）；驻留归提供者、装预算归引擎；超预算走声明好的降档梯子（数据，不是 if）并如实报（血槽位）；用户可钉某一级（UX，上线后）。
4. **一个全量引擎 + 规则覆盖**（T7 / T14）：固定的是阶段顺序（提取 → 几何 / 光照 → 后处理）和每阶段的数据契约；**哪几个 pass 这一帧存在 = frame graph 动态决定**（每个 pass 声明输入 / 输出 / 代价，没人消费的输出不产、没人要的 pass 不跑）；预设 = 在**四个挂点**上拧的一组旋钮（材质翻译 / 光与环境 / 后处理 / 几何预处理），要新挂点 = 改引擎、过 grill；卡西欧 / GB / 纯线稿另开小管线（它们不走「有光照的表面」）。
5. **pass 代码里没有设备分支；代价表是数据**（T18）：每设备档一张系数表（启动微基准 + 运行时帧计时校准），frame graph 按表 + 实测选 pass 和降档；瓶颈变了改表不改码；WebGPU 来了 compute pass 当新节点。
6. **屏幕处理是一刀**（T20 / T22）：引擎交一帧（按屏幕**声明的表示**：GPU 纹理 / CPU 缓冲 / 线段表 / 瓦片 + 色板 / 一维信号流 / 时间序列），屏幕接管之后的一切，连同鼠标逆变换；默认全程 GPU，回读永不强制（VR 会哭）；不迎合任何一块屏。
7. **编辑器叠加层是第五样**（T19 / T31）：选中、悬停、吸附标记、锁轴线、面点、gizmo、尺规（球规 / 量角器 / 卷尺 / 坐标架）由消费方画，不归风格；风格可**认领**「选中」（Tron = Clu 橙）。契约：屏幕空间恒定大小的几何 + 深度感知（被挡变淡）+ 文字标注 + 永远在上的开关。
8. **材质 = 语义通道 + 工艺标签 + 涂装翻译**（T8 / T16 / T17 / T21 / T35；**另一个模块** `minccino/material/`，现在只钉接口、内容绘制纪元磨）：通道注册表是**开放集**（颜色 + 各种做旧：锈 / 灰 / 划痕 / 苔 / 雨痕 / 烟熏…；每通道「每面一个数」和「每像素一张图」两形；物理纪元会往里写）；工艺标签进文件（已上光 = shadeless / unlit、自带高光、铸铜、剪纸、塑料…）；翻译函数按工艺写、住视图侧、覆盖可替换；PBR 只在翻译的输出里存在；**翻译只做一次「工艺 → 中间层」，中间层 = 一张开放的槽表、不是 PBR 的子集**（T35 / T36）：PBR 那几个槽（颜色 / 粗糙 / 金属 / 自发光 / 高度或法线 / 遮罩）只是一组，小管线要的槽另外登记——色阶带（GB 四色）、墨线色 / 线宽 / 内线（Casio 线稿）、纸色 / 纸层序 / 纸厚（剪纸色纸）、包浆色 / 凹处程度（铸铜）、描边色 / 色阶数（像素描边）、边发光色 / 强度（CRT Tron）；翻译往槽表里填它知道的槽，没填的用槽自己声明的默认（墨线默认跟硬边、色阶带默认按亮度分）；**每条管线声明它读哪些槽**（`reads`，守卫盯读了没登记的槽）；预设在材质挂点上改槽（白模 = 忽略颜色）——翻译数 = 工艺数，不组合爆炸。材质槽之外的两类不归材质：**几何派生通道**（硬边 / 轮廓 / 折痕、编号、深度、法线、曲率 / 凹腔）由几何准备挂点 + frame graph 按需产；**管线参数**（像素网格、层影偏移、四色调色板）住预设；shadeless 材质照过后处理，只是光照 pass 不碰它。浮雕（高度）通道按实验室约定（0.5 = 原表面 + 尺度）。
9. **视图是一等对象**（T19 / T35）：**VR native 从第一天**——视图 = 相机 + 画到哪 + 画质档；主视口一个、VR 两个（共一份提取，小学就要能跑：CatsUp 现有 VR 在笼子里照跑）、小地图 / 缩略图 / UV 画布各一个；每目标自己的分辨率 + 有效期；VR 里的规则是**默认不是禁令**（扭曲屏幕、SSR 可开，晕动就晕动）；静帧 = 一个画质档。
10. **three 关在后端模块里，引擎零 three 类型**（T25 / T29）：后端接口 = 目标 / 程序（自己的 GLSL）/ 缓冲 / 绘制清单 / XR 会话钩子；守卫 = three 的 import 只准在 `minccino/backend/`；**不出 `@internal/` 包**，按内部库边界标准写（单一接缝、带类型契约、零 app 知识、自己的文档）；RealHome 真用时再打包，是搬不是重写；彻底无头化归初中。

## 2. 四层 + 第五样（修订版）

```
内容（文件：原子 + 语义）
   │ 提供者（流：视锥带 + 预算 → 块；编辑器 / glTF / 串流 / 生成器 各一个实现）
   ▼
引擎 = frame graph 上的固定阶段：提取（按块缓存 GPU 批、按帧重映射编号、合批）→ 几何 / 光照（挂点：几何预处理、材质翻译、光与环境）→ 后处理（挂点）
   │ 目标：每个自己的分辨率 + 有效期；深度 / 法线 + 编号（RGBA8 一张）按需才产
   ▼
屏幕一刀（交一帧按声明的表示；分辨率上限 / 整数倍 / 色板 / 变形 / 逆变换；复古屏另开小管线）
   +
叠加层（消费方画；风格可认领选中）
```
烤作业（光照图 / 探针 / 低模代理 / 每格通道贴图）= 后台预算里的作业，产物进**派生缓存 IDB**（专门 quota、全删可再生、低精度格式：RGBM / RGB9E5 / 半精度球谐 / 压缩纹理），按池版本增量重烤，静默 + 开发者叠加层可查（T17 / T19）。

## 3. backbone 的槽位（只留形状，不实现——「不绊下一步」）

视锥带数组（superlod、月亮永远在）· 池的「额外通道」槽 · 编号按帧重映射约定 · 屏幕表示声明 · 后台预算对象 · 降档梯子的数据形状 · 工艺标签注册表 · 惰性池标志 · 原语种类开放（三角 / 线段 / 点 / **笔画**）· 浮雕通道位 · 块版本流（半成品池持续流进视口）· 后台作业的进度 / 取消 · 派生代理（float / surrogate）槽 · 空间格子（按空间键、不按组件树）· LOD 槽 · SSR / AO / relief / 折射的 pass 声明（只声明不启用）· 串流提供者接口（空实现）· 灯进文件带烤法标签（烤死 / 混合 / 实时）。

## 5. 代价模型（每设备一张表的字段）

每帧毫秒 · 显存 · draw call · 带宽（写 / 读目标图 + 贴图取样）· **回读**（帧内禁，屏幕一刀和后台例外）· **pass 断开次数**（分块 GPU 的真大头）· 过绘（半透明层数 × 像素）。半透明两种代价：普通混合 = 丢隐面剔除的过绘；读当前帧的折射 / 玻璃 = pass 断开（resync）。**编辑器的 X 光是手机上最贵的视图**，要自己的预算。省电的大头按序：不动不画 → 分辨率 / 帧率上限 → 贵后处理半分辨率 → MSAA 只按需 → 后台 / 低电量整体降档；效果开关在这五条后面。

## 6. 本周第一步（小学第一刀 = 「现状原样搬进笼子，画面一个像素不变」）

目标：CatsUp 画面逐像素不变（截图基线探针 < 0.5% 像素差），但渲染代码已经住在笼子里。顺序（每步独立可验、可提交）：

1. **截图基线**：现有探针场景（盒子 / 坦克 / 网格体 / X 光 / 尺规）各出一张基线图；之后每步对比。
2. **目录和守卫先立**：`src/minccino/`（`contract/` 流 + 块 + 视图 + 预算 + 材质的类型；`graph/` frame graph；`backend/three/`；`overlay/` 契约），守卫测试：three import 只准在 backend、引擎零 three 类型、pass 代码无设备判断、三条 lint（抄云同步接缝 lint 的写法）。
3. **流提供者 = 编辑器**：把 render3 现在「每池一份几何 + 每槽一个矩阵 + 变了的池重提取」改成走契约里的块流（视锥带数组先只传一带、预算先只记不裁），池版本号 = `Kernel.rev`。
4. **frame graph 骨架**：现状的三个 draw call（网格 + 轴、膜、边）+ 叠加层 + X 光 = 几个 pass 声明；目标带分辨率 + 有效期；按需渲染照旧。
5. **后端模块**：three 的 BufferGeometry / ShaderMaterial / LineSegments2 / 渲染目标 / xr 全部收进 `backend/three/`，引擎侧只认自己的类型；拔三个漏点（`onBeforeCompile` 的轮廓逻辑改成自己的 shader 源；three 向量矩阵颜色换仓里的 Pt3 / Xform；`renderer.xr` 收进会话钩子）。
6. **叠加层契约**：选中 / 悬停 / 吸附 / 锁轴线 / 面点 / 尺规 / gizmo 经叠加层接口画（现状搬，不改样子）。
6½. **VR 照跑**：XR 会话钩子进后端接口，两只眼 = 两个视图一份提取，叠加层在 VR 里也画；假 XR 探针进截图基线（现有 `probe-xr-fake` 不许退）。
7. **代价表骨架 + 血槽位实测**（毫秒 / 显存 / draw call 三个数先上）。
8. **材质模块只钉接口 + 交接点**：`minccino/material/` 的通道注册表 / 工艺标签 / 翻译签名 / **槽表**（开放集：PBR 组 + 色阶带 / 墨线 / 纸层 / 包浆 / 描边 / 边发光，T36）/ 管线 `reads` 声明 + 守卫；内容不填。第一刀到此为止，Opus 从这里接风格和材质（§7）。

验收：所有既有探针绿；截图基线逐张过；三条新守卫绿；render3.ts 被 `src/minccino/` 吃掉（editor.ts 的渲染调用只剩接缝）。预计 Fable 一个会话到一个半。
