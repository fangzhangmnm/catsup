## 0. 一句话

渲染器骨架 = **四层各一个接口，层与层之间只传数据**：① 内容（场景原子 + 原子上的语义，文件里的）→ ② 提取（每帧按「变了的池」把内容翻成 GPU 批：几何 / 边信息 / 材质语义 / 实例矩阵）→ ③ 画法（一个风格 = 一组 shader 原子 + 它自己声明要哪些批、接不接 X 光、选中怎么画）→ ④ 屏幕（分辨率 / 色板 / 变形 / 逆变换，和风格正交）。编辑器的叠加层（选中、gizmo、吸附标记、面点）是**第五样东西**，不归风格，但风格可以**认领**它（Tron 认领选中 = Clu 橙）。现在的 `render3.ts` 已经是 ①②③ 糊在一个文件里的雏形（retained、3 个 draw call、顶点色 + 一盏方向光），Tron 纪元的活 = 把缝切开、让第二个风格进得来，而不是先做效果。

## 1. 四层（【提案】）

### 1.1 内容：什么进文件（定了，这里只重述）
文件只存原子和原子身上的意思（明暗方式 + 手标、折痕、细分笼子、镜像约束、材质语义）；风格 / 细几级 / 工艺预设是 view、能换能摘。渲染器**不许**往文件里写任何东西（view 住 `CATSUP_desk`，不进指纹、不标脏）。

### 1.2 提取：内容 → GPU 批（【提案】新模块 `src/render/extract.ts`）
- 输入 = `Scene` + 显示契约 `KernelView`（两种身体都有；渲染只读它，不读内核——和编辑器同一条纪律）+ 池级版本号（`Kernel.rev`，v0.9.15 起）。
- 输出 = 按池缓存的批：`{ 三角（位置 / 法向 / 材质槽 / 面 id）, 边（两端 / 四种边的种类 / 两侧法向 / 面数, 实验室边信息约定的格式）, 点, 实例矩阵（每槽一个） }`。**每个池一份几何、每个槽一个矩阵**（现在就是这样）；变了的池重提取，没变的复用。
- 边信息按实验室约定由 app 给（user 10-26「硬边 catsup 里面会有 app 侧提供」）：轮廓 / 折痕 / 软边 / 边界 四种 + 两侧法向——现在 `edgeMat.onBeforeCompile` 里按实例算轮廓的那套，搬进提取层当数据。
- 材质：槽号 → **语义材质**（B48 / FM71：颜色、苔藓、腐朽……不是 PBR 槽；导出时才翻成 PBR）。提取层只把语义打包成每面的属性 / 每材质的 uniform 块，不解释。

### 1.3 画法：风格是一个接口（【提案】`src/render/style.ts`）
```ts
interface Style {
  id: string; label: string;
  needs: { tris: boolean; edges: boolean; points: boolean; normalsDepth: boolean };   // 要哪些批（像素描边要深度 + 法向）
  xray: "yes" | "no";              // FM54：接不住的风格 X 光开关灰掉并说为什么，不偷换画法
  selection: "own" | "overlay";    // own = 风格自己画选中（Tron：Clu 橙）；overlay = 外壳叠淡线框 + 点（雕塑那档）
  draw(batches, view, screen): void;   // 一帧：风格内部几个 pass 自己管（可以是一遍、也可以是 G-buffer + 后处理）
}
```
- **shader 是原子**（B49）：一个风格 = 若干 shader 原子 + 胶水；shader graph 以后可以有，只用来产出原子。
- 两类风格（FM49）：**覆盖模式**（白模 / 线框 / Tron / 切面 / 剪纸 / 补土 / 玉石 / 像素…；读顶点色或贴图或都不读）和**全量渲染**（先进实时 GI 追 Cycles 的那条，PS3 / PS4 级硬件；user 10-28 定了做法、不跑光追）。两类走同一个接口，全量只是 `draw` 里 pass 多。
- 第一个风格 = **现状**（顶点色 + 方向光 + 粗线轮廓）原样搬进接口 = 零行为变更的那一刀；第二个 = **Tron**（线框是画面、选中 = Clu 橙、接 X 光）；第三个 = 雕塑那档（圆润 + 可开关的淡线框）——三个做完接口就定型。

### 1.4 屏幕：和风格正交（实验室已有；【提案】`src/render/screen.ts`）
分辨率 / 整数倍放大 / 色板 / CRT 弧面 / 机框，外加**鼠标逆变换**（屏幕变形时点下去先反算回风格画的那张图的像素，再打射线；实验室 §2.6 倾向）。CatsUp 第一步只接「分辨率上限 + 整数倍」（iPad 高 DPI 别全分辨率画粗线，代价表里 iPad A 1.8 ms 一半是这个），色板 / 变形等场景 3 来了再接。

### 1.5 编辑器叠加层（第五样）
选中高亮、悬停、吸附标记、锁轴线、面点、gizmo、参考线、镜像面——**外壳画，不归风格**；风格可以**认领**其中的「选中」（`selection: "own"`）。叠在屏幕前还是屏幕后（像素化时选中要不要也像素）= 开着（§4 问 3）。

## 2. 物体私有 vs 全局（FM71，先 grill 的那条）——我的读法【未拍】
- **全局**：风格（整张画一种画法）、屏幕、光、雾 / 天空、后处理。
- **物体私有**：材质语义（这个面是苔藓还是铸铜）、明暗方式、折痕——全在原子身上，文件里。
- **不做**「一个场景里同时铸铜雕像 + Tron 线框」这种按物体换风格：那是材质语义的事（铸铜是材质，Tron 不是）；真要「这件东西用另一种画法」= 以后的「图层 / 剖面」纪元（复杂场景）再说。

## 3. 工程取舍（【提案】）
- **缝先于效果**：Tron 纪元第一刀 = 现状搬进四层接口、探针逐字一样（截图比对）；第二刀 = Tron 风格；第三刀 = 雕塑档；之后每个风格是一个文件、可扔（命令模块同款纪律）。
- **three 还留在 render/ 里**（三只准出现在 render 层，lint 已有）；风格的 shader 原子用 three 的 `ShaderMaterial` / `RenderTarget` 就够，不引第二个引擎；全量渲染（GI）那一刀再评估是否要 WebGPU。
- **性能**：按需渲染不变（有变化才画；步行 / XR 连续）；每个风格自报一帧的代价（实验室代价表的做法），切风格时右下角血槽位显示实测毫秒；分辨率 flooring（user 10-28「每一个有一个最低支持到的算力，一直降到 casio」）住屏幕层。
- **探针**：每个风格一张截图基线（`probe-style-<id>`），改提取层 / 接口不许改任何一张（像素差 < 0.5%）。

3. 叠加层和屏幕的关系：像素化 / GB 屏下，选中高亮和 gizmo 要不要也变成像素（叠在屏幕前 = 清晰、叠在屏幕后 = 一起像素化）？
