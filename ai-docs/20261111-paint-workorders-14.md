## 要达到什么

user 在 iPad 上对着自己建的模型，切到「画画」，用笔画、用手指转视角，画完存盘，关了再开还在。

## 定下来的

1. **画画是单独的一个工作台**（user 11-11），和自由建模、表面那几个并排。只对网格体有。
2. **笔和手指**：笔（Pencil）= 画；手指 = 转、移、缩视角，照现在视角的手势；手掌搭在屏幕上不算数。鼠标：左键画，转视角照现在的键位。一笔进行当中视角不动。
3. **工具第一版只有两样**：笔、橡皮。设置三样：大小（屏幕上的像素）、浓度、硬度。取色：一个颜色块，点开选颜色；另有「吸管」，点模型上一处取那里的颜色。像素笔是后面的工单。
   - 选颜色的面板先侦察：画画仓的取色面板能不能搬（家规：不另写一份；不用系统自带的颜色框）。搬不动的话停下来告诉我要多少活，先用最简单的几排色块顶上也行。
4. **开始画**：进了画画工作台，当前物件还没有画 → 工作台里一颗明着的钮「开始画」。画哪些面：选中了面就是这些面，没选就是这个物件的所有面。新材质的底色：这些面现在是同一个材质就用它的颜色，不是就用白模的灰。名字自动起，不问。
   - 物件已经有画 → 直接能画。一个物件上有不止一张画时，画的是笔落点那张面所走的那张画。
   - 硬表面的物件：不能画，说清「先转成网格体」。
5. **进门就准备好**：切进画画工作台时，把当前物件的画提前打开（变热）、把落点和铺法要用的表建好，落笔不卡。还在打开时落笔：这一笔不开始，提示行说一句（1-8b 已经有这个口）。
6. **撤销重做**用现有的那两颗钮，和建模是一条线。一笔一格都没碰到时不产生撤销步，界面上也别显示成画了一笔。
7. **带着画的面现在还搬不了**的那几种动作（并物件、分出、变成独立的、复制粘贴、炸开、转硬表面）：被拒绝时说的话要是人话，说清是因为这些面上有画、这个功能还没做。
8. 笔的设置记在设备上，不进文件。
9. 没进过画画工作台、文件里也没有画的时候，三维软件不为画画多做任何事（内核不起、定时器不挂）。

## 不能破的规矩

- 画画工作台里，笔不会选中、拖动任何东西；出了画画工作台，笔和以前一样。输入归谁照输入闸那一套登记，不另开一路监听。
- 手指转视角的那一下不会画出一个点；手掌搭着的时候笔照常画。
- 探针：进工作台 → 开始画 → 画一笔 → 橡皮擦一半 → 撤销两次 → 重做 → 存盘 → 重新打开，每一步屏幕上和数据里都对。吸管取到的颜色 = 那一格的颜色。
- 第一次画的人不看说明也知道下一步点什么：「开始画」看得见；没选对东西时说清为什么不能画。
- 现有工作台的截图基线、键位、探针不变。

## 碰到这些就停下来报

- 笔和手指分不开（某种设备上分不清是笔还是手指）。
- 画画仓的取色面板搬过来要动画画仓。
- 进门准备（打开画、建表）在一万面的模型上超过半秒。

## 施工细则

> Catsup小弟（Claude Opus 5.5）2026-11-11 夜写，as-of 三维 v0.19.23。施工单说细则不用先报（截图和「怎么用」合之前报）。

- **工作台**：新工作台 `paint`（「画画」），只对网格体（`KINDS.mesh.modes` 加一项，排自由建模、表面后面）。三把工具：`paintPen`（笔）、`paintEraser`（橡皮）、`eyedrop`（吸管）；左柱定死一列（`placement.ts RAIL_FIXED.paint`），立场表三行（`stance.ts`）。工作台的登记从 `editor.ts` 挪到 `modes/index.ts`（editor.ts 行数棘轮只降不升）。
- **工具不碰几何**：照验证工作台「步行」那一套——工具按下 / 拖 / 松手只经 `ToolCtx` 一个口交给宿主（`paint(...)`），画画内核、画板、落点都在 app 层的画画控制器（`src/app/paint-workbench.ts`），编辑器不认识画画内核。一笔 = 现有的 `SpacePaintStroke`（1-4b），抬笔 = `commitRecordsStep`（1-8a）；一格都没碰到 = 内核不封步 = 不进撤销、提示行不说「画了一笔」。
- **笔和手指**：路由照旧（见过笔的设备：笔 = 工具、手指 = 相机、单指当手掌）；加一条：**画画工作台里一笔进行当中相机不动**（gestures 问一句「这一下锁相机吗」，平时「画到一半双指转视角」照旧）。没有压感（输入层没有压力这个口；第一版不做，写进没做的）。
- **落笔**：拾取笔尖下那张面 → 它走的那张画（一个物件几张画 = 落点那张面的画）→ 问 1-8b 的 `paintStrokeGate`（还在打开 = 不开始 + 提示；只能看不能画 = 说为什么）→ 开一笔。落在没画的面 / 硬表面 / 空处 = 提示行说清（「这个物件还没开始画：点上面的『开始画』」「硬表面的物件不能画：先转成网格体」）。
- **开始画**：画画工作台、当前这一层是网格体、还没有画 → 工具条上一颗明着的钮「开始画」。选中了面 = 这些面，没选 = 这个物件全部的面；底色 = 这些面同一个材质就用它的颜色，不然白模灰；名字自动（「画」「画 2」…）。走现有的 `startPaint` 指令（一步撤销）。
- **设置**：笔 / 橡皮各自一套：大小（屏幕像素，左栏 dial 第一格，档位同软选择那张表）、浓度（不透明度，左栏 dial 第二格）、硬度（工具条）。记在设备上（tool-config device scope）。颜色：工具条一个色块，点开 = 家族色表排成的几排色块（三维现成的 PALETTE_ZH）；**选颜色只有一个入口** `paint-color.ts pickPaintColor()`，以后换色轮只改这一处（统筹 11-11）。
- **吸管**：点模型上一处 → 画过的面 = 那一格合成出来的颜色（热的读内核合成那一张的一个像素；冷的先热）；没画的面 = 材质的颜色。取完自动回到上一把工具（笔 / 橡皮）。
- **进门就准备好**：切进画画工作台 = 当前物件的画全部 `warm()`（冷的解开），落点表（`paintTargets`）先算好放着、模型一改就作废。量一万面的模型。
- **人话拒绝**：`PAINT_CANT_MOVE` 改成「这些面上有画：带着画的面现在还不能并进别的物件、分出去、做成唯一、复制粘贴、炸开或者转成硬表面（这个功能还没做）」。
- **不用不多做事**：控制器懒：没进过画画工作台、文件里没有画 = 不建画板、不起内核、不挂定时器（0-3a 的定时器本来就跟着画板走）。
- **探针** `probe-paint-workbench`：进工作台 → 开始画 → 画一笔 → 橡皮擦一半 → 撤销两次 → 重做 → 存盘 → 重新打开，每一步屏幕和数据对；吸管 = 那一格的颜色；手指转视角不画点；画画工作台里笔不选中东西；出了工作台笔照旧。截图：iPad 竖屏（820 × 1180）和桌面（1280 × 800）。

统筹 11-11 改的两处：合之前不用等统筹看截图（界面归小弟自己合，截图和「怎么用」写进这里、合了发统筹转 user）；取色的过渡 = 色块旁边加一个填颜色代码的框（#rrggbb），和色块、吸管走同一个入口。色轮抽成共享库 = 家族周账 F-253，这一张不碰。

**怎么用（给 user 的说明草稿）**
1. 双击进到一个网格体里，左上角的工作台下拉选「画画」。
2. 这个物件还没有画时，右下角有一颗「开始画」：没选面 = 整个物件，选了面 = 只给这几张面；点了就能画（一步，能撤销）。
3. 左边三把：笔、橡皮、吸管。笔 / 橡皮的大小和浓度在左栏那两根竖滑条，硬度在右下；右下的色块点开选颜色（几排色块，或者直接填 #rrggbb）。
4. iPad：Apple Pencil 画，手指转视角 / 双指移动缩放；一笔画到一半手指碰屏幕不会转视角。电脑：左键画，转视角照旧（中键 / 右键）。
5. 吸管点模型上一处 = 取那里的颜色，取完自动回到笔（或者橡皮）。
6. 撤销 / 重做和建模是一条线；存盘照常，关了再开画还在（第一次落笔前会先「打开」一下那张画）。

**做了什么**
- 工作台 `paint`（modes/paint.ts）：三把工具 paintPen / paintEraser / eyedrop，工具只经 `ToolCtx.paint` 把「哪把、哪个阶段、在哪」交给宿主；工作台登记挪到 `modes/index.ts`（editor.ts 行数 4110 → 4107）。立场表三行、左柱一列、硬表面不收这三把。
- 「开始画」= 动作 / 指令 `mesh.startPaint`（mesh-edits/start-paint.ts）：选中的面 / 没选 = 全部（已经有画的物件不露）；同一材质用它的颜色，不然白模灰；名字自动「画」「画 2」…；右下工具条的动作里露（没选东西也露）。
- 画画控制器 `app/paint-workbench.ts`：落笔找面（射线打正在编辑的物件，三角格子按网格版本缓存）→ 画 → 1-8b 的门 → SpacePaintStroke（落点只认正在编辑的这一份摆放：`paintTargets` 多一个 chain）；吸管（`PaintBoard.pixelAt`）；进门 warm 这个物件上冷的画。
- 颜色一个入口 `app/paint-color.ts`（色块 + 填代码；存哪由宿主给的口定，现在只在这一次打开里记，见「没做的」）；面板 = index.html `#paintColorSheet`，进输入闸名册。
- 设置：tool-config 笔 / 橡皮各一套（大小、浓度在左栏 dial = `app/paint-sliders.ts`，硬度在工具条），**session**（见「没做的」）；tool-config 多一个 `elsewhere`（有自己的控件、不进工具条）。
- 手势：`cameraLocked`——画画的一笔当中，环绕 / 平移 / 双指都不动相机（平时「画到一半转视角」照旧）。
- 拒绝的话：`PAINT_CANT_MOVE` 改成人话（守卫跟上）。
- 一笔建表出错（见下）：这一笔取消、零痕迹、提示行说人话；以前这个错在每帧的「准备」里抛。

**接上 1-4c（v0.19.24 合了之后 rebase 上来做的）**
- 撞上的那个上限（1-4b 每格紧凑表 16 位，默认密度下 96 张面起就画不了）已经由 1-4c 修掉（每格定长 8 字节、没有第二张表）。
- 工作台每帧对一次「画画的准备」（`space-prep.ts`）：进门 / 换了正在编辑的物件 = 这个物件上冷的画解开、新建还没画过的建画板（存出去和没建一样是那份空白的）、热的画的每份摆放准备现成；**在工作台里撤销到建模那几步（网格体修改号变了）= 这一帧就重建，不等落笔**；出了画画工作台 = 全放。落笔只取现成的；没准备好 = 这一笔不开始、提示行「画布的表还在准备（刚才改了模型），等一下再画」；撞到容量上限 = 这一笔不开始、提示行说那个上限的人话（`strokeFailedSay` 认它们带的 `say`）。
- 某一帧才知道的上限（一颗笔尖下同一块挂了八张以上的面、一帧的数据表放不下）：这一笔取消、零痕迹、提示行说那句人话（以前只有「建表出错」走这条）。统筹 11-11：八张面那条就这样；数据表那条在「流畅第一批」里改成分批画。
- 合之前统筹要的数：在 wip2021（15282 个三角形）上用工作台允许的最大的笔（400 像素）快速画（从头到脚每帧挪 60 像素、来回横扫五趟每帧挪 80 像素），默认密度和 4194304 格各一遍：一帧最大的数据表 = 实例表 35452–37656 个数，上限 16777216（**用了 0.21–0.22%**）。正常用碰不上 → 照统筹说的 1-7 先合、过渡期用「取消 + 说人话」。（探针 `probe-paint-scale.mjs` 的 I 段，真模型那一档；`SpaceLayer.peak` 记这一笔一帧最大的那张表。）

**没做的 / 别扭的**
- **笔的设置和颜色先不记在设备上**（第 8 条没做）：笔 / 橡皮的大小、浓度、硬度和颜色只在这一次打开里记，换页面回默认值。原因：第 8 条「记在设备上」是统筹写进施工单的，user 没说过；`test/tool-config.test.ts` 的守卫要求开 device 先有 user 同意，拦得对（统筹 11-11：不许为它加白名单）。统筹去问 user；点头了改回 device（tool-config 六处 + main.ts 颜色那两个口换回 device-kv），守卫白名单写上 user 的原话和日期。
- app 层按工作台名字分叉的棘轮（≤ 6）：1-7 原来加了三处 `modeId === "paint"`，改成问手上拿的是不是画画的工具（`tool-ids.ts isPaintTool / paintPenOf`；那三把只在画画工作台里有），回到 6。
- 没有压感（输入层没有压力这个口）。
- 冷的画在解 PNG 那几帧显示底色；第一次落笔若还没热好，这一笔不开始（1-8b 的规矩），要再落一次。进门准备（几何 + 每格的表）在大物件上是一帧卡一下（24576 张面约 1 秒），没有进度条。
- 颜色只有色块 + 代码（色轮 = F-253）。
- 没有快捷键（B / E / I 会和自由建模的键在肌肉记忆上打架，没加）。
