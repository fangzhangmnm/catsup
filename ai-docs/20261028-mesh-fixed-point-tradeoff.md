> 读者：user（iPad 上看）。一页：硬表面为什么要定点、网格体现在怎么存、四个选项各买到什么 / 付什么、我的推荐。**要你拍一句**（§5）。

## 0. 一句话

硬表面体定点是因为**它的身份就是位置**（公理 3「重合即同一」）；网格体的身份是**下标**（Blender 那一派），位置只是属性。所以「全程上格」对网格体买不到硬表面那份好处、却要付同样的账（每个算子出点都吸格、累积误差、文件 major）。**推荐 B：只在存盘那一刻把坐标吸到 1 µm 格，文件键不变、内存照旧 f64**——零吃书、可逆、和硬表面同一个格、以后想把文件压小随时能换整数键。

## 1. 硬表面为什么定点（现状，立宪页 §0）

- 内核坐标落在 **1 µm 格**上（Q = 1e-6）；顶点身份 = 格点坐标——两条路算到同一个点就是同一个点（面找回、结算机、像表全靠这个）。
- op 日志按 **µm 格点坐标寻址**（不含运行时 id）：撤销 = 重放、联机各 peer 重放同一份。
- 文件：顶点按能整除的最粗单位存整数（1 cm … 1 µm 阶梯），平面法向定点 2⁻³⁰——小、规范、逐字可比。
- 已付的账（立宪页「已知残余」）：Q = 1 µm + 共面 τ = 1 mm，斜面推拉的无理数位移会让同一点经两条路落到**相邻**格点 → µm 尖刺 → 环撞环。

## 2. 网格体现在怎么存

- 内存：`MeshKernel.pos` = f64；身份 = 顶点下标；边 = 两个下标；面 = 下标环。**没有任何地方靠「坐标相等 = 同一个点」**：合并是显式动作（右键「合并到中心」、镜像纪律 R2 的并点〔1 mm 容差〕、对称对齐〔容差〕）。
- op 日志按 **下标 + 定义 id** 寻址（`meshMove { v, to }`），撤销 = 下标寻址的差量表；重放 oracle（撤销 fuzz）已经证明 f64 下逐字一致——IEEE 的加减乘除是精确舍入的，同一串 op 在任何机器上算出同一串浮点。
- 文件：`CATSUP_mesh` 1.2 `positions` = f64（24 B / 点；1 万点 = 240 KB，白模级别的模型不疼）。
- 容差散在三处（`mirror.ts` 1 mm、`bevel.ts`、`select-loop.ts`），都是「近不近」的判断，不是身份。
- 镜像：`mirrorPt` = 把一个坐标取负——f64 下**精确**，两半本来就严格镜像，不需要格来保证。
- brep → mesh：硬表面的点在 µm 格上，f64 能精确装下（到 2⁵³ µm ≈ 九百万公里）；mesh → brep：吸到格上（有损但定义清楚，转换本来就是一次性动作）。

## 3. 四个选项

| | 买到什么 | 付什么 | 吃书？ |
|---|---|---|---|
| **A 什么都不做**（f64 全程） | 现状；撤销 / 重放 / 镜像已经逐字 | 文件 24 B / 点；和硬表面不是「同一套制度」（文件里的数不在格上） | 不 |
| **B 存盘吸到 1 µm 格，文件键不变，内存 f64**（推荐） | 文件里的数全是整 µm（和硬表面同一个格）；存 → 读 → 存幂等；镜像的两半吸完仍严格镜像（格以原点对称、取负精确）；以后想换整数键压文件是 minor 的事、不是现在 | 存盘那一刻 ≤ 0.5 µm 的挪动（重开模型和关掉前差 ≤ 0.5 µm；撤销栈只活在会话里，不受影响）；细分 / 倒角的「数学上的光滑」在 µm 级被打断——看不见 | **不**（键不变、老文件照开；只是写入器的约定，可随时撤） |
| **C 全程定点**（内核坐标上格，身份仍按下标） | 文件 = B；brep ↔ mesh 来回少一次吸格 | 每个算子（细分 / 倒角 / 插入 / 镜像切开 / 挤出沿法向）出点都要吸格 → 累积误差 + 硬表面那种「相邻格点」病搬进来；`CATSUP_mesh` major（老 f64 文件 → 读成格上 = 语义有损，立宪 §7 要「语义无损」）；收益只有「同一套制度」这句话 | **吃**（major） |
| **D 身份也按位置**（公理 3 搬到网格体） | 两条路算到同一点自动焊上 | 整个 bmesh 式设计推翻：Blender 的双点是故意留着等「按距离合并」的；刚落地的镜像纪律 R2（显式并点）白做；细分 / 倒角的中间态全靠下标 | **吃**（纪元级） |

## 4. 我的推荐与理由

**B。** 理由三条：① 网格体的身份是下标，定点买不到「重合即同一」——这是硬表面定点的全部意义；② B 把「同一套制度」里**真正有用的那一半**（文件里的数在同一个格上、规范、可比、以后能压）拿到手，不碰内核、不碰格式键、不吃书；③ 可逆：写入器一行约定 + 一条「存 → 读 → 存幂等」的测试，不满意删掉就回 A。C 和 D 等真有需求（联机按坐标寻址？两个网格体靠坐标自动焊？）再谈，今天没有。
