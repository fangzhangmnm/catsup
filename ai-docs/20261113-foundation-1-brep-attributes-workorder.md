# 筑基第一步：硬表面接上图元属性（施工单）

> created 2026-11-13 by Claude Fable 5.2（Catsup统筹）· as-of 分支 `objects-wave1`（1aa84a82），主分支开发版 v0.19.113
> **这一页是什么**：筑基三步里的第一步的施工单。制度和登记册 = [物体上的数据](20261113-object-data-registry.md)；规矩表 = [属性规程](20261112-attribute-protocol.md)（那一页里的「元素」现在叫图元）。
> **谁做**：Catsup小弟施工；统筹审。过统筹这一关的：内核对外的接口、文件里怎么写、撤销和存盘。
> **什么时候开工**：第 1 版（物体的管理）合了之后。在新分支上做，**做完之前不往开发版推**（原因见第八节）。

## 一、做完是什么样

1. 硬表面内核里每一样「每个图元一个值」的数据，都是一列带声明的图元属性。声明和自由建模用同一个形状、同一份规矩代码、同一张保留名的表。
2. 硬表面多出两类图元：**角**（某张面的某个顶点）和**面的一侧**（某张面的正面或反面）。
3. 切、并、擦、推拉、挪点之后，每一列照它声明的规矩走，包括角上的列。核心代码不认识任何一列的意思。
4. 两头转换（硬表面 ↔ 自由网格）照列的声明带着走，带不过去的有数。
5. 通用的那一层（图元页、存盘、清理、登记表）对两种几何用同一个接口，不知道底下怎么存。

## 三、设计

### 3.1 共用的属性模块 `src/attr/`

从 `mesh/columns.ts`、`mesh/reserved-columns.ts` 里把和「网格怎么存」无关的部分搬出来。这个目录不许 import `mesh/`、`kernel/`（几何的点类型除外）、`scene/`、`editor/`。

- **声明**：`ColumnDef`、`ColumnType`、`MergeRule`、`sameColumnDef`、`typeName`。`Domain` 加一个 `"faceSide"`。「这个内核做不做得了这种组合」的检查留在各自的内核里。
- **规矩**（全仓取值的代码只此一份）：并成时取哪一个（`pickMerged` / `mergeScalar`）；「之间」的混法（按权重、取整到步长；离散的取权重最大的）；**在一张带角值的多边形上取某个位置的值**（输入 = 三角形、各角的位置、各角的值、一个位置）。
- **取样的两种边界**：位置在多边形外面时，自由网格照旧夹到最近的点；硬表面按最近那个三角形**顺延**（平面上的面，顺延是有定义的）。这是一个明写的参数，由几何的种类给。
- **保留名**：一张表管两个种类。每个名字：类型、缺省值是公认的；挂在哪可以按种类不同（只有材质槽号：自由网格挂在面上，硬表面挂在面的一侧）。
- **报告的形状**：哪些图元的哪几列，值不是干干净净照来历得来的。
- **通用层的契约**（3.9）。

### 3.2 硬表面内核里的列

`kernel/layers.ts` 换成 `kernel/columns.ts`。一张表：名字 → 声明 + 数据。名字在整个物体里不重复。

| 挂在哪 | 能声明的类型 | 存法（内核自己的事） | 一个图元的编号 |
|---|---|---|---|
| 边 | 布尔、整数 | 布尔 = 边号的有序集合；整数 = 按边号的表 | 边号 |
| 面 | 布尔、整数 | 同上，按面号 | 面号 |
| 面的一侧 | 布尔、整数 | 按「面号 × 2 + 哪一侧」的表 | 0 = 平面法向那一侧，1 = 另一侧 |
| 角 | 几个小数 | 跟着面的记录走：每一列一条数组，和这张面的环（外环在前、洞在后）上的点一一对齐 | — |
| 点、面边 | 声明了就抛「还没做」 | — | — |

- 没有值 = 这一列的缺省值。带保留名的列第一次写进非缺省值时才出现（和自由建模一样）。
- 存法照旧用内核现成的按编号的表和有序集合（编号不复用、遍历按编号）；改动日志的钩子照旧。
- 热路径照旧能直接拿到某一列的集合（现在的 `kernel.soft`），不每次按名字查。

### 3.3 名字对成一套

| 现在的名字 | 改成 | 挂在哪 | 类型、缺省 | 并成时（保持现在的行为） |
|---|---|---|---|---|
| 边层 `soft` | `soft` | 边 | 布尔 0 | 不一致回缺省 |
| 边层 `smooth` | `smooth` | 边 | 布尔 0 | 不一致回缺省 |
| 边层 `hidden` | `hide_edge` | 边 | 布尔 0 | 不一致回缺省 |
| 边层 `curve` | `curve` | 边 | 布尔 0 | 不一致回缺省 |
| 边层 `fold` | `fold` | 边 | 布尔 0 | 不一致回缺省 |
| 面层 `hidden` | `hide_poly` | 面 | 布尔 0 | **取第一个不是缺省的**（和自由建模的「不一致回缺省」不一样，见下） |
| 面层 `material` + `materialBack` | `material_index` | 面的一侧 | 整数 −1 | 取第一个不是缺省的 |

- `curve`、`fold` 进保留名的表。
- 已知两个种类不一样的两处，这一步不动、写进表里：材质槽号挂的地方；藏着的面并起来是藏还是露（任务清单里「人擦边时一藏一露并成藏着的要不要收」那一条等 user 定，定了再对齐）。

### 3.4 边、面、面的一侧怎么走

规矩表照属性规程第五节。核心只照声明办：

- **边**：切开 = 一块（照抄）；溶解并成一条、焊点时两条边落到同一对点上 = 并成（照声明取，不一致进报告）；搬到另一个点上 = 一份；删 = 没了。
  - 焊点那一处现在是「另一头已经有边就把搬过来的那条丢掉」。改成并成，先后 = 原来在的那条、搬过来的那条。这是这一步唯一有意的行为改动。
- **动词说「这些线段上的边带这个值」**（现在的 `layerSegs`）：照旧，是「给定」。只支持布尔列写 1；整数列用到时再加。
- **面**：分开 = 一块；并 / 吸收 = 并成（照声明取，不一致进报告，带各来源的值）；出生 = 新长（像带着值的 = 给定）；拉伸 / 一对一 = 原样；炸 / 擦 = 没了。
- **面的一侧**：和面一样走，另加一条——面翻了（落到法向相反的平面记录上、镜像、明着翻面），这张面在**所有**挂在面的一侧的列上两个值对调。核心不看名字。

### 3.5 角上的列过结算机（这一步的核心）

原则和结算机自己的原则一样：**动词不碰图，像带着值走，机器按坐标取。**

1. `Image` 加一栏 `corner`：每一列一条数组，和像的环上的点一一对齐。
2. **机器自己交的身份像**（没被动词动的面）：自动带上这张面现在的角值。
3. **动词交的继承像**：必须带。用一个共用的小函数造：照旧环逐点映射到新位置，跳过的点连值一起跳过；像上新插进来的点（推拉时被拉长的邻面多出来的两个点）= 旧面的图在那个位置上的值（顺延）。内核有角上的列而继承像没带 = 抛（程序错误），免得哪个动词忘了。
4. **新像**（并入、粘贴）：可以带，是给定；没带 = 缺省值。
5. **机器铸面 / 落面时**（第 ⑧ 步，`mint` / `setFace`），这张面每个角的值这样取：
   - 对每一张认领了这个胞腔、属于这个身份的像：这个角正好是像上的一个点 → 那个点的值，逐位照抄；不是 → 像的图在这个位置上的值。
   - 只有一张像 → 就是它。好几张（并面、同一张面折成的几片）→ 照这一列声明的并成规则取，先后 = 事件里的先后；不一致 → 报告记「对不上」。
   - 取不到（像退化、切不出三角形）→ 缺省值，报告记「取不到」。
   - 手势围出来的新面 → 缺省值。
6. **擦边机**（并 / 吸收不走像）：把要出库的面当成身份像，调同一个函数。
7. **溶解**（环上去掉一个二度共线的点）：角值的数组同一处去掉一个角。别的原地改环的地方见第五节第 2 条。
8. **取样用哪套三角形**：没有洞的面用 `triangulateFace`（和自由网格显示用的同一个函数）；有洞的用 `triangulateRings`。以后硬表面显示画时，显示也要用这同一套。
9. 这段代码只有一份，放 `kernel/corner-carry.ts`（规矩本身调 `src/attr/`）。内核一列角上的列都没有时，一行都不多跑。

结果上的意思（给审查和测试用）：

| 操作 | 角上的值 |
|---|---|
| 画线把面切开、擦边并回去 | 老角不变；新角 = 那个位置上的值；切了再擦回去逐位相同 |
| 挪点、转、缩放、镜像 | 跟着点走，值不变 |
| 推拉：被推的那张面 | 跟着面走，值不变 |
| 推拉：被拉长的邻面 | 老角不变；新角 = 顺延（画接着铺，不拉伸） |
| 推拉长出来的侧面、手势围出来的面 | 缺省值 |
| 两张面并成一张 | 公共点上各取各的来源，不一致进报告 |

### 3.6 懂意思的代码放哪

- **核心**（不许出现任何保留名，有守卫）：`src/attr/**`、`kernel/columns.ts`、`kernel/corner-carry.ts`、`kernel/settle.ts`、`kernel/face-lifecycle.ts`、`kernel/delta.ts`、`kernel/topology.ts`。
- **动词和用到意思的那一层**（可以按保留名读写，白名单列在守卫里，加一个文件要改守卫）：
  - 侧棱表、帽边不带折线：搬到 `kernel/policy.ts`，推拉和跟随用。
  - 默认背面（并面之前先处理、新面定两侧）：`kernel/face-sides.ts`。`Kernel.emit` 在通用的「照事件走」之前调它。
  - 折线每步检查、曲线的成员边：留在 `kernel/kernel.ts` / `kernel/curves.ts`。
- 正反两面互换：变成 3.4 那条通用的，核心里不再有 `material` 这个词。

### 3.7 「两张面能不能并」看列

`flatSoftMergeable` 现在点名看材质和隐藏。改成通用的：软边、恰好两张不同的面、同一平面、边自己没藏，而且——

- 面上的每一列、面的一侧的每一列，两张面的值都一样；
- 角上的每一列：两张面的图是同一张图的两块。判法 = 把一张面的图顺延到另一张面的每个角上，和那个角自己的值一样（连续的列差不超过半个步长，离散的相等），两个方向都查。

用它的两处不变：挪点之后 180° 的软边自动并、转回硬表面时并共面的三角形。

### 3.8 两头转换照列带

每一列在每个方向上有一个去向，登记在 `scene/kinds.ts` 现成的那张去向表里（现成的守卫：少一列 = 红）。去向三种：

| 去向 | 意思 | 哪些 |
|---|---|---|
| 照带 | 通用代码按几何对上、照声明取 | 藏着的边、藏着的面、接缝、自己加的列（面、边、角） |
| 换算 | 那个种类自己的一段代码 | 材质槽号（一面 ↔ 两侧）；柔边 / 平滑 / 手标的棱（两个种类明暗的规矩不一样，照旧） |
| 丢 | 有数、转之前说 | 这一步结束时：贴图坐标的两列（见下）；别的照现在的清单 |

通用代码三段（代替 `carryMeshSides` 里管藏的那一半和 `carryHiddenEdges`）：

- **面上的列**：一张硬表面的面 ← 盖着它的网格面。背靠背的两张网格面落到一张面上 = 并成，先后 = 朝法向那一侧的、另一侧的；不一致的记成丢了几张。
- **角上的列**：硬表面的角 ← 同一个位置上的网格角，照抄；被切过的面在盖着它的网格三角形上取样。
- **边上的列**：硬表面的边 ← 落在那条网格边线段上的边；对不上的记成丢了几条。
- 反方向（硬表面 → 自由网格）：面按侧出面，面上的列照抄，面的一侧的列取那一侧的值；角按同一个点照抄（背面那张照翻过来的顺序）；边按同一对点照抄。
- **同一张网格面三角化出来的三角形，共面就并回去**，不用过 3.7 的角那一条（它们本来就是一张面；不然不是平行四边形的四边面回来会变成两个三角形）。不同网格面之间照 3.7。

**贴图坐标的两列这一步先不放开**（去向保持「丢」，转换时明着去掉这两列）。原因：画画那一层记「哪块画布空出来了」只看自由网格；硬表面要是带着贴图坐标而那一层不知道，那块地方会被记成空的、再分给别的面，转回来两张面叠在同一块画上——这是会弄坏用户的画的。放开排在收口（物体属性那一步之后，那张对照表得能留在硬表面的物体上；画画那一层先学会看硬表面）。

### 3.9 通用层的契约

两个内核都实现；`scene/attribute-list.ts` 里两个函数合成一个；以后的清理、登记表、存盘只用它。

```ts
interface AttributeHost {
  /** 这种几何有哪几类图元、现在各多少个。读写一整列时的顺序就是这里的枚举顺序。 */
  domains(): readonly { readonly id: Domain; readonly count: number }[];
  columnDefs(): readonly ColumnDef[];
  /** 一整列的一份拷贝（个数 × 每个几个数）；没有这一列 = null。 */
  readColumn(id: string): Float32Array | Int32Array | Uint8Array | null;
  /** 整列写回；长度不对 = 抛。撤销由调用的那一层包。 */
  writeColumn(id: string, data: ArrayLike<number>): void;
  addColumn(def: ColumnDef): void;
  removeColumn(id: string): boolean;
}
```

硬表面的枚举顺序：边、面 = 现在快照的顺序；面的一侧 = 面的顺序 × 2；角 = 面的顺序，每张面外环在前、洞在后。

### 3.10 快照、撤销、文件

- `BrepSnapshot`：`edgeLayers`、`faceLayers` 两栏换成一栏 `columns`（每一列：声明 + 按 3.9 的顺序排的数据）。`bake.ts` 这类读快照的地方用小函数按名字取，不自己翻。
- 差量（`KernelDelta`）：两本层的字典换成一本列的；面的记录带着角值，拷的时候一起拷。
- 文件（硬表面那一段）：一列 = 声明 + 数组，**名字和程序里的一样、不重排**（登记册规矩第 12 条「没有隐藏数据」，user 11-13 夜）。怎么压归编码那一层，解开就是程序里那一列。自由网格那一段这一步不动（两段收成一种写法 = 筑基收口时的文件方案，统筹出、user 点头）。
- 一个身体里有好几个池（根 + 组）时：同名的列各池声明必须一样（自检加一条）；加列加到这个身体的所有池。

## 五、开工前先核（核完一条消息报统筹；和下面写的不一样，统筹改设计）

1. 胞腔的环会不会同一个点走两次（桥、缝、伸进面里的悬空线）。会的话「这个角正好是像上的哪个点」要多看环上前后两个点，统筹补一条。
2. `settle.ts` 第 514 行附近那处原地改环：改了什么，角的个数会不会变。全仓原地改环的地方列全。
3. 所有造继承像的地方列全（推拉的帽、被拉长的邻面、挪点、全池变换、跟随、别的）。每一处「像上的点对旧环上的哪个角」写不写得出来。
4. `triangulateFace` 和 `triangulateRings` 对同一个没有洞的平面多边形切出来的三角形一不一样。
5. 硬表面显示时现在怎么切三角形（3.5 第 8 条要和它对上）。
6. 焊点时「另一头已经有边」那条路，带着标记的边被丢掉的情况现有测试里有没有。
