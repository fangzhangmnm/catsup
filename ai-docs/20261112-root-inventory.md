## 三、不在根上（文档级，包一层不碰）

设置（网格 / 单位制 / 尺度参考）、桌面态（画风、视角、参考窗位置）、参考窗牌组、材质表、贴图表、图层表、素材架、缩略图。

## 四、要先想清楚的（给统筹）

1. **老文件打开时包不包**：包 = 打开就改了结构（存回去就是新的样子，老版本读到的是多一层）；不包 = 两种结构并存，代码里「根」的意思分两种。这条决定第 6、11 条怎么做。
2. **根的坐标架**（第 3 条）：现在住在场景上而不是根的身体上，是根唯一一处和别的定义长得不一样的数据；包一层正好可以让旧根和别人一样（住自己的 drawFrame），新根的坐标架是什么要定。
3. **按 `rootIndex` 认人的携带**（第 6、7 条）：包之前就该改成按 GUID，不然包的那一下会把带回的东西挂错地方。
4. **缺省的落点**（第 11、12 条）：指令缺 `at`、粘贴、导入都默认根；包完之后默认新根还是旧根，三处要一起定。
