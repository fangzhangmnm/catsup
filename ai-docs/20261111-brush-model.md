# 笔的模型：一支笔由哪几样组成、存成什么样

> created 2026-11-11 by Claude Fable 5.2 · as-of 三维 v0.19.46、画画开发版 v0.14.84
> 出处：user 11-11 晚「手指和笔的界限和抽象本来就很乱……关键是tool的抽象吧。以后可以weebpaint跟着我们学学，记账」；总表 `20261111-brush-master-table.md` 文末那一条里 Fable 答应的「把这个模型定成一支笔存成什么样，赶在第一批笔开工之前，按两个 app 都能用的样子写」。
> 这一页是模型和格式，不是施工单。哪些是 user 说的、哪些是 Fable 定的，都标了。第一批笔的施工单在小弟做到那一步之前另写。

## 一、一句话

**一支笔 = 画画内核现有的那条笔记录，原样，再加三处。** 画画软件笔架里现在的每一条记录，不改一个字就是这个模型里合法的一支笔。

- 「画画内核」= 两个 app 共用的那套二维画画引擎（正本在画画仓，三维这边是拷贝）。它出笔尖、算压感、收尾、平滑，吃的就是这条记录。三维里的笔也是它出的笔尖，所以不另起一套字段。
- 下面说「只有画布的宿主」= 画画软件、三维里的画布小窗；「有表面的宿主」= 在模型上画的那个视图。模型里不出现「三维」「二维」这两个词。

## 二、八根轴，各落在哪个键上

| 轴 | 键 | 现在的取值 | 状态 |
|---|---|---|---|
| 对像素做什么 | `tool` | `brush` 上色、`eraser` 擦、`smudge` 抹（现有）；`fill` 填整张面（新） | 现有的键，加一个取值 |
| 笔尖的形状 | `shape { kind, aspect, rotation, hardness }`、`pixelMode` | 圆、椭圆；`pixelMode` = 一格一格、不抗锯齿 | 现有，不动 |
| 多大，用什么量 | `size { base, max, unit }` | `unit` 缺 = 宿主自己的习惯（见第三节）；`"cell"` = 画布的格 | `unit` 是新的 |
| 怎么出漆 | `spacing`（按走过的距离） | 按距离 | 现有；按时间出漆等第二批的真喷枪再加键 |
| 一笔里自己叠自己 | `compositeMode` | `wash`（取最浓的，自己叠自己不变深）、`buildup`（越叠越浓） | 现有，不动 |
| 和底下怎么混 | `blendMode` | 正常、正片叠底、滤色…… | 现有的键（画画软件界面上还没露出来，周账 F-254） |
| 手感 | `sizeCoeff` `opaCoeff` `flowCoeff` `pressureGamma` `pressureCurve` `pressureLPF` `taper` `taperFloor` `smooth` `defaultOpa` | | 现有，不动 |
| 吃哪种几何 | `geo { by, … }` | 缺 = 不吃；`concave` 凹缝、`convex` 凸棱（第一批）；以后 `up` 朝上…… | 新的 |

另有身份和摆放：`id`、`name`、`folder`（现有）。不认识的键原样带回（现有的规矩）。

**这一版不给键的轴**（记着，到第一支用得着的笔出现时再加，加之前发统筹）：

- 写到哪（颜色 / 光泽那一槽 / 选区）：现在一律写颜色。
- 带多少自己的颜色、带多少底下的颜色（普通笔 ↔ 湿画 ↔ 手指是这一根轴）：画画软件现有的手指那几个键照旧，这里不重新起名。
- 沿不沿棱走（渗线、勾边）、从一个点喷出去（真喷枪、水贴）。

**不属于笔的**（Fable 定）：只画哪里（选中的面、选区、蒙版）是工作台的状态，不存进笔；颜色是全局的；大小、浓度是旋钮（第五节）。

## 三、新加的三处

1. **`tool: "fill"`**：按住在模型上拖，划过哪张面填哪张面（user 11-11：「按面填色 同意，记得做成拖动选择的」）。它没有笔尖，用到的只有颜色和浓度。它和笔记在同一张表里，是为了旋钮、禁用、探针都走同一条路。
2. **`size.unit`**：
   - 缺：宿主自己的习惯。只有画布的宿主 = 画布像素（画画软件一直如此）；有表面的宿主 = 屏幕像素（轨迹在屏幕、笔尖是空间里的球，user 11-10 定的）。
   - `"cell"`：画布的格，两种宿主一样。有表面的宿主里换算成空间里的长度（格数 ÷ 这套排法的密度），**笔尖照旧是空间里的球，不在贴图坐标里画方块**（「工具只在视图或三维空间里做，绝不 UV」那条不破）。一条硬规矩：按格的笔永远包含落点所在的那一格（user 11-10：「点到哪个texel就是那个texel」）；大小是 1 格时就只涂那一格。
   - 以后要按真实长度（米）的笔，加一个取值。
3. **`geo`**：出漆时多乘一个数，这个数来自这一格的几何。
   - `by`：`"concave"`（离凹缝越近越吃墨 = 渍洗）、`"convex"`（离凸棱越近越吃墨 = 干扫）。同一张图，两支笔方向相反（user 11-11：「这个是不是可以和刷突出的一起做」）。取值开放。
   - 别的参数（多远以内算近、怎么衰减）在第一批笔的施工单里定，定的时候守两条：长度一律用米存；每个参数单独管一件事，不许为了调一样去动另一样共用的数（家规：调参按物理量纲独立定义）。

## 四、一支笔在这里能不能用

- **不存「只能在哪用」**。每个宿主列一张自己认得什么的单子（哪些 `tool`、哪些 `geo.by`、哪些 `size.unit`、哪些笔尖形状、哪些 `compositeMode` 和 `blendMode`）；一个函数拿一支笔和这张单子比，出「能用」或者「不能用 + 原因」。
- 带着宿主不认得的**取值**的笔 = 在这里禁用、说原因，记录原样带着。不许悄悄当成别的笔画（家规：不静默）。
- 所以：渍洗、干扫、按面填色在只有画布的宿主里是灰的；草稿、勾线、普通笔、按格的笔、橡皮两边都能用；软喷枪（`buildup`）和真喷枪是两支不同的笔，小窗里拿到的永远是软的那支（user 11-11：「3d笔 2d禁用。2d的喷枪是2d的喷枪不要用3d的」）。
- 带着不认识的**键**的笔照常能用，那个键原样带回（新版本加的功能在旧版本里没有，画出来可能不一样，不坏数据）。

## 五、存在哪

| 什么 | 存在哪 | 状态 |
|---|---|---|
| 内置的笔 | 代码里的一张表，每行就是第二节那条记录；`id` 是固定的字符串，定了不改、不重用 | 第一批笔时做 |
| 每支笔的旋钮停在哪（大小、浓度、硬度） | 文件的桌面态（`CATSUP_desk`），按笔的 `id` 记 | 第一批笔时改，见下 |
| 每种 `tool` 上次拿的是哪支 | 同上 | 同上 |
| user 自己做的笔 | 文件里的条目，身份是 GUID，进身份层和素材架；记录就是第二节那条，一个字不变 | 以后的笔架那一轮。user 11-11 定的方向：笔架跟着文件走、内置的笔不拷进文件。改内置的笔 = 另存成一支自己的笔，是 Fable 顺着这个方向定的，user 没逐字说 |

`CATSUP_desk` 1.6（第一批笔时落地；minor）：`paint` 里加两个可选键，改过才写。

- `brushes: { <笔的 id>: { size?, opacity?, hardness? } }`。不认识的 `id` 和键原样带回。
- `active: { <tool 的取值>: <笔的 id> }`。指着这一版没有的笔 = 用这种 `tool` 默认的那支，原样带回。
- 1.5 的 `tools` 保留读、停止写：`paintPen` 那一行读成普通笔的旋钮，`paintEraser` 读成橡皮的。
- 硬度现在还是旋钮；自己的笔做出来之后它属于笔，这个键保留读、停止写（1.5 的头注释里已经这么写了）。

## 六、第一批七支笔在这个模型里是什么

| 笔 | `tool` | 靠哪几个键和普通笔不一样 | 能在哪用 |
|---|---|---|---|
| 普通笔（现有） | `brush` | | 两边 |
| 橡皮（现有） | `eraser` | | 两边 |
| 草稿笔 | `brush` | 手感那一组和叠法：照画画软件的「铅笔」——压感管粗细和浓淡，不收尖，轻微的平滑，叠法是取最浓的 | 两边 |
| 勾线笔 | `brush` | 手感那一组和叠法：照画画软件的「勾线」——压感只管粗细而且很强，起笔收尖，平滑大，硬度 0.5，叠法是取最浓的 | 两边 |
| 按格的笔、按格的橡皮 | `brush` / `eraser` | `pixelMode`、`size.unit = "cell"` | 两边 |
| 按面填色 | `fill` | | 有表面的宿主 |
| 渍洗、干扫 | `brush` | `geo.by` | 有表面的宿主 |

草稿笔的数先照画画软件的「铅笔」抄，勾线笔照它的「勾线」抄（总表第 1、2 行的出处），画出来不对再调（手感归 user 判断）。

（11-12 更正：上表这两行原来写的「两头收尖」「硬」是 Fable 凭印象写的，和画画仓内置笔的数据对不上，已照小弟读出来的数据改。另：记录里的 `smooth`（平滑）内核出笔尖时不自己读，要宿主换算了递进去；换算收成内核里的一个函数，两边共用。）

## 七、给施工的三条规矩

1. 现在的 `paint/brush-kinds.ts`（每种笔一行：拿哪把工具、擦不擦、怎么叠）长成「内置的笔」那张表，行的样子换成第二节的记录；`erase`、`accum` 从 `tool`、`compositeMode` 算出来，不另存一份。
2. 探针按「走的是哪条路」覆盖，不按支数：一支笔的路 = `tool`、`compositeMode`、`pixelMode`、`size.unit`、`geo.by`、`blendMode` 这几样的组合。表里出现的每一种组合都要在探针里有一组（现有的守卫照这个意思改）；只是手感的数不一样的两支笔算同一条路。
3. 认记录、比能不能用的那一个文件不引用三维自己的东西（加一条守卫）：它以后要搬进画画内核，两个 app 用同一份。搬的时候是改内核对外的接口，发统筹。

## 八、画画软件那边（只记账，等它的周；家族周账 F-256）

- 它的记录不用改。
- 它可以跟着做的：「能不能用」那张单子和那个函数；`tool` 这一栏在界面上的说法（笔、橡皮、手指是同一张表里 `tool` 不同的行，架子只是摆法）；`blendMode` 露到界面上（F-254）。
