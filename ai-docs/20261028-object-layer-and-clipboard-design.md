词（本稿里固定）：**上下文** = 你双击进去的那一层（最外层 / 某个组 / 某个组件里面）；**散几何** = 这一层里不在任何组 / 组件里的面和线；**组件** = 有定义、能摆好几份的物体；**组** = 硬表面体里把一团散几何隔开不粘连的分区（不是物体，user 10-24「地位类似选区」）；**容器** = 组或组件；**身体种类** = 硬表面体 / 网格体。

## 0. 一句话

**组件是通用货币，散几何按种类；跨容器只有两个动词真的碰散几何（炸开、粘贴），它们按「对方能不能接」判，不转种类。层级移动 = 剪切 → 走到那一层 → 原位粘贴（SketchUp 的做法），不另发动词。分开 = 原地建组件。合并 = 宏（剪切其余 → 进目标 → 原位粘贴 → 炸开），目标是你右键点的那个，不是「先选的那个」。不做物体模式。**

## 1. SketchUp 和 Blender 各怎么做（对照着看税在哪）

| | SketchUp | Blender | CatsUp 现状 |
|---|---|---|---|
| 散几何 | 允许（每一层都有） | 没有（一切都是物体） | 允许（硬表面 = 一层一个汤 + 组；网格体 = 一个定义一个网格） |
| 物体和几何 | 同一层并存，双击进出 | 两个模式（Object / Edit，Tab 切） | 并存，双击 / 手指双击进出 |
| 层级移动 | **没有专门动词**：剪切 → 进 / 出 → 原位粘贴；Outliner 拖 | Ctrl+P 设父、Alt+P 清父、M 移集合（两套层级：父子 + 集合） | 没有 |
| 合并 | 炸开到当前层 / 剪切进去炸开 | Ctrl+J 并进「活动物体」（最后选的那个，颜色略不同） | 只网格体、只「第一个选的」、目标摆多份就拒 |
| 分开 | 建组 / 建组件（原地） | P → 新物体（原地，同一集合） | 只网格体、搬到上一层、摆多份就拒 |
| 复制粘贴 | Ctrl+X / C / V + Paste In Place | Ctrl+C / V（同集合、同位置） | **没有**（只有移动复制 / Ctrl 拖 / Shift+D） |

**税在哪**：允许散几何，跨容器的动词就得问「散几何是哪种身体的、对方接不接」。Blender 不交这笔税，但交另一笔：碰另一层要切模式，合并要先认「活动物体」（看不见的先后顺序）、分开后还得再设父。user「Blender 更不舒服」= 模式切换 + 隐形的活动物体。本稿保留 SketchUp 的并存，去掉 Blender 的隐形目标。

**税到底多大**：载荷只有两种散几何（硬表面的面 / 线 / 组、网格体的面 / 点 / 线）+ 一种通用货币（组件实例，任何容器都接，和身体种类无关）。只有**炸开**和**粘贴**会把散几何送进另一个容器，所以只有这两个动词要查接纳表。其余物体动词（移 / 转 / 缩 / 复制 / 删 / 锁 / 藏 / 进出 / 改原点 / 改名）作用在「实例 + 变换」上，**和身体种类无关，一份实现**。税 = 两个动词各一行查表。

## 2. 接纳规则（「取决于对方能不能接，不允许强制类型转换」）

| 载荷里有 | 贴 / 炸进硬表面上下文 | 贴 / 炸进网格体上下文 |
|---|---|---|
| 硬表面散几何（面 / 线 / 组的子树） | ✓ | ✗ |
| 网格体散几何（面 / 点 / 裸线） | ✗ | ✓ |
| 组件实例（里面是什么种类都行） | ✓ | ✓ |
| 空的容器（只有子组件、没散几何） | ✓ | ✓ |

- 判的是**实际内容**，不是容器的名义种类：一个网格体组件里面没有自己的几何、只摆着子组件，炸进硬表面层照样行。
- 混合载荷（面 + 组件）里有一部分接不了 → **整份拒绝**，提示行点名哪部分（「3 张面是硬表面几何，网格体接不了」）。v1 不做「只贴能贴的」——部分成功最容易误导（10-26「UX 误导 = 数据安全缺陷」）。
- 显式转换照旧在物体设置窗（「转成网格体 / 转回硬表面体」，v0.15.12）：那是用户点的，不是动词偷偷做的。**v0.16.37 炸开自动转种类（`explodeAcrossKinds` 里的 castBody）违反这条，撤**。
- 组只有硬表面体有，这是**原则不是漏洞**：组存在是为了隔开粘连（结算机），网格体不粘，不需要组；网格体里只有组件。网格体上下文里「建组」不露，Ctrl+G 提示「网格体里没有组，用建组件」（不自动替补，10-07）。

## 3. 剪贴板（最重要的缺件）

- **一份、app 内、不进撤销**（SketchUp 同款：剪切后撤销，剪贴板还在，再贴 = 两份，正常）。跨文档 / 系统剪贴板以后再说（载荷能序列化成 .catsup 片段，留口）。
- 载荷 = 带种类标签的值拷贝：`{ 散几何快照（世界坐标）, 组子树快照, 实例 [{定义 id, 世界变换}], 每个被引用定义的深快照（兜底）, 锚点 }`。锚点 = 剪切 / 拷贝时菜单点的那一点（没有 = 包围盒底面中心）。
- **剪切 = 拷贝 + 删除**（删除走现有的删动词；锁着的不剪，和删除一样）。剪切掉的组件定义**不回收**（现在炸开会回收零实例定义——剪切不许）。
- **粘贴**（Ctrl+V / 右键空处「粘贴」）= 载荷挂在光标上、按锚点、点一下放下；吸附和移动一样；走现有的移动复制预演（副本槽）。笔：拖着走、抬笔放；点一下 = 放在点的那一点。
- **原位粘贴**（Ctrl+Shift+V / 右键「原位粘贴」）= 世界位置一点不动；在摆了多份的组件里 = 按你**进来的那条链**换算（这就是多份时的消歧：你从哪一份进来，世界位置就按哪一份算——SketchUp 同款，也是用户自己走的路）。
- 贴的时候定义在模型里已经没了（撤销过了头）→ 按深快照重造一份新定义，提示行说「组件「X」在模型里已没有，贴出来的是新的一份」。粘贴不许静默失败。
- 贴进摆了多份的组件 = 改定义 = **每一份都变**，提示行写「N 份一起变」（SketchUp 语义；v0.14.4 孪生槽本来就实时跟）。**现有两条「摆了 N 份先做成唯一的」拒绝撤掉**。要只改这一份 → 「做成唯一」（SketchUp Make Unique；库里没有，补一条物体动词）。

## 5. 要不要一个专门的物体模式（user 问的）

**推荐：不要。** 理由：

- 物体模式解决的是 Blender 的问题（没有散几何，所以必须有个地方只摆物体）。我们有散几何（user 10-23「我经常全量 explode 然后重新整理」= 扁平单池是常态），物体模式在这儿会是半个模式：散几何算什么？要么藏起来（那最外层的几何去哪编辑）、要么当成隐形的「根物体」（= 又回到并存）。
- 真正要的「统一」不是模式，是**一份实现**：物体动词作用在实例 + 变换上，本来就和身体种类无关。现在的病是老物体动词（炸开 / 建组 / 建组件 / 锁 / 藏）手写在 HUD 和编辑器里、按**容器**的种类守门（炸开网格体 bug 的根，周账 F-126），而不是按被操作那个单位的种类路由。治法 = 把它们搬进注册表的 object 族（v0.15.16 的 `Action.commands` 按单位种类路由，`object.toMesh` 已经是样板），所有工作台自动都有，工作台只能**显式退订**（验证台不要炸开），守卫测试逼每个物体动作都有 object 那一条。
- 「所有工作流都有、但 brep 和 mesh 里不一样、有的台不开」= 一张动作表：动作 → { brep: 指令, mesh: 指令, object: 指令 } + 工作台退订表。移动 = `brep.move`（粘连）/ `mesh.move`（自由点 + 软选择 + 沿边滑）/ `object.move`（变换）；验证台退订几何那两条只留 object 那条。这张表就是 user 要的整理，立场表（工具 × 工作台）管手感，动作表（动作 × 单位种类）管路由，两张表不混。
- 沉浸感：双击进出 + 右键对着什么点就给那一层的动词（心智模型 §2.2）已经是「物体层」了，只是它是**选区的一种**而不是模式。物体设置窗 = 物体模式的面板那半；以后的树视图（Outliner，拖着换层级）= 物体模式真正值钱的那半，做成窗口不做成模式。
- 什么时候该反悔：如果以后物体动词多到右键菜单放不下、或者 user 发现自己老是误碰几何——那时再考虑「物体层锁」（一个开关：只选容器不选几何，像 Photoshop 的自动选择图层），仍然不是模式。

## 10. 落地（v0.16.45，Claude Fable 5.1）：炸开 / 分开 / 合并 / 做成唯一
