## 一、保留名表逐行核对

网格体现在有三条写死的数组：`edgeFlags`（每条边一个字节，六位）、`faceFlags`（每张面一个字节，只用了一位）、`faceMat`（每张面一个整数）。逐行对表：

| 保留名（表里的） | 现在是哪一位 / 哪条数组 | 现在的意思（读的人、写的人） | 和表里的意思一样吗 | 建议 |
|---|---|---|---|---|
| `material_index`（面，整数） | `faceMat` | 网格体材质槽表（`MeshBody.materialSlots`）的下标；**小于 0（−1）= 没有槽 = 用缺省材质**。读的人 32 个文件（渲染、导出、画、拾取、粘贴、文件）。新面：切开照抄原面；并面留第一张的（`joinFaces` 改的是第一张面的环）；挤出侧面、倒角补片照抄旁边那张面 | 名字的意思一样；**缺省值不一样**：Blender 是 0（第一个槽），我们是 −1（没有槽）。我们没有「物体至少有一个槽」 | 叫 `material_index`、整数、缺省 −1、挂在面上（面的一侧留给硬表面那一轮）；并成 = first；新长跟旁边 = 跟 |
| `sharp_edge`（边，布尔） | `F_SHARP`（32） | 手标的棱：明暗断开、而且画线；压过物体的「默认平滑」；手标时清掉另两位（三位互斥）。写的人：手标指令、导入时按文件法线判、硬表面转过来时「夹角小于默认角度的硬边」补标 | 明暗那半一样（Blender 的 `sharp_edge` 只管法线分开）。「画线」是我们推出来的（`edge-smooth.ts edgeSoft`：标了手标、又没标不画线 = 画线），不是这一位自己的意思 | 照用 `sharp_edge`；说明里写「画不画线由 soft 推」 |
| `smooth`（边，布尔） | `F_SMOOTH`（2） | 强制平滑：明暗连续，**压过**物体的「默认平滑」。界面上「手标平滑」是这一位和不画线一起设 | 不完全一样：SketchUp 的 smooth 就是这条边平滑不平滑的全部（没有「物体的默认平滑」这一层）；我们是「物体一个默认 + 边上覆盖」两层。新建的网格体默认「全是棱」，那时两者一样；「按角度」「全平滑」时没标的边也会平滑 | 照用 `smooth`；说明里写「是覆盖」。**硬表面归一时要定**：硬表面加「默认平滑」，还是网格体去掉这一层 |
| `soft`（边，布尔） | `F_SOFT`（1） | 只管**不画线**（渲染、导出的线、吸附的线段都按 `edgeSoft` 判）。界面不单独设它（手标平滑 = 它 + smooth 一起）；单独出现只来自硬表面转过来 | **只对上一半**：SketchUp 的 soft 还是「两边的面算一整块」（点一张面连带选中）。网格体里没有任何地方按它把面连成一块——油漆桶「平滑组」、选面用的都是 `edgeSmooth` | 建议仍叫 `soft`（硬表面那边就是这个名字，归一时是同一列），说明里写「网格体现在只用了不画线那一半」。另一条路是另起名（比如「不画线」的英文），归一时再合。**等你定** |
| `uv_seam`（边，布尔） | `F_SEAM`（4） | 展开的接缝：自动标接缝写、展开在这里剪开、画成红线 | 一样 | 照用 |
| `hidden`（边，布尔） | `F_HIDDEN`（8） | 不画、不导出成线、点不中、扩选跳过；镜像配孪生时不看这一位。**谁写**：只有硬表面转过来（任何边都抄，不只游离的）、粘贴 / 读文件原样带、倒角搬家、镜像照抄。网格体自己没有藏边的入口 | 意思和 SketchUp 一样。内核注释写的「点 / 边的显隐从面推导，游离的才自己带」和实际不符：读的人都按这一位单独判，两张看得见的面之间的边也能单独藏 | 你上一轮让我提的问题，见第四节 |
| `hidden`（面，布尔） | `faceFlags` 的第 1 位（`FF_HIDDEN`） | 不画、不吸、点不中、导出不出。**谁写**：硬表面转过来、读文件、镜像照抄、合并点剪圈照抄；网格体也没有藏面的入口。切开之后新的一半不带 = 那个毛病 | 一样 | 照用；第三步跟着修切开那个毛病 |
| `sharp_face`（面，布尔） | 没有 | 网格体没有逐面的平滑开关（只有物体的默认平滑 + 边上的标记） | — | 不建 |
| `curve`、`fold`（边） | 没有 | 网格体没有曲线、没有折线（硬表面转过来时折线变成 soft + smooth） | — | 硬表面那一轮 |
| 画布代号 / 角上坐标 | 已经是列：`uv-set`（面，整数，缺省 −1，defaultIfMixed）、`uv-at`（角，两个小数，步长 1024，first） | 第 1½ 刀搬上来的 | — | 名字照旧（我们自己的） |
| （不是属性）裸线 | `F_WIRE`（16） | 「这条边可以不挂面」：删面时留下、自检认它合法、导出成线 | — | **结构位**，不进属性表：内核另留一张位表（`isWire` / `setWire`），属性页的「几何」那一块显示「不挂面的线 N 条」 |

另外核到的一件：界面「手标 ›」只会写三种组合（棱 / 平滑 + 不画线 / 清掉），`soft` 和 `smooth` 单独一位只会从硬表面转过来。

## 二、接口草案

**声明**（`mesh/columns.ts ColumnDef`，第二节那一份）：
- `on` 多一种 `"edge"`（这一步实现「边」这一类；点、面边、面的一侧以后）。类别的名单这一轮还写在自由建模里（规程第三节：硬表面那一轮改成由几何给）。
- `type` 多一种 `"bool"`：内存 `Uint8Array`（0 / 1）；只能是离散的（声明成连续 = 抛）；缺省 0 或 1。
- `merge` 只有三个规则名，没有函数（规程第二节）。

**边的来历**（规程第四节；现在内核里边没有来历，标记都是各个操作手写的）：
- `MeshKernel.ensureEdge(a, b, origin?)`，`origin` = `piece(e)`（劈边的两半）/ `copy(e)`（复制、镜像、挤出的帽）/ `joined([e…])`（溶解二度点、有限溶解、合并点并成同一对点）/ `grown(neighbor?)` / `given(值)`；不给 = 新长、没有旁边 = 全是缺省值。规矩表（第五节）对边一样；并成不一致进报告（`report.oddEdges`，和面的 `odd` 同形）。
- 合并点里换一头的边 = 原样（`relinkEdgeEnd`，不用申报）；`EDGE_FLAG_RULES` 那张表删掉，换成每一列自己的 `merge`。`edge-mark-rules.ts` 的 JOIN / MOVE 两张表同样退役（JOIN = 每列的 `merge`；MOVE = 「一份就是全部列照抄」），OPS 表留着当文档：每个操作申报哪种来历。

**保留名的声明住在核心外面**：`mesh/reserved-columns.ts`（名字 → `ColumnDef`；边五个、面两个）。核心（内核、`columns.ts`、`merge-points.ts`）不 import 它（守卫）；操作和读的人按名字取：
- 可以没有：没有 = 每个元素都是缺省值。第一次写进非缺省值时才建这一列（`k.ensureColumn(RESERVED.edge.uv_seam)`）。
- 可以删：`k.removeColumn(name)`，一步撤销（属性页第二版用）。
- 每帧都读的（材质、隐藏、不画线）：`k.column(name)` 拿到数组拿在手里（数组扩容时会换，按内核 `rev` 重拿）。
- 读的人改成经一个小函数（比如 `edgeBool(k, "soft", e)`：没有这一列 = 缺省值），不直接摸数组。

**文件门口**：`MeshDoc` 的形状不变（边一个字节六位、面一个字节、面一个整数），门口在列和这三条之间来回换 → 写出来的字节和 v0.19.82 一样（照第 1½ 刀的做法对拍 640 份）。占了保留名、但类别或类型不对的列 = 当普通的列，提示一句（规程第二½节）。用户自己加的列进文件 = 属性页第二版「加一列」时一起做（现在没有这种列）。

**属性页要的（第 3½ 步）**：
- 内核出一张只读的清单：`k.columnList()` → `{ id, on, type, count, bytes }[]`，加几何本身的数 `{ points, edges, faces, corners, wires }`。
- 显示名表在核心外面（`app/attribute-names.ts`：保留名 → 中文名，比如 `sharp_edge` → 棱、`uv_seam` → 接缝、`material_index` → 材质、`uv-set` → 画布代号）。对人叫「元素属性」，物体窗口两页「物体」「元素」（统筹 11-13 夜转的叫法）。
- 硬表面同形：`brepColumnList(kernel)` 把 `layers.ts` 的边层（soft / curve / smooth / hidden / fold）当「边上的布尔」、面层（material / materialBack / hidden）当「面上的整数 / 布尔」，出同一种行；只读。

## 三、改成按来历走之后会变的行为（每条要你点头）

1. **藏着的面切开，新的一半也藏着**（规程第九节：要修的毛病）。
2. **挤出的帽上的边带上隐藏**：现在帽带手标和接缝、不带隐藏（`MOVING_MARKS`），倒角搬家却带——「一份 = 全部列照抄」之后两处一样，都带。
3. **复制（Shift+D）的边带标记**：现在复制出来的边一律不带（`duplicate.ts`「现状」）；改成「一份」之后照抄（Blender 复制也带）。补洞、桥接的新边 = 新长，照旧不带。
4. **两张面并成一张时，隐藏 = 都藏才藏**：现在留第一张面的那一位（`joinFaces` 改第一张面的环）；按列的 `defaultIfMixed` 之后一藏一不藏 = 看得见（和边那条「看得见的赢」同一个规矩）。材质照旧留第一张的（`first`）。
5. 别的（劈边两半、细分两半、合并点、倒角带不搬、倒角圆角中间写平滑）结果不变；细分的折痕照旧读 `sharp_edge`。

## 四、边的「隐藏」这一列留不留（你上一轮让我到这一步提出来）

- **建议留**，和面的那一列各一列（规程第八¾节已经是这样排的）。理由：① 读的人现在就是按这一位单独判的，两张看得见的面之间的一条边可以单独藏；② 硬表面能单独藏边（SketchUp 也是），归一时是同一列；③ 拿掉它 = 硬表面转过来时藏着的边露出来，是行为改动。要改的只是内核那句注释。
- 另一条路：网格体不要这一列，边的显隐全由面推（两边的面都藏 = 边藏；不挂面的线才自己带一位）。好处是少一列、不会出现「面看得见、它的边藏着」；代价是上面 ③，以及归一时两个引擎在这一点上不一样。

## 五、分几刀（每刀单独一版）

- **3a 内核**：「边」这一类 + 布尔 + 边的来历 + 裸线位单列。标记还在老数组里，行为零改动；邻接金样哈希不变、文件对拍字节一样。
- **3b 面**：隐藏、材质槽号搬上属性表（修切开那个毛病 = 第三节第 1、4 条）；读的人改经小函数。
- **3c 边**：五个标记搬上去；各操作改成申报来历（第三节第 2、3 条）；倒角按名字往 `smooth` 写，是第一个用户；`edge-mark-rules.ts` 的 JOIN / MOVE 退役。
- **3d 收**：三条老数组删掉；守卫「`src/mesh/ops` 和读的人都不碰老数组，只经属性表」；属性页要的只读清单。
- 每刀：文件对拍（640 份字节一样）、邻接金样（3b / 3c 会变的逐类列给你）、红线组 + 网格体探针。
