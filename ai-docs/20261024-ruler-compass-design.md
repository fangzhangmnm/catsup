## 1. 读法

精度不是打进去的，是**作出来**的：尺（量 / 偏移 / 平行）+ 规（圆 / 弧 / 角）作出参考线，参考线的交点就是你要的点，然后在那个点上下笔。推断引擎是圆规的针脚（它替你找交点、中点、垂足），参考线是草稿纸上的辅助线，轴是纸的边。Blender 没有这三样，所以它不是 SU 的平替；它有的是数值面板和修改器，那是另一种思考。

所以本稿不加动词：**卷尺、量角器、轴** 三个工具 + 绝对网格一个开关，全部在「参考几何」这一层，**不进内核**。

## 2. 现状（代码事实）

- 推断目标：端点 / 中点 / 线上 / 世界原点 / 三条世界轴线 / 对齐线（从充能点出发的轴向线）/ 载线交点 / 面交线。**没有**：参考线、参考点、上下文（组 / 组件）的原点与轴、网格点。
- 轴：世界轴固定在原点、方向固定；组 / 组件有 `axes: Frame`（原点 = 包围盒最小角，方向 = 单位），**只是存储和变换的基，不参与推断，也没有工具改它**。
- 网格：地面画着自适应网格，只是画，不吸。A10 已拍：incremental 整数长度 + 绝对网格两种都要，「绝对网格只作用于新笔画，旧几何永不静默改」，内部单位米。
- 没有任何参考几何；B14 wishlist 写过「吸附平面工具 + 参考线（CAD 味；轴来设定画线平面）」。

## 3. 数据模型：参考几何层（不进内核）

```ts
type Frame = { origin: Pt3; u: Pt3; v: Pt3; w: Pt3 };              // 已有（组 / 组件的轴）
interface Guides {                                                  // 每个池（definition / group）一份，跟着那个上下文的坐标系
  lines: { id; p: Pt3; dir: Pt3 }[];                               // 无限直线（卷尺偏移出来的、量角器转出来的）
  points: { id; p: Pt3 }[];                                        // 参考点（卷尺沿边量出来的）
  planes?: { id; p: Pt3; n: Pt3 }[];                               // 参考面（B14；第二期）
}
document.axes: Frame                                                // 绘图轴（世界轴可被轴工具搬 / 转；默认 = 单位帧）
```

- 参考几何**不是模型**：内核零感知；渲染单独一层（虚线 / 小叉）；格式进 `annotations.guides`（契约里 definitions.list[i].annotations 那一格；绘图轴进 `CATSUP_document`）。保存，SU 也保存。
- 参考几何**参与推断**：参考线 = 1-D 目标（线上 / 线 × 线交点 / 线 × 边交点 / 垂足）；参考点 = 0-D 目标；上下文的原点 + 三轴 = 0-D / 1-D 永久目标（进组后用组的，不进组用绘图轴）。优先级：模型端点 > 参考点 > 中点 > 参考线交点 > 线上 / 参考线上 > 轴 > 网格点（网格最低，A10 原话「几何推断优先于网格」）。
- 参考几何**随工作集显隐**（创新点，也是 SU 满屏虚线的解药）：始终画，但远离光标 / 当前上下文之外的淡掉；一键全删（SU 同款）；对象是池级的，所以进组只看组里的。

## 4. 三个工具 + 一个开关

| 工具 | 手势（SU 同款，三下以内） | 产物 |
|---|---|---|
| **卷尺 T** | 点一条边 → 拖开 → 打距离 / 吸附落定 → **平行参考线**（偏移）；点一个端点 / 参考线交点 → 沿边拖 → 打距离 → **参考点**；点两个点只量不留（状态行报长度） | 参考线 / 参考点 |
| **量角器 (Protractor)** | 点圆心（定平面）→ 点参考方向 → 转到角度（15° 咬合 + VCB 度数）→ **角度参考线** | 参考线 |
| **轴 (Axes)** | 点原点 → 点 x 方向 → 点 y 方向（SU 三下）；在组 / 组件里 = 改那个上下文的轴（Change Axes，几何不动、帧换掉、内核坐标用逆变换补回） | 绘图轴 / 上下文轴 |
| **绝对网格开关** | HUD 一个钮 + 格距（1 m / 10 cm / 1 cm / 二进制预设）；在**当前绘图轴**的帧里 | 网格点 = 最低优先级的 0-D 目标；incremental 长度取整随同一开关 |

居中 3×5 的尺规做法：卷尺从 y 轴偏 1.5 两次（±）、从 x 轴偏 2.5 两次 → 四条参考线 → 矩形从一个交点拉到对角交点。或者先把轴搬到想要的中心再偏移。没有新动词，没有「中心」目标，三个原子。

## 5. 刀口顺序（依赖序）

① 上下文轴参与推断（原点 + 三轴；进组用组的）——零新工具，先把「纸的边」接上
② 参考几何层：存储 + 渲染 + 推断目标 + 全删 / 显隐（没有工具也能靠测试造）
③ 卷尺（偏移参考线 + 参考点 + 只量）
④ 轴工具（绘图轴三下；组 / 组件 Change Axes）
⑤ 绝对网格 + incremental（A10）挂在绘图轴上
⑥ 量角器
⑦ 格式：`annotations.guides` + `document.axes`，冻结样本；app minor = 0.11 尺规纪元
