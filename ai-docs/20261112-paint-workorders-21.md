# 施工单（二十一）：小窗里能画，第一步

> created 2026-11-12 by Claude Fable 5.2 · as-of 三维 v0.19.55（开发版）
> 施工：Catsup小弟。排在施工单二十 1b 之后。先后和起因 = 设计日记第四十七到四十九轮；小窗和工具栏的关系 = `ai-docs/20261112-canvas-window-modes-design.md`（设计稿，这一张只用到第四节「一只手，两块画面」）。

## 一、为什么，做完是什么样

user 11-12：「其实我要真开始做东西的话，最大的杠杆是在窗口里面画，因为这样的话我可以画一些普通的二维像素贴图。」「就是说不切 app，我能画二维贴图。」

做完：画布小窗浮着的时候，手上的笔、橡皮、吸管落在小窗的画布上就能用；画的是和模型上同一块画板，三维那边实时跟着变；能新建一张不属于哪个物件的二维贴图（平铺的画），在小窗里画，再用油漆桶贴到面上。

这一张不做：选区、填色桶、移动和变换（等三维自己的选区交互那一步）；小窗停在下面和全屏；图层面板；别的画画软件的工具。

## 二、定下来的（改之前先问统筹）

1. **一只手，两块画面。** 手上的工具只有左边工具柱里的那一个。落在模型上走空间那条路，落在小窗的画布上走内核自己的二维笔。小窗不带自己的工具栏。
2. **同一块画板、同一套底子。** 二维笔画在 `PaintBoard` 上，不另起一份：撤销进同一串（一笔 = 编辑器撤销里的一步）、存盘和崩溃快照走同一个钉点、锁照样四层都问、睡和醒照第 3 刀的规矩（小窗里开着的那块算「正在编辑」）、「手上有一下没收」的名册里有它。
3. **笔的记录两边共用。** 小窗里用的就是笔的表里那几行，经 `resolvedBrushOf` 交给内核的二维笔。一支笔在画布上能不能用，照笔的模型第四节做成「这块画面认得什么」的单子和一个函数；用不了的在画布上是灰的、说原因。
4. **手势和模型上一样**：笔画，手指看（挪、缩）；鼠标左键画、滚轮缩。手在哪块画面上就动哪块。
5. **平铺的画**是贴图表里的一行：内容是分层的（和别的画一样），带 `sizeM`、不带 `layout`。这个组合现在的格式本来就允许（`sizeM` 和 `layout` 正好有一个），但以前没有意思；给它意思 = `CATSUP_textures` 升 1.2（旧版本读到它当成不认识的画、按底色显示、原样带回）。施工单十八原来打算用的 1.2 顺延成 1.3，我去改那一页。
6. 平铺的画只能在小窗里画。手上拿着笔落到贴着它的面上 = 不画、说原因（一格对着模型上很多个地方，在模型上画没有意义）。

## 三、分三刀

**第 1 刀：画板多一个二维落笔的口**（没有界面；内核白名单要加的名字、撤销和锁那几行发统筹）

你 11-12 列的六截照做：
- `PaintBoard` 多一个开二维笔的口：档口用内核的 overlay 方式加 `BrushEngine`，落层经 `gpu()` 走 `commitBrushStroke`（照画画仓后端那十几行）。
- 合成时把笔尖的薄层也递进去；`strokeOpen` 认它，画着的时候不许睡。
- 封的步交给同一个 `HostedSteps`，接到编辑器撤销那一步的入口。
- 问锁（开一笔、落层两问），进像素写入名单，「睡着时怎么办」那一栏填上。
- 名册：这一笔开着时 `hand.busy()` 是真的；来源用现成的还是加一行你定，加了就要有那条「没收时存盘」的检查。
- 内核白名单要加哪些名字，合之前列给我，连同为什么不能少。
- 检查在 node 里：二维笔画几笔，图层和合成逐字节等于内核自己那套测试里同样几笔的结果；撤销逐位还原；锁着画不上；一笔当中存盘存的是落定那一版。

**第 2 刀：小窗接上手**（自己合，一个版本）
- 指针落在小窗的画布上：屏幕坐标换成画布像素（跟着小窗的缩放和平移），交给第 1 刀的口。事件时间和压感照 1a 的规矩。
- 笔、橡皮、吸管能用；别的工具在画布上是灰的。
- 放大到看得见格子时画出像素格；悬停时会被涂到的格子亮出来。
- 三维那边实时跟着变（同一块画板，不用另做）；核一下一笔当中每帧只重做改到的那一块，小窗和三维各自都对（开着核对开关）。
- 两块画面来回画：在模型上画一笔、在小窗里画一笔、撤销两次、重做两次，每一步两边看到的都一样。

**第 3 刀：平铺的画**（格式的 diff 发统筹）
- 小窗「…」里「新建平铺的画…」：选像素大小（16 / 32 / 64 / 128 / 256）和它在模型上多大（米，默认 1）。建一行贴图和一个用它的材质，开在小窗里。
- 渲染器认它：贴着它的面显示它的合成图，按 `sizeM` 平铺，过滤照现在自由的图的规矩。
- 存盘、读盘、撤销、睡和醒、锁，和别的画一样走；`CATSUP_textures` 1.2，冻样本，旧版本真代码当读者（照门 6）：打得开、按底色显示、存回去这一行还在。
- 没有面的轮廓，小窗里就是一张图。

## 四、测试（照家族的 `ai-docs/20261112-test-tiers-and-release.md`）

- 第 1、3 刀碰撤销、存盘、文件格式：合之前把那一块点名的跑完；推完后台跑红线那一小组。红线那一小组里的 paint-undo、paint-save、mid-stroke-save 各加一段二维笔的，不另开新的红线探针。
- 探针按路覆盖：这一张新增的路 = 二维笔（笔、橡皮各一组）。
- 做完把这三刀里的细探针收成一两条综合的；碰了画画那条路，收尾跑一次性能档。
