# D11 τ 带 / µm 尖刺：问题陈述 + 候选修法实测（研究稿，等 user 当导师批）

> as-of v0.13.20 / 2026-10-24 · created 2026-10-24 by Claude Fable 5.1（user「我回家说设计。别的难的数学和算法还有什么你现在可以做的吗」→ 选了总账「难数学待做」里的 D12 → D11 这条线）
> 两段式：本稿 = stage 1（AI 撒开跑，数字都在），stage 2 = user 过目后拍默认值。**本稿没有改任何默认行为**：旋钮 `STICKY.r` 出厂 = Q（现状）。

## 1. 问题陈述（输入是什么、输出是什么）

- **内核的两把尺子不一致**：身份用格点 Q = 1 µm（`ptKey3`：两点落在不同格 = 两个顶点），共面用 τ = 1 mm（`coplanarTol`：1 mm 内都算同一张平面）。
- **输入**：一个新顶点 / 新线段落在既有顶点或既有边旁边 **1–2 µm**（格点身份说「不同」，几何上投影到平面后却分不开）。来源：沿既有边方向「画过头」（方向从量化坐标算出来，长度一放大就差 µm）、Pencil / VR 噪声、计算交点。nasty fuzz 的「过头 + ±2 µm 抖动」生成器就是在造它。
- **输出（现状）**：平面图里出现 1 µm 高的尖刺三角 / 擦着顶点过去的边 → `findRegions` 的嵌入自相矛盾 → 某张膜的身份像一个胞腔都认领不到 → 结算机守恒断言 **拒绝这一步**（v0.9.16 起；之前是静默 BURST 膜）。用户看到的是「这一步做不了」（报错胶囊），不是消失的墙。
- **期望**：这种输入根本不该产生新身份——1–2 µm 之隔的「两个东西」就是一个东西。

## 2. 分类实测（nasty fuzz 80 种子 × 12 步，v0.13.19 现状）

每个被拒绝的步，记拒绝前内核的三个量：最近两顶点距离 `minVert`、顶点到非邻接边的最近距离 `minVertSeg`、近平行（|n·n'| > 0.999）且 0 < Δd < τ 的平面对数。

| 指标 | 数 |
|---|---|
| 被守恒断言拒绝的种子 | **29 / 80** |
| 其中 `minVertSeg` ≤ 2.2 µm（顶点擦着边 1–2 µm） | **29 / 29** |
| 其中 `minVert` ≤ 2.2 µm（顶点对顶点尖刺） | 28 / 29 |
| 近平行膜对 < τ 的 | 1（且那一步的失败点也是 0.6 µm 的擦边，平行膜是别处的，红鲱鱼） |
| 按动词：line 过头 20 · pp 7 · rect 2 | |

**结论：全部 29 个 = 同一类——「顶点离非邻接的边 ≤ 2 µm」**。总账里原来的第二张脸「推拉把面推到离平行膜 < τ 但没重合」在这 80 个种子里没出现（10-22 序列 400 变体里那 2 个属于它，本稿没覆盖，见 §6）。

两个被单独 dump 的样本：
- 种子 62 步 2（`rect`，`minVert` 0.54 m 看着不像尖刺）：上一步从顶点 1 沿边 4 的方向画过头到 7 m 外（边 5），边 5 擦着顶点 4 过去 2.03 µm，没被 INSERT_TOL = 1 µm 切进来；再画一张矩形挂在边 5 远端 → `findRegions` 在顶点 1 处边 4 / 边 5 角序 ε 级 → 把「外面」那圈当成了区域、原来的四边形环丢了 → 膜 1 认领不到。
- 种子 47 步 9（`pp`）：失败膜 15 的点离一条边 0.61 µm；25 µm 的平行膜对在别处。

## 3. 候选修法 (a)：sticky 半径从 Q 放到 k·Q（身份层，不是结算层）

实现 = `src/kernel/subdivide.ts` 的 `STICKY = { r: Q }` 旋钮，`r > Q` 时：新段端点吸到 r 内最近的既有顶点；新段与既有边的交点落在某既有顶点 r 内 = 那个顶点；既有顶点离新段 ≤ r → 切进来；`moveVertices` 落点离不在手里的既有顶点 ≤ r → 落到它身上（走既有的同格点合并）。**r = Q 时与原逻辑等价**。

仪表 = nasty fuzz 拒绝数（越低越好）+ clean fuzz 必须全绿 + 全量快测（golden / settle-images / 差分 oracle）必须全绿。

| r | nasty 拒绝 | 其中顶点-边 ≤ 10 µm | clean fuzz | 全量 429 条 |
|---|---|---|---|---|
| 1 µm（现状） | **29** | 29 | 绿 | 绿 |
| 2 µm | 19 | 19 | 绿 | — |
| **3 µm** | **4** | 3 | 绿 | **绿** |
| 5 µm | 3 | 2 | 绿 | 绿 |
| 10 µm | 2 | 1 | 绿 | — |

- 3 µm 就吃掉 86%；再往上收益递减。全量快测在 3 / 5 µm 下 **一条 golden 都没变**（所有既有样本的坐标本来就在格点 / mm 上，3 µm 碰不到任何真实特征）。
- 3 µm 下剩的 4 个：① 种子 1 / 34 / 38 的「过头线」——擦边发生在**既有顶点对既有边**（不是本次插入造的，是上一步留下的 1–2 µm 擦边，等到后面某一步才炸）→ 插入时的 sticky 管不到，要么回溯修（插入时也把「端点离既有边 ≤ r」当成切到那条边上），要么认了；② 种子 3 的 `move`：落点离另一顶点 15 µm，超出 r，另一类（可能是细长条膜的代表点问题，没细查）。

## 4. 候选 (b)「推拉位移落格前按邻接一致量化」

没单独做：pp 的 7 个拒绝全部也是 ≤ 1 µm 擦边（帽的边擦着既有顶点），(a) 一起吃掉了（3 µm 下 pp 只剩 1 个）。

## 5. 候选 (c)「推拉高度通道把『离平行膜 < τ』当成吸附到它」

属于对齐引擎（编辑器层），不在本稿范围；本稿 80 种子里没有这一类样本。10-22 序列 400 变体里的 2 个（盒宽 4.645 / 4.646，推 4.6458）是它的样本，要做时拿那两个当靶。

## 6. 建议（user 拍）

1. **采纳 (a)，r = 3 µm**：把 `STICKY.r` 默认改 3·Q、去掉 `> Q` 的实验护栏，再把「端点离既有边 ≤ r → 切到边上」补齐（§3 剩余 ①）。语义 = 「身份分辨率是 3 µm，Q 只是存储格」；对用户零可见（最小可操作尺度 1 mm）。
2. 或 **不采纳**：删旋钮，D11 维持「拒绝这一步」的现状（报错不消失）。
3. 两者都不动的话旋钮留着也无害（默认 = 现状），但要在总账记退场条件：下次碰 D11 时二选一。

**本稿没碰的**：D12 的根（τ 带脏嵌入给膜配碰着外环的假「洞」= `findRegions` 洞归属在边界退化点上的判定）——v0.13.19 只在 `reconcileErase` 上加了占用护栏 + 外环代表点二次机会，假洞本身还会生成；(a) 采纳后这类脏嵌入会少很多，但不是零。
