## 2. planarize 契约（对抗式表述，user 2026-09-01）

「对抗攻击者瞎动你的顶点和膜注册表——但不许破坏更底层的引用完整性——然后你自愈。」

- **前置（攻击面）**：顶点坐标任意脏（交叉/骑点/重合/共线重叠/退化）；膜注册表 stale。
- **保底（不许碰）**：拓扑层引用完整性（边表/顶点表/膜环引用不悬空）。
- **后置**：平面性不变量全恢复（无边边交叉、无点骑边、无重合顶点、无共线重叠、无平行重边）；
  膜环经切割血缘重写为合法闭循环；事件叙事流照发。
- **确定性**：输出只依赖终态几何（arrangement 规范性），与调用顺序/历史无关。

**深模块提取**：planarize 是两动词共享的裁决机——
画笔 = 加线段 + planarize（**注入手势边集**→BIRTH 依据）；move = 改坐标 + planarize（注入空集→永不生膜）。
insertSegment 降格为单线段增量特例。血缘管道（父边→子边）同时喂膜环重写与手势身份传承。
**测试红利**：契约支持 fuzz 攻击测试（随机扰动→planarize→断言全不变量），golden 靶之外的第二道网。

## 3. 覆盖代数（user 逐条拍板）

- **1+1=1**（OR；不 mod 2、不看方向、不看次数）。「膜没有出身，填着就是填着。」
- 实机证词（user 2026-09-01）：2D 小矩形移进大矩形不挖洞；**3D 双立方拼合，共享面被分割但不挖洞**
  （截图证词，与此前 stuck-cube dedup 单膜结论互证）。
- 压扁膜 = 环覆盖空集 → 自然无膜（指示函数推论，非特例规则）；日志发 BURST 纯属叙事。
- 自交环（蝴蝶结）：planarize 先自切，交点成顶点；两瓣 |绕数|≥1 → 全填。伪问题已消解。
- id/事件 = 叙事层：一对一保 id（STRETCH）、一对多 DIVIDE、多对一 MERGE（dedup）带血缘。

## 5. golden 靶清单（实现前先红）

1. 验尸重现①：整移边跨静态边 → 直达终位、S 原样、无幽灵切点、无吞 move。
2. 验尸重现②：边移进膜内 → 膜边界原样、膜活、悬边落内。
3. 蝴蝶结：单顶点拖穿对边 → 自切成两瓣、两瓣全填（DIVIDE 叙事）。
4. 压扁：膜移成零面积 → 无膜 + BURST 叙事。
5. 重叠 dedup：填膜移压填膜 → A/O/B 三膜全填、O 单膜（MERGE 叙事）；与「静态叠画两矩形」终态逐胞腔等价。
6. 守恒律回归：move 闭合开折线不出面（既有 golden 保绿）。
7. 多选混移：线+面混选一批刚移，等价于顶点并集单 δ。
8. fuzz：随机扰动 N 轮 → planarize → 不变量全绿。
