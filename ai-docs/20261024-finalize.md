## 1. 一句话

☰「定稿…」= 给模型盖一个版本章：`rev` +1、记下**内容指纹**（几何 + 组 / 组件 / 参考几何 + 材质 + 绘图轴；视图 / 网格设置不算）、烤好的 .glb 本身就是发行那一份（封面 = 缩略图）；之后锁住一切改几何 / 材质的操作，只能看、量、导出；☰「改稿」解锁（rev 不减）。读文件时指纹对不上（旧版 app 或别的软件改过）= 定稿作废 + 说一声。

## 2. 四层护栏（瑞士奶酪，每层各自承重）

| 层 | 在哪 | 拦什么 |
|---|---|---|
| ① 界面 | `body.doc-final`：左柱 / 工具条 / 选区浮条灰掉（`pointer-events:none`），左上角标「定稿 N」，☰ 只剩「改稿」 | 手误 |
| ② 状态入口 | `Editor.commitOp / undo / redo / applyVcb`：`locked` → 拒 + 提示「定稿了：锁着，☰ 改稿才能改」 | 快捷键 / 手势 / 指令绕过界面 |
| ③ 格式 | `session.encode()`：`doc.final` 在 → 重算指纹，≠ 记录 → **抛**（不写） | ② 漏的任何写 |
| ④ store 接缝 | `session.save()` 抓到 ③ 的抛 → 这一轮不保存、脏留着、说一句 | ③ |

指纹 = `src/format/final.ts contentFingerprint(doc)`：sha256（WebCrypto）盖 definitions（规范序 brep + groups + instances + guides + materialSlots）+ materials（名字 / 颜色 / 贴图字节 sha256 + 尺寸）+ axes；**不含** settings / lastView / thumbnail。

## 3. 格式（CATSUP_document，不升版本，只加可选字段）

`final?: { at, rev, app, fingerprint }`、`finalRev?: number`（定稿过几次，改稿不减）。老 app 读到：未知键直通（读时带 `documentExtra`，写回原样）——老 app 改了内容但带着 `final` 存回去 → 新 app 读到指纹不对 → 作废 + 说一声。守卫：`test/final.test.ts`。

## 4. 这次按推荐稿定的

| 问题 | 定的 | 为什么 |
|---|---|---|
| 发行那一份是什么 | 文件本身（烤好的 glTF）+ 缩略图 | CatsUp 的"渲染"= 烤，一直在做；没有另一份 mp3 式产物 |
| 定稿锁着时还能做什么 | 看、量（卷尺 / 量角器出参考线算改吗——**算**，参考几何进指纹）、导出、改文件名 | 「都冻」同 MoonSinger；参考线以后若要放开再议 |
| 定稿 / 改稿进不进 undo | 不进 | 撤销定稿 = 偷偷作废 |
