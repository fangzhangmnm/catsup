# Ctrl / Shift 的意思：盘点 + 统一提案

> created 20261027 by Claude Opus 5.5 · as-of v0.15.19 / 2026-10-27 深夜 · 纪元账本 FM114（user「ctrl shift的语义全家理一下」）
> 范围：CatsUp 的全部工具和三个工作台（硬表面建模 / 表面 / 自由建模）+ 键盘快捷键。**只是提案，user 过目前不改行为**；新做的工具先按 §3 的两句话写。

## 1. 现状（按工具）

指针上的「Ctrl」= Ctrl、Alt、⌘ 任何一个（代码里合成一个 `copy` 旗，`app/gestures.ts`）。iPad 没有修饰键，最后一列是触屏上同一件事在哪。

| 工具 | 按住 Shift | 按住 Ctrl（/ Alt / ⌘） | iPad 上怎么做 |
|---|---|---|---|
| 所有画 / 挪的工具（硬表面） | 格点吸附反过来（开着 = 临时不吸、关着 = 临时吸；含整格长度、15° 档） | — | 右上角格点锁钮（锁住式） |
| 选择 | 点：切换；框：加选 | 减选 | 右下角「选区」选项 |
| 移动 / 变换 | （格点反转） | 复制 | 底部「复制」开关 |
| 旋转 | （格点反转 = 15° 档反过来） | 复制 | 「复制」开关 |
| 缩放 | （格点反转） | — | — |
| 推拉 | （格点反转 = 整数长度反过来） | 加边（不自愈，SU 推拉 + Ctrl） | 右下角「推拉：接着长 / 加边」 |
| 矩形 | （格点反转） | 临时从中心 | 现在 = 单独的「中心矩形」工具（v0.15.19） |
| 中心矩形 | （格点反转） | 临时从角 | 「矩形」工具 |
| 弧 | 提示里显示扫过的角度 | — | — |
| 橡皮 | 硬化 | 软化 + 平滑 | 软边橡皮工具 |
| 焊边橡皮 / 软边橡皮 | 动作反过来（焊 ↔ 拆、软 ↔ 硬） | — | 右下角「动作」选项 |
| 油漆桶（表面） | — | 临时吸色 | 吸色钮 |
| 自由建模：挪 | **开吸附**（点 > 边 > 面，v0.15.18） | — | **没有** |
| 自由建模：转 / 缩 | 15° / 0.1 一档 | — | **没有** |
| 自由建模：挤出 / 刀 | — | — | — |

键盘（和工具无关）：方向键 = 锁轴、Shift+方向键 = 锁面；Shift+Tab = 格点吸附开关；Shift+Z = 缩放到全部；Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z = 撤销 / 重做 / 重做；Ctrl+A 全选、Ctrl+I 反选、Alt+A 全不选；Ctrl+G 建组、Ctrl+Shift+G 炸开；Alt+H 全部显示、Alt+Z X 光。

## 2. 现在其实已经差不多是两条规律

- **Shift = 把这个工作台默认的对齐反过来。** 硬表面默认吸（格点 / 整格长度 / 15°），按住 Shift = 临时不吸；自由建模默认不吸，按住 Shift = 临时吸（挪：吸到点 / 边 / 面；转 / 缩：咬 15° / 0.1 档）。user 10-27「shift挪就是开吸附啊……就是控制吸附开关」和硬表面 DT51「按住 Shift = 格点吸附反过来」是同一句话的两面。
- **Ctrl = 这个工具的另一种做法。** 复制（移动 / 旋转 / 变换）、从中心（矩形）、加边（推拉）、软化（橡皮）、减选（选择）、吸色（油漆桶）。大多是 SketchUp 原样。

不合这两条的地方：
1. **选择的 Shift = 加选 / 切换**：全世界的约定，选择也没有「对齐」可反，不冲突，留着。
2. **橡皮的 Shift = 硬化、焊边 / 软边橡皮的 Shift = 动作反过来**：橡皮没有对齐，Shift 被拿去当「另一半动作」。SketchUp 的橡皮是 Ctrl = 软化、Ctrl+Shift = 取消软化、Shift = 隐藏。
3. **弧的 Shift = 显示角度**：小事。
4. **iPad 上自由建模的吸附 / 档没有按钮**：Shift 规则在触屏上缺一半。

## 3. 提案（两句话，写进 CatsUp 规矩；新工具照着写）

- **Shift = 反转对齐**（位置、角度、倍数）。没有对齐可反的工具（选择、橡皮）可以借来用，但要在提示行写出来。
- **Ctrl（指针上 Alt / ⌘ 同）= 这个工具的另一种做法**，提示行写出来；每一个 Ctrl / Shift 行为在 iPad 上都要有一个看得见的开关（锁住式，等于一直按着）。

## 4. 要 user 拍的（都有默认，不回就按默认）

1. **橡皮的 Shift 要不要改成 SketchUp 那样**（Shift = 隐藏、Ctrl+Shift = 硬化）？改了 = 和 SU 肌肉记忆一致、Shift 在橡皮上有了「藏」这个新用处；不改 = 你现在的手感不变。**默认：不改**。
2. **刀的 Ctrl = 溶解（去边、两张面并成一张）**？这是纪元账本 FM11「按住快捷键 = 橡皮」的落地。**默认：是**。
3. **Alt 要不要从 Ctrl 里分出来**（现在指针上三个键当一个）？分出来 = 多一档（比如 Alt = 吸色 / 选环）；代价 = Windows 上单按 Alt 会唤出浏览器菜单栏、Mac 上 ⌘ 和 Ctrl 要分开想。**默认：不分**。
4. **自由建模右下角加一个「吸附」开关**（锁住式，等于一直按着 Shift；iPad 上唯一的入口）？**默认：加**。
5. **「全家」的范围**：这份只盘了 CatsUp。要不要按同样两句话把 WeebPaint / MoonSinger / KudsRocket 也盘一遍？**默认：先 CatsUp，别的 app 碰到修饰键的时候再对一遍**（家族周账记一行）。
