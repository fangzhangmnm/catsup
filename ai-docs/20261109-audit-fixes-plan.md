## 3. 工单 2：强行对称真的对称（三个问题一个根）

### 定理（做完要成立）

强行对称开着时，任何一步提交之后，这个网格体关于镜像面严格对称：点、边（含没有面的裸线）、面、面的朝向、面的材质槽、边的标记，两边一一对应。中缝上的东西对应它自己。

唯一的例外是已有的那条：有面跨过镜像面又劈不开（凹面）时这一步不对称化，并且在提示行说出来。这条保持原样。

### 根因

现在是「做完以后看一眼结果，猜对不对称、猜动的是哪边」。看的那一眼（`isSymmetric`）漏了面缺失、朝向、材质、标记；猜哪边（`sideOfChange`）不算删掉的东西；对称化本身不镜裸线和孤点。

### 做法

全部落在 `src/mesh/mirror.ts`（纯函数）和一个薄的调用点上。

1. **对称化补全**（`symmetrize`）：
   - 留下的那边的裸线（没有面的边）和孤点也镜过去；
   - 镜过去的面，材质槽照抄（现在已经是）、朝向相反（现在已经是）；
   - 留下的那边边上的标记镜过去（现在只镜了面的边，补上裸线）。
2. **`isSymmetric` 改对**。它还被「开镜像时提示已经对称」和右上角橙色标记用着，自己得是对的：
   - 每张面换成对面的点之后，那个点序列必须真是一张面，绕向相反，材质槽相同；
   - 每条边（含裸线）的镜像是一条边，标记相同；
   - 孤点有对面。
3. **哪边为准，改成从指令读**。新函数 `forceSide(before, after, op, lastSide)`，提交和预演共用：
   - 第一优先：指令自己点名的东西（`faces` / `edges` / `verts` / `moves` 里的编号），在 `before` 里按它们在哪边投票（中缝上的不投）；
   - 第二：现在的 `sideOfChange`，但让**删掉的点和面也投票**（按删之前在哪边）；
   - 第三：`lastSide`；都没有 = +1（现状）。
4. **什么时候对称化，改成按指令的种类**（`mesh/mirror-ops.ts` 的分类表已经有）：
   - `topo`、`flags`、`move`：做完用修好的 `isSymmetric` 查；不对称就对称化。（查是为了不让另一半白白重建。）
   - `whole`：同上。
   - `meta`：不动。
   - 也就是调用点的形状不变，变的是 `isSymmetric` 说真话、`forceSide` 认得删除。**如果施工时发现修好的 `isSymmetric` 在大模型上每步太慢**（它是 O(模型)），量出数字写进 §8，交回 Fable 定要不要改成「topo / flags 一律对称化」。
5. `editor.ts` 的 `mirrorForceAfter` 和预演那段（第 3599 行附近）都改成调 `forceSide`。行数不许涨。

### 验收

- 新测试 `test/mirror-force-symmetric.test.ts`，里面写一个**独立的**对称检查（不调 `isSymmetric`；按坐标配对点，再比面的点集、绕向、材质、边和标记）。用它断言：
  - 报告 §4.1 表里四种只改一边的改动（挖里面的面、翻面、换材质槽、打标记），各自做完再走一遍「强行对称每步之后」的逻辑，结果对称；
  - 报告 §4.2：分别在左、右删角上一张面，`lastSide` 分别取左、右、没有，六种组合都是「两边都删了」；
  - 报告 §4.3：留下的那边有裸线 / 孤点，对称化之后对面也有；再对称化一次，报告是「删 0、加 0」（不再每步重建）。
  - `isSymmetric` 自己的真值表：上面每种不对称的情形都答「不对称」，对称的答「对称」。
- 随机测试：强行对称开着，从一个盒子起随机做 60 步（挪点、挤出、插入、倒角、环切、删面、删边、翻面、标记、细分），每步之后用独立检查断言。至少 8 个种子。放进同一个测试文件，总时长控制在几秒。
