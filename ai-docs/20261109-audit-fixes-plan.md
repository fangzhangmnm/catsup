## 3. 工单 2：强行对称（第 2 版）

### 先看最重的一条（11-09 真 app 里跑出来的）

强行对称开着，模型整个在镜像面的一边时，**一步小操作会把整个模型删到只剩一张面，没有提示**。复现：一个盒子转成网格体 → 开强行对称 → 选右边那张面 →「设置原点到选择中心」（模型现在整个在镜像面的负的一侧，镜像还开着）→ 把落在镜像面上的一个点往上挪一点 → 6 张面、8 个点变成 1 张面、4 个点。撤销能回来。

原因：这一步「看不出动的是哪边」时，代码默认以正的那一半为准（`|| 1`）；正的那一半是空的，于是「删掉另一半、把这一半镜过去」= 全删。打开强行对称那一下（`symmetrizeNow`）也是同一个默认：模型偏在负的一侧、又没选东西时打开，同样全删（这条是读码，那一下提示行会说「另一半删了 N 张面、镜过来 0 张面」）。

### 定理（做完要成立）

强行对称开着时，任何一步提交之后，这个网格体关于镜像面对称：
- 点、边（含没有面的裸线）、面一一对应；
- 对应的面朝向相反、材质槽相同；对应的边标记相同；
- **整张躺在镜像面上的面对应它自己**（朝向不反）；两头都在镜像面上的边、镜像面上的点同理；跨过镜像面的边 / 面，镜过去是它自己（面的点序倒过来和自己是同一圈）；
- 「隐藏」不算在对称里（那是看法，不是形状）。

两个例外，都必须在提示行说出来：
- 有面跨过镜像面又劈不开（凹面）：这一步不对称化（现状，保留）。
- user 在第 2 层的询问里选了「取消」：这一步没做。

另有一条比定理更硬的：**强行对称自己绝不把模型删空**（第 0 层）。

### 六层（每层写明挡什么）

**第 0 层：不许把空的那一边当准。** `mesh/mirror.ts` 加纯函数 `pickSide(m, axis, wanted)`：`wanted` 那一边没有任何面也没有裸线（东西全在另一边和镜像面上）→ 换另一边；两边都没有 → 返回「不用做」。`symmetrizeNow`、每步之后、预演三处选边都必须过它。挡：上面那条全删。

**第 1 层：会让整个模型对镜像面挪位的操作，先看结果再决定。** 换原点（`setAxes` 落在定义根上、`mesh.originToSelection`）、应用缩放（`applyScale`）作用在开着强行对称的网格体上时：在副本上先做一遍，结果仍然对称 → 照做；不对称 → 用已有的那张询问（`mirrorBlocks` 那一套）问「关掉镜像，照做 / 取消」。镜像编辑模式不问（那个模式下挪原点正是推荐做法，提示行自己就这么教）。挡：镜像面被悄悄挪走、下一步模型被切成两半重建。

**第 2 层：管不管，看「改没改到这个网格体」，不看指令的名字。** 现在的判断是「指令名以 mesh 开头」。粘贴、合并物件、炸开、分离也会改网格体，但不叫这个名字，所以不对称化；之后在另一边随便做一步，它们就被当成「另一半」删掉。11-09 真 app 里跑出来的：左边贴进一张面，再在右边挪一个点，贴的那张没了。改成：指令的目标定义是开着强行对称的网格体，并且做完以后这个网格内核的版本号变了 → 走每步之后的检查。`mirror-ops.ts` 的分类表补上这几条不叫 mesh 的指令（`paste`、`mergeObject`、`explode`、`separateObject`；`setHidden` / `unhideAll` 归「不对称化」）；守卫 `test/mirror-ops.test.ts` 的登记范围从「名字以 mesh 开头」改成「`applyOp` 里碰到网格内核的每一条」。

**第 3 层：删除、翻面、标记，把对面的一起做，不猜哪边。** 这三种是「点了谁就对谁做」的操作。强行对称下，提交前把指令里点名的点 / 边 / 面各自的镜像加进去（模型此刻是对称的，镜像都找得到）。做完自然对称，另一半不用重建，编号不乱。
  - 标记已经有这段改写（`mirrorRewrite` 里），只是被 `if (ms.mode !== "edit") return` 挡在强行对称之外，去掉这个限制。
  - 删除（`meshDelete`）和翻面（`meshFlip`）照样加。找镜像的函数放 `mesh/mirror.ts`：点用 `mirrorPairs`，边 = 两头的镜像之间那条边，面 = 点集是镜像点集的那张面。
  - 为什么不用「哪边为准」：左边删 A、右边删另一张 B 时，按一边为准会把其中一张镜回来。这是 Fable 定的边界规则，不是 user 原话；user 的原话「动了哪边哪边为准」留给会长出新东西的操作（第 5 层）。

**第 4 层：`isSymmetric` 说真话。** 它是「要不要对称化」的守门人，也被「开镜像时提示已经对称」和右上角橙色标记用着。改成照上面定理的条文逐条查（面的存在、朝向、材质；边含裸线的存在和标记；孤点；镜像面上的东西对应自己）。不查隐藏。

**第 5 层：对称化本身补全，选边改好。**
  - `symmetrize`：留下的那边的裸线、孤点也镜过去；镜过去的面连「隐藏」标志一起抄（不然另一半每次重建都会重新露出来）。T45 在这里结掉。
  - 选边（挤出、插入、倒角、环切、切割、粘贴这类会长出新东西的）：新函数 `forceSide(before, after, op, lastSide)`，提交和预演共用。优先级：指令点名的东西在 `before` 里在哪边 → 新长出来的和**删掉的**点 / 面在哪边（现在的 `sideOfChange` 不算删掉的，补上）→ 上一次的边 → 都没有。最后一律过第 0 层的 `pickSide`。
  - 走到「上一次的边」或更后面才定下来的，提示行说一句「强行对称：这一步看不出动的是哪边，按 X 那半为准」。

## 4. 工单 3：自由建模吸附不吸跟着动的点

### 不变量

4. 硬表面旋转第三步吸到自己原来的角点：**不改**（转回 0° 会咬住是好事）。在吸附模型文档里记一句。
