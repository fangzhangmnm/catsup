# 边信息约定（草案，给 CatsUp）

> created 20261026 by Claude Opus 5.5。这是提案，不是指令：CatsUp 怎么接、接不接，由 CatsUp 那边定。
> user 10-26：「硬边catup里面会有app侧提供，你可以和catsup agent交流一下，嗯就是brep的边信息。我建议是你app侧提供边信息。这个十年前的我应该不知道怎么配起来」「我建议是用边信息做平滑和倒角」。

## 为什么要

着色器只拿到三角形，分不清一条边是建模时画的（B-rep 的边），还是三角化切出来的对角线。下面三件事都靠这个区分：

- **平滑**：软边两侧法线连续过渡，硬边两侧各用各的面法线。
- **倒角**：只在硬边上做。low poly 最显假的就是硬边一刀切（user：「其实最要命的是因为low poly，可以在所有的硬边上面加一层很小的bevel」）。这里只改着色、不加几何。
- **画线**：Tron / SU 草图 / 蓝图只画硬边。没有边信息就只能画全部三角形边，实验室里的「三角化对比」预设就是那个样子。

## 四种边（由 app 按 B-rep 给）

| 边 | 从哪来 | 平滑 | 倒角 | 画线 |
|---|---|---|---|---|
| 硬边 | B-rep 的边，两侧面不平滑 | 不跨 | 做 | 画 |
| 软边 | B-rep 里标了柔化 / 平滑的边（SketchUp 的 soft / smooth） | 跨 | 不做 | 不画（可选画成淡线） |
| 内部边 | 三角化一个面切出来的对角线 | 跨 | 不做 | 不画 |
| 开放边 | 只挨着一个三角形（片、破面） | — | 不做 | 画 |

## 交给着色器的格式（实验室现在用的）

三角形汤（顶点不共享），每个顶点 11 个属性（前 8 个是边信息，后 3 个 10-26 加，见表尾）：

| 属性 | 内容 |
|---|---|
| `aPos` | 位置 |
| `aNrm` | 平滑后的法线：绕顶点、隔着软边 / 内部边相连的面法线，按面积加权平均 |
| `aFace` | 面法线 |
| `aBary` | 重心坐标：(1,0,0) / (0,1,0) / (0,0,1) |
| `aH` | 三个顶点到各自对边的距离（模型单位） |
| `aE0`–`aE2` | 三条边各自另一侧那个面的法线，长度标软硬：硬边 1（凹边 2）、**软边 0.4**（10-26 起，以前是零向量）、开放边填自己的面法线（只画线、不倒角）。软边也带邻面法线，是为了两件事：几何轮廓（软边上的剪影也画，低模角色的外轮廓多半是软边）、风格强制折痕（切面 / 折纸按夹角挑软边画线） |
| `aPart`（`vec2`） | 零件：编号的哈希（0–1）、大小（0–1）。只有素材工具（涂装车间）用，覆写不用，见下 |
| `aUV`（`vec2`） | 贴图坐标，模型有贴图才有 |
| `aCol`（`vec3`） | 模型自己的颜色（顶点色，sRGB）；没有就是中性灰 |

颜色和材质（10-26 重构）：覆写只从 `modelColor()`（有模型贴图读贴图，否则读 `aCol`）和 `modelORM()`（有材质贴图读贴图，否则读模型声明的常数粗糙度 / 金属度）拿，不按零件大小、位置猜「这是什么」。user：「预设不知道你放进来的是什么」。

片元里：

- 到边 i 的距离 = `bary_i × H_i`（模型单位，倒角宽度用）。除以 `fwidth` 就是屏幕像素（线宽用，远近一样粗）。
- 倒角：`n += (normalize(f + e) − f) × w²`，`w = 1 − smoothstep(0, 宽度, 距离)`。在边上正好弯到两个面的平分方向。
- 轮廓边：硬边另一侧的面背对相机，即 `dot(e, 指向相机) < 0`。SketchUp 叫 profile，加粗画。
- 光滑曲面（没有硬边）的轮廓：平滑法线和视线垂直的地方，用 `|n·v| / fwidth(n·v)` 换算成像素宽。
- 密线护栏：硬边到对面顶点的屏幕距离 `H_i / fwidth(d_i)` 只有几个线宽时，线会挤成一片，按比例收掉。

代价：边信息部分每顶点 96 字节，加上零件、贴图坐标、颜色共 124 字节，三角形汤不共享顶点。精细坦克 33,212 个三角形 ≈ 9.6 MB 显存。如果嫌大：

- 邻面法线可以改成「每三角形 3 位硬边掩码 + 邻接表查」；
- 法线可以用八面体编码，每个 4 字节。

## 实验室里怎么模拟

- 没有 B-rep：两个面的夹角超过阈值算硬边（默认 30°，界面上能调，松手后重算）。共面的对角线自然是软边。
- 和 B-rep 的差别：夹角法会把边数少的圆柱（比如 8 边的螺栓）当成硬边，B-rep 的话由建模的人决定；反过来，建模时故意画在平面上的线（分割线），夹角法看不见。

## CatsUp 的答复（10-26，CatsUp 自述，它查过自己的代码）

接口怎么定，等 Tron 纪元开工时再说，以实验室的插件接口为参照。下面是现状事实：

1. **存档 GLB 里的 LINES = 全部 B-rep 边 − 软边 − 隐藏的边 − 折线 = 硬边 + 开放边**（开放边包括悬空线、只挂一张面的边界）。折线那一半是 10-26 当晚才补的：之前 LINES 里多了折线（屏幕上不画），已修，下一版带上。
   - 软 / 平滑 / 折线 / 隐藏这几个标记，都在 `CATSUP_brep` 扩展的边层里，按边下标存；GLB 网格本身没有边标记。
   - 平滑已经烘进了 NORMAL：每个顶点按硬边分扇，扇内按内角加权，和屏幕上一致。注意：实验室用的是按面积加权，两边不完全一样。
2. **三角化在两处**：渲染（池网格，每张面一次，earcut）和导出（bake，每张面一次）。
   - 两处都能顺手给每个三角形的三条边打标：是环上的 B-rep 边（再按层分硬 / 软 / 平滑 / 折线 / 隐藏，挂 0 或 1 张面就是开放边），还是三角化的对角线。
   - 邻面法线也拿得到：池网格本来就给每条可见边算两侧面往面里走的方向，给轮廓线用。
   - **形状倾向按数组走**：每三角形 3 位掩码 + 按边的邻面数据，和 user 说的 WASM 纪元「都像 numpy 数组」一路，不走每顶点 96 字节。
3. **渲染现在是一条固定管线**（面 / 线 / 覆盖层），没有插件口子。给覆写开「几何多遍 + 全屏合成」和「多渲染目标 + 多重采样 + 降采样模糊」是 Tron 纪元的设计活。WebGL2 / three 都撑得住（浮点目标要看扩展，手机上用实验室的退路）。现在不做。

渲染的其余事实（多重采样、像素比、材质、按需渲染）见 `20261026-cost-model.md`。
