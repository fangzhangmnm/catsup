## 3. 交给 CatsUp 拍的（实验室不替它定）

1. **要不要做颜色映射**（往调色板推、饱和度、粉彩化这些对模型颜色的加工）。实验室里扁平化有，材质 / 写实没有。
   **分色（给零件上颜色）是 CatsUp 的事**（user 10-26「分色是catsup管的」）：覆写只借模型给的颜色；实验室第 7 版那种按零件大小自动分四色的做法已经撤掉。
2. **和 Workbench 的描边怎么不打架**：实验室的覆写自己画线（Tron、风之杖的解析描边、扁平化的像素描边）。CatsUp 的 Workbench 模式本来就有描边，两层线叠起来怎么取舍。
3. **性能取舍**：每个覆写在 Quest / PC / iPad 上的代价估算在页面「代价」栏（`ai-docs/20261026-cost-model.md`）；乞丐版是每个覆写自己的便宜近似；自适应降级（按实测帧时间逐级降）还没做。哪些设备默认开哪档，CatsUp 定。
4. **真倒角在哪一层做**：实验室只改法线（轮廓还是直边）。轮廓真要圆，得在 B-rep 出网格时做圆角（WebGL2 没有几何着色器）。要不要做、做多宽，CatsUp 定。
5. **边信息约定改了一处（10-26 晚）**：软边也存邻面法线（长度 0.4），不再是零向量——几何轮廓（低模角色的剪影多半在软边上）和风格强制折痕（切面 / 折纸）都靠它。CatsUp 的 B-rep 边如果只给软硬标记、不给邻面法线，这两样就做不了。
6. **顶点格式要不要跟**：实验室现在每顶点 12 个属性（见 §4），比边信息约定草案多了零件、贴图坐标、顶点色、倒角封顶。哪些进 CatsUp 的格式、怎么压，CatsUp 定。
7. **给内容挑默认覆写**：`ai-docs/20261026-content-vs-override.md` 是 user 的结论（精细硬表面 → 光固化 / 补土；直面结构 → 剪纸；圆润 → 半透 / 透明；像素坦克 → 低分辨率 / Tron）。覆写本身不知道内容，挑默认值那一步在 app 或用户手里。
9. **愿望单（user 10-26）**：「其他的风格化看看能不能接住catsup的轮廓边 硬边 软边，点 和边点面的高亮」——每种风格化覆写都要能画 CatsUp 编辑时的轮廓边、硬边、软边、点，以及点 / 边 / 面的选中高亮。需要 CatsUp 的选择数据怎么给（每顶点 / 每面的选中位、悬停位），等 CatsUp 定格式再接。
10. **起伏（relief）的约定（10-26 夜）**：覆写不从颜色推刻线，只读模型带的一张独立高度图（0.5 = 原表面 + 一个「0 → 1 对应多高」）。CatsUp 的资产要不要带、怎么带（贴图？顶点？），CatsUp 定。
11. **资产的颜色贴图里有没有画光**：pixel perfect 的手绘贴图（光和影画进去了，小红帽、熊、像素坦克）和 PBR 的底色是两种东西；有光照的覆写借前者会把画好的明暗再打一遍。实验室不替它路由（user「我们这里覆盖不管你的材质」），只记下这件事；要不要在资产上标一下、覆写怎么对待，CatsUp 定。

## 7. 几何画板纪元（记账，added by Claude Opus 5.5 2026-10-28；给 CatsUp 以后的纪元，不是实验室的事）

- 起因：Shader 实验室做珠宝做了一天，user 出了一道题：「catsup里面怎么画那关最经典的钻石的形状 / 如果是你的话肯定mcp里面rant根号了，但是如果是人类呢，这是不是一个把球规逼出来的时候？」
- user 看完 AI 的回答：「没太看懂。但是除了球需要平面而不是只是靠axes。然后布尔切。记到以后的catsup的几何画板纪元，记账」。所以要的工具是三样：**球**（在方向球面上选一个方向）、**平面**（不只是靠坐标轴，任意摆的平面）、**布尔切**（拿平面把东西切掉一块）。
- AI 当时的回答，说白了是这样（〔AI 的读法，user 没拍〕）：
  - 标准圆钻 57 个面（加底尖 58）：冠部台面 1、星刻面 8、风筝面 8、上腰面 16；亭部主面 8、下腰面 16；8 重镜像对称。Tolkowsky 1919 的比例：台面约 53%、冠角约 34.5°、亭角约 40.75°。
  - 难点：SketchUp 式「先放点和线、围合成面」画不了。风筝面 4 个顶点必须正好在一个平面上，人手放的点几乎不可能共面，面会裂成两个三角形。钻石是先有平面，三个平面相交的地方才是顶点。
  - 真实世界的做法是宝石切磨机：一个角度 + 一个分度（分度盘常见 96 齿，8 重对称 = 每 12 齿一个面）定一个面的方向，往下磨到碰到已有面的交点为止（行话 meetpoint）。宝石设计软件（GemCAD）里一颗钻石就是一张（角度，分度）的清单，不用开根号。
  - 所以「球规」= 在方向球面上选方向（吸附到对称的分度）+ 推一个平面进去、碰到某个顶点停下 + 切掉外面那块；形体 = 这些半空间的交集。和 CatsUp 0.16 账本 UX36（尺规做成几何画板 / GeoGebra 式求解器）是一路。

## 8. 炫光遮罩约定（第 51 版，user 拍过：「嗯和我想的一样，做」）

- 炫光（辉光 + 星芒）和曝光、色调映射一起算相机这层，是视口的一个开关；谁发光由亮部门槛定（按线性光、大于 1）。
- 画进浮点图时 alpha 当遮罩：1 = 按场景算光的材质（写实、金属、玻璃、天）；0 = 按屏幕调色的（二次元、shadeless、平涂）——原样上屏，不进炫光；负数 = 按屏幕调色但点名发光（发光的眼睛、魔法），按 −alpha 的强度进炫光、不看门槛。
- 对 CatsUp 的意思：一个场景里二次元角色和写实场景混着放时，角色的材质写 0，不会被曝光和炫光弄脏；自发光是材质上的一个语义（哪块、多亮），不是靠颜色多亮猜出来的。

## 9. 像素模式强制最近邻（第 61 版，user 10-28「像素模式贴图应该强制覆盖nearest，然后这个覆盖行为catsup tron纪元文件你也更新一下」）

- 过滤本来是资产的事：小红帽、熊、可莉这些贴图按普通资产，线性 + mip。
- **像素模式一律盖成最近邻**：预设开了 `texNearest`（像素分类的都开），或者外壳在像素化 / 固定低分辨率档下画（`f.pixelArt`）。用采样器对象盖，不改资产自己的贴图状态。
- **缩小也最近邻**：像素模式是低分辨率渲染，贴图几乎都在缩小，只把放大设成最近邻照样糊。缩小用 `NEAREST_MIPMAP_NEAREST`——按 mip 选到大约一个低分辨率像素对一个纹素的那一级再取最近的，放大上屏就是一格一格；有 mip 兜着，转动时不高频闪。
- **复古平台自己管过滤**（插件声明 `ownTexFilter`）：每台主机的过滤是它的硬件特征（N64 三点双线性、PS1 最近邻……），外壳不盖。
- 对 CatsUp 的意思：「强制最近邻」是视口（风格 / 屏幕）这层的覆盖，不写进资产；资产只声明自己正常情况下怎么过滤。

## 10. user 的模型进实验室时定下的几条（第 58–61 版）

- **载入时细分只照作者的级数**（user「不要额外改我的细分，细分一变很多东西会胖或者瘦，就不对了」）：GLB 节点 `extras.subdiv` = Blender 里设的级数，传笼子、载入时 Catmull-Clark。CatsUp 的细分笼子标记（FM131）同一个意思：级数是模型的，视口不改。
- **阵列载入时铺开**（user「array之类的你也可以抠一下让程序接一下」）：`extras.array = [[个数, dx, dy, dz], …]`（节点局部坐标，一层层），只存一份。
- **贴图适当高压的 JPG**（user「贴图尽量用适当高压的jpg」）：没 alpha 的手绘 / 烘焙图 JPG q65；像素贴图、起伏深度图留 PNG。位置 16 位、法线 8 位（`KHR_mesh_quantization`）。
- **室内场景**：相机进屋（离房间中心 0.25，场景可以自带默认视角）；不打光的风格（线稿、平涂、像素、老主机）都接得住，打光的（写实、手办、玉石）屋顶挡了太阳，要室内灯光，还没做。
- **透明裁切是模型的语义**（第 63 版，user「alpha cutout没接住」）：叶子、花、栅栏带一张遮罩，视口所有画模型的着色器先按遮罩丢像素，阴影 / 遮蔽深度图也丢（不然投方块影子）。
- **「锁平滑」是模型的语义**（第 63 版，user「钻石之类的脸能不能强制覆盖成平滑」→「只有脸平滑，其他部件还是正常的」）：模型标出哪几块不许切刻面（角色的脸），风格的「刻面感」在这些面上当 0。和细分笼子标记一样，是模型说的，不是视口全局开关（全局开关试过，user 否了）。
