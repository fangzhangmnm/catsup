## 二、逐条：现状、原因、方案

### 1. 每个工具记住锁的轴

- **现状**（`editor.ts`）：锁轴和锁面是编辑器上的两个量；手势一落定就清掉（代码里写着「SU 同款」），换工具、按 Esc 也清掉。
- **我对这句话的读法**：每个工具各自记住上一次锁的是哪根轴，下次再用这个工具时自动带上。比如缩放一直锁着 X，移动一直不锁。
- **方案**：
  - 锁的记忆按工具存，手势落定不清；换回这个工具时恢复。只记在这次打开期间，不进文件。
  - 锁着的时候要一直看得见（工具条上那根轴亮着），点一下就解。不然记住的锁会变成看不见的规矩。
  - 键盘上再按一次同一个轴键 = 解，和现在一样。
- **另一种读法**（如果你是这个意思，告诉我）：「别忘了每个工具都要支持锁轴」。我顺手查了：现在吃锁的有画线、弧、圆规、矩形、量角器、卷尺、移动、旋转、挤出、网格的挪转缩；**不吃锁的有刀、内插、偏移、推拉、硬表面的缩放、跟随、新建**。

### 2. 沿一根轴缩到零

- **现状**（`mesh-transform.ts`）：缩放手势中可以打数，沿锁住的轴缩到 0 就是压平；这条路只有键盘能走。
- **它是干什么的**：把选中的一圈点压到同一个平面上。建角色时最常见的两种：把一圈歪了的点压平；把中缝上的点压到镜像面上。
- **方案（两个入口都做，算法是同一段）**：
  - **专门的动作「压平」**：选中点之后，右键菜单和工具条上各一个入口。点开选沿哪个方向（X / Y / Z / 这圈点自己的平均朝向），再选压到哪（这圈点的平均位置 / 镜像面 / 最后选中的那个点）。一步撤销。这是 iPad 上的主入口，不用进手势、不用键盘。
  - **缩放时的快捷值**：缩放手势中锁了轴，数值小窗上出一排常用值：0、½、2、−1。点 0 就是压平。键盘用户照旧敲。
- 「压到镜像面」单独列出来，是因为它压到的不是平均位置，而是正好等于零的那个面；中缝合不上多半就是差这一下。

### 3. 刀：先悬停、先滑动，再定第一个点

- **现状**（`mesh-knife.ts`、`editor.ts` 的按下和松手那两段）：
  - 悬停时只在落点处画一个小标记，不亮边。鼠标和支持悬停的笔才有悬停；手指和不支持悬停的笔什么都看不到。
  - **按下的那一瞬间，第一个点就定在按下的位置。** 没按在点或边上，这一下就作废，只给一行提示。之后拖动是在找第二个点。
  - 所以在 iPad 上，第一刀要求你的笔尖或手指一落下就正好压在一条边上，而且你事先看不到会吸到哪。
- **硬表面那边怎么样**：画线的第一个点也是按下就定，但它落在哪都行（落空了就落在地面上），而且悬停时有完整的吸附预告（端点、中点、边上）。所以同样的手势，在画线上不难受，在刀上就难受。
- **方案**：
  - **第一个点改成「按下、滑动、松手才定」**：按下以后落点标记跟着笔走，沿着边滑；松手的位置才是第一个点。按下时没在点或边上也没关系，滑上去就行。
  - 第一个点定了之后照旧：再按下滑动、松手 = 切一刀，接着切。
  - 鼠标点一下 = 原地按下松手，行为和现在一样。
  - **悬停预告补到和硬表面一个水平**：端点、中点、边上三种标记；边上的点沿边滑。中点现在没有，加上。
- **我对「slide first before the first cut commit」的读法就是上面这样。** 如果你说的是环切（先选一圈、沿边滑到想要的位置、再落定，像 Blender 的 Ctrl+R），那是另一件，下面第 4 条里的 4-2 正好要动环切，可以一起做，告诉我。
- **其他工具对不对得上**（只读了代码，没在真 app 里逐个试）：

| 工具 | 要不要指一个精确的位置 | 悬停有预告吗 | 第一下能不能先滑再定 |
|---|---|---|---|
| 刀 | 要（点或边上的点） | 只有小标记 | 不能 |
| 内插 | 不要（作用在选中的面上） | 没有 | 不涉及 |
| 挤出、沿法线 | 不要（相对拖动） | 有 | 不涉及 |
| 网格的挪 / 转 / 缩 | 不要（相对拖动；按住 Shift 才吸） | 有（把手） | 不涉及 |
| 新建（方块、圆柱……） | 要（放在哪） | 没有 | 按下就定 |
| 网格的橡皮、软橡皮 | 要（擦哪条边） | 没有 | 按下就开始擦 |
| 硬表面：画线、矩形、圆、弧、卷尺、量角器 | 要 | 有，完整的吸附预告 | 按下就定，但落空也成立 |
| 硬表面：推拉、偏移 | 要（哪张面） | 没有 | 按下就定 |

  - 规律：**要你指一个精确位置、而且落空就作废的工具，才需要「先滑再定」。** 按这个标准，要改的是刀；新建和橡皮值得跟着看一眼；别的不用动。
  - 你 10-27 定过「自由建模模式不要悬浮高亮」。这次加的是落点的预告（一个标记），不是把整条边或整张面点亮，两者不冲突。

### 4. 刀在落定前画面不对

读代码查到四处，前两处我比较确定就是你看到的，后两处要在真 app 里看一眼：

- **4-1 落点会沿着边偏。** 光标在边上的位置，现在是在屏幕上按比例算的，再拿这个比例到空间里那条边上取点。有透视的时候，屏幕上的一半不是空间里的一半，所以标记和切出来的点不在光标正下方，边越斜、越朝里伸，偏得越多。改法：用光标的射线和这条边在空间里求最近点。这条和画贴图那边「点到哪就是哪」是同一个要求。
- **4-2 第一下点在边上，立刻预演出一整圈环切。** 规则是「同一条边点两下 = 环切」。第一下点完，光标还停在这条边上，程序就认为你在指同一条边，于是把一整圈切开的样子画出来。看起来像是点了一下整个模型被切了一圈；这时手一抖再碰一下，环切就真的落定了。改法：环切只走它自己的入口（工具条的环切钮、Ctrl+R），或者至少要求光标离开过这条边再回来才算「点第二下」。倾向前一种，简单、不会误触。
- **4-3 预演一会儿有一会儿没有。** 光标在面的中间时没有落点，预演消失，模型变回没切的样子；滑到边上又出现。整个网格每次都重画一遍，可能会闪。要在真 app 里看闪不闪。
- **4-4 光标没落在点或边上时，刀线画到一个悬空的点。** 这个点在「过第一个落点、正对相机」的平面上，不在模型表面上。屏幕上看是一条直线，问题不大；但转过视角再看会觉得线飘着。要看一眼再决定管不管。

另外两条现状，不算毛病，列出来让你知道：刀不能停在面的中间（只能点到点、点到边）；两个点不在同一张面上时切不了，要先切到中间那条边上。

**5. 刀后面的手感和画线对齐**

- 画线现在是：每个点都是按下、拖、松手落定，或者点一下；连着画；同一处再点一下 = 收笔；Esc = 收笔。
- 刀对齐成：第一个点和后面每个点都是「按下、滑动、松手才定」；同一处再点一下 = 收刀（环切不再占用这个手势）；Esc = 收刀。

**6. 画完要有逃生口**

- 现状：收刀靠 Esc；见过笔的设备上手指轻点一下也是取消。左下角有一排键名芯片，里面有「取消」。iPad 上这一排在刀进行中出不出、出了看不看得懂，要在侦察里确认。
- 方案：多步的工具在进行中，屏幕上固定有一个看得见的「收」的钮，文字跟着工具走（刀 =「收刀」，画线 =「收笔」）。位置第一版放在现有那排芯片里，侦察之后看要不要挪。所有多步工具用同一个位置。

**7. 锁轴要能在落笔之前先选，入口整理到右上角**

- 现状：锁轴的入口有三个，都不顺手。键盘方向键；右上角吸附钮长按出来的菜单里；左下角芯片。移动工具的把手也能锁，但那是按在把手上才锁这一下。
- 你要的两件事：落笔之前先选好（落笔之后再去按钮很反人类）；按哪个面移动经常要换，换起来要快，不然就得不停转视角。
- **第一版方案**：
  - 右上角视图方块下面那一列里，吸附钮旁边，加一块锁的区域，直接摆出来不用长按：一排三个「沿 X / 沿 Y / 沿 Z」，一排三个「面 YZ / 面 XZ / 面 XY」。带文字，颜色和坐标轴一致。
  - 点一下 = 锁上，再点一下同一个 = 解开。当前锁着的那个一直亮着。
  - 没在做手势时也能点，点了就预备着，下一笔直接按这个锁走。锁着时模型上照现在的做法画出那根轴线或那个面，落笔前就看得见会沿哪走。
  - 每个工具记住自己的（第 1 条），所以移动一直停在你上次选的那个面上，缩放停在上次那根轴上。
  - 只在当前工具吃锁的时候出现；只吃面锁的工具（矩形、圆、弧、旋转）只出第二排。
  - 吸附钮长按菜单里那一段锁的选项去掉，免得两处。
- 这是第一版，占的地方、要不要能收起来、六个钮够不够顺手，等你用了再磨。

**8. 切割做完之后的小窗要有确定键**（user 11-10 深夜：「切割的马后炮应该有commit键」）

- 「马后炮」是三维软件里已有的东西：刚做完一步，右下角的参数小窗还能改这一步的数，改了就撤掉重做。内插、倒角、细分都有；刀和环切现在没有。
- 方案：刀切一刀、环切做完，都进这个小窗。环切能改位置（沿着边滑）和圈数；刀切能改落在边上的那个点的位置。小窗上有一个「确定」键，点了这一步就定了、小窗收起。
- 这同时回答了环切「先滑到位置再定」：切完在小窗里滑，滑好了点确定。

**第二节第 4 条的四处**

- **4-1 落点沿边偏**（截图 `A1-hover-edge.png`、`B-persp-marker-vs-cursor-at-half.png`；紫色十字是我画上去的光标位置，红点是 app 的落点标记）
  - 默认视角、立方体占屏幕三分之一左右：悬停在一条边的正中，标记离光标 8 个屏幕像素。
  - 强透视：沿 Y 方向 4 m 长、截面 1 m × 1 m 的长条，一条往里伸的长边，近端离相机 1.4 m、远端 5.0 m。光标放在这条边屏幕投影的 15% / 30% / 50% / 70% / 85% 五处，标记离光标 124 / 160 / 148 / 101 / 54 像素；落在边上的点和光标正下方的真实位置差 0.41 / 0.77 / 1.12 / 1.21 / 0.94 m（边长 4 m）。标记总是偏向远端。
  - 同一个视角换正交相机：五处都是 0 像素、0 mm。
  - 顺带看到（只报事实）：相机里已经有一段「屏幕上的比例 → 透视下空间里的比例」的现成算法（`src/editor/camera.ts` 约 142 行，注释「1/z 在屏上线性」），刀算边上的点时没用它。
- **4-2 第一下点在边上，立刻预演整圈环切**（`A2-first-tap-on-edge-cursor-still.png`）
  - 鼠标点一下竖边，光标不动：模型上马上画出一整圈水平的环切线，预演里的面 6 → 10，提示行「环切（松手 / 点下去 = 切）」。
  - 0.12 秒后在旁边 2 像素处再点一下：环切真的落定了（面 6 → 10，记一步撤销），刀跟着收了。
- **4-3 预演一会儿有一会儿没有**（`A3-cursor-in-face-middle.png`、`A4-cursor-on-another-edge.png`）
  - 光标在同一张面的上边和面中间来回挪六次：在边上有预演（7 张面），在面中间没有，模型变回没切的样子，每挪一次换一次。每次重画量到 0.4–1.2 ms（软件渲染），不卡。无头浏览器看不出肉眼的「闪」，只能说画面每次都在「切开 / 没切」之间跳。
  - 光标在面中间时，提示行停在上一句（「环切（松手…）」或「切一刀」），不跟着清掉。
  - 光标在面中间时，起点到光标之间照样画一条灰色刀线，没有落点标记。
- **4-4 刀线画到悬空的点**（`A5a-cursor-off-model.png`、`A5b-same-gesture-after-orbit.png`）
  - 光标挪到模型外面：灰色刀线从起点画到「过起点、正对相机」那个平面上的点，这次落在盒子外面的 (1.33, 1.12, 1.07)。
  - 刀没收、转视角之后：线还连着那个空中的点，从盒子表面伸出去、伸进空的地方，看起来是飘着的。

**① 用笔走刀（iPad，笔没有悬停）**（`C2-pen-knife-started-full.png`、`C3-pen-after-one-cut-full.png`）

- 刀闲着：左下角那排芯片不出。
- 笔按在面中间：刀不开始，提示行「切割：在点或边上按下开始切；同一条边点两下 = 环切」。按着滑到边上再抬笔，也还是没开始（W-3 要改的就是这个）。
- 笔点在边上：刀开始了。芯片只出一枚「取消」，左下角，灰色小字，不带键名。提示行是底座通用的那句「移动预览，再点一下落定；中途可以转视角；Esc / 单指轻点取消」，不是刀自己的那句。
- **刀开始的那一下，屏幕上立刻画出一条蓝色刀线，连到上一次笔滑过、停下的另一条边上。** 那条边这一笔从没指过。笔没有悬停，落点标记和刀线用的是上一次留下来的位置（C2 那张图）。
- 切了一刀之后：芯片还是只有「取消」，提示行「切了一刀；接着点下一个点继续切，Esc 收刀」。
- 手指轻点收刀：
  - 抬笔后 600 ms 以内的手指一律当手掌，不算（`src/controller/feel.ts` 的 `PALM_PEN_GUARD_MS = 600`）。这段时间里点了没反应，等多久都不会补上。
  - 过了 600 ms，手指轻点一下，空处、模型上都行，刀立刻收。已经切的那刀留着，不多记一步撤销，人还在组件里。
- 也看到：没在手势中按 Esc = 退出组件（我的脚本多按了一下 Esc，被退到外面的硬表面里去了）。所以拿 Esc 收刀时，多按一次就出组件了。

**② 右上角视图方块下面那一列**（`D-desktop-right-top-column.png`、`D-ipad-right-top-column.png`）

- 从上到下：① 一行「参考窗」「渲染（☰）」② 视图方块 ③ 一行「平移（手）」「缩放（放大镜）」，只在 iPad 上出，电脑上藏着 ④ 一行「吸附（磁铁带小锁）」「X 光」。
- 选择工具闲着，和自由建模移动工具有选区时，这一列完全一样，没有跟着工具变的东西。
- 锁的入口：
  - 吸附钮长按（电脑上右键）的菜单（`D-desktop-snap-long-press-menu.png`、`D-ipad-snap-long-press-menu.png`），从上到下：网格平面「XY 地面 / YZ 立面 / XZ 立面 / 关（不显示网格）」、「不锁」、「方向锁 X / Y / Z」、「面锁 YZ / XZ / XY」、「单位设置…」。电脑版每项后面印着键（方向键、Shift+方向键），iPad 上长按弹出的是同一份。
  - 另外两个入口：左下角芯片那排，移动工具有选区时出「锁 X / 锁 Y / 锁 Z / 锁 XY / 锁 YZ / 锁 XZ」，电脑上带键名（X / Y / Z / Shift+Z / Shift+X / Shift+Y），用过笔就不带；还有键盘的方向键和 X / Y / Z。

**③ 移动工具：落笔之前先锁轴**（`E-mouse-move-prelocked-arrow.png`、`C5-pen-move-prelocked-X-full.png`）

- 鼠标，自由建模，全选，移动工具，没做手势时按 →：锁上 X，芯片「锁 X」亮，模型上画出那根轴线。
  - 拖：拖的过程中锁着，结果只沿 X 走（+0.294, 0, 0）。
  - **一松手锁就清了。** 不重锁再拖一次就是自由的（+0.296, +0.143, −0.117）。
  - 按 X 键锁也一样，拖完同样清掉。
- 笔（iPad）：点芯片「锁 X」= 锁上、亮、画出轴线。笔拖一个角：拖着时锁着、只沿 X；抬笔清掉；第二次拖是自由的。
- **和第二节第 1 条写的现状不一样**：锁 Z 以后，在左柱点「旋转」再点回「移动」，锁还在（还是 Z）；没在手势中按 Esc 才清（同时也退出了组件，见上）。也就是说，现在清锁的是「落定」和「Esc」，换工具不清。

**④ 右键内插 / 倒角之后的参数小窗**（`F1-after-right-click-inset.png`、`F2-after-right-click-bevel.png`）

- 右键一张选中的面，菜单里有「插入」「倒角（4 条边）」；右键一条选中的边，有「环切（4 条边）」「倒角（1 条边）」。
- 小窗在右下角那块工具条的上半格：标题「刚才：插入」，一行「宽度 − 7.9 cm +」。倒角是「宽度 − 5 cm +」「段数 − 1 +」两行。下半格是当时那把工具自己的选项（选择工具 = 选区 替换 / 空处拖 框 / 拾取三颗 / 垃圾桶）。
- **没有「确定」键，也没有关闭钮。**
- 怎么关：按 Esc、点空处、换工具，都会收起；收起之后刚才那一步留着（面数不变，没撤销）。点 + 改数，小窗留着。
- 刀切完一刀、环切落定、Esc 收刀之后：都不出这个小窗。刀开着的时候，右下角工具条是空的，没有任何选项。
- 环切现在的入口：选中一条边后右键菜单里的「环切（N 条边）」，加上 Ctrl+R；刀的「同一条边点两下」。
