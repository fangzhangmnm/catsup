## 二、逐条：现状、原因、方案

### 1. 每个工具记住锁的轴

- **现状**（`editor.ts`）：锁轴和锁面是编辑器上的两个量；手势一落定就清掉（代码里写着「SU 同款」），换工具、按 Esc 也清掉。
- **我对这句话的读法**：每个工具各自记住上一次锁的是哪根轴，下次再用这个工具时自动带上。比如缩放一直锁着 X，移动一直不锁。
- **方案**：
  - 锁的记忆按工具存，手势落定不清；换回这个工具时恢复。只记在这次打开期间，不进文件。
  - 锁着的时候要一直看得见（工具条上那根轴亮着），点一下就解。不然记住的锁会变成看不见的规矩。
  - 键盘上再按一次同一个轴键 = 解，和现在一样。
- **另一种读法**（如果你是这个意思，告诉我）：「别忘了每个工具都要支持锁轴」。我顺手查了：现在吃锁的有画线、弧、圆规、矩形、量角器、卷尺、移动、旋转、挤出、网格的挪转缩；**不吃锁的有刀、内插、偏移、推拉、硬表面的缩放、跟随、新建**。

### 2. 沿一根轴缩到零

- **现状**（`mesh-transform.ts`）：缩放手势中可以打数，沿锁住的轴缩到 0 就是压平；这条路只有键盘能走。
- **它是干什么的**：把选中的一圈点压到同一个平面上。建角色时最常见的两种：把一圈歪了的点压平；把中缝上的点压到镜像面上。
- **方案（两个入口都做，算法是同一段）**：
  - **专门的动作「压平」**：选中点之后，右键菜单和工具条上各一个入口。点开选沿哪个方向（X / Y / Z / 这圈点自己的平均朝向），再选压到哪（这圈点的平均位置 / 镜像面 / 最后选中的那个点）。一步撤销。这是 iPad 上的主入口，不用进手势、不用键盘。
  - **缩放时的快捷值**：缩放手势中锁了轴，数值小窗上出一排常用值：0、½、2、−1。点 0 就是压平。键盘用户照旧敲。
- 「压到镜像面」单独列出来，是因为它压到的不是平均位置，而是正好等于零的那个面；中缝合不上多半就是差这一下。

### 3. 刀：先悬停、先滑动，再定第一个点

- **现状**（`mesh-knife.ts`、`editor.ts` 的按下和松手那两段）：
  - 悬停时只在落点处画一个小标记，不亮边。鼠标和支持悬停的笔才有悬停；手指和不支持悬停的笔什么都看不到。
  - **按下的那一瞬间，第一个点就定在按下的位置。** 没按在点或边上，这一下就作废，只给一行提示。之后拖动是在找第二个点。
  - 所以在 iPad 上，第一刀要求你的笔尖或手指一落下就正好压在一条边上，而且你事先看不到会吸到哪。
- **硬表面那边怎么样**：画线的第一个点也是按下就定，但它落在哪都行（落空了就落在地面上），而且悬停时有完整的吸附预告（端点、中点、边上）。所以同样的手势，在画线上不难受，在刀上就难受。
- **方案**：
  - **第一个点改成「按下、滑动、松手才定」**：按下以后落点标记跟着笔走，沿着边滑；松手的位置才是第一个点。按下时没在点或边上也没关系，滑上去就行。
  - 第一个点定了之后照旧：再按下滑动、松手 = 切一刀，接着切。
  - 鼠标点一下 = 原地按下松手，行为和现在一样。
  - **悬停预告补到和硬表面一个水平**：端点、中点、边上三种标记；边上的点沿边滑。中点现在没有，加上。
- **我对「slide first before the first cut commit」的读法就是上面这样。** 如果你说的是环切（先选一圈、沿边滑到想要的位置、再落定，像 Blender 的 Ctrl+R），那是另一件，下面第 4 条里的 4-2 正好要动环切，可以一起做，告诉我。
- **其他工具对不对得上**（只读了代码，没在真 app 里逐个试）：

| 工具 | 要不要指一个精确的位置 | 悬停有预告吗 | 第一下能不能先滑再定 |
|---|---|---|---|
| 刀 | 要（点或边上的点） | 只有小标记 | 不能 |
| 内插 | 不要（作用在选中的面上） | 没有 | 不涉及 |
| 挤出、沿法线 | 不要（相对拖动） | 有 | 不涉及 |
| 网格的挪 / 转 / 缩 | 不要（相对拖动；按住 Shift 才吸） | 有（把手） | 不涉及 |
| 新建（方块、圆柱……） | 要（放在哪） | 没有 | 按下就定 |
| 网格的橡皮、软橡皮 | 要（擦哪条边） | 没有 | 按下就开始擦 |
| 硬表面：画线、矩形、圆、弧、卷尺、量角器 | 要 | 有，完整的吸附预告 | 按下就定，但落空也成立 |
| 硬表面：推拉、偏移 | 要（哪张面） | 没有 | 按下就定 |

  - 规律：**要你指一个精确位置、而且落空就作废的工具，才需要「先滑再定」。** 按这个标准，要改的是刀；新建和橡皮值得跟着看一眼；别的不用动。
  - 你 10-27 定过「自由建模模式不要悬浮高亮」。这次加的是落点的预告（一个标记），不是把整条边或整张面点亮，两者不冲突。

### 4. 刀在落定前画面不对

读代码查到四处，前两处我比较确定就是你看到的，后两处要在真 app 里看一眼：

- **4-1 落点会沿着边偏。** 光标在边上的位置，现在是在屏幕上按比例算的，再拿这个比例到空间里那条边上取点。有透视的时候，屏幕上的一半不是空间里的一半，所以标记和切出来的点不在光标正下方，边越斜、越朝里伸，偏得越多。改法：用光标的射线和这条边在空间里求最近点。这条和画贴图那边「点到哪就是哪」是同一个要求。
- **4-2 第一下点在边上，立刻预演出一整圈环切。** 规则是「同一条边点两下 = 环切」。第一下点完，光标还停在这条边上，程序就认为你在指同一条边，于是把一整圈切开的样子画出来。看起来像是点了一下整个模型被切了一圈；这时手一抖再碰一下，环切就真的落定了。改法：环切只走它自己的入口（工具条的环切钮、Ctrl+R），或者至少要求光标离开过这条边再回来才算「点第二下」。倾向前一种，简单、不会误触。
- **4-3 预演一会儿有一会儿没有。** 光标在面的中间时没有落点，预演消失，模型变回没切的样子；滑到边上又出现。整个网格每次都重画一遍，可能会闪。要在真 app 里看闪不闪。
- **4-4 光标没落在点或边上时，刀线画到一个悬空的点。** 这个点在「过第一个落点、正对相机」的平面上，不在模型表面上。屏幕上看是一条直线，问题不大；但转过视角再看会觉得线飘着。要看一眼再决定管不管。

另外两条现状，不算毛病，列出来让你知道：刀不能停在面的中间（只能点到点、点到边）；两个点不在同一张面上时切不了，要先切到中间那条边上。

**5. 刀后面的手感和画线对齐**

- 画线现在是：每个点都是按下、拖、松手落定，或者点一下；连着画；同一处再点一下 = 收笔；Esc = 收笔。
- 刀对齐成：第一个点和后面每个点都是「按下、滑动、松手才定」；同一处再点一下 = 收刀（环切不再占用这个手势）；Esc = 收刀。

**6. 画完要有逃生口**

- 现状：收刀靠 Esc；见过笔的设备上手指轻点一下也是取消。左下角有一排键名芯片，里面有「取消」。iPad 上这一排在刀进行中出不出、出了看不看得懂，要在侦察里确认。
- 方案：多步的工具在进行中，屏幕上固定有一个看得见的「收」的钮，文字跟着工具走（刀 =「收刀」，画线 =「收笔」）。位置第一版放在现有那排芯片里，侦察之后看要不要挪。所有多步工具用同一个位置。

**7. 锁轴要能在落笔之前先选，入口整理到右上角**

- 现状：锁轴的入口有三个，都不顺手。键盘方向键；右上角吸附钮长按出来的菜单里；左下角芯片。移动工具的把手也能锁，但那是按在把手上才锁这一下。
- 你要的两件事：落笔之前先选好（落笔之后再去按钮很反人类）；按哪个面移动经常要换，换起来要快，不然就得不停转视角。
- **第一版方案**：
  - 右上角视图方块下面那一列里，吸附钮旁边，加一块锁的区域，直接摆出来不用长按：一排三个「沿 X / 沿 Y / 沿 Z」，一排三个「面 YZ / 面 XZ / 面 XY」。带文字，颜色和坐标轴一致。
  - 点一下 = 锁上，再点一下同一个 = 解开。当前锁着的那个一直亮着。
  - 没在做手势时也能点，点了就预备着，下一笔直接按这个锁走。锁着时模型上照现在的做法画出那根轴线或那个面，落笔前就看得见会沿哪走。
  - 每个工具记住自己的（第 1 条），所以移动一直停在你上次选的那个面上，缩放停在上次那根轴上。
  - 只在当前工具吃锁的时候出现；只吃面锁的工具（矩形、圆、弧、旋转）只出第二排。
  - 吸附钮长按菜单里那一段锁的选项去掉，免得两处。
- 这是第一版，占的地方、要不要能收起来、六个钮够不够顺手，等你用了再磨。

- **W-0 先看，不改代码（已放行）**：在真 app 里（无头浏览器）把刀的手势走一遍并截图，确认第二节第 4 条的四处各是什么样：悬停；第一下点在边上之后光标不动；光标滑到面中间；滑到另一条边；透视相机下斜着的边上标记和光标差多少。现成的 `test/probes/probe-mesh-knife.mjs` 可以当起点。另外看三样：① 用笔的指针事件（没有悬停）走一遍刀，刀进行中左下角那排芯片出不出、有没有「取消」；见过笔之后手指轻点能不能收刀；② 右上角视图方块下面那一列现在有哪些钮，截一张图；③ 移动工具在没做手势时先按方向键锁轴，再落笔拖，锁还在不在。把看到的写进施工记录，截图放作业的临时目录，告诉 Fable 路径。**这一条是侦察，Fable 看完结果再放后面几条。**
- **W-1 刀的落点用射线和边求最近点**（4-1）。门：探针里透视相机下，标记离光标不超过 1 个屏幕像素；正交相机下结果和现在一样。
- **W-2 环切只走自己的入口**（4-2，user 同意了）。去掉刀的「同一处再点一下也递给工具」，这样同一处再点一下回到底座的默认行为，对刀来说 = 收刀（和画线的收笔对齐，见第 5 条）。门：点一条边之后光标不动，没有环切的预演；连点两下同一条边不落定环切；环切钮和 Ctrl+R 照旧。

- **W-4 每个工具记住锁的轴**（第 1 条，user 同意了：是「各自记住上次锁的」）。和 W-6 一起做。门：缩放锁 X 做一下，再做一下还是锁着 X；换到移动没有锁；换回缩放又是 X；工具条上看得见、点一下能解。
- **W-5 「压平」动作 + 缩放时的快捷值**（第 2 条，user 同意了：两个都做）。门：选一圈歪的点，压平后这一圈在指定方向上的坐标相等；压到镜像面后那个坐标正好是零；一步撤销回原样。
- **W-6 锁的入口整理到右上角，落笔前能先锁**（第 7 条，第一版）。门：没做手势时点「面 XY」，再落笔拖一个点，只在那个面里动；再点一下解开；换工具再换回来还是它；工具条上看得见；吸附钮长按菜单里不再有锁的选项。
- **W-7 多步工具进行中有看得见的「收」的钮**（第 6 条，第一版）。门：用笔的指针事件，刀切了一刀之后屏幕上有「收刀」，点它刀就收了；画线同理是「收笔」。
- 通用的门：`npm test` 全过；`probe-mesh-knife`、`probe-mesh-transform`、`probe-axis-lock` 不红；`editor.ts` 的行数只许降不许升（有棘轮）；改了流程的同一个提交里更新流程图文档。
