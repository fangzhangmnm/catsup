# 撤销重设计：每一步带着会话走 + 换场景只有一个入口

> created 20261026 by Claude Opus 5.5 · as-of v0.14.27 / 2026-10-26
> 起因（user 2026-10-26）：「undo似乎全坏了，可能需要系统大修。涉及组件的修改进出之类的」「undo你先修，不要ad hoc，而是思考系统重新设计。周账让fable审计」。
> 审计：家族周账 F-93（Fable）。

## 1. 问题陈述（复现过的）

撤销的底子没坏：记一串可重放的指令，每 8 条存一份场景快照；撤销 = 回到快照重放到上一步。逐步比对（每个动作后记场景指纹，一路撤回去、一路重做回来）在「建组件 / 复制 / 进组件推拉 / 移动实例 / 组件里画线」这一串上每一步都对得上。

坏的是**撤销流程本身和「会话状态」**：

1. **撤到一半崩掉**（真 bug，老毛病）：在组件里面一路撤销，撤过「建出 / 复制出这个组件」那一步时，当前所在的组件已经不存在了。撤销流程先关参数小窗（会通知界面刷新 → 画面包屑去读「当前在哪个组件」）、后校正位置，于是抛错 `instance N does not exist`。此时历史游标已退、场景已换，人却卡在一个不存在的组件里——之后一切操作都跟着出错。这就是「全坏了」。
2. **在组件外撤组件里的改动**：改动没了，人还在外面，选区被清空（选区快照只在「所在组件和当时一样」时才还原）。看起来像撤销乱撤。
3. **两张表对齐的隐患**：选区快照住在编辑器另一张按历史位置编号的表里，和历史的步各管各的截断。

## 2. 不变量

- **I1 一步 = 指令 + 会话的前后。** 历史的每一步存：这一步的指令；这一步之前的会话；撤销它那一刻的会话（= 重做要回到的样子）。会话 = 在哪个组件里编辑 + 选区。
- **I2 撤销 = 场景和会话一起回到之前；重做 = 一起回到之后。**（user 10-26「多步操作的 ctrl z 统一应该是取消操作回到操作前，这时候往往是保留选区的」的推广：位置也是「操作前」的一部分。）
- **I3 会话记录归历史模块管**：和指令同一个数组下标、同一次截断（新分支一起作废），不会对不齐。
- **I4 换场景只有一个入口**（`Editor.installScene`）：换场景 → 校正所在组件（退到还在的最深一层；组没了退到那个实例的根）→ 剪 / 还原选区 → 充能点重核。**入口里不通知界面**，调用方之后才关参数小窗、刷新 HUD。撤销、重做、马后炮的「撤 n 条重来」、提交失败回滚全走它。（打开文件 `loadScene` 直接回最外层、历史清零，本来就安全。）
- **I5 撤销不在手势中途发生**：手势进行中按 Ctrl+Z = 取消这次手势（原样保留）。
- **I6 不在历史里的东西**：视图（相机 / 只看这个 / 网格设置 / 隐藏显示的视图态）不进撤销；工具中间态、参数小窗、预演在撤销时一律清掉。

## 3. 落地（v0.14.27）

- `src/editor/history.ts`：`History<M>`，`commit(s, op, join, before?)`；`undo(now?) → { scene, before }`；`redo(s) → { …, after }`；`undoOp() → { scene, before }`；`sessions[]` 与 `ops[] / joins[]` 同步截断。单测「会话记录」一条。
- `src/editor/editor.ts`：`Session = { ctx, sel }`；`sessionSnap / sessionRestore / validCtx / installScene`；`bump()` 改用 `validCtx`（以前一律回根）；`stepSel` 表删除。
- 探针 `test/probes/probe-undo-session.mjs`：组件外撤组件里的推拉 → 人回到那份组件里、选区 = 顶面；重做 → 回到撤销时的位置；组件里撤 → 还在组件里；组件里一路撤过「复制」「建组件」→ 不报错、退回最外层；一路重做 5 步逐步和当初一致。

## 4. 留给审计 / user 的点

- **撤销会把人带回那一步所在的组件里**（I2 的直接结果）。我认为这是对的（看得见撤了什么；Blender 撤销也会切回编辑模式）。如果 user 觉得被「拽进去」别扭，改成「只还原选区、不动位置」只动 `sessionRestore` 一处。
- Fable 审：I4 有没有漏掉的换场景路径；会话 id 在快照重放后是否总指向同一批东西（重放确定性，公理 5）；马后炮 / 数值小窗重做（`undoN`）和「一步」打包的交互。

> **2026-10-27 夜追记（Claude Fable 5.1）**：I1–I6 保留；底下的「op 日志 + 每 8 步整场景快照 + 回到快照重放」换成「指令流 + 差量栈」（`ai-docs/20261027-undo-delta-design.md` §7）。会话记录的形状、`installScene` 唯一入口都没变。
