# 存盘忠实度清点：存盘是不是只把软件里的东西原样写出去

> created 20261112 by Claude Opus 5.5 · as-of v0.19.68 / 2026-11-12（第八节 = 统筹裁定和 v0.19.68 做了什么）
> 起因：user（统筹转述，11-13 北京时间）「存盘只该把软件里的东西原样写出去 系统的查一下」。统筹定的范围：写的一头（存盘、自动保存、崩溃影子、另存、导出、复制粘贴的载荷）+ 读的一头（每一步格式升级、补默认值、读的时候记的说明、精度、丢掉认不出的东西）。**只查不改代码。**
> 分类：**A** = 人做的东西意思变了；**B** = 意思一样、写法不一样；**C** = 软件自己生成的（缩略图、烘焙、版本串）。拿不准的标「拿不准」。

## 零、结论先说

1. **真软件存的文件，打开 → 什么都不动 → 再存：只差缩略图和两处版本串，别的每一段字节都一样。** 打开不算「改过」，不触发自动保存；只转视角也不算。（第二节）
2. **反方向有一个真问题：人改的没写出去。** 换单位制、吸附长度、硬表面的吸附开关、网格住哪个面、尺度参考的开关 / 清空——这六样都存在文件里，可是改了**不算改过**：不自动保存、崩溃影子也不带、离开时不问。只改了这些就关掉 / 新建 / 开别的，改动就没了；要等下一次真的存盘才顺带写进去。（第五节）
3. **读的时候悄悄修掉三种悬空引用**：材质槽指向表里没有的材质 → 变成默认正面；组的父亲、实例的父亲指向不存在的组 → 变成顶层。读的时候的说明（readNotes）一条都不记，存回去原来的值就没了。只有外来 / 手改 / 坏掉的文件会碰到，软件自己存的文件不会出现。（第四节 R1、R2）
4. **写盘时「定义已经不在的实例滤掉」是走不到的兜底**：已知的路上不会出现这种实例；真走到了就是悄悄丢东西、没有任何记录。（第四节 W2）
5. 冻样本（测试用的旧版本样本）存回去差得多，**大部分是样本本身不自然**（冻样本脚本拼文件时没走软件存盘的那一步），不是软件改人的东西。（第三节）

冻样本是 `scripts/freeze-format-fixtures.mjs` 拼出来的，不是在软件里按保存存的，所以有几处和软件存的文件天生不一样。**这些差不是软件改了人的东西。**

**当前版本 24 份（真软件存回去）**：每一段原有二进制在新文件里都找得到一模一样的一段；多出来的只有缩略图。JSON 的差：

## 五、反方向：人改的没写出去（单列）

这六样都是**住在文件里的设置**（存盘时 `session` 从 `editor.docGrid` 和尺度参考拼进 `CATSUP_document.settings`），可改它们的口子只通知界面刷新（`host.changed()`），**不升文档版本号**。软件判断「改过没有」只看文档版本号和参考窗版本号，所以：

| 改的东西 | 口子（`src/editor/editor.ts`） | 实测：改完算改过吗 |
|---|---|---|
| 换单位制（公制 → 英制 / D&D） | `setGrid({ system })` | 不算（版本号不动） |
| 吸附长度 | `setGrid({ snap })` | 不算 |
| 硬表面的吸附开关 | `setGrid({ on })` | 不算 |
| 网格住哪个面 / 显示不显示 | `setGrid({ plane, shown })` | 不算 |
| 尺度参考的开关 | `toggleScaleRef` | 不算 |
| 尺度参考清空 | `clearScaleRefs` | 不算 |

后果：
- 自动保存不存、崩溃影子不写（两者都只看版本号）。
- 离开（新建、开别的、关页）前那一问（`leaveGate`）只在「改过」时才问 / 才存 → **只改了这些就离开，改动没了，也没人说**。
- 改了这些之后又做了任何一步真正的修改，再存时会顺带写进去（存盘读的是当时的设置）。

归类：**人做的东西没被如实写出去**（和这次查的「软件多改了」方向相反）。

同一类但**按契约有意不标脏**的（契约 §5.7 桌面态，WeebPaint 同款）：画风、屏幕、参考窗的位置、☰ 停留在哪一页。实测换画风也不算改过；同样只改这些就离开也不会存。列在这里交统筹判：桌面态要不要和上面六样一起看。（自由建模工作台自己那一份吸附开关按设计不进文件，不在此列。）

## 六、打开没动，算不算改过

- 真软件：当前版本 24 份 + 真文件 1 份 + 现造场景 1 份，打开后都不算改过、不触发自动保存；只转视角不算。
- 全部 413 份冻样本（49 个格式版本，含当前版本）在真软件里逐份打开、等 0.7 秒：**全部打开成功，没有一份算改过，没有一份弹出「先保存吗」之类的问话。** 老文件读的时候做的升级（铸 GUID、搬贴图表、改设置写法……）都不让文件变成「改过」，要等人真的改了东西、存盘时才写下去。
- 所以「打开不动」不会产生一次存盘；第二、三节说的那些差，只在人改了别的东西、触发存盘时才会落到文件上。

## 八、统筹的裁定和 v0.19.68 做了什么（2026-11-12）

| 条 | 裁定 | v0.19.68 |
|---|---|---|
| 第五节六样设置 | 改了要算改过（user 明着改的，悄悄没了 = 丢人做的东西）；不进撤销 | 做了：编辑器加「设置改动号」，`docRevision` 带着它；自动保存、崩溃影子、离开前那一问跟着对。探针 `probe-settings-dirty`：v0.19.67 上 9 红，v0.19.68 上 20 绿（每样改完算改过 → 空闲 30 秒自动保存写了 → 刷新后值还在；换画风照旧不算） |

| R1、R2 | 各在 readNotes 记一条、打开时提示一次；不改修法、不带着悬空的值走 | 做了：`danglingMaterialSlots`、`danglingParents`，算「会丢」（第一次存盘前点头，同悬空贴图引用）；老格式升级时序号越界也记 |

**顺手修的一处**：`read.ts` 决定「读完挂不挂 readNotes」用的是一条手写的键名单，R1 / R2 两个新键没在名单里，记了也被整个吞掉（测试先红在这里）。改成按值判（任何一个键有值就挂上），测试钉住不许回到名单；413 份冻样本读下来照旧一份都不挂。
