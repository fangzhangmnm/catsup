# 施工单（草稿）：镜像只认精确的孪生

> created 2026-11-13 by Claude Fable 5.2 · as-of 三维 v0.19.78（开发版）
> 状态：设计定了方向，**还没排施工**。排在「画跟着面走」（施工单十八）之后、展开接进「开始画」（施工单二十二第 3 刀）之前。开工前小弟先来找统筹过一遍。
> 施工：Catsup小弟。事实是小弟 11-13 只读查的，统筹没有自己核代码。

## 一、现状（小弟查的）

- 网格体的镜像面 = 网格体自己坐标里某一根轴 = 0 的平面；镜过去 = 那个坐标取反，逐位精确；网格体的点不量化，文件里也是 64 位浮点。
- 孪生关系不存，每次现找：`mirrorPairs` 在 1 毫米（`mesh/mirror.ts MIRROR_TOL`）以内找对面最近的点，一样近取编号小的，不要求互相。
- 「在中缝上」= 离镜像面 1 毫米以内的一条带。用的地方：挪点时钉住、并点、穿过去夹住（`mirrorMoves`），分哪一边，跨中缝的面、沿面切开、强行对称、清中缝夹层面，编辑器里画中缝点、选环，画画时认镜像那一半的面（`paint-upkeep.ts`）。
- 挪点：被挪的点的孪生直接写成它的精确镜像。副作用：对面差 1 毫米以内的点被悄悄改成精确镜像。落到中缝 1 毫米以内 = 钉到 0、和孪生并成一个。
- 改拓扑的指令（挤出、刀、环切、插入、倒角、复制、删除、合并点）：镜像编辑开着时先问「关掉镜像照做 / 取消」，不在两边同时做。
- 强行对称：每一步之后沿面切开（1 毫米带）、带里的点钉成 0、删另一半、这一半镜回去。
- 「对称对齐」（右键指令，只对选区）：参数 = 镜像面、容差（默认 1 厘米，0.1 毫米到 1 米）、以哪边为准；找到对面的对成精确镜像，离面在容差内的钉到面上，找不到的不动并数出来。一步撤销，做完能改参数。
- 硬表面只有一条一次性的「镜像」指令，不记孪生；它先把离镜像面 0.1 毫米以内的选中点吸到面上。

## 二、毛病：一个 1 毫米当了三种意思

1. 两个点是不是一对（几何的事）。
2. 一个点在不在中缝上（几何的事）。
3. 拖到中缝附近要不要吸上去（手势的事）。

后果：毫米零件上，离中线不到 1 毫米的特征被当成在中缝上，挪的时候被钉住、和孪生并成一个；相距 0.5 毫米的点会配错。还有一处看不见的：挪一个点时，对面差一点的点被悄悄修成精确镜像。

这和 v0.19.72 那批门槛是同一类：手势的门槛和几何的判断混在一个数里。

## 三、改成什么

1. **几何只有一个容差**：`MIRROR_EPS` = 内核「是同一个点」的那个数（`STICKY_R`，3 微米，同一个常量来源，不另写一个数）。
   - 孪生 = 离「镜过去的位置」不超过 `MIRROR_EPS` 的最近的点。
   - 在中缝上 = 离「自己镜过去的位置」不超过 `MIRROR_EPS`（也就是离面不超过 1.5 微米）。两条是同一个定义。
   - 不取 0 的原因：把整个模型绕竖轴转 180° 这类操作，数学上对称的两点会差出 1e-16 量级，取 0 会让整个模型都「对不上」。
   - 用到「在面上 / 配对」的地方（第一节列的那些，含画画和选环）全部改问这一个定义。
2. **吸到中缝是手势的事**：按屏幕像素，中缝面当成吸附里一个具体的东西。
   - 作用在整个手势上：参考点吸到面上，别的点跟着同一个位移；不是每个点各自被吸（缩小视图时几个像素换成的世界长度很大，逐点吸会把一片点压平）。
   - 吸上去之后正好落在面上的点才和孪生并成一个。穿过去夹住照旧。
   - 机制怎么接（吸附求解器加一种目标，还是工具里先修位移再交给 `meshMove`）小弟提方案。网格体那一层不许知道屏幕。
3. **松的配对只留在「对称对齐」里**：它本来就有看得见的容差参数，这一版不改它。右上角橙色的「对不上 N 个」照新定义数，提示里说一句「选中后右键 · 对称对齐」。
4. **强行对称**：切开和钉成 0 的带都用 `MIRROR_EPS`。离面 0.5 毫米的点不再被压到面上，镜回去之后中缝两边各有一个点，这是模型本来的样子。

## 四、user 会感觉到的变化（发的时候要说）

- 往中线上拖点：以前离中线 1 毫米以内自动吸上去，以后按屏幕上的距离吸。
- 导入的、差一点对称的模型：橙色的「对不上」数字变大，要点一次对称对齐。
- 挪点不再悄悄修对面差一点的点。

## 五、这一版不做

- 一对一配对（互相最近）：只有两个点相距不到 6 微米才会出现「不互相」，那是重合点的事。
- 硬表面那条一次性「镜像」里的 0.1 毫米吸面：是另一个写死的数，毫米零件上同样会咬到细节。记在这里，到 user 在毫米尺度用硬表面镜像之前要看。
- 把孪生关系存进文件。

## 六、验收（探针）

- 毫米零件：离中线 0.5 毫米的点，开着镜像挪别的点，它不动、不被钉。
- 两个点相距 0.5 毫米：不配错。
- 对称的模型整体绕竖轴转 180°：仍然全部配上。
- 把一个点拖到中线附近：吸上、和孪生并成一个；缩小视图拖一片点靠近中线：形状不被压平。
- 一个每个点都差 0.2 毫米的模型：橙色计数 = 点数；对称对齐之后 = 0。
- 画画：开着镜像画一笔，另一半照旧跟着变。

## 七、什么时候必须做

- 展开接进「开始画」那一刀之前：那一刀的「开着镜像只展开一半、另一半共用」靠的是同一个配对。
- 或者 user 要在毫米尺度做对称零件之前，哪个先到算哪个。

## 八、强行对称不许吃东西（Claude Fable 5.2，2026-11-13 晚；小弟做第 1 版时报的，主分支上就有）

现象：开着强行对称，拷一张面原位粘贴，对面不补；下一步在另一边动一下，贴的那张被当成「另一半」删掉。成因还没证实（第 1 版施工单第九节要小弟先写最小复现）。统筹读代码看到的两个口子：
- 「这一步动的是哪边」（`mirror.ts sideOfChange`）只看点，不看面：新出现的面要是落在已有的点上，看不出来，就落到「上一步是哪边，没有就按 +」的猜法上。
- 「是不是对称」（`mirror.ts isSymmetric`）按一圈点认面，叠在同一圈点上的两张面被当成一张：左边多一张也算对称，这一步就不对称化，毛病留到下一步。
- 另外两种「这一步没对称」的情况（两边都没有面、有面跨过镜像面劈不开）之后，物体同样停在两边不一样的状态，下一步照样以一半为准、把另一半换掉。

修的时候守这几条（不变量先于修法）：
1. **开着强行对称的物体，每一步结束时要么两边一样，要么明着标成「两边不一样」**。没有第三种悄悄的状态。
2. **「以哪半为准」只从这一步实际改了什么来定**：点、边、面都看（新出现的、消失的、挪过的）。不看指令的名字、不看场景里别的东西、不靠上一步是哪边。
3. **定不出来就不换、不删**：这一步不对称化，提示行明说；物体标成「两边不一样」。
4. **标着「两边不一样」的时候不做「以一半为准把另一半换掉」**（那正是会丢东西的一步），直到人自己点了以哪半为准，或者关掉强行对称。
5. 「是不是对称」要数面的张数，叠着的两张不算一张。

和第二、三节（孪生只认精确的）是同一件事的两头：那边管「谁和谁是一对」，这边管「不成对的时候怎么办」。一起做。
