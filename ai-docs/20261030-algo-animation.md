## IK
- MMD 的逐节逼近（CCD）+ 角度限制；两节骨头（手 / 脚）的解析解。
- 全身 IK：抓手一拖身子跟着走（MikuMikuMoving 是前辈）。
- 「目标 / 钉子」数据：只写要什么（这只脚第 a–b 帧钉在这），哪个解算器都得满足；导出烘成每帧 FK。治「两帧之间脚滑」、也治「回去改比例后脚浮」。
- 允许伸长（路飞）。
- 全身 IK 的去处（第三轮，凭记忆）：动捕清理 / 重定向（MotionBuilder、HumanIK：部位钉子 + 硬度、「全身跟」vs「只动这节」两种模式）；VR 三点推全身（Unity Final IK 那套）；摆关键姿势（Cascadeur：拽几个点 + 显示重心，神经网络补全姿势；MikuMikuMoving）；UE5 Control Rig 的全身解算器。手 K 主流仍是 Maya 控制器（每肢 IK / FK 可切）。
- **拍了（第七轮）**：默认局部 IK；全身 IK 明着切换；**不同的 rig 可以切换**（同一份数据：每根骨头的转动 + 钉子），以后加别的。全身 IK rig 里 = user 的摆法（先摆 → 钉核心 → 拖核心动全家 / 框选拖），规矩「拖谁谁的子孙跟着走、钉住的不走、中间关节自己弯」（Opus 读法，没拍）；一进去钉不钉屁股和脚，到实验室里两种都试。画重心落点 + 支撑范围。
- **核心体验拍了（第八轮）**：拖关节点、不想欧拉角（「就是画火柴人」）；AI 不是必须。不用 AI 的自然补全 = 关节极限 + 改得最少 + 往放松站姿拉一点 + 脊椎分摊；扭转用多放点 / 末端转圈补，不露三个数。
- 画 2D 火柴人推 3D 姿势（Opus 记得 2003 年一篇，没核）= **wishlist**（user 10-30 夜），和动作线一家。
- **第九轮**：一开始只做一个全身 IK（拍了）；局部 IK = 全身 IK + 自动钉住链以外的一切（前提：钉子能钉转动、钉子是硬的、手肘朝向偏好一致）；两节骨头精确解以后当快路，和全身 IK 对拍。
- 插值空间：FK 插（弧线好、换 rig 不变、能拧多圈、glTF 原样；脚会滑）vs 目标空间插（着地稳；直线像机器人、半路翻面、换解法就变、要逐帧烘）；手 K 行走老规矩 = 腿 IK、胳膊 FK；**拍了（user「FK 插值 + 钉子 同意」）= FK 插 + 钉子时段用全身 IK 拉回**。
- 以后在实验室玩：自动物理（重心轨迹 / 支点 / 抛物线 / 修正版一层）、二次动作滑条、AI 补间。
- **第十三轮拍了**：钉子硬 / 软不一刀切（每颗钉子带硬度；读法：人点的默认硬、动捕着地默认软、打架时说出来）；一个全身 IK 同时接普通 IK；自定义骨骼 + 语义见 `20261030-algo-rig.md`。
- **第十二轮拍了**：不用 AI 的四样（关节极限 / 改得最少 / 往放松站姿拉 / 脊椎分摊）；**gizmo 带人体解剖的意思**，不是每根骨头一视同仁的平移旋转缩放；**手掌开合小控件**（MMM 有）。前辈 = Unity 人形「肌肉」（每个自由度起解剖名、-1…1 对应极限两头，凭记忆）——**第十四轮拍了：Unity 是滑条，我们是屏幕上拖然后反算**（肌肉数只当里面的坐标，界面不露）；左右成对 → 抄姿势 / 镜像姿势是一个动词。
- **看向拍了（第十一轮）**：数据 = 通用约束（某根骨头的某个方向对准目标点 + 权重 + 上限）；预案 = 眼睛先转 → 头跟 → 脖子 / 胸分摊、双眼对同一点、各向极限；VRM 看向两种（眼球骨 / 四个看向表情，后者可绑贴图偏移 = 表情卡片的眼睛）。
- 别的 rig 候选：纯 FK；MMD 式（腿 IK 骨 + 逐节逼近）；曲线 rig（尾巴 / 辫子 / 脊椎）；看向；动作线摆姿势（2013）；学出来的摆姿势（Cascadeur 式）；Quest 手柄直接带两只手、边播边录。
- 只管点时扭转的三处坑：手肘往哪撇（拖手肘点定）；跟拖的顺序有关、多次以后小臂 / 脊椎扭转攒歪（扭转极限拦着）；手 / 脚 / 头的朝向点给不出（末端带转动把手，或多给脚尖 / 指尖点）。多圈扭转只能手动。
- Cascadeur（Nekki）对照：自动摆姿势（神经网络补全）、自动物理（重心轨迹 / 支点 / 抛物线，修正版放旁边一层）、二次动作滑条、AI 补间、反烘焙（动捕抽稀成关键帧）、人形一键生成控制点。

## 曲线与插值
- 已有几家：贝塞尔（每帧两个把手）、TCB（张力 / 连续 / 偏移）、阶梯（一拍二）。
- 导出边界：glTF 只认线性 / 阶梯 / 三次（带进出切线）；分段三次能无损写出去，别的烘。
- 转动的岔路：欧拉好编但导出要采样；四元数走近路，拧 720° 存不下。
- 工作流：姿势到姿势 → 过渡姿势 → 调间距（user 的「二阶微扰」）；洋葱片、运动轨迹（打点看间距）。
- 论文方向：时空约束（1988）、动作线摆姿势（2013）、时空草图（2015）。
- 学出来的补间：Ubisoft La Forge（2020，给关键姿势、AI 补中间帧）= 一种可选的插值方案。

## 动捕（wishlist，user 10-30 夜「如果有轻量级小月相级别的ai或者cv的话，可以做动捕。这个相当于moonsinger的让用户自己唱。记账wishlist」）
- 流程：视频 → 每帧 2D 关节点 → 抬成 3D → 套 VRM 人形表 → 去抖 + 找脚着地（写成钉子）→ 全身 IK 推整个人 → 抽稀成关键帧，人再修。
- 2D 关节点（小、手机能实时跑）：MediaPipe 的姿势 / 手 / 脸那套（BlazePose）、MoveNet、RTMPose。
- 抬 3D：VideoPose3D、MotionBERT 这一路；整段视频直接出 3D 人体的（WHAM、4D-Humans 一类）准但重。**许可证逐个核**（有的只许非商用）。
- 稀疏输入：Quest 头 + 两手三个点 → 全身（同一个全身 IK 解算器）。
- 脸：关键点 → VRM 表情（VTuber 那套）。
- 只在本机算、画面不外发（Opus 建议，照「语音不出设备」的精神）；模型走家族模型库。
- 商用参照：Move.ai、Rokoko、DeepMotion（拿视频动捕）。- 两个场景（第六轮）：① 下载的跳舞教学视频 → 左右对调（镜面教学）、选段、选人、换机位分开算、跟拍时靠脚着地推位移、转圈 / 交叉腿标出来；② 自己录 → 只留骨架轨迹不留视频（每分钟约 1 MB）、多条挑着拼（录歌的 comping）。
- 视频大小：iOS 1080p30 约 60 MB / 分钟，4K60 约 400 MB / 分钟；模型只看 ~256 像素，720p–1080p 足够。

## 反烘焙（wishlist，user 10-30 夜「这个必须要」）
- 每帧一个关键帧 → 少数人能改的关键帧；人点的「语义帧」一定保留，算法再补到误差小于阈值。
- 候选算法（凭记忆没核）：逐条曲线的折线简化（Ramer–Douglas–Peucker 一类）；给定 k 个关键帧、动态规划挑时刻使误差最小；「显著姿势」挑帧那一路论文；挑好时刻后拟合三次曲线的切线（落在 glTF 能无损导出的分段三次里）。
- 所有骨头共用同一组关键帧时刻（姿势到姿势），不是每根各抽各的。
- 着地时段识别成钉子。
- 病人：动捕、二次动作烘的、保样子烘的、Blender 导出的 glb（默认逐帧采样）。- **原视频要留**（第十轮更正）：分层 = 原视频（或缩小版）→ 每帧 2D 关节点 + 可信度（最贵的一步的产物，下游参数改了从这层重跑）→ 关键帧 + 钉子。默认录的时候不开麦克风；录了声音只在本机（家规第 8 条）。

### 一键程序化行走（拍了，不靠生成式 AI，低保真够用）
- 参考：GDC「Animation Bootcamp: An Indie Approach to Procedural Animation」（Wolfire / Overgrowth，凭记忆）。
- 配方：步子跟距离转（不滑）；脚 = 着地钉子 / 迈步弧线 + 落脚点预测 + 射线找地面；全身 IK 解腿；身体按相位起伏 / 晃、加减速前倾后仰、转弯内倒；胳膊反甩（FK）；头看前方；毛发尾巴交给二次动作。
- 步态表：两足交替；四足走 / 小跑 / 跑；马多几种；蜘蛛机器人分组交替。只认腿的角色。
- 输入：地上画路径 / 步行模式的方向键手柄；产出 = 烘成关键帧 → 反烘焙抽稀给人改。
