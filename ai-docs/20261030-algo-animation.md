## IK
- MMD 的逐节逼近（CCD）+ 角度限制；两节骨头（手 / 脚）的解析解。
- 全身 IK：抓手一拖身子跟着走（MikuMikuMoving 是前辈）。
- 「目标 / 钉子」数据：只写要什么（这只脚第 a–b 帧钉在这），哪个解算器都得满足；导出烘成每帧 FK。治「两帧之间脚滑」、也治「回去改比例后脚浮」。
- 允许伸长（路飞）。

## 曲线与插值
- 已有几家：贝塞尔（每帧两个把手）、TCB（张力 / 连续 / 偏移）、阶梯（一拍二）。
- 导出边界：glTF 只认线性 / 阶梯 / 三次（带进出切线）；分段三次能无损写出去，别的烘。
- 转动的岔路：欧拉好编但导出要采样；四元数走近路，拧 720° 存不下。
- 工作流：姿势到姿势 → 过渡姿势 → 调间距（user 的「二阶微扰」）；洋葱片、运动轨迹（打点看间距）。
- 论文方向：时空约束（1988）、动作线摆姿势（2013）、时空草图（2015）。

## 二次动作
- Verlet 链 / 位置约束（XPBD 一类），每根骨头几次乘加，N64 级跑得动；球 / 胶囊碰撞。
- 导出口：VRM 弹簧骨（glTF 原生）；对照 VRChat 的 PhysBones（2022 起）/ 更早的 Dynamic Bone。
- 两种出口（没拍）：烘成关键帧再手 K 修 / 导出弹簧参数给运行时算；可以都要。
