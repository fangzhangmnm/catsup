## 一、规矩（user 定的）

1. 动作进行中，X、Y、Z、N、T 五个键当轴用，各有单按和加 Shift 两种。动作之外它们不是轴（「动作里外」那条线）。
2. X / Y / Z = 轴（硬表面跟着坐标架，自由建模是物体自己的轴）。N = 光标下那张面的法线，T = 光标下那条边的方向；**按键那一刻离光标最近的那个算数**。
3. **单按 = 要这个方向**（一条线）。**这把工具要几个方向就记几个**：画线、移动、挤出、旋转、缩放要一个，再按别的单按 = 换（和 Blender 的手感一致）；矩形和圆要两个（两条边），两根一起撑出面，再按第三个挤掉最早的。按了 Shift 把面定住之后，单按一律只记一个（只管边在面里朝哪边）。
4. **加 Shift = 垂直于它的那个面**。最多记两个；两个夹出一条线（两个面的交线）。
5. **一个 Shift 加一个单按 = 面里的那个方向**（把单按的方向投到面里）。
6. **同一个键再按一下 = 取消它**。N、T 第二次按到的是同一张面 / 同一条边才算同一个；是另一个 = 新的一条。
7. **组合不成立时，后按的盖掉先按的。**（例：Shift+Z 之后单按 Z，方向垂直于面、投不进去 → 面的锁让位。）
8. 快捷键按出来的约束只管这一下，动作做完全部清空；显示成空心。按钮点的锁是实心、管到放下工具为止（触屏的按钮怎么对应这一套以后再定）。
9. 硬表面和自由建模同一套读法。硬表面里约束是加在吸附之后的（吸附照常全量地求，求出来的点再约束），结果要精确；自由建模里差不多就行，之后用 R 微调。

user 说「非常舒服」的两个例子，都要成立：Shift+N 再 X = 贴着光标下这张面、边顺着 X；N 再 X（矩形 / 圆）= 立在这张面上，一条边沿法线竖起来、另一条顺着 X。
中间试过把矩形也统一成「单按只记一个」，user 看到代价（N 再 X 没了）之后改回：「好吧我还是想要这个，这个才是最重要的」「那么还是分开来」。

## 二、怎么收：三个文件，各管一件事

### 2.1 语法模块 `controller/axis-constraint.ts`（深模块；纯函数，零 DOM、零编辑器引用）

规矩第 3–7 条全部住在这里，别处一条都不许有。

```ts
export type AxisKey = "x" | "y" | "z" | "n" | "t";
/** 一次按键。dir = 这个键此刻指的方向（单位向量，由调用方解析好）；ref = 它指的是谁（哪根轴 / 哪张面 / 哪条边的身份），只用来判「是不是同一个」。 */
export interface AxisPress { readonly key: AxisKey; readonly shift: boolean; readonly dir: Vec3; readonly ref: string }
/** 模块自己的状态。**不透明**：外面只存、只传回来，不许读里面。 */
export type AxisState = { readonly __axisState: unique symbol };
/** 一个动作开始时拿一份空的状态。wants = 这把工具要几个方向（画线 / 移动 / 挤出 / 旋转 / 缩放 = 1；矩形 / 圆 = 2）。工具只说这一个数，别的规矩它不知道。 */
export function axisBegin(wants: 1 | 2): AxisState;
/** 按了一下之后的状态。换 / 加 / 取消 / 最多几条 / 谁盖谁，都在这里。 */
export function axisPress(s: AxisState, p: AxisPress): AxisState;
/** 现在被限制成什么。工具只认这四种。 */
export type AxisConstraint =
  | { readonly kind: "free" }
  | { readonly kind: "line"; readonly dir: Vec3 }                         // 只沿这条线
  | { readonly kind: "plane"; readonly normal: Vec3 }                     // 只在这个面里
  | { readonly kind: "planeDir"; readonly normal: Vec3; readonly dir: Vec3 };  // 在这个面里，并且指定了面里的一个方向（dir ⟂ normal）
export function axisConstraint(s: AxisState): AxisConstraint;
/** 给人看的：亮哪几个键（带不带 Shift）、一句话。 */
export function axisDescribe(s: AxisState): { readonly keys: readonly { key: AxisKey; shift: boolean }[]; readonly say: string };
```

里面怎么做（可以改，外面不受影响）：
- 状态 = 按先后排的若干条，每条 = 键、带不带 Shift、方向、身份；外加开头给的 wants。容量：Shift 最多两条；单按在没有 Shift 时最多 wants 条，有 Shift 时最多一条。
- 按一下：
  - 同键、同 Shift、同身份的已经在 = 去掉它（规矩 6）。
  - 新来一条单按：有 Shift 在 = 把原来的单按换掉；没有 Shift = 加进来、只留最近的 wants 条（两条平行 = 只留新的）。然后看它和 Shift 合不合：和唯一那条 Shift 的轴平行（投不进面里）= 丢掉那条 Shift；有两条 Shift 而它不沿着那条交线 = 丢掉早的那条 Shift，再照上一句看剩下的（规矩 7：后按的单按盖掉先按的 Shift）。
  - 新来一条 Shift：加进来、只留最近的两条（两条平行 = 只留新的）；单按只留最近的一条；这条单按和现在的 Shift 不合（投不进面里 / 不沿交线）= 丢掉单按（后按的 Shift 盖掉先按的单按）。
- 结果：
  - 空 → free
  - 一条单按 d → line(d)
  - 两条单按 d1、d2（只有 wants = 2 才会有）→ planeDir(法线 = d1 × d2，方向 = d1)：第一根照原样，第二根取和它垂直的那一部分
  - 一条 Shift a → plane(a)
  - 两条 Shift a、b → line(a × b)
  - 一条 Shift a + 一条单按 d → planeDir(a, d 投到面里)
  - 两条 Shift + 一条沿着交线的单按 → 还是那条线
- 「平行」「垂直」用一个角度的门槛判（先取 1 度；写成具名的数，带单位）。

### 2.2 解析「这个键此刻指哪个方向」——编辑器里一处

`Editor.resolveAxisKey(key): { dir, ref } | { fail: 给人看的原因 }`，只读。
- x / y / z：当前上下文的轴（硬表面 = 坐标架那一套现成的 `contextFrame`；自由建模 = 物体自己的轴）。ref = "axis:x" 这类。
- n：按键那一刻光标下最近的面的法线（`pickFace` 那一套现成的）；ref = 那张面的身份。取不到 = fail「N：把光标放到一张面上再按」。
- t：光标下最近的边的方向（拾取半径照「选」的）；ref = 那条边的身份。取不到 = fail「T：把光标放到一条边上再按」。
- 硬表面：光标正压在分不清的地方（点上、两张面的棱上）= 取拾取现成的优先级给出的那一个，并在提示行说取的是谁；自由建模取最近的，不多说。
- fail = 状态不变、提示行说原因，不进语法模块。

### 2.3 每把工具怎么用结果 `controller/axis-apply.ts`（纯几何）

一族工具一个函数，工具只调自己那一个，不自己读 kind 分叉：

| 工具 | free | line | plane | planeDir |
|---|---|---|---|---|
| 画线、移动、挤出、偏移这类（一维） | 照原来 | 只沿这条线（过锚点） | 只在这个面里（过锚点） | 只沿面里那个方向 |
| 矩形、圆（二维） | 默认的面和朝向 | 图形的面里含这条线，另一半跟光标（像旋转矩形） | 躺在这个面里，边照默认 | 躺在这个面里，一条边顺着那个方向 |
| 旋转 | 照原来 | 绕这条线转 | 绕面的法线转 | 绕面的法线转 |
| 缩放 | 照原来 | 只沿这条线缩 | 只在面里缩 | 只在面里缩 |

三个边角（统筹定的，可改）：
- 二维工具拿到一条线、光标没压着任何东西时，光标的点落在「过锚点、含这条线、最正对视线」的那个面上；这条线几乎正对着视线时退回默认的面。
- 打数字时：有指定方向的（line、planeDir），第一个数对应顺着那个方向的那条边；没有就照工具原来的先后。
- 默认的面和朝向（free、plane 两格里说的「默认」）：光标下有面就贴着它、边顺着离起点最近的那条边；没有面落在地面、边顺着世界的轴。

## 三、和外面接的地方（只有四处）

1. 键表：手势层里 X / Y / Z / N / T 和加 Shift 的各一条，动作 = `axis.press:<键>[:shift]`。别的层不绑它们。
2. 编辑器收到这个动作：`resolveAxisKey` → `axisPress` → 存状态 → 重画。
3. 工具每次要落点时：拿 `axisConstraint(状态)` 调 2.3 里自己那一个函数。硬表面里放在吸附求完之后（现成的 `applyLock` 的位置）。
4. 动作开始：`axisBegin(这把工具要几个方向)`；动作做完（落定 / 取消）：状态丢掉，下一个动作重新 `axisBegin`。
- 画面：每按一下，照 `axisConstraint` 画出那条线或那个面，提示行说 `axisDescribe().say`；按钮照 `keys` 亮成空心。
- 按钮点的锁（实心）这一刀先不重做：它们现在锁的是 X / Y / Z 的轴和面，等于往同一个语法模块里按对应的键，只是寿命长。两份状态并存时，快捷键的那份在就以它为准，动作做完回到按钮的那份。

## 四、守卫和验收

- **守卫**：`AxisState` 里面的东西只有 `axis-constraint.ts` 读；工具文件里不许出现键名（"x" / "n" / "shift"）来判断约束；规矩第 3–7 条的任何一句只许在语法模块里实现。
- **对照表就是规矩**：单元测试是一张「按键顺序 → 结果」的表，改规矩 = 改表。至少这些行：
  - （wants = 1）X → 沿 X；X、Y → 沿 Y（换）；X、X → 不限制（取消）；N（面甲）、X → 沿 X（换）
  - （wants = 2）X、Y → 水平面、方向 X；N（面甲）、X → 立在面上：面由法线和 X 撑出、方向 = 法线（user 的例子）；X、Y、Z → 丢掉 X，Y 和 Z 撑出的面；X、X → 不限制
  - （wants = 2）Shift+N、X、Y → 贴着面、方向 = Y 投到面里（面不变，单按换掉）
  - Shift+Z → 水平面；Shift+Z、Z → 沿 Z（后按的盖掉）；Shift+X、Shift+Y → 沿 Z
  - Shift+N、X → 贴着面、方向 = X 投到面里（user 的例子）
  - Shift+N、Shift+Z → 这张面里的水平线
  - Shift+N（面甲）、Shift+N（面乙）→ 两张面的交线；Shift+N（面甲）两次 → 不限制
  - （wants = 1）N（面甲）、N（面乙）→ 沿面乙的法线（换）；（wants = 2）→ 两条法线撑出的面
  - Shift+N、Shift+T → 面里垂直于这条边的方向
  - Shift+X、Shift+Y、Shift+Z → 丢掉最早的，剩 Y、Z 两个面 → 沿 X
- **探针**（两个工作台各走一遍）：移动里 X / Shift+Z / N / T / Shift+N 再 X；画线里同样几种；矩形里 Shift+N 再 X（贴着面、边顺着 X）、N 再 X（立在面上、一条边沿法线、另一条顺着 X）、单按 N（立起来、朝哪边跟光标）；旋转里 T（绕着一条边转）；每按一下画面上有线或面、提示行有一句话；动作做完按钮全暗；N 取不到面时不变并说原因。硬表面里锁着时端点吸附、充能的对齐照常起作用，结果落在锁的线 / 面上。
