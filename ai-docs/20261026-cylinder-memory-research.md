## 现在已经有什么（核过代码）

- **圆 / 弧已经被记住**：内核的曲线登记（`src/kernel/curves.ts`）给每条圆 / 弧存 圆心、半径、法向、起始方向、段数。画圆、推拉圆之后上下两圈都还是带参数的圆（单测里看得到）。
- **它什么时候丢**：挪点时，一条曲线上的点**整体平移**才保留参数，否则退成「折线」（`Kernel.moveVertices` 尾巴）；整池变换时相似变换保圆，非等比缩放 → 折线（`transformAll`）；线穿过圆把它切开 = 两段弧，各自保参数（`rechain`）。
- **圆柱侧面没被记住**：推拉圆长出的侧面只是一圈平面长条，侧棱打 软 + 平滑，明暗靠扇内平滑法线（v0.14.52）。内核里没有任何「这一圈长条是同一个圆柱面」的记录。
- **重新细分只在刚画完的时候有**：画完圆 / 弧右下角马后炮能改段数（撤掉按新段数重画，DT95）；一旦推拉过，就改不了了。
- **认回来的路已有一半**：焊边时自动认回圆 / 弧（`kernel/weld.ts fitCircle`：≥ 3 段、共面、等距、等长，v0.14.45）。

## 要做成的样子（分四层，越往后越贵）

1. **出生就记（便宜，价值最大）**：推拉一个圆 / 弧（或沿直线跟随）时，侧面那一圈长条一出生就知道轴（圆心 + 推拉方向）、半径、高度范围、是哪两条曲线夹着。登记成一张「曲面」：`{ kind: "cylinder", 轴, 半径, 段数, 上下两条曲线, 侧面的面 }`。
   - 维护：和曲线登记同一套套路——侧面被切开（DIVIDE）跟着记、并起来（MERGE）跟着记；点被挪到不在圆柱上（离轴的距离 ≠ 半径超过 τ）就退成「普通平滑组」（和圆退成折线一样，**不硬拦**）。
   - 格式：`CATSUP_brep` 加一个可选键 `surfaces`（子结构 minor +1、冻结样本；读不认识的照旧直通）。
2. **认回来（修复面板里的一步）**：老模型 / 外来网格没有记录 → 修复指令「认回圆柱」：拿一个平滑组（软边连着的那一片），看是不是圆柱：每张面都平行于同一根轴（轴 = 面法向分布里最小的那个主方向），每个点离轴的距离相等，上下边界是两圈圆（顺手认回圆）。和「焊边认回圆」同一路。顺便把排期外的旧待办「认回圆」（修复指令版）一起做。
3. **重新细分（修复面板里的一步）**：知道了参数，就能按新段数重做：上下两圈曲线按参数重画、侧面重建。**先只做「干净的圆柱」**：两条完整的曲线（圆或同一段弧）+ 中间一圈长条，侧面上没有别的线 / 洞 / 别的几何粘着；不干净的报出来不碰（默认 + 披露）。干净的情况覆盖轮子、炮管、柱子这类最常见的。
   - 做法：在同一步里擦掉侧面和两圈，按参数画新的两圈（带新段数），再按原来的高度推拉——三条现成的动词，结算机照常管，不另写几何。顶盖如果带材质 / 隐藏标记，按身份像跟着走（推拉本来就这么做）。
   - 导出时按任意精度细分 = 同一件事在导出那头做一遍（不改模型本身），glb 里给别的软件看的网格按导出设置的段数烘；`CATSUP_brep` 里仍存模型自己的段数。
4. **精确圆柱的工业格式（STEP）**：要一个 STEP 写出器（B-rep + 解析曲面：平面 / 圆柱 / 圆），工作量是一整个纪元的级别，现在不建议排。等有 CAD 方面的真需求（比如要拿去 CNC / 给别的 CAD 软件）再说。

## 多段圆柱 = 回转体（user 10-26 夜追问后推广；edited by Claude Opus 5.5）

> user：「圆柱 如果是多段的圆柱怎么办，你想一下坦克的炮管是怎么拉的。很规整，但是有时竖着车有时横着车 圆柱的思路先完整帮我说一下吧」

炮管不是一根圆柱，是**车床车出来的一个零件**：根部粗、中间一截细、炮口制退器又鼓出来一圈，台阶处是平的圆环，有时一段是锥（收口）。
所以记的不该是「圆柱」，而是**回转体**：

- **一根轴**（任意方向——竖着车 / 横着车 / 斜着都一样）+ **一个段数** + **起始方向**（所有圈的点对齐，侧面才是直的长条）；
- **一条轮廓**：沿轴从一头走到另一头的折线，每一段是车刀的一刀——
  - **竖段**（半径不变、沿轴走）= 圆柱带（车外圆）；
  - **横段**（位置不变、半径变）= 端面圆环 / 圆盘（车端面；台阶、炮口端面）；
  - **斜段** = 圆锥带（车锥面；收口、倒角）。
- 圆柱 = 轮廓只有「横 · 竖 · 横」的最简单回转体。

**怎么出生就记**（SketchUp 式的拉法，每一步都保持「同轴、同段数、同起始方向」）：推拉圆 → 一段竖段；在顶盖上偏移出同心圆 → 一段横段；再推拉里面那个圆 → 下一段竖段；绕圆心缩放顶盖 → 斜段；跟随（圆当路径、轮廓绕一圈）→ 整条轮廓一次出生。新长出来的一段和已有的回转体同轴 → 并进同一条记录。

**怎么认回来**（老模型 / 外来网格）：先认圆（焊边认回圆那一路）→ 找出**同一根轴上、段数和起始方向都一样**的一串圆 → 相邻两圈之间的面正好是一圈长条 / 圆环 / 圆盘 → 这一串就是一个回转体，轮廓 = 各圈的（沿轴位置，半径）。

**重新细分**：每一圈按新段数重画，相邻两圈之间重建一圈长条——整根炮管一次改完。**「干净」推广成**：这个回转体和别的几何只在**两头的整圈**上相接（比如炮管根部那圈正好嵌在炮塔前面那张平面里——平面上的那个圆洞跟着新段数重画，平面还是平的）；侧面上粘了别的线 / 洞 / 零件、或者有一刀把它切开 → 不干净，报出来不碰。被一刀从中间切开的半个回转体（镜像建模常见）= 轮廓绕的角度不是一整圈，第二期。

**存**：`CATSUP_brep` 可选键（子结构 minor +1）一条记录 = 轴、段数、起始方向、按顺序的各圈（曲线 id）+ 每段的面。维护照圆的规矩：整体刚体变换跟着走；把某段挪得不同轴了 → 那段退出记录变普通平滑组，不硬拦。

**以后**：导出时按任意精度烘；STEP 里竖段 = 精确圆柱面、斜段 = 精确圆锥面、横段 = 平面（不排）。

## 和别的指令的关系

- **吸到格点**（v0.14.55）：圆 / 弧整条按圆心平移，曲面记录跟着平移就行（v0.14.60 修了「别处有点合并 → 这批的圆全丢参数」）。
- **镜像 / 整体变换**：相似变换保圆柱（轴、半径跟着变）；非等比缩放 → 椭圆柱 → 退成普通平滑组。
- **推拉侧面一片**：现在就拒绝（「推拉曲面一片拒绝（先硬化）」），不变。
- **渲染**：不用改——明暗已经是扇内平滑法线；以后精确圆柱也可以在着色时按轴算法线（Tron 纪元渲染覆写的事）。

## 风险

- 第 1 层要在内核的面生灭事件上挂维护（像曲线登记那样），属于内核红线区：先写不变量（「记录里的面都还在、都还在那个圆柱上；不在了就退」）+ 随机对拍，再请 Fable 审。
- 第 3 层的「干净」判定要严：判错了 = 把用户粘在柱子上的东西擦掉。宁可报「不干净，没碰」。
