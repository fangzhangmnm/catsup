## 5. 验证 = 常开的叠加层（定）

- 猫娘的本质：「答案比你想的更不可爱 【验证】」。「验证不需要点compile或者play，编译不通过，花括号都没有合并的时候，的时候vs code还是有lint的。我们有静态验证，实机验证，模块测试，依赖图。想明白这一点才知道那堆跑跑跳跳的猫娘其实不是最好的设计」。
- 「这么说的话验证确实不是一个tab，而是一直开着的。因为你要边编辑边看。当然嫌烦可以关」；「猫娘代替了很多需要戴meta quest进去走的需求。让猫娘替你验证。所以vr 和步行也是验证tab里面的」。
- 程序里的两种非代码验证物：
  1. **注释** = 举牌子的猫娘（「这里是什么，哪里是什么，明天做什么。以及抱怨同事又把光照弄坏了的脏话」）；「也许icon比猫娘更好」，可按角色分组（boss / 杂兵 / 主角 / 程序员）。
  2. **断点 / C# `[]` 标签** = 钉在位置上持续求值的谓词：
     - **射界对**：「放两个小人，跟着地板的高度动，anchor在face上面。然后射击小人会对靶子小人发raycast，你编辑白盒的时候可以立刻知道谁能打中谁」；相机机位也是这一类。
     - **走得过去吗 + POI 间几秒几拍（最重要）**：「全局配置好navmesh的规则……默认有collider和navmesh而不是需要额外加挂件……另外一个线程，和fps raycast一样异步慢慢跟着你实时更新，但是不卡你工作。然后你要放source和sink……看门是不是太矮了会把capsule卡住，楼梯是不是太陡了还是太缓了……设置好移动速度之后，从A到B需要几拍几秒。显示在猫娘头上（也许可以选择路径可视化，出一个capsule push pull出一道线的虚影，这样就可以对标门的大小不会错」。
- 踩踏、战斗模拟 = 玩具 / 每个游戏现做（脚本 + MCP），不进核心。
- 人的尺度：面积换成「平方米 × 上海房价 → 人民币」这类人能感知的量；分级可借家族项目 Arch PhD 的检查器——code / brief / heuristic 计权阻塞，**advisory 不计权、什么都不挡**。
