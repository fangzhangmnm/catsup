## 零、这次长跑是什么，停在哪算收工

**起点（user 11-10）**：「这一轮……的毕业条件就是我能进行最基本的手感不差的在模型上的贴图绘制」「把这个角色的脸在模型上画出来」「草稿笔和套索，这个是我们这个画画软件一开始活下来创世纪的第一个东西」。

**user 11-13 夜回头看这一趟**（语音，「技术战」= 技术债）：
- 「画跟着面走之前还有笔刷……我们最一开始……是在做笔刷吧。其实我也是没信心，你说先硬着头皮做，然后就逼出了那么多东西」
- 「我反而感觉这次其实蛮健康，就是因为我们在做一个特别难的东西，然后我随时是停下来还技术战，不管是 UX 设计上的，还是算法上的，还是数据结构架构上的，就好几次停下来，其实本质上都是技术债的原因。而且这些技术债确实是开发功能的时候才暴露出来。就如果你直接一口气帮我开发完了，可能他们还埋在里面。」
- 「如果我们做了很多基建的调整的时候，当我们开始点上一个大话题的时候，可能有些设计文档得重新评估一下。」（→ 第五节）

**收工条件（user 11-13 夜）**：「我们这一session能停下来的时候，至少套索这个东西是要做的，还有就是涂色，以及还有就是说物体的管理。现在最卡我的是这三个，然后是就是遇到建模的一些卡，随手修，这个是你之前答应我的，这个倒不是卡的，而是说只是一个 interrupting 抢占。」
