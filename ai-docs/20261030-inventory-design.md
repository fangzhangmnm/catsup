## 1. 一个物品栏，标题下拉换页

标题 = 下拉：**层级 · 图层（以后）· 素材**。三页共用一个窗口壳（标题栏、关、记位置），内容各管各的。

## 2. 层级页

> **v0.18.1 更正（Opus 5.5 2026-10-30）**：组不进树，一行 = 一个物件。user 10-24「组永远不进hierarchy，是brep的内部矛盾」「组不是物体层级，只是brep模式下面方便编辑的分组拆组」，本稿起草时漏核这条；下面表里「组 / 物件」读作「物件」。第一行叫「根」。

一行 = 一个组 / 一个物件（组件实例、网格体）。从你所在的这一层往下，或者永远从最外层往下（见 §8 问题 ③）。

| 部件 | 做什么 | 和现有的哪个是同一份 |
|---|---|---|
| 小三角 | 展开 / 收起孩子 | 只是这一页的视图态，不进文件、不进撤销 |
| 小眼睛 | 藏 / 显这一个 | 就是 H / Alt+H 那条（op `setHidden`，进撤销） |
| 点一行 | 选中它（画布上一起亮） | 选区，和画布点选同一份 |
| 双击一行 | 进去编辑 | 「进入编辑」 |
| 右键一行 / 点那一行的「…」 | 物件菜单 | 画布上右键那个物件弹的同一张表（`selection-actions.ts objectMenuItems`） |
| 改名 | 在行上点名字（或菜单「改名…」） | 新动作：组件定义改名 |

**「物品按钮和空白处右键是对齐的吗？」**——规则写成一句话：菜单对着谁，就是谁的菜单，层级里一行和画布上点到同一个物件，弹同一张表。

- 层级里一个孩子那行 = 画布上右键那个子物件 = 物件菜单（子物件的动词 + 物件设置…）。
- 层级最上面「这一层」那行 = 画布空白处右键 = 空白处菜单（粘贴 / 退出一层 / 新建 / 全部显示 / 物件设置…（这一层），v0.17.64 刚补齐）。
- 现在两份都从同一张 HUD 表里按层取，所以天然对齐；做层级时只要不另写一份菜单就不会分叉（守卫：层级页不许自己拼菜单项，只许调 `objectMenuItems` / `menuItems(…, "empty")`）。

**层级管理**：

- 挪到别的父亲底下 = 剪切 → 粘贴（v0.16.44 的剪贴板，一步撤销），拖拽只是它的另一个入口。
- 改名。
- 「清理没用的组件定义」：零实例、也没上素材架的那些。

### 2.1 拖拽：建议做

难点就是你说的那个：拖到一个**展开着、有孩子**的物体下面那条缝时，到底是「当它的最后一个孩子」还是「当它的下一个兄弟」？通行的解法（VS Code 文件树、Blender 大纲、Notion）是看横向位置：

- 拖到一行**中间**（上下各留 25%）= 放进去当孩子。
- 拖到两行之间的**缝**：插入线的缩进跟着指针的横向位置走。指针往左 = 浅一层（当外面那个物体的兄弟），往右 = 深一层（当里面那个的最后一个孩子）；插入线画出缩进，松手前看得见放到哪一层。
- 触屏：长按一行才起拖（平时上下划 = 滚列表）；拖到窗口上下边缘自动滚。
- 拖到画布上 = 不做（层级页的拖只管层级）；素材页的拖才往画布放（§4）。

**要先说清的代价**：「同一个父亲底下谁排前面」现在文件里没有专门记（实例按编号排），拖拽排序要在文件里记顺序 = 格式改动（`CATSUP_definitions` 加一个可选键，minor +1），按分工要 Fable 事先看。只做「挪到别的父亲底下」、不做同级排序的话不用改格式。

**WeebPaint 跟着学**：树 + 拖拽 + 缩进判深度写成一个不认识 CatsUp 的小模块（输入 = 一棵树的形状 + 指针位置，输出 = 「放进 X」或「插到 X 的第 n 个孩子前」），以后进 `@internal/workbench-elements`，WeebPaint 的图层组也能用。

## 3. 图层页（以后）

- 图层 = 贴在物件和面上的标签，一个东西可以挂几个（SketchUp 的「标记」）。
- 显示规则：一个东西看得见 = 它自己没被藏 **并且** 它挂的图层都开着。和小眼睛是两条独立的开关，你说的「另外一个显示隐藏」。
- 存盘：物件和面上记挂了哪些图层 = 格式改动（Fable 事先看）。排在复杂场景纪元（UX71）。

## 4. 素材页（素材架）

| 事 | 怎么做 |
|---|---|
| 放上架 | 物件菜单多一项「放上素材架」（层级行的「…」、画布右键同一张表）：素材架记住这个组件定义 |
| 场景里删了还在 | 上了架的定义不算「没用的」，§2 的清理不碰它；零实例也照样存盘（现在就保留零实例定义） |
| 拖出来 | 从素材架拖到画布 = 在落点放一个实例（落点吸附和「右键新建」同一套：吸点 / 面 / 原点 / 地面）；触屏 = 长按起拖，或点一下再点画布 |
| 文件夹 | **先做**：素材架自己的文件夹树（建 / 改名 / 删空的 / 拖进拖出）；一个定义只住一个文件夹 |
| 标签、分类、搜索、管理 | 以后 |

存盘：素材架 = 定义编号 + 文件夹树，跟着文件走，是**这个模型**的素材架。要么塞进定义表，要么新开一个子结构，都是格式改动（Fable 事先看）。

和跨模型的关系：跨模型拿东西是 Fable 下次第一件（F-127，「载荷带值走 + 内容指纹对上」）。那件做完，素材架才能装别的模型里的东西；那之前只装本模型的组件。

## 5. 摆哪：素材适合底部、层级适合浮窗，怎么办

> **10-30 晚改了（Opus 5.5 记）**：user「两个大按钮太占地方了。我想的是窗口名字就是下拉」「物品栏和物品栏按钮是不是可以sunset……素材库和层级应该用同一个screen icon。两个太多了」「先就只有浮窗吧，然后商城和层级合租？」→ **只有浮窗、一颗钮**：层级 / 资源 / 以后的素材 = 同一个浮窗，标题「层级 ▾」下拉换页；旧的底部抽屉（组件清单）v0.18.5 sunset（内容早在「资源」页）。下面「素材 = 底部抽屉」「两个钮」作废，留着当来路。

推荐**乙：两个窗口，按形状分**：

- **层级 / 图层 = 一个浮窗**，标题下拉在这两页之间切。两页都是竖着的长列表，适合窄高的侧边浮窗，和视图窗口一样能拖、能关、记位置。
- **素材 = 底部抽屉**（就是现在的「商城」那个位置）。一排缩略图横着摆，适合宽矮的底部。
- 两个窗口可以同时开（一边看层级，一边从底下拖素材出来）。
- 手机竖屏：浮窗自动变底部抽屉（指令板现在就是这样），和素材抽屉抢同一个位置，一次一个。

另外两个方案和为什么不推荐：

- 甲：一个窗口，切页时自己换形状（切到素材就跳到底部）。窗口在屏幕上跳来跳去，你刚找好的位置每次切页都丢。
- 丙：一个窗口，拖到底边就吸成底部抽屉、拖离又变浮窗（像 Unity / Blender 的停靠）。最灵活，但停靠是一套不小的东西，可以以后在乙上升级，不用现在定。

这样「物品栏」三个字就分成两个钮：

- 层级钮（新）：放左上物件钮旁边，它管的也是「这一层有什么」。
- 素材钮：现在的「商城」钮。

页签名、钮的名字等你定（问题 ①）。

## 6. 动画时间轴放哪（以后；剧透：全身 IK）

- 时间轴是一条宽矮的横带，放**底部**，和素材抽屉同一个位置。用工作台分谁占底部：以后有个「动画」工作台（左上下拉多一项），进了它底部默认就是时间轴；别的工作台底部是素材抽屉。
- 全身 IK（user「动画我们以后做fbik」）：摆姿势 = 抓手 / 脚 / 头拖，身子跟着走（不是一根根骨头转）。所以时间轴上的东西先是**姿势关键帧**：这一帧整个人的姿势，曲线编辑器以后再说。
- 抓手脚的把手就是自由建模那套操纵手柄（`mesh-handles.ts`）的另一个用户：抓哪个做哪种。
- 骨架在层级页里显示成这个角色底下的一串（能藏、能选），不另开一个窗口。
- 这节只是占位，不排期。和验证纪元「先要角色 / 车跑一下定了尺度」（T178）连着：动起来的人就是验证用的那个人。
