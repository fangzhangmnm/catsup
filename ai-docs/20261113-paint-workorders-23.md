## 一、定下来的

user 定的：
1. 套索分两步：先「判断哪些贴图像素在圈里」→ 套索涂色、套索当选区、转成蒙版；再做移动。（11-13 夜）
2. 圈的规则：一个贴图像素投到屏幕上落在圈里 = 圈中；圈到模型外面没关系。（11-10）
3. 穿透是一个开关：不穿透只管朝着你的；穿透 = 圈里的面前后都算，「圈一条腿，一次填完」。（11-10）
4. 蒙版和选区是两回事，两个同时起作用。（11-10）
5. 选区的手势用三维自己的一套（框、套索、加选减选、点空白取消），像素那一份的算法用画画内核现成的。（11-12）
6. 移动 = 图章：浮起来的那一块 = 原来那些贴图像素 + 抬起时的视角；在屏幕上滑、然后拍上去，不贴着表面滑；拖的时候在真实的贴图上预览；放下时每个目标格子回原贴图取一次样；没挪就放下一个像素都不变。（11-13 夜）
7. 斜着的面：图章和套索加角度护栏，可调，硬切、按整张面、不做软过渡，默认 80 度；笔不加，只把现成的「拐角」选项露出来。（11-13 夜「先按照这个做」；80 这个数是统筹定的起点，没量过）
8. 带透视修正的图片导入框、贴图纪元的材质 = 下一次长跑；这次只做图章的地基。导入的照片以后也是图章，来源换成外面的图。（11-13 夜）

- 第 1 刀的手感：圈完抬笔就直接填当前颜色，不经过选区（和画画软件的套索填色一样；已告诉 user）。

## 三、第 1 刀：套索填色

### 3.1 用起来什么样
- 画画工作台里，放在油漆桶那一格：油漆桶带小三角，「按面」（现在的）和「按圈」两种。理由：都是大块上颜色；按面的拖动已经有意思了（拖过哪张面填哪张），所以按圈得是另一种，不能靠手势分。（放哪儿是统筹定的。）
- 手势照笔的规矩，画画这一族 = 轻按：落笔开始记轨迹，屏幕上画出这一圈；抬笔 = 自动闭合、填。没拖出去（一小点）= 什么都不做。Esc = 这一圈不要了。手指照旧转视角。
- 两个设置，放在这把工具自己报的选项里：**穿透**（开 / 关，默认关）、**角度**（度，默认 80；只在不穿透时起作用）。
- 一圈 = 一步撤销。填的是当前颜色、写进当前层、不透明度 100%，和按面的油漆桶一样。

### 3.2 哪些格算圈中（这一节是后面四刀的地基）
做成一个纯函数，手势只管收折线：给它目标（当前在画的那个物件的格子表）、屏幕上的折线、视角、两个设置，它给出要填的格（行段）。**开工前把它的签名和放在哪个文件发统筹看一眼**；代码自己合。

一格算圈中，要同时满足：
1. 它归某一张面（归属表里有主；往面外延出去的那几格跟着它的主走）。不归任何面的格、空出来的地方，一格都不碰。
2. 这一格的中心，用它那张面的位置公式算到空间里、再投到屏幕上，落在圈里。圈 = 折线自动闭合，奇偶规则（和建模的套索选择同一个判法，`editor/marquee.ts` 里现成有，别再抄一份）。
3. 不穿透时：它那张面朝着眼睛，而且面的法线和「面到眼睛」的方向夹角不超过设置的角度。**一张面要么整张算、要么整张不算**（不平的四边形也按一张面算，用内核现成的面法线；透视下方向取面的中心）。穿透时不看这一条。
4. 藏起来的面不算（格子表里本来就没有）。
5. 一格被几张面共用（镜像两半、复制出来的面）：任何一张面上的落点满足 2、3 = 圈中。填一处另一处跟着变，这是共用像素决定的，和按面的油漆桶同一个说法。

这一刀**不判有没有被挡住**（第 2 刀）。所以朝着你、但被前面的东西挡住的面也会中。这一条写进工具说明，不许藏。

### 3.3 写进去
和按面的油漆桶同一个档口、同一条落层路、同一个撤销口（`space-fill.ts`：开一笔问锁、落层再问一次、`commitStep "fill"`）。只是「填哪些行段」换成 3.2 给的。锁着的文件照笔的规矩拦。

### 3.4 花多久
每格要判一次。先做 CPU 的（按面先用屏幕包围盒筛掉整张不沾边的面）。量三个数报统筹：256、1024、2048 的画布上圈住整个模型，抬笔那一下各多少毫秒。超过 100 毫秒不要自己降级、不要悄悄少判：报上来，统筹定要不要改成在显卡上判。

### 3.5 验收（无头探针，并进现有的画画探针，不另起一套）
1. 画过的方块，正面圈一块：填了的格 = 笨办法的标准答案（每格中心投影、判圈、判朝向），逐格相同；别的格逐字节不变。
2. 不穿透：背面、正侧面（90 度）一格不变；摆一张斜 85 度的面不填、斜 70 度的填；把角度调到 89，85 度的那张也填。
3. 穿透：圈住整个方块 = 六个面全填。
4. 一步撤销、重做；和笔、按面的油漆桶混着随机撤销重做，逐字节回得去。
5. 圈到模型外面、圈自己交叉、只有两三个点、没拖出去：前两种照奇偶规则填，后两种什么都不做、历史一步不多。
6. 镜像开着：填一半，另一半跟着变。
7. 不归任何面的格和空出来的地方：一格不变（删一张画过的面再圈那一带）。
8. 带压感的笔：轻按着画圈、抬笔 = 填；Esc = 没填。
9. 没有页面错误；3.4 的三个数。

### 3.6 和别的规矩对一下
- 命令和工具分家（还没做）：3.2 那个函数加上「填」就是一条命令（参数 = 折线、视角、两个设置、颜色、层）。这一刀不搭命令的架子，但函数里不许出现手势、预演、撤销的东西。
- 文件就是语义：两个设置要是进文件，键名写明意思和单位（度）；要加新的键或新的取值先发统筹。
- 读贴图坐标、每格归谁，只走现成的入口（归属表、`C.paint.uv`），不另算。

## 四、第 2–5 刀的要点（各自开工前统筹补细则）

**第 2 刀：被挡住的不算。** 画一张「屏幕上每一点看见的是哪张面」的图；一格投到屏幕某处，那里（半个屏幕像素以内）看见的正是它自己那张面，才算看得见。和显示同一遍规则，不另外比深度（11-10 定的，六月稿比深度的容差问题不再走）。先有纯 CPU 的标准答案对拍。不穿透 = 第 1 刀的 1–5 条再加这一关。

**第 3 刀：像素选区。** 手势用三维自己的那一套；动手前先把「手怎么动」和「选中的是什么」分开（第四十九轮统筹记着的结构问题）。选区 = 每格一个值，进内核现成的选区（存、挡、加减交反、填、清都是只看一个像素的，安全）；反选要乘上画布的形状，不然空地会被填脏。显示先不做蚂蚁线：在真贴图上给选中的格着色，看到的就是选中的。小窗里的选区一起做。

**第 4 刀：蒙版。** 做在画画内核里（施工方案 0-8），画画软件同时得到；跟着画存 = 文件格式，方案先给 user。

**第 5 刀：图章。** 抬起 = 记住选中的格和抬起时的视角，原处不动；拖 = 屏幕上的挪、转、缩；每一帧：每个目标格 → 投到屏幕 → 倒着走这次的挪转缩 → 在抬起时的视角下打到原来的表面 → 回原贴图取一次样 → 画进薄层（笔边画边看的那条路，预览 = 结果）；放下 = 原处清掉 + 薄层落层，一步；没动 = 什么都不做。带插值的选项（最近邻 / 线性）、角度护栏、穿透开关。没定的：浮着的时候能不能转视角（11-10 的旧稿写的是锁住）——到时问 user。
