## 1. 规则（user 的思路，AI 只是整理）

| 手势 | 移动 / 挤出 / 旋转 / 缩放 都一样 |
|---|---|
| **按下就拖** | 直接做，用这把工具的默认方式：移动 = 屏幕空间（相对拖）、挤出 = 沿法向 / 垂直、旋转 = 绕视线、缩放 = 均匀 |
| **点一下（不拖）** | 在目标上**弹出手柄**：每根轴一个把手（移动 / 挤出 = 箭头、旋转 = 圆环、缩放 = 方头），拖哪根就只沿哪根；**中心那个把手 = 默认方式**（移动的屏幕空间、缩放的均匀） |
| 手柄旁边的**小按钮** | 切这些轴朝哪：**世界 / 物体 / 法向**。全家族同一个按钮、同一套词（谁有手柄谁就用这个） |

- 「点一下」以前在取量型工具里是「进入预览、再点一下落定」（SketchUp 的点 → 挪 → 点）。按这个设计，点一下改成弹手柄，点 → 挪 → 点那套就退了（要不要留一条退路见 §4）。
- 手柄弹出以后，选区 / 目标不变，可以连着拖好几次（E S G E S G 不换工具，设计稿 §2-11「操纵器」、纪元账本 FM17 浮着的小把手同一件事）；点空处或 Esc 收起。
- 方向键锁轴 / 锁面、Blender 的 X Y Z 留着当键盘加速键：按了 = 等于抓了手柄上那根。

## 2. 对齐方式按钮（全家族一个样）

- 三档起步：**世界**（绘图轴 / 上下文坐标架）、**物体**（选中的组件自己的轴；组没有原点 = 回落到它所在那层的坐标架，DT86）、**法向**（选中的面的法向 = Z，边 / 点 = 连着的面的平均；多选取平均）。以后要「视图」「游标」再加档。
- 按钮在手柄旁边、跟着手柄走；记住上一次选的（会话内，所有工具共用一个值）。
- 「全家族对齐」= 有手柄的 app（CatsUp 两个工作台；以后 WeebPaint 的变换要不要也长这个按钮是 user 的事，二次元的变换另做，FM94）都用这三个词、这个位置、这个图标。家族级规矩等 user 拍了再写进家族 CLAUDE.md。

## 3. 这样 Shift 就能只剩一个意思

现在乱在「对齐」一个词装了两件事：**吸附**（位置跳到目标上：点 / 边 / 面 / 格点 / 15° 档）和**约束方向**（只沿法向、只沿某根轴）。挪的 Shift 管的是吸附，挤出的 Shift（v0.15.21）管的是约束——所以 user 觉得没理清。

手柄把「约束方向」全接走以后：

| 键 | 只剩一个意思 |
|---|---|
| **Shift** | **吸附开关（按住 = 把默认反过来）**：硬表面默认吸 → 按住不吸；自由建模默认不吸 → 按住吸 |
| 约束方向 | 手柄上的轴 / 中心（+ 方向键、X Y Z 当加速键） |
| **Ctrl**（Alt / ⌘） | 这把工具的另一种做法（复制、从中心、加边、软化、溶解、吸色……，修饰键稿 §3 那句不变） |

要搬家的几处：挤出的 Shift = 自由拖 → 改成「手柄中心 = 屏幕空间」，Shift 回到吸附；橡皮 / 焊边橡皮 / 软边橡皮的 Shift → 挪到 Ctrl / Ctrl+Shift（SketchUp 橡皮就是 Ctrl 软化、Ctrl+Shift 取消软化）；弧的 Shift 提示角度 → 改成一直显示。选择的 Shift = 加选 / 切换留着（全世界的约定，选择也没有吸附）。

## 4. 要 user 拍的（都有默认）

## 5. 和现有代码的关系

硬表面已经有 `editor/transform-gizmo.ts`（变换工具的把手）、`plane-gizmo.ts`（镜像面）；自由建模的工具（`tools/mesh-transform.ts` / `mesh-pull.ts`）现在没有手柄。做法：把手柄做成两个工作台共用的一个模块（只认「目标点集 + 轴心 + 一组轴」，不认内核），四把工具都接它。

## 6. 「最普通的变换」放哪（user 同夜追问）

user：「以及我们最普通的transform你也到时候一起做一下，还是放到选择里面？」

AI 推荐（Claude Opus 5.5）：**一起做，但留成单独的工具，不放进选择**。同一个手柄模块两种进法——
- 移动 / 旋转 / 缩放 / 挤出：点一下只弹自己那一家把手（箭头 / 圆环 / 方头）；
- **变换**：三家把手一起、选中就直接挂在选区上（不用点），= 现在硬表面「变换」工具的升级版；自由建模左柱要不要加它，user 定。

不放进选择的理由：选择是用得最多的工具，iPad 上把手常驻在选区上会挡住加选 / 减选的那一下点按。要「选完就出把手」，做成选择工具的一个选项（纪元账本 FM4 / FM17「选完要不要弹把手」的实验）以后再试。

**状态：拍了（user 10-27 §7 / 10-28 重申「我已经拍板了……就是不弹变换手柄，但是你第二次点选区的时候会弹一个expand shrink selection。三击还是全选」）——选择不带变换手柄。** 下面是当时拍之前的权衡，留档。原状态：大决策，待 user 拍（user：「选择是否自带gizmos是一个很大的设计决策」）。上面的推荐只是一个选项；两种都不做实现，等 user 想清楚。要权衡的点（只列不判）：选择自带手柄 = 少一个工具、选完就能动（Unity / Blender 的「变换」模式那样），但会挡点按、和「点一下选 / 点两下环 / 点三下整块」的点击族抢同一次点击、iPad 上更明显；不自带 = 选择干净、动东西要换工具或点一下弹手柄。

## 7. 选择工具的手柄 = 扩 / 缩选区的拖动条（user 同夜，纪元账本 FM119）

user：「选择的时候双击的时候能不能旁边出一个gizmos条，拖动的时候就是expand/shrink选区，或者选择模式下面再次点中选区的时候会弹这个expand/shrink拖动条，这样就回答了选择模式下面的gizmos的问题」

- 选择工具不带变换手柄；它自己的手柄是一根**扩 / 缩选区的拖动条**：往一边拖 = 一圈一圈扩（沿边连着的点 / 边 / 面）、往另一边 = 一圈一圈缩；松手 = 选区定在那一档（选区变化 = 撤销里的一步）。
- 什么时候出来：双击选择之后出在旁边；或者在选择工具里再点中已选的选区时弹出。点空处 / 换工具收起。
- 要先有扩 / 缩选区的指令（`select.grow` / `select.shrink`，FM27），键盘加速键 Blender 是 Ctrl+小键盘 + / −（user 没小键盘，键位另定）。
- §6 的「变换要不要放进选择」就此有了 user 的答案：选择的手柄管选区，变换的手柄归变换工具。
- **落地 v0.16.34（2026-10-28 夜 Claude Opus 5.5）**：替换档里点中已选的 = 出条（多选档里点 = 切换照旧，条从双击出）；规则 = Blender 默认（点沿边、边 / 面共点）；没绑键。
