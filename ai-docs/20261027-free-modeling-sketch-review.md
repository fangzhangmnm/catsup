## 1. 最小操作集（照 SU 的理法）

SU 的最小集 = **选 + 线 + 橡皮 + 移动**（+ 选中删面、打组）：线画闭合的共面环自动长面，移动拖点（不共面就折开），橡皮去边，剩下的推拉 / 偏移 / 旋转 / 缩放 / 跟随都是加速器。

自由建模在同一份 brep 上的最小集，**几乎就是 SU 那套，只换三处**：对齐由人声明（不推断）、去边走折线亚种（两张面并成一张，不破面）、长面要显式（不自动长）。

| # | 最小集动词 | SU（硬表面）里的孪生 | 自由建模里差在哪 | 手稿哪条 |
|---|---|---|---|---|
| 0 | 选 | 选择工具 | 双击 / 三击的意思（见 §2-0，**冲突**） | 0 |
| 1 | 建 n 边形 | 多边形 / 矩形 | 「插」点在空处 | 3 on nothing |
| 2 | 刀（面上加边） | 线（画在面上 = 切开） | **只切不长**（§3 坑 ①）；不推断 | 5 |
| 3 | 去边 | 橡皮 | 折线亚种（DT87 已铺：能折的折、只连一张面的照常擦、连三张以上拒绝） | 5 的 XOR |
| 4 | 挪 | 移动 | 屏幕空间、一比一、不推断；锁轴由人声明（现有方向键 / X Y Z 锁） | 6 |
| 5 | 合（点并成一个） | 移动时端点吸端点（公理 3：重合即同一） | 不吸附就碰不准 → 「尺寸缩到 0」或数值框输 0 | 7 |
| 6 | 填 | SU 自动长面；修复「补洞」 | 选中洞再填（user 后补）；非平面靠折线 | user 后补 |
| 7 | 删 | 选中 + Delete（共用层已有） | 同 | — |
| 8 | 分家 | 打组（共用层已有） | 同：一个池里不能有两个重合但不同的点（公理 3），「沿边环切成两块」（user Blender wishlist ②）= 选一边 + 打组 | — |

**图灵完备？设计上是。** 用「建 / 填」能做出任意顶点位置的多边形，「刀 / 去边」能任意改一张面怎么分，「合」能把点认成同一个，「删」能开洞，「分家」管拆开——brep 能表示的任何表面（平面块 + 折线、允许非流形、双面无向不用翻法线）都够得着。**前提是内核在自由建模亚种下守住两条不变量：刀只切不长、挪点不丢面。现在两条都破（§3）**。

加速器（不在最小集里，手感全靠它们）：**套索 + 软 TRS（user 后补「可能承重」，§2-12）**、拉（= SU 推拉的「总是长新几何」那一档）、插（= SU 偏移 + 倒角 + 多边形）、尺寸（= SU 缩放）、**转（= SU 旋转，手稿里没有）**、软编辑、雕、硬边 / 缝、自动镜像、操纵器、刀的环切（= Ctrl+R）。

## 2. 逐条挑刺（标准 = user「不要一个工具在不同模式下面语义和用法差太多」）

- **2-0 选（冲突，要拍）**：CatsUp 现在三个工作台单 / 双 / 三击 = 这个东西 → 面带它的边（表面工作台 = 到锐角为止）→ 整块连着的（`editor.ts` 选择扩张、`surface-assign.ts`）；双击组 / 组件 = 进去。手稿：双击 = 环、三击 = 带。AI 推荐：**三击保持「整块连着的」全家一致；双击 = 环；带降成选中边后的一个动作**——Ctrl+R 交给刀以后，带的主要用户（环切）没了，带的频率跟着降。Shift 加减 = 手稿写了 like in hard surf，一致。
- **2-1 刀**：Ctrl+R 交给刀（user 后补）的形状建议：**刀双击一条边 = 沿它的带切一圈；有选区就只切选区里那段**——user Blender wishlist ①（Ctrl+R 被选区截断）自然就有了；切几刀在马后炮里改；刀切完马上能沿边滑（= GG）。带要跨折线认「一个四边形」（`flood.ts polygonFaces` 已经能把折线连着的块认成一个多边形）。「can stop mid face」= 面里留一条悬线，SU 本来就允许；穿过折线的那一段要在折线处拐弯贴着面走。
  - **XOR**：SU 的线描一条已有的边 = 什么都不变（重描是 SU 修面的老办法），刀描已有的边 = 删掉它 → 同一个动作两边意思相反，撞 user 的标准。去边已经有家：橡皮的折线亚种（DT87 铺好了）。AI 推荐：**刀不带 XOR，去边留给橡皮**；如果来回切工具烦，再给刀加一个按住才生效的修饰键。要 user 拍。
- **2-2 拉**：「screen space」对点 / 边很自然（手稿的小图：边拉成墙、点拉成线）。**对面有个死角**：正对着一张面的时候（最常见的选面姿势），它的法线垂直于屏幕，屏幕空间里拖不出「往外」，只能往旁边拖歪。Blender 的 E 拉面锁法线，就是为了躲这个。AI 推荐：**面沿法线、拖多少走多少（一比一，不停在推断点上）；点 / 边走屏幕空间；按轴键随时换方向**。另外 SU 推拉面时，邻面垂直的话只是把墙拉长、不长新几何，自由建模的拉应该总是长新的（= SU 推拉按 Ctrl 那一档，`pushPull` 的 `keepRing`）——语义不分叉，只是默认档不同。
- **2-3 插**：去掉 edge ring（交给刀）之后，「插」的意思收成一句：**在目标处长一圈**（面 → 里面一圈、点 → 一圈、边 / 边环 → 一条带，空处 → 一个 n 边形）。面上的插 = SU 偏移，同语义。和拉一样定规则：悬停的那一个 = 单独、有选区 = 整片。空处建 n 边形要定落在哪个平面：AI 推荐 = 工作坐标架里最朝向镜头的那个平面（和 SU 画矩形一样）。
- **2-4 挪**：= SU 移动，只差对齐（屏幕空间、不推断）。user 在 D-9 里大量用 G Y、S Z、Shift+Z——**锁轴不是吸附**：吸附是位置跳到目标上，锁轴是把连续的拖动投影到一条线 / 一个平面上，不跳，守得住「石膏没有刻度」。现有方向键 / X Y Z 锁直接复用。顺手：挪 + Ctrl = 复制（和 SU 移动一样），手稿没写复制，这样白得。
- **2-5 尺寸 / 合**：「can toggle auto weld」——内核里两个点落到同一格就是同一个点（公理 3），缩到 0 一定会合，关不掉；而不吸附的话拖不到正好 0。AI 推荐：**不要这个开关**；合 = 数值框输 0 或右键「合到中心」（D-9 里的 merge at center 本来就是单独一步）。
- **2-6 转（手稿缺）**：D-9 里 Shift+右键放 3D 游标再转手臂。SU 旋转本来就是「先点中心、再转」，直接复用、去掉推断即可；常驻轴心 = DT21 的 3D 游标脑洞。
- **2-7 软编辑 / 雕**：软编辑是挪 / 尺寸 / 转的修饰项，SU 没有，自由建模独有，没冲突。雕的「no soft edit: push/pull」和工具「拉」**撞名**：一个长新几何，一个只挪不长。AI 推荐：雕 = 笔刷式的「沿法线挪 + 软编辑半径」；单个点 / 边 / 面沿法线挪 = 挪加一个「法线」锁轴，不另起名。雕不在最小集里，可以晚做。
- **2-8 硬边 / 缝**：硬边 = 现有橡皮的硬化 / 软化亚种，一致。缝 = 新的一种边属性（文件多一种层 = 格式拍子），但现在还没有 UV、没有人读它；AI 推荐等贴图 / 和 WeebPaint 结婚纪元有 UV 时一起做（「硬边通常也是缝，除非手动改」那条规则到时照手稿）。
- **2-9 自动镜像**：现有「镜像…」指令（DT23：默认删对面、中缝能消就消）每步做完自动跑一次。要定三件：① **哪边说了算**——AI 推荐：这一步按下时指针在哪边，哪边就是源（每一步都有按下点，规则总有定义）；② 中缝上的点钉在镜像面上；③ 物体本来就不对称时打开自动镜像 = 会用一边盖掉另一边 → 先说清「右边这几处不对称会被左边换掉」、给翻转（镜像小窗已有翻转），不静默。推广到别的对称群、和后处理器怎么选 → §7。
- **2-10 吸附**：手稿还没定。AI 推荐：参考线 / 圆 / 球永远吸（人特意放的 = 声明过的对齐）；「全部都吸」一个开关、默认关；轴和原点不单独吸（到处都是，拖到附近就跳）；格点 / 增量留给硬表面。
- **2-11 操纵器**：选中的东西被挡住时抓不到——给选区一个浮着的把手，反复拉 / 挪 / 缩（E S G E S G）不用重新点。复用 `transform-gizmo.ts`；X 光（Alt+Z）已有。把手可以顺带长出轴向箭头 = 触屏上的锁轴（D-9 里「也许可以试」那条，信心低）。

- **2-12 套索 + 软 TRS（user 后补：「二次元绘制调整大型里面是day2的necessity，我们这里也许它也会承重」）**：调大形 = 圈一片 → 整片移 / 转 / 缩，离中心越远动得越少。拆开是三件已经在稿里的东西拼起来：**套索选**（新；屏幕上圈一圈选点，被挡住的要不要算按 X 光开关走；笔画套索最自然；现有框选 `marquee.ts` 旁边加一种形状；**三个工作台都能用 = 不分叉**）+ **TRS 把手**（2-11 的操纵器：移、转、缩）+ **软编辑半径**（第 8 条，手稿只写了挪和缩，**转也要软**）。交互可以照 WeebPaint 的套索 + 变换（user 自己的画画 app，二次元调大形就是在那里练出来的）。对内核的意思：软 TRS 一下动一大片点、动得不均匀 → 一大片 n 边形同时变不平，**坑 ② 被放大**；每帧也要动很多点（§6 的性能）。
- 硬表面要不要软 TRS：一片平面被软变换拉弯 = 一片折线；在硬表面里通常不是想要的，默认只在自由建模里开，硬表面要用再说。

D-9 肌肉记忆逐项对照（人体版的完备性）：E G S / I / Ctrl+B / Ctrl+Shift+B / K J / 溶解 / 中心合并 / 压平面（= 修复「拍平」）/ 镜像 / 硬边 / X 光 / 衰减（= 软编辑）都有着落；**缺：旋转 + 轴心、沿边滑（GG，建议放进刀的马后炮 + 挪的「沿边」锁）、选区扩一圈（Ctrl+小键盘+）**；wishlist ① 由刀解决，② 由打组解决。

## 2½. UX（user「其实主要还是看ux」）——和用哪个内核无关的那一半

- **点的是点、边还是面**：手稿是不分模式的（插在点上 = 倒角、在面上 = 内插），全靠点中了什么。低多边形角色在 iPad 正常缩放下，点 / 边 / 面挤在一起，手指一偏就从面上的内插变成边上的倒角。Blender 靠 1 / 2 / 3 三种模式解决（user D-9 也说「有时候我会123里面不同的模式g」）。AI 推荐：默认不分模式（现有拾取：点优先于边，边优先于面），另给一个可选的「只点 / 只边 / 只面」筛子（键盘 1 / 2 / 3、触屏一个小芯片）；操作前高亮会被作用的东西，做完马后炮里可以「改成作用在边上」。
- **手指挡住要拖的点**：挪 = 相对拖动（手指在哪都行，拖多少点走多少），不是「点跟着手指」。现有「点两下」语法（点一下选中目标、手抬开、在旁边拖）正好接得住。
- **E S G 循环在触屏上**：键盘上是三个键，触屏上是来回换三个工具。手稿第 11 条的操纵器才是触屏的主界面：选区上浮一个把手，同时带拉（沿法线的箭头）、缩（一圈）、挪（中间一块）、转（一个环）和三根轴向箭头（= 锁轴），E S G E S G 不用换工具，选区被挡住也抓得到。AI 推荐把它当触屏主路，不是附加项。
- **刀要吸、挪不要吸**：「有机不吸附」管的是对齐（轴、推断、格点）。刀的落点是拓扑——要切在已有的点上或边上，不吸就切出一堆差 0.1 mm 的碎边。所以吸附要分两种：拓扑目标（点 / 边，刀和填用）永远吸；对齐目标（轴 / 推断 / 格点）在自由建模里关。
- **刀怎么收尾**：连续切、能停在面中间，触屏上要有「完成 / 取消」（参数小窗里两个钮），键盘 Enter / Esc。
- **软编辑半径**：Blender 拖的时候滚滚轮调，触屏上双指已经给了相机。AI 推荐：参数小窗里一个滑条 + 场景里画出半径圈。
- **自动镜像看得见**：镜像面淡淡画出来，中缝上的点高亮（它们被钉在面上，拖不出去要让人知道为什么）。
- **一个工具几种意思，要看得出来**：提示行实时说「在点上 = 倒角成一圈 / 在面上 = 内插」，和现有工具提示一样。

## 3. 两个已复现的内核坑（→ Fable，user「如果有大坑的话可以停下来然后escalate fable」）

**坑 ① 刀绕一圈，圆柱里面长出一张夹层面。** 八棱柱侧面在 z = 1 每面切一段（8 段）：10 面 → 19 面，事件 = 8 × DIVIDE + **1 × BIRTH**，新面是 z = 1 的水平八边形，8 条环边各挂第三张面（之后橡皮折线亚种碰到「连三张面」会拒绝）。这就是手稿里的「no double face!」。SU 原版也这样：面在「封闭手势」那一刻长出来（公理 4 修正版），画线闭合一个共面环就长面。自由建模要的是刀只切不长。应用层的绕法：同一步里把 BIRTH 的面删掉，一步撤销。干净的做法：结算机加一个「只切不长」的亚种参数，和 DT87 的 `eraseNonCoplanar` / `autofold` 同一种接法。**user 倾向干净的做法**（原话见 §0），同时担心「在内核的公理上面动刀，很疼，可能会导致很大的混乱」。判断：单看这一条不算大坑，但它是 §6 那个问题的一个样本：SU 的公理在自由建模里要逐条加开关。

**坑 ② 自由拖点后，八边形整张消失。** 平面 n 边形拖点（`moveVertices(…, { creaseLayers: ["fold"] })`），结果：

| n | 只抬一个点 | 交替上下 | 拧一下 |
|---|---|---|---|
| 4 | 2 面 / 1 折线 | 2 / 1 | 2 / 1 |
| 6 | 3 / 2 | 4 / 3 | 4 / 3 |
| 8 | 3 / 2 | **0 面，BURST** | **0 面，BURST** |

`autofold.ts` 找极大共面段，结点多边形 k ≥ 4 又不平就返回 null，调用方 BURST 当诚实退路。硬表面里拖乱一个八边形很少见，退路合理；**自由建模里四肢截面 / 洞口就是八边形，拖乱它是日常 → 天天丢面**。选洞再填一个不平的八边形，走的也是同一条路。修的方向（给 Fable 参考，可整个丢掉）：自由建模亚种里，结点多边形折不平就继续三角化成折线，永远不破面——三角形一定是平的；难点是拧得厉害时三角化在投影里会自交，要定拿哪个面投影、自交了怎么办。判断：**大坑**（数据安全 + 内核平面性公理的执行器），按 user 交代停下交 Fable。

复现（node 24 直接跑，路径按自己的仓改）：

```ts
// 坑 ①
const k = new Kernel();
k.addEdges(Array.from({ length: N }, (_, i) => [pt(i, 0), pt(i + 1, 0)] as const));
k.pushPull(k.faces()[0].id, 2);
console.log(k.addEdges(Array.from({ length: N }, (_, i) => [pt(i, 1), pt(i + 1, 1)] as const)).map((e) => e.type)); // …, "BIRTH"
// 坑 ②：平面八边形，点交替抬 ±0.2（顶点 id 按坐标查回来）
const m = new Kernel();
m.addEdges(Array.from({ length: N }, (_, i) => [pt(i, 0), pt(i + 1, 0)] as const));
const vid = (i: number) => { const p = pt(i, 0); for (const e of m.edges()) for (const v of [e.a, e.b]) { const q = m.graph.pt(v); if (Math.abs(q.x - p.x) < 1e-6 && Math.abs(q.y - p.y) < 1e-6) return v; } throw 0; };
console.log(m.moveVertices(Array.from({ length: N }, (_, i) => ({ id: vid(i), to: pt(i, i % 2 ? 0.2 : -0.2) })), { creaseLayers: ["fold"] }), m.faces().length); // BURST, 0
```

## 7. 自动对称：后处理器，还是每步立即生效（user「可以好好想一下」）

先拆成两个互不相干的问题：**存什么为真**（一份基本块 + 群，还是整个几何）；**用起来像不像真几何**（能不能在任何一份上改、环能不能穿过中缝、导出要不要先「应用」）。

| | Blender 后处理器 | 组件（CatsUp 已有：一份定义 + 几份实例，负变换也行，改一份其他实时跟） | 每步立即生效（user） |
|---|---|---|---|
| 存的 | 基本块 + 群 | 定义 + 实例变换 | 整个几何（群当物体上的工作设置） |
| 在哪份上改 | 只有真的那份（别的是影子） | 进任何一份 | 任何一份 |
| 中缝 | 生成时焊 | 不焊（两个池：缝上有线、平滑断开） | 每步焊（「镜像…」指令第 ⑤ 步已有） |
| 选环 / 带跨缝 | 不跨 | 不跨 | 跨 |
| 改份数（6 → 8） | 改参数 | 重新摆实例 | 要重切 |
| 要不要「应用」 | 要（D-9 的「低频必卡」之一） | 不要 | 不要 |
| 精度漂移 | 无（永远从基本块算） | 无 | 见下 |
| 每步代价 | 显示时 × 份数 | 几乎无 | 每步 × 份数 |

AI 看法：**按「几份要不要焊成一张表面」分两条路，不做第三种东西**。

- **不用焊**（硬表面大多数：轮毂辐条、一圈螺栓、柱廊、旋转楼梯、地砖花样）→ 组件 + 一条「按对称群摆实例」指令。群可以随便变态：转一圈（Cn）、转一圈 + 镜（Dn）、平移阵列、螺旋（楼梯）、多面体群（二十面体那种）、墙纸群的一块——实例的变换每次都从群公式重新算、不累积，零漂移；改份数 = 重新摆。CatsUp 现在「旋转复制 + 6x」就是这条路的最小版。
- **要焊成一张**（角色左右、一圈连成一体的瓶身）→ 每步立即生效，**镜像先做**：轴对齐的镜像面就是坐标取负，在量化网格（1 µm）上精确，没有漂移，直接存整个几何；每步跑一次现有「镜像…」指令（切开 → 删对面 → 镜回来 → 缝上自愈）。
- **立即生效 + 转一圈的坑**：60° 这种旋转在浮点里不精确。这步改第 3 份、下步改第 5 份，每步都从被改的那份重新转出其余几份 → 没被改的点也被反复转来转去，误差一步步累积。解法 = **底下仍存「第 1 份」当真**（后处理器的存法），界面上照样每份都能改、看着是焊好的一整块真几何；改了第 k 份，就把改动按逆变换搬回第 1 份，没动的点不重算。一句话：**存法像后处理器，手感像立即生效**。只有轴对齐镜像和绕轴 90° / 180° 是精确的，可以直接存整个几何。
- **每步哪份是源**：按下时指针在哪份；没有按下点的指令（右键修复、拍平、键入数值）按选区重心所在那份。
- **不动点**：镜像面上的点钉在面上，转轴上的点钉在轴上（多面体群的各条轴同理）。
- **开对称时几何本来不对称**：先说清会被盖掉的地方（§2-9），不静默。
- **群设置住哪**：组 / 组件上的工作设置，存进文件（definitions 加一个可选键 = 该子结构 minor +1）。
- **不推荐 Blender 式后处理器栈**：它不破坏原件的那一半，组件已经有了；它的代价（影子不能改、要「应用」）正是 user 在 D-9 嫌的低频必卡，而且这个仓本来就定了「我不喜欢modifier，我喜欢指令」（`mirror.ts` 头注释引的 user 原话，10-25）。
