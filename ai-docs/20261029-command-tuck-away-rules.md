# 右下角参数小窗太吵 + 不常用命令怎么收：规则稿（等 user 拍）

> created 20261029 · as-of v0.16.57 / 2026-10-29 · created by Claude Fable 5.1 · 周账 F-129（user 10-29「硬表面右下角参数小窗太吵，以及不常用命令的收纳规则。 让fable好好想一下系统的想一下」；10-27 FM5「su模式的右下角目录里面噪声太多我还没整治」、FM35「系统的想一下放不常用命令的组织和收纳方法」）
> 已有的骨架：账本 UX41「面板」七分法（左栏 / 指令窗口 / 指令板 / 窗口 / 模态 sheet / 物品栏 / 时间轴）；放置表 `controller/placement.ts`（左柱分组预算 + ☰ 页签 + 每个面谁画）；指令注册表（指令 + 动作 + 放置）。

## 0. 一句话

吵 = **同时露出来的东西比「此刻能用上的」多**。两条规则就够：**① 右下角只露「这一下会改变结果」的选项**（其余按需长出来）；**② 命令按「多久用一次 × 用的时候多急」分四档，档决定住哪**——档位是注册表放置的一个字段，不是每条命令各自拍脑袋。

## 1. 右下角为什么吵（硬表面，量的）

右下角 = 工具选项条（`context-bar.ts`，读 `tool-config.ts TOOL_OPTIONS`）+ 参数小窗（马前炮 / 马后炮）+ 数值小窗胶囊。硬表面工具的选项一共 28 个字段，常驻露出的问题三类：

| 类 | 例 | 为什么吵 |
|---|---|---|
| **常量型**：一年改一次 | 圆 / 弧「段数」、表面「锐角阈值」、焊边 / 软边「最大角度」 | 每次拿起工具都在，但 99% 的操作不碰 |
| **模式型但有默认**：偶尔切 | 推拉「接着长 / 另起一圈」、坐标架「只设原点 / 原点 + 方向」、选择「替换 / 多选」「框 / 套索」 | 切一次用很久，却一直占一格 |
| **这一下要的**：真该在 | 移动 / 旋转「复制」、拉出「形状 / 尺寸 / 锁比例」、软选择开关 | 这才是选项条该放的 |

再加马后炮（刚做完一步的字段）和数值小窗同一时间挤在角上，三件事抢同一块。

## 2. 规则 ①：右下角只露「这一下会改变结果」的

- 每个选项字段加一个档：`when: "now" | "mode" | "const"`（`tool-config.ts` 一个字段的事）。
  - `now` = 这一下操作直接受它影响、常换（复制、形状、锁比例、软选择）→ **常驻**。
  - `mode` = 切一次用很久（推拉接着长、选区两档、空处拖框 / 套索）→ **收进工具的「⋯」小三角**（左柱那把工具图标的长按 / 右键菜单，和形状格一个做法），当前值在选项条上**只显示不可改的一个字**（如「替换」），点它 = 打开那个小三角。
  - `const` = 一年改一次（段数、阈值、最大角度）→ **收进设置页「工具」节**（☰ → 设置），选项条不露。马后炮里照旧能改（刚画完一个圆改段数 = 马后炮的事）。
- 马后炮和马前炮不变（它们本来就是「此刻」）；数值小窗胶囊只在有去向时亮（v0.16.56 已是）。
- 预期：硬表面常驻字段从 28 降到 ~8；触屏上右下角一行放得下。

## 3. 规则 ②：命令四档，档决定住哪

档 = 注册表放置表（`commands/action.ts Placement`）的一个字段 `tier`，守卫逼每条动作登记：

| 档 | 判据（多久用一次 × 用时多急） | 住哪 | 例 |
|---|---|---|---|
| **手** | 每分钟都用、用时急 | 左柱常驻 + 快捷键 | 选择 / 画线 / 推拉 / 移动 / 挤出 / 切割 |
| **口袋** | 每次建模会用几次 | 左柱折叠组（用过才长出来，`RAIL_FIXED_FOLD` 已是）+ 快捷键 | 删除 / 插入倒角 / 笔刷 / 偏移 / 跟随 |
| **抽屉** | 偶尔用、用时不急 | 右键菜单（按点在哪分层）+ 物件窗口 | 合并 / 做成唯一 / 翻转法线 / 补洞 / 桥接 / 软化所有边 |
| **仓库** | 一年几次、或某类用户一辈子不用 | **指令板**（一次一块的浮板，UX41 的「机器」）或 ☰ 模型页；以后**空格搜索**（UX21）兜底 | 修复九条 / 镜像会话 / 细分 / 还原出厂 / 以后的上帝发脾气模拟器 |

两条配套：
- **「用过才长出来」推广**：口袋档和抽屉档都按最近用过排前面（左柱折叠组已这么做；右键菜单的「最近用过」放第一节，最多 3 条）。
- **空格搜索**（UX21，等名字稳定）= 仓库档的正门，也是忘了在哪时的兜底：搜的是动作的中文名 + 别名；回车 = 跑；搜出来的那条顺手显示它住哪（「在：右键 › 物件」），教人下次直接去。

## 4. 不做的

- 不做「自定义工具栏」（SketchUp 那种拖来拖去）：档位 + 用过才长出来已经够个人化，而且可被守卫盯住。
- 不做第二个常驻面板放常量。

## 5. 要你拍的（一次问完）

1. 规则 ①：`mode` 档收进工具的小三角、选项条只显示当前值的一个字——同意吗？替代 = 都留在选项条但折成「⋯」展开。
2. 规则 ①：`const` 档（段数 / 阈值 / 最大角度）搬去设置页「工具」节，马后炮里照旧能改——同意吗？
3. 规则 ②：四档的名字（手 / 口袋 / 抽屉 / 仓库）和判据能用吗？每条动作要登记一档（守卫逼），没登记 = 红。
4. 仓库档的正门 = 空格搜索——名字稳定了就做，还是先用指令板 + ☰ 顶一阵？
