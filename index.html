快捷键与手势
空格 / L / R / C / M / Q / S / P / F / W / B / E
选择 / 画线 / 矩形 / 圆 / 移动 / 旋转 / 缩放 / 推拉 / 偏移 / 跟随 / 油漆桶 / 橡皮（对齐 SketchUp）。左柱钉死 选择 / 画线 / 矩形 / 橡皮 / 移动 / 旋转 / 推拉；圆 / 缩放 / 偏移 / 跟随 / 油漆桶在「更多」里，用过的会在「更多」上面留两格（屏幕矮就不留）
油漆桶的模式
底部选项条「涂哪些」：一张面 / 平滑组 / 到锐角为止（阈值可调）/ 连通体 / 整个组或组件；按住 Ctrl = 平滑组、Shift = 连通体、Ctrl+Shift = 到锐角为止（松开回选项条的值）
在哪个组里
进了组 / 组件后，左上角出面包屑「根 › 组件「盒子」› 组」，点前面一级就退到那级。重叠的面：正在编辑的那一层（在根就是散放的几何）画在上面、也优先被点到
移动 / 旋转：点而不是拖
移动 = 点一下拿起、点一下放下（拖着放也行）；旋转 = 点圆心、点参考方向、点角度（三下；也可以第三步拖）。笔和手指都一样
右上角 gizmo
Blender / Unity 式：点 X / Y / Z 球 = 右视 / 后视 / 顶视，再点一次翻到对面（左 / 前 / 底），空心球 = 负向；在 gizmo 上拖 = 环绕。下面三个小拖柄：✋ 按住拖 = 平移、🔍 按住上下拖 = 缩放、⛶ 点 = 缩放到全部（Shift+Z）——数位笔 / 无键盘鼠标也能完整导航
右键 / 长按
画布上右键（桌面）或在选择工具里长按（iPad，Pencil 或手指）：指针下的东西不在选区就先选上，弹出同一份菜单——删除 / 建组 / 建组件 / 炸开 / 进入编辑 / 退出一层 / 软化 / 硬化 / 选择连通体。用笔或手指时，选中东西后顶部还会浮出这排动词（鼠标有右键，就不浮了）
数值小窗（精确输入）
刚做完一步（画线 / 矩形 / 圆 / 推拉 / 偏移 / 移动 / 旋转 / 缩放）后，右下角小窗亮起：桌面直接打数字 + Enter；触屏点小窗展开自家数字键盘（不弹系统键盘）。长度默认米（菜单「单位」可换米 / 厘米 / 毫米 / 英尺英寸 / 英寸），后缀 cm / mm / ft / in 或 3'6" 写法覆盖；矩形 `宽,高`；圆 `0.5` 半径或 `24s` 段数；旋转 度；缩放 倍率或 `x,y,z`；移动复制后 `5x` 向外阵列 / `/5` 内分。可以连着改几次，直到开始下一步
线稿
默认 1 设备像素的细线（最省，VR / PC 都不卡通）；选中 / 刮擦 / 悬停的边仍是粗线。视图菜单「粗线稿」切回全粗线
圆的段数
圆工具的底部选项条 − / +（3–96，默认 24）
偏移
按住一张面沿面拖：往里内缩、往外外扩（只偏移外环；边长缩到 0 的边自动合并）
跟随（Follow Me）W
先用选择工具选好路径（一串边，或一张面 = 它的外环），再点轮廓面：沿路径扫出实体。与既有面重合的部分自动湮灭——在盒子的棱上画个倒角轮廓、选顶面当路径、点轮廓 = 四条棱一起倒角；圆路径 = 旋转体（侧面自动平滑）
橡皮 + Ctrl / Shift
刮过的边软化（不画线 + 平滑着色）/ 硬化；菜单「软化所有 ≤ 20° 的边」= SU 软化边对话框默认角
油漆桶
右栏「材质」选颜色或导入图片，点面涂上；点在选中的面上 = 整个选区一起涂；贴图默认 1 m 宽按比例、沿面投影
G / Ctrl+G / Ctrl+Shift+G
建组件 / 建组 / 炸开（选区）；双击组或组件=进入编辑，点空处或 Esc=退出一层；移动工具可直接拖组或组件
旋转
先选中，点圆心（落在面上=绕该面法向），再按住参考点拖出角度（15° 咬合）
缩放
先选中，拖包围盒上的柄：角=等比，面心=单轴（0.5 / 1 / 1.5 / 2 / 3 / 4 咬合）
Ctrl+Z / Ctrl+Y
撤销 / 重做
Delete
删除选区（Shift 点选可加选）
Esc
取消当前手势 / 收笔
鼠标
左键=工具（可点两下）；右键/中键拖=环绕，Shift+拖=平移；滚轮=朝光标缩放
Apple Pencil
笔=工具，悬停有吸附预告；手指=相机
手指
单指拖=环绕；双指=平移+捏合缩放；双指轻点=撤销；三指轻点=重做；单指轻点=取消
画线
连画，出膜自动收笔；停在端点/中点 0.3s 充能成共轴参考（对齐时出提示线）
推拉
沿面法向拖；吸到点/线/面=取其高度；靠近已有高度会咬合
步行相机
WASD 走 · Shift 冲刺 · 空格跳（双击=飞行开关）· Q/E 下/上 · Ctrl 蹲 · ←→ 转身 · 右键拖=看 · T 按住瞄准瞬移 · G 回上一点 · Tab 选择 · X 橡皮
